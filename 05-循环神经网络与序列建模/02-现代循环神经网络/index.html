    现代循环神经网络

    更新于 2026-11-05

    一句话定义：现代循环神经网络是对基础 RNN 的四类扩展——门控单元（GRU/LSTM）、深层堆叠、双向结构和"编码器-解码器"（seq2seq）架构——用来解决梯度不稳定、长程依赖、上下文缺失和"变长输入→变长输出"的序列转换问题。

    基础 RNN（见循环神经网络）的隐状态每步都被覆写，存在三类结构性缺陷：早期重要信息难以长期保存、无关词元无法跳过、序列的逻辑断点（如章节切换）无法重置记忆。加上梯度消失/爆炸的数值问题，催生了门控机制；而机器翻译这类输入输出都是任意长度序列的任务，则催生了编码器-解码器架构。

    核心原理

    1. 门控循环单元（GRU）

    GRU（Cho et al., 2014，比 LSTM 晚约 20 年但更简单、计算更快，效果通常相当）用两个可学习的门（取值 0~1 的向量）决定隐状态"何时更新、何时重置"。设输入 X_t ∈ R^{n×d}，上一隐状态 H_{t-1} ∈ R^{n×h}：

    重置门与更新门（sigmoid 全连接层）：

    \[R_t = \sigma(X_t W_{xr} + H_{t-1} W_{hr} + b_r), \quad Z_t = \sigma(X_t W_{xz} + H_{t-1} W_{hz} + b_z)\]

    候选隐状态（tanh，⊙ 为按元素乘）：

    \[\tilde{H}_t = \tanh(X_t W_{xh} + (R_t \odot H_{t-1}) W_{hh} + b_h)\]
    • R_t 接近 1 → 退化为普通 RNN；R_t 接近 0 → 旧隐状态被重置，候选隐状态只由当前输入决定（处理逻辑断点）。

    隐状态更新（凸组合）：

    \[H_t = Z_t \odot H_{t-1} + (1 - Z_t) \odot \tilde{H}_t\]
    • Z_t 接近 1 → 只保留旧状态、跳过当前输入——序列开头的旧信息可以不经覆写一路传到结尾，这是缓解梯度消失、捕获长期依赖的关键。
    • 分工：重置门管短期依赖，更新门管长期依赖。

    在时光机器字符语言模型上：从零实现困惑度约 1.1，nn.GRU 高级 API 约 1.0。

    2. 长短期记忆网络（LSTM）

    LSTM（Hochreiter & Schmidhuber, 1997）引入独立的记忆元（memory cell）C_t，用三个门控制：

    三个门（均为 sigmoid 全连接层，取值 0~1）：

    \[I_t = \sigma(X_t W_{xi} + H_{t-1} W_{hi} + b_i) \quad \text{（输入门）}$$ $$F_t = \sigma(X_t W_{xf} + H_{t-1} W_{hf} + b_f) \quad \text{（遗忘门）}$$ $$O_t = \sigma(X_t W_{xo} + H_{t-1} W_{ho} + b_o) \quad \text{（输出门）}\]

    候选记忆元（tanh）：C̃_t = tanh(X_t W_xc + H_{t-1} W_hc + b_c)

    记忆元更新：

    \[C_t = F_t \odot C_{t-1} + I_t \odot \tilde{C}_t\]

    当 F_t≈1 且 I_t≈0 时，旧记忆原样传递——记忆的高速通道，缓解梯度消失。

    隐状态（记忆元的 tanh 门控版本）：

    \[H_t = O_t \odot \tanh(C_t)\]

    要点：隐状态与记忆元形状相同，但只有隐状态传到输出层，记忆元纯属内部信息；LSTM 隐状态是 (H, C) 二元组（框架里 nn.LSTM 的 state 是 tuple，nn.GRU 只有一个张量）。从零实现困惑度约 1.3，高级 API 约 1.1。

    3. 深层（多层）循环神经网络

    L 个隐藏层堆叠，每个隐状态同时传给"当前层的下一时间步"和"下一层的当前时间步"：

    \[H_t^{(l)} = \phi_l(H_t^{(l-1)} W_{xh}^{(l)} + H_{t-1}^{(l)} W_{hh}^{(l)} + b_h^{(l)}), \qquad H_t^{(0)} = X_t$$ $$O_t = H_t^{(L)} W_{hq} + b_q\]

    把基础 RNN 换成 GRU/LSTM 即得深层门控版本；框架里只需指定 num_layers。两层 LSTM 训练后困惑度可达约 1.0。经验：深层 RNN 更依赖调参（学习率、裁剪）且训练更慢，初始化需谨慎。

    4. 双向循环神经网络（BiRNN）

    填空任务（"我___饿了，我可以吃半头猪"）说明下文也携带关键信息。BiRNN（Schuster & Paliwal, 1997）加一条反向 RNN，思想对应隐马尔可夫模型的前向-后向递归（动态规划可在 O(kT) 内对隐变量求和）：

    \[\overrightarrow{H}_t = \phi(X_t W_{xh}^{(f)} + \overrightarrow{H}_{t-1} W_{hh}^{(f)} + b_h^{(f)})$$ $$\overleftarrow{H}_t = \phi(X_t W_{xh}^{(b)} + \overleftarrow{H}_{t+1} W_{hh}^{(b)} + b_h^{(b)})\]

    两个方向的隐状态拼接后 H_t ∈ R^{n×2h} 送入输出层（O_t = H_t W_{hq} + b_q，输出层输入维度为 2h）。

    两个硬约束： - 它同时使用过去和未来的观测来估计当前输出，因此不能用于预测下一个词元——训练时有未来数据、测试时只有过去，精度会崩。把双向 LSTM 当语言模型训练，困惑度看着正常（约 1.1），生成文本却是 travellererererere... 的复读，是典型的错误用法反面案例。 - 前向传播要跑两个方向、梯度链更长，训练代价高、速度慢。

    适用场景：序列编码（机器翻译编码器）、词元标注（命名实体识别）、填词/补全等整段上下文可见的任务。

    5. 机器翻译与编码器-解码器（seq2seq）

    机器翻译是"序列转换（sequence transduction）"的核心问题，数据集是源语言-目标语言的句对（如 Tatoeba 英-法）。预处理特点：

    • 词级词元化（非字符级）：词表大得多，低频词（min_freq=2）归并到 <unk>；
    • 每种语言各建一个词表；特殊词元 <pad>（填充）、<bos>/<eos>（起止）；
    • 截断 + 填充使批内序列等长；末尾补 <eos>，并记录有效长度（排除填充）供损失遮蔽用。

    编码器-解码器架构：编码器把变长序列压成固定形状的编码状态，解码器把它映射回变长序列。

    seq2seq 实现（Cho et al., 2014; Sutskever et al., 2014）：

    • 编码器：嵌入层（embedding，代替独热）+ 多层 GRU；上下文变量 c = q(h_1,...,h_T)，常取 c = h_T（最后时间步隐状态）。
    • 解码器：另一个 RNN，隐状态 s_{t'} = g(y_{t'-1}, c, s_{t'-1})；用编码器最终隐状态初始化（要求两者层数/隐藏单元一致），并把上下文变量在每个时间步与输入拼接。
    • 训练：强制教学（teacher forcing）——解码器输入是 <bos> + 真实输出序列（而非模型自己的预测）；损失用遮蔽的 softmax 交叉熵（MaskedSoftmaxCELoss），把填充位置的损失置零。
    • 预测：逐词元生成，遇到 <eos> 停止；每步用上一时间步 argmax 的词元作输入。

    BLEU 评估（Papineni et al., 2002）：

    \[\mathrm{BLEU} = \exp\left(\min\left(0, 1 - \frac{\mathrm{len}_{label}}{\mathrm{len}_{pred}}\right)\right) \prod_{n=1}^{k} p_n^{1/2^n}\]

    p_n 是 n 元语法精确率（预测中匹配标签的数量 / 预测中 n 元语法总数）。例：标签 A,B,C,D,E,F、预测 A,B,B,C,D → p1=4/5, p2=3/4, p3=1/3, p4=0。指数项惩罚过短的预测（如标签 6 词、预测 2 词时惩罚因子约 0.14）；指数 1/2^n 让长 n 元匹配权重更高。完全一致时 BLEU=1。小型 seq2seq 模型在短句上可达 BLEU≈1，稍长句则明显退化（0.4~0.7）。

    6. 束搜索（beam search）

    逐词元生成序列时从 O(|Y|^{T'}) 个候选序列里选最优：

    • 贪心搜索：每步取条件概率最高的词元，计算量仅 O(|Y|·T')，但不保证全局最优（示例中第二步选次优词元的序列总概率 0.054 > 贪心的 0.048）；
    • 穷举搜索：保证最优，但 |Y|=10000、T'=10 时要评估 10^40 个序列，不可行；
    • 束搜索：超参数束宽 k，每步从 k·|Y| 个候选里保留概率最高的 k 个序列，计算量 O(k·|Y|·T')，介于两者之间。最终在候选中按长度惩罚的对数概率选优：
    \[\frac{1}{L^\alpha}\sum_{t'=1}^{L} \log P(y_{t'} \mid y_1,\ldots,y_{t'-1}, c), \qquad \alpha \text{ 通常取 } 0.75\]

    贪心搜索 = 束宽为 1 的束搜索；调 k 即可在精度与算力间权衡。

    术语表

    术语 含义
    重置门 R_t GRU 中控制旧隐状态有多少参与候选状态计算，管短期依赖
    更新门 Z_t GRU 中控制新旧状态的凸组合比例，管长期依赖（≈1 时跳过输入）
    记忆元 C_t LSTM 的内部"传送带"，只有隐状态对外输出，记忆元不参与输出层
    输入门/遗忘门/输出门 LSTM 三门：写多少新记忆 / 留多少旧记忆 / 输出多少记忆
    双向 RNN 前向 + 反向两条 RNN，隐状态拼接成 2h 维，只适合整段可见的编码/标注任务
    编码器-解码器 变长序列 → 固定状态 → 变长序列的架构，seq2seq/翻译的基础
    上下文变量 c 编码器对输入序列的压缩表示，常取末时间步隐状态 h_T
    强制教学 训练时用真实输出序列而非模型预测作为解码器输入
    遮蔽损失 按有效长度把填充位置的损失置零
    BLEU 基于 n 元语法精确率 + 长度惩罚的翻译质量指标，完全一致为 1
    束宽 k 束搜索每步保留的候选序列数；k=1 即贪心搜索

    经验与常见坑

    • 门控模型不是万能药：LSTM/GRU 缓解但不根除梯度问题，梯度裁剪仍然要加；训练长序列成本依然很高。
    • 双向 RNN 拿来做"预测下一个词"是经典误用：困惑度可能很低，生成结果却是复读机——评估指标正常不代表用法正确。
    • 深层 RNN（num_layers≥2）显著变慢且更难收敛，需要更仔细的学习率与初始化（如对 Linear 和 RNN 权重统一 Xavier 初始化）。
    • 计算损失时若忘记遮蔽填充词元，模型会浪费大量容量去预测 <pad>。
    • BLEU 对过短预测有惩罚项，但靠"输出更长的错误句子"刷分不可取——对比评估时保持解码策略一致。

    ⚠️ 时效性说明

    • GRU/LSTM/双向/深层 RNN 属于前 Transformer 时代的主流序列建模技术，在 NLP 主流已被注意力机制与 Transformer 取代（ seq2seq 也演进为注意力增强的 seq2seq，再到纯 Transformer）。直接动因是训练 LSTM/GRU 的成本相当高，更高级的替代模型（Transformer）由此成为主流。
    • RNN 系模型在部分低资源、流式、时序场景仍有实用价值，且门控思想（类似"门"的信息流控制）也影响了后续架构设计。
    • BLEU 至今仍用于翻译评估，但现代模型普遍搭配更丰富的评估维度；词级词元化已被 BPE 等子词方法取代。
