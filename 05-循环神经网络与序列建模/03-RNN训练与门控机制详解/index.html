    RNN 训练与门控机制详解

    更新于 2026-11-05

    一句话定义：RNN 训练的核心矛盾是"梯度要穿过 T 步矩阵乘法链"——\(\mathbf{W}_{hh}^\top\) 的高次幂使梯度按特征值消失或发散；截断 BPTT 与梯度裁剪是数值上的应急，GRU/LSTM 的门控则是从结构上给梯度修一条"高速通道"。

    循环神经网络与现代循环神经网络已给出 BPTT 三策略和 GRU/LSTM 公式的概要，本篇深化：梯度的完整推导与特征值分析、裁剪与优化的关系、门控的参数账与结构对比、深层/双向结构的依赖关系图。

    核心原理

    1. 隐状态梯度的完整推导

    简化模型（恒等激活、无偏置）：

    \[h_t = W_{hx} x_t + W_{hh} h_{t-1}, \qquad o_t = W_{qh} h_t, \qquad L = \frac{1}{T}\sum_{t=1}^T l(o_t, y_t)\]

    关键递推：对任意 \(t < T\)，\(\partial L/\partial h_t\) 同时通过"下一步隐状态"和"当前输出"两条路径传来：

    \[\frac{\partial L}{\partial h_t} = \underbrace{\left(\frac{\partial L}{\partial h_{t+1}}\right) \frac{\partial h_{t+1}}{\partial h_t}}_{\text{时间路径}} + \underbrace{\left(\frac{\partial L}{\partial o_t}\right) \frac{\partial o_t}{\partial h_t}}_{\text{输出路径}} = W_{hh}^\top \frac{\partial L}{\partial h_{t+1}} + W_{qh}^\top \frac{\partial L}{\partial o_t}\]

    展开（设 \(\partial L/\partial o_{T+1}=0\)）：

    \[\frac{\partial L}{\partial h_t} = \sum_{i=t}^{T} \left(W_{hh}^\top\right)^{T-i} W_{qh}^\top \frac{\partial L}{\partial o_{T+t-i}}\]

    问题全部集中在 \((W_{hh}^\top)^{T-i}\)：设 \(W_{hh}\) 的特征值为 \(\lambda_i\)，\(|\lambda_i|<1\) 的分量随幂次指数消失、\(|\lambda_i|>1\) 的分量指数发散（对称矩阵下 \((M^k)v_i = \lambda_i^k v_i\)，随机向量经高次幂后大概率倒向最大特征值方向——数值上的"蝴蝶效应"）。对非线性 RNN 同理，只是被雅可比矩阵的乘积代替。梯度消失的后果：远处的误差信号传不到近处，模型学不到长程依赖；爆炸的后果：一步坏梯度毁掉全部参数。

    参数梯度再由隐状态梯度汇总：

    \[\frac{\partial L}{\partial W_{qh}} = \sum_t \frac{\partial L}{\partial o_t} h_t^\top, \qquad \frac{\partial L}{\partial W_{hx}} = \sum_t \frac{\partial L}{\partial h_t} x_t^\top, \qquad \frac{\partial L}{\partial W_{hh}} = \sum_t \frac{\partial L}{\partial h_t} h_{t-1}^\top\]

    2. 三种梯度计算策略的取舍

    策略 做法 优点 缺点
    完全计算 精确算满 \(\partial h_t/\partial w_h\) 的全部 \(\tau\) 项和 无偏 计算内存不可行；数值不稳定（高次幂）
    常规截断 每 \(\tau\) 步截断求和 便宜、稳定，附带轻度正则化（偏向短期/简单模型） 有偏，偏短期依赖
    随机截断 以期望为 1 的随机变量 \(\xi_t\) 替换截断（\(P(\xi_t=0)=1-\pi_t\)） 理论无偏，长序列自动低频高权 方差抵消收益，实践不比常规好

    实践结论：常规截断（τ 步 + detach）是默认。工程上"截断"即顺序分区时小批量间对隐状态 detach()——把梯度计算限制在一个小批量的时间步内，否则计算图随训练无限拉长；随机采样则每个批量重新初始化隐状态。

    3. 梯度裁剪：与学习率的关系

    处理大梯度有两个旋钮：降低 \(\eta\) 全局变慢，或裁剪只处理罕见的大范数步。裁剪的理论依据是 Lipschitz 连续：若 \(|f(x)-f(y)| \le L\|x-y\|\)，则一步更新最多改变目标 \(L\eta\|g\|\)——限制 \(\|g\|\) 就是限制"变糟的程度"。投影回半径 \(\theta\) 的球：

    \[\mathbf{g} \leftarrow \min\left(1, \frac{\theta}{\|\mathbf{g}\|}\right) \mathbf{g}\]

    要点：保持方向、只缩范数；范数是所有参数梯度合成的全局范数（先平方求和再开根，再统一缩放）。副作用是限制单个样本/批量对参数的影响，给模型额外稳定性。裁剪只防爆炸不防消失——消失要靠门控/更好的初始化。

    4. 门控机制：结构对比与参数账

    GRU 与 LSTM 的公式见现代循环神经网络，这里补"为什么这样设计"：

    • 门控的共同原理：在"覆写式"更新 \(H_t = \phi(\cdot)\) 之外开一条线性、可学习的传递通道（GRU 的 \(Z_t \odot H_{t-1}\)、LSTM 的 \(F_t \odot C_{t-1}\)）。当门 ≈1 时，梯度沿这条加法通道回传几乎无衰减——这正是针对 \((W_{hh}^\top)^k\) 消失问题的结构解，LSTM 论文里称记忆元的这条通道为恒定误差轮盘（constant error carousel）。
    • LSTM 比 GRU 多出的设计：独立的记忆元 \(C_t\) 把"长期记忆"与"对外输出"解耦（\(H_t = O_t \odot \tanh(C_t)\)，输出门决定泄漏多少记忆给输出层）；三扇门允许"同时记住旧的 + 写入新的"（\(C_t = F_t \odot C_{t-1} + I_t \odot \tilde{C}_t\)），GRU 的凸组合 \(Z_t\) 则强制二者此消彼长。
    • 参数量对比（输入 \(d\)、隐藏 \(h\)）：
    \[\text{GRU：} 3(dh + h^2 + h) \qquad \text{LSTM：} 4(dh + h^2 + h)\]

    LSTM 多 1/3 参数（多一个门 + 独立记忆元），换表达能力；效果上两者通常相当，GRU 计算更快，小数据/快迭代选 GRU 是合理默认。 - 门控不减参数更新义务：LSTM/GRU 缓解但不根除梯度问题，裁剪仍要加；深层门控网络（如深层 LSTM）尤其依赖裁剪与学习率。

    5. 深层与双向：依赖关系与适用性

    深层 RNN（\(L\) 层）中隐状态有两个传播方向：\(H_t^{(l)}\) 依赖"同层上一步" \(H_{t-1}^{(l)}\) 和"下层当前步" \(H_t^{(l-1)}\)——梯度也要沿这两个方向回传，链更长，故更难训练、更依赖调参（学习率、裁剪、统一 Xavier 初始化）。

    双向 RNN 的输出 \(O_t = [\overrightarrow{H}_t; \overleftarrow{H}_t] W_{hq}\) 同时用了过去与未来。理论背景：其前向-后向递归对应隐马尔可夫模型的动态规划（\(O(kT)\) 对隐变量求和）。硬约束：训练时能看到未来、推理（逐步生成）时看不到，所以绝不能当语言模型用；只适合整段输入一次性可见的编码类任务（翻译编码器、NER 标注）。双向隐状态拼接成 \(2h\) 维，下游输出层输入维度随之翻倍。

    术语表

    术语 含义
    BPTT 把 RNN 沿时间展开后用链式法则反传，梯度核心是 \((W_{hh}^\top)^{T-i}\) 的高次幂
    常规截断 每 τ 步截断梯度求和（detach），默认做法，偏短期 + 轻度正则
    随机截断 用期望为 1 的随机变量随机终止递归，理论无偏但方差大，实践少用
    梯度裁剪 \(\min(1,\theta/\|g\|)\) 全局范数缩放，方向不变只限制步长
    恒定误差轮盘 LSTM 记忆元的加法传递通道，门≈1 时梯度近似无损回传
    输入门/遗忘门/输出门 LSTM 三门：写多少新记忆 / 留多少旧记忆 / 泄漏多少给输出
    双向隐状态 前向与反向隐状态拼接为 \(2h\) 维，仅用于整段可见的编码任务

    经验与常见坑

    • 训练 RNN 的固定三件套：截断（detach）+ 裁剪 + 困惑度监控，从零实现时缺一个都可能发散或误判。
    • 裁剪阈值 \(\theta\) 是超参数：太小相当于常年小学习率，太小米不到保护作用；常见量级 1~10，按梯度范数日志调。
    • 随机采样与顺序分区的隐状态管理不同：前者每批量重置，后者周期头初始化一次、批量间 detach 传递——用错会学到虚假的跨批量依赖或白白丢掉上下文。
    • LSTM/GRU 的隐状态初始化为全零张量是常规操作，不需要"随机初始化隐状态"。
    • 双向 RNN 训练语言模型的经典反面案例：困惑度 1.1 看着正常，生成却是复读——评估指标正常 ≠ 用法正确，生成类任务永远检查实际输出。
    • 深层 RNN（num_layers≥2）训练慢且对初始化敏感，框架内对 Linear 与循环权重统一 Xavier 初始化是稳妥起点。

    ⚠️ 时效性说明

    • 门控 RNN 在 NLP 主流已被 Transformer 取代（并行性、长程依赖均占优，见 ../06-注意力机制与Transformer/03-Transformer 架构.md），但梯度链分析（高次幂 → 消失/发散）是所有深度序列模型共用的心智模型，Transformer 的残差 + LayerNorm 也是对同一问题的另一套解。
    • 梯度裁剪至今仍是训练 RNN 和大模型（如 Transformer 训练中 clip grad norm）的标配技术。
