    序列到序列与机器翻译

    更新于 2026-11-05

    一句话定义：seq2seq 用"编码器把变长输入压成状态 + 解码器逐词元生成变长输出"解决翻译等序列转换问题；训练靠强制教学与遮蔽损失，解码在贪心、采样、束搜索之间权衡质量与算力，评估用 BLEU。

    现代循环神经网络已给出编码器-解码器与 seq2seq 的概要公式、BLEU 和束搜索的入门版，本篇深化：两种解码器状态传递设计的差异、强制教学的代价（exposure bias）、BLEU 的精确计数细节与缺陷、束搜索的复杂度与长度惩罚推导，以及基础 seq2seq 内容未覆盖的采样与温度。

    核心原理

    1. 编码器-解码器：接口设计思想

    架构三要素（以编码器/解码器基类接口固化）：编码器把长度可变的序列转为固定形状的编码状态；解码器把固定状态映射回长度可变的序列；init_state 把编码器输出转换成解码器初始状态（可能需要输入序列的有效长度等信息）。两个设计自由度：

    • 编码器和解码器不必是同类网络（RNN+RNN、RNN+Transformer 都行）——接口抽象保证这一点；
    • 同一架构可服务多种任务：翻译、摘要、语音识别、对话——凡是"变长→变长"皆可套。

    2. seq2seq 的两个关键设计决定

    编码器侧：嵌入层（代替独热）+ 多层 GRU。上下文变量 \(c = q(h_1,\ldots,h_T)\)，常取 \(c = h_T\)。

    解码器侧：隐状态递推 \(s_{t'} = g(y_{t'-1}, c, s_{t'-1})\)。如何把 \(c\) 喂给解码器，历史上有两种设计：

    设计 做法 代表 特点
    Sutskever 式 (2014) 只用编码器最终隐状态初始化解码器隐状态，之后 \(c\) 不再出现 早期 seq2seq 信息一次性注入，长句易丢信息
    Cho 式 (2014) 编码器最终隐状态在每个时间步都与解码器输入拼接 后续 seq2seq 的通行设计 信息持续供给，缓解长句遗忘；进一步演化为注意力机制（按需回看全部 \(h_1..h_T\)，见 ../06-注意力机制与Transformer/01-注意力机制.md）

    用编码器最终隐状态初始化解码器，要求两者层数与隐藏单元数一致；不一致时需接一个全连接层变换（可自行验证）。

    3. 训练：强制教学与遮蔽损失

    • 强制教学（teacher forcing）：解码器输入 = <bos> + 真实输出序列（去掉 <eos>），而非模型自己的预测。收益：训练并行性好（各时间步输入已知）、收敛快、训练更稳。代价：exposure bias——推理时输入换成模型自己的预测，分布与训练时不同，一个错误词元会带偏后续所有步（对比训练与推理的输入分布即可体会这一差异）。
    • 遮蔽 softmax 交叉熵：填充的 <pad> 不该参与损失。用有效长度把掩码置 0、逐词元损失乘掩码：valid_len=4/2/0 的三条相同序列损失为 2.303/1.151/0（每条损失 = 有效长度 × 单词元损失均值）。有效长度在数据预处理时随 <eos> 一起记录。
    • 训练目标本质：解码器是一个以 \(c\) 为条件的条件语言模型 \(\prod_{t'} P(y_{t'} \mid y_1,\ldots,y_{t'-1}, c)\)。

    4. BLEU：精确定义与缺陷

    \[\mathrm{BLEU} = \exp\left(\min\left(0, 1 - \frac{\mathrm{len}_{label}}{\mathrm{len}_{pred}}\right)\right) \prod_{n=1}^{k} p_n^{1/2^n}\]
    • \(p_n\) = n 元语法精确率：预测中匹配标签的数量 / 预测中 n 元语法总数，且匹配计数有上限（标签中该 n 元组出现几次最多记几次，防止靠重复词刷分）——标签 A,B,C,D,E,F、预测 A,B,B,C,D 时 \(p_1=4/5\)（不是 5/5，A,B,B 中重复的 B 不计），\(p_2=3/4\)，\(p_3=1/3\)，\(p_4=0\)；
    • 指数权重 \(1/2^n\)：长 n 元匹配更难，权重更高（原始论文用 \(1/n\)）；
    • 简短惩罚：预测越短 \(p_n\) 越高（分子分母同小），靠输出"最短安全句"刷分会占便宜，指数项惩罚过短——标签 6 词、预测 2 词时 \(p_1=p_2=1\) 但惩罚 \(\exp(1-6/2)\approx0.14\)；
    • 经典教学实验：小型 GRU seq2seq 短句 BLEU 可达 1.0，稍长句明显退化（0.447~0.658）。

    已知缺陷（使用时须知）：只衡量与参考答案的 n 元重合，不管同义改写与语法流畅性；对短句敏感、多参考答案支持弱；现代评估常补充人工评估、chrF、BERTScore 或基于模型的评估。

    5. 解码策略谱系：贪心 → 束搜索

    解码 = 从 \(O(|\mathcal{Y}|^{T'})\) 个候选序列中选 \(\prod_{t'} P(y_{t'}\mid y_1,\ldots,c)\) 最大的：

    策略 复杂度 质量
    贪心搜索 \(O(\lvert\mathcal{Y}\rvert\cdot T')\) 不保证最优：一个经典反例中第二步选次优词元的序列总概率 0.054 > 贪心的 0.048
    穷举搜索 \(O(\lvert\mathcal{Y}\rvert^{T'})\) 最优但不可行（\(\lvert\mathcal{Y}\rvert=10^4, T'=10\) 时 \(10^{40}\)）
    束搜索 \(O(k\cdot\lvert\mathcal{Y}\rvert\cdot T')\) 每步从 \(k\lvert\mathcal{Y}\rvert\) 候选取 top-k；\(k=1\) 即贪心

    束搜索最终在候选中选长度惩罚对数概率最大者（连乘概率下溢，取对数求和）：

    \[\frac{1}{L^\alpha} \sum_{t'=1}^{L} \log P(y_{t'} \mid y_1,\ldots,y_{t'-1}, c), \qquad \alpha \approx 0.75\]

    \(L^\alpha\) 分母惩罚长序列（对数项随 \(L\) 线性增多，不惩罚会系统性偏向长句）；\(\alpha\) 是可调旋钮：\(\alpha=0\) 无惩罚、\(\alpha=1\) 按平均对数概率。注意束搜索没有任何最优性保证，只是实践中质量-算力的好折中；\(k\) 太大还会倾向通用平淡的输出（翻译任务常用 k=4~10）。

    6. 采样与温度（现代补充）

    束搜索找"概率最高"的序列，适合翻译等有唯一答案的任务；开放生成（对话、写作）要的是"多样且合理"，此时用随机采样：每步按概率分布抽样而非取 argmax。温度（temperature） 重塑分布控制随机度：

    \[P(y = i) \;=\; \frac{\exp(o_i / \tau)}{\sum_j \exp(o_j / \tau)}\]
    • \(\tau \to 0\)：分布趋近 one-hot，退化为贪心（保守、重复）；
    • \(\tau = 1\)：原始分布；
    • \(\tau > 1\)：分布压平，低概率词元更多被采到（多样、但胡言风险上升）。

    实践中 \(\tau\) 常与 top-k / top-p（核采样，截断长尾后再归一化）配合使用。这是现代语言模型解码的标准件，属通行的后续发展。

    术语表

    术语 含义
    编码状态 编码器输出的固定形状表示，seq2seq 中即编码器最终隐状态
    上下文变量 c 输入序列的压缩编码，Cho 式在每个解码步拼接输入
    强制教学 训练时用真实输出序列作解码器输入，代价是 exposure bias
    遮蔽损失 按有效长度把 <pad> 位置损失置零
    简短惩罚 BLEU 中 \(\exp(\min(0, 1-\mathrm{len}_{label}/\mathrm{len}_{pred}))\)，罚过短预测
    束宽 k 束搜索每步保留的候选数，k=1 即贪心
    长度惩罚 α 候选按 \(\frac{1}{L^\alpha}\sum\log P\) 排序，防偏长句，常用 0.75
    温度 τ softmax 除以 τ 控制采样随机度，τ→0 退化为贪心

    经验与常见坑

    • 忘记遮蔽填充词元的损失：模型浪费容量去预测 <pad>，BLEU 明显下降（可自行复现的结果）。
    • 预测阶段没有用 <bos> 起步、或 <eos> 后没有停止，会输出无限长或错位的序列。
    • BLEU 对比实验要固定解码策略与 k/τ——解码器不同造成的分数差异可能大于模型差异。
    • 束搜索 k 调大不一定更好：翻译常见 k=4~10，开放生成用采样而非束搜索（束搜索输出保守平庸）。
    • 编码器/解码器层数或隐藏维度不同时，不能直接拿最终隐状态当解码器初始状态，需线性变换桥接。
    • 顺序分区采样的翻译数据若批内长度差过大，<pad> 比例高、计算浪费——按长度分桶（bucketing）是常见优化。

    ⚠️ 时效性说明

    • RNN seq2seq 已被注意力增强的 seq2seq（Bahdanau）→ 纯 Transformer 取代；编码器-解码器接口、强制教学、遮蔽损失、BLEU、束搜索全部被沿用到 Transformer 时代。
    • 温度/采样属现代 LLM 解码通行实践；现代部署常配 repetition penalty、top-p 等进一步控制（见 ../07-大语言模型/01-NLP 基础概念.md）。
    • BLEU 仍在用但已非唯一标准；词级词元化已被 BPE 等子词方法取代。
