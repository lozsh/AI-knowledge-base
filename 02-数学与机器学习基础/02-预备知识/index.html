    入门导读 数学基础 深度学习

    预备知识

    更新于 2026-11-03

    一句话定义：深度学习的四项入门技能——张量数据操作（PyTorch）、数据预处理（pandas）、线性代数与微积分/自动微分（优化与求导）、概率语言（不确定性推断）。

    所有机器学习都涉及从数据中提取信息：线性代数提供处理表格数据的方法，微积分（配合 autograd 自动微分）决定每步如何调整参数，概率语言支撑不确定性下的预测推断。

    一、数据操作：张量

    张量（tensor） 是 n 维数组，是深度学习存储和操作数据的主要接口。深度学习框架的张量类比 NumPy ndarray 多两个关键能力：GPU 加速计算、自动微分。

    • 轴数对应数学对象：1 轴 = 向量，2 轴 = 矩阵，更多轴无特殊名称（如 RGB 图像 = 高 × 宽 × 通道 3 轴张量）。
    • 关键 API 模式：
    • 创建：torch.arange(12)、torch.zeros((2,3,4))、torch.ones(...)、torch.randn(3,4)（标准高斯随机初始化，常用于神经网络参数）、torch.tensor([[2,1,4,3],...])（嵌套列表赋值）；
    • 形状：x.shape（各轴长度）、x.numel()（元素总数）、x.reshape(3, 4) 或 x.reshape(-1, 4)（-1 自动推算维度；reshape 不改变元素数量和值）；
    • 按元素运算：+ - * / ** 对同形状张量逐元素执行；torch.exp(x) 等一元函数同理；
    • 连结：torch.cat((X, Y), dim=0) 沿轴拼接；
    • 逻辑运算：X == Y 生成同形状布尔张量；
    • 归约：X.sum() 得单元素张量。

    广播机制（broadcasting）：形状不同的张量做按元素运算时，先沿长度为 1 的轴复制扩展到相同形状再运算。例：3×1 与 1×2 矩阵相加 → 双方各自复制行/列 → 3×2 结果。

    索引和切片：与 Python 数组一致，X[-1] 取最后一行，X[1:3] 取第二三行，X[1, 2] = 9 写入单元素，X[0:2, :] = 12 批量赋值。

    节省内存（原地操作）：Y = Y + X 会分配新内存并让 Y 指向新位置（id(Y) 改变）。要避免的原因：① 机器学习中参数可能有数百兆且每秒多次更新，应原地执行；② 不原地更新时其他引用仍指向旧内存，可能无意中引用旧参数。做法：Z[:] = X + Y 或 X += Y。

    与其他对象互转：X.numpy() 与 torch.tensor(A) 双向转换且共享底层内存（就地改一个会改另一个）；单元素张量用 a.item()（或 float(a)/int(a)）转 Python 标量。

    二、数据预处理：pandas

    现实数据从 CSV 等原始格式起步，用 pandas 读取后再转张量。关键流程（以房价小数据集为例）：

    1. 读取：pd.read_csv(data_file)；
    2. 处理缺失值（NaN）：两条路线——插值法（用替代值弥补）和删除法（直接忽略）。
    3. 数值列：inputs.fillna(inputs.mean()) 用列均值填补；
    4. 类别列：把 NaN 视为一个类别，pd.get_dummies(inputs, dummy_na=True) 独热化（如 Alley 列变成 Alley_Pave / Alley_nan 两列 0/1）；
    5. 转张量：torch.tensor(inputs.to_numpy(dtype=float))。

    三、线性代数

    数学对象与代码对应

    对象 数学表示 代码 轴数
    标量 x ∈ ℝ torch.tensor(3.0) 0
    向量 x ∈ ℝⁿ torch.arange(4) 1
    矩阵 A ∈ ℝ^(m×n) torch.arange(20).reshape(5, 4) 2
    张量 花体大写 torch.arange(24).reshape(2, 3, 4) 任意

    约定：向量默认为列向量；表格数据集惯例是一行一个样本（沿最外轴遍历小批量）。A.T 转置；A == A.T 成立的是对称矩阵。

    ⚠️ "维度"一词有歧义：向量/轴的维度指长度（元素数）；张量的维度指轴数。

    核心运算

    • Hadamard 积（按元素乘）：A * B，符号 ⊙，不要与矩阵乘法混淆。
    • 降维：A.sum(axis=0) 沿轴 0 求和（该轴在输出形状中消失）；A.mean(axis=0) 同理；axis=[0,1] 等价全量求和。非降维求和：A.sum(axis=1, keepdims=True) 保持轴数，便于之后用广播做 A / sum_A（按行归一化）；A.cumsum(axis=0) 累积求和也不降维。
    • 点积：x⊤y = Σᵢ xᵢyᵢ，torch.dot(x, y) 等价 torch.sum(x * y)。三大用途：加权和 x⊤w（权重非负且和为 1 时即加权平均）、规范化后表示夹角余弦（余弦相似度的来源）。
    • 矩阵-向量积：Ax 是长度 m 的列向量，第 i 个元素是 A 第 i 行与 x 的点积，torch.mv(A, x)。可将矩阵看作 ℝⁿ→ℝᵏ 的线性变换（如旋转）；神经网络每层的计算就是矩阵-向量积。
    • 矩阵-矩阵乘法：\(C = AB\) 的 \(c_{ij}\)（结果矩阵第 \(i\) 行第 \(j\) 列元素）= \(A\) 第 \(i\) 行与 \(B\) 第 \(j\) 列的点积，torch.mm(A, B)；可视为 m 次矩阵-向量积的拼接。
    • 范数：把向量映射到非负标量的"大小"函数，满足 f(αx)=|α|f(x)、三角不等式 f(x+y)≤f(x)+f(y)、非负且仅零向量取 0。
    • L2 范数：‖x‖₂ = √(Σxᵢ²)，即欧几里得距离，torch.norm(u)（u=[3,-4] → 5）；
    • L1 范数：‖x‖₁ = Σ|xᵢ|，torch.abs(u).sum()，受异常值影响较小；
    • 一般 Lp 范数：(Σ|xᵢ|^p)^(1/p)；
    • Frobenius 范数：矩阵版 L2，‖X‖_F = √(ΣΣxᵢⱼ²)。
    • 深度学习的目标函数（最小化预测与观测的距离、最大化/最小化样本间距离）通常以范数表达。

    四、微积分

    深度学习的训练 = 最小化损失函数，可拆成两个问题：优化（用模型拟合观测数据）与泛化（生成在未见数据上仍有效的模型）。

    • 导数：\(f'(x) = \lim_{h\to 0}\,[f(x+h) - f(x)]/h\)，是瞬时变化率，也是曲线切线斜率。常用法则：常数、幂律 \(\frac{d}{dx}x^n = nx^{n-1}\)、\(\frac{d}{dx}e^x = e^x\)、\(\frac{d}{dx}\ln x = 1/x\)，以及常数乘法、加法、乘法、除法四则法则。
    • 偏导数：多元函数对单个变量的导数——把其余变量当常数。
    • 梯度：∇f(x) 是把所有偏导数连结成的向量。常用结论（深度学习优化算法的基础）：
    • ∇_x Ax = A⊤；∇_x x⊤A = A；∇_x x⊤Ax = (A + A⊤)x；∇_x ‖x‖² = 2x；∇_X ‖X‖²_F = 2X。
    • 链式法则：微分复合函数的工具。单变量 dy/dx = (dy/du)(du/dx)；多变量时 y 对 xᵢ 的偏导 = Σⱼ (∂y/∂uⱼ)(∂uⱼ/∂xᵢ)。这是反向传播的数学根基。

    五、自动微分（autograd）

    深度学习框架自动计算梯度，开发者只需定义前向计算。关键模式：

    x = torch.arange(4.0, requires_grad=True)  # 或 x.requires_grad_(True)
y = 2 * torch.dot(x, x)   # 前向计算
y.backward()              # 反向传播
x.grad                    # 梯度 4x
    • 非标量变量的反向传播：先对结果求和（归约为标量）再 backward；
    • 分离计算（detach）：u = y.detach() 把 u 当常数参与后续计算，其梯度不回传到 y 的计算链；
    • Python 控制流的梯度：即使前向计算含分支、循环（计算图每次动态构建），自动微分同样可用；
    • ⚠️ 经验：反向传播之后立即再次 backward 会报错（计算图已被释放），需要重新前向计算。

    六、概率

    机器学习就是做出预测：预测心脏病发作概率、判断发动机读数正常概率、估计用户购买图书概率。概率是表达确定性程度的灵活语言——既覆盖真实的随机事件（明天是否下雨），也覆盖确定性未知但观测受限的情况（低分辨率图像里是猫还是狗，P(y="猫") 在 0.5 到 1 之间表达信心程度）。

    基本概念

    • 抽样与分布：从概率分布抽取样本叫抽样；给离散选择的概率分配称多项分布。大数定律：随着投掷次数增加，相对频率估计会逼近真实概率（公平骰子掷 1000 次，各面频率 ≈ 0.167）。
    • 联合概率 P(A=a, B=b)：两者同时发生，恒有 P(A,B) ≤ P(A)。
    • 条件概率：P(B|A) = P(A,B)/P(A)。
    • 贝叶斯定理：P(A|B) = P(B|A)P(A)/P(B)。由乘法法则 P(A,B)=P(B|A)P(A) 与对称性推出。
    • 边际化（求和法则）：\(P(B) = \sum_A P(A, B)\)（对 \(A\) 的所有取值求和）。
    • 独立性：A ⊥ B ⟺ P(A,B) = P(A)P(B) ⟺ P(A|B) = P(A)。条件独立：P(A,B|C) = P(A|C)P(B|C)。

    经典应用：HIV 检测（贝叶斯定理 + 条件独立）

    检测准确率很高（健康人误报率仅 1%，感染者绝不漏检），但人群感染率 P(H=1)=0.0015 很低。计算 P(D₁=1) = 0.01×0.9985 + 1×0.0015 ≈ 0.0115，于是阳性时真感染的概率仅约 13.06%——因为健康人群基数大，误报数量压倒了真阳性。概率推断可能高度违反直觉。

    补救：做第二次（准确率其实更低的）独立检测。若也呈阳性，假设两次检测条件独立，P(H=1|D₁=1,D₂=1) 升至 83.07%。启示：多次独立证据的累积能显著提升置信度，这是朴素贝叶斯类方法的思想源头。

    期望与方差

    • 期望：E[X] = Σₓ xP(X=x)；函数的期望 \(E_{x \sim P}[f(x)] = \sum f(x)P(x)\)（\(E_{x\sim P}\) 表示对服从分布 \(P\) 的随机变量 \(x\) 取期望）。
    • 方差：Var[X] = E[(X−E[X])²] = E[X²] − (E[X])²，量化随机变量偏离期望的程度；平方根为标准差。
    • Var[f(x)] 衡量采样波动导致函数值波动的程度。
