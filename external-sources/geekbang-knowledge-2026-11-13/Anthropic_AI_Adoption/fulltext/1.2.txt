Anthropic 的内部团队正在用 Claude Code 改造工作流（workflow），让开发者与非技术岗位的员工都能攻克复杂项目、自动化任务，并弥合此前限制他们生产力的技能差距。

通过对我们自己的 Claude Code 高级用户（power user）的访谈，我们汇总了以下见解：不同部门如何利用 Claude Code、它对这些部门的工作有何影响，以及给正在考虑采用它的其他组织的建议。
