8 周做什么、最后手上留下什么，这一页说清楚：每周一个能验收的产出，加深多少按需选，最后都落到同一个能公网访问的 Agent 服务上。

8 周下来的成品是一个能公网访问的 Agent 服务。它不是第八周才开始赶的东西：从开营前的预习算起，每周的主线项目都在给它添一块。

8 周分成两个阶段：前六周做主线，每周给你的服务加一个能力；最后两周是你的大作业工坊，把它做成你自己想要的样子。

每周你能做出什么

  • 开营前：完成预习与准备——跑通环境自检、完成第一次 LLM API 调用，登记大作业选题意向。
  • 第一周：一个文章总结器——粘贴一篇长文，流式输出结构化总结，并能说出本任务中确定性/概率性的拆分。
  • 第二周：一个记得住你的聊天机器人——连续 20 轮人设不崩、重启历史不丢、/clear 生效，人设为可配置模板。
  • 第三周：一个带工具的助手——一句话完成建文件，外加至少一个你自选的新工具可演示。
  • 第四周：一个自己的资料库——10 个测试问题命中率 ≥ 8/10、答案带出处，附命中率记录表。
  • 第五周：一个会自己干的 Agent——只给目标不给步骤，自主完成 ≥3 步任务，附轨迹与花费报告。
  • 第六周：一个上线的服务——公网可访问、流式对话、重启不丢、key 不在代码库。
  • 第七周（工坊）：说清自己的方案——通过中期检查三件套（可访问地址、演示录屏、成本预估），并对大作业做分层选型判断、算出月成本账。
  • 第八周（工坊）：讲清自己的作品——按「场景一句话 → live demo → 亮点 → 成本账」完成 5 分钟展示，答好三类标准问题（为什么这方案、成本怎么算、出错怎么办）。

每一周都在为大作业攒模块

大作业和每周练习不是两件事。课程主线只有一条：从开营前登记选题起，每周给你的服务加一个模块——

  • 信息处理
  • 人设与个性化
  • 功能扩展
  • 知识与出处
  • 自主执行
  • 公网上线

前五周每周练一个能力，第六周把它部署成公网服务，最后两周围绕你自己的大作业做中期检查、集中辅导与展示答辩。

往哪儿加深，按需选

结业只有一个标准：8 周后你手上有一个能公网访问的 Agent 服务，并且讲得清它怎么做的、成本怎么算。答辩按四项成果（项目仓库、可访问服务、演示录屏、答辩材料）与四条标准（实现、判断、验证、复盘）逐一对照。

至于往哪个方向加深，可以根据自己重点关注的方向选择：想先把服务跑起来，可以先改提示词与配置项；想练动手，可以在基础代码上定向加一个能力（记忆、工具、RAG、循环，四选一）；想练工程判断，就往成本、安全护栏、效果数据方面深入。具体怎么选，对照课程详情页的说明即可。
