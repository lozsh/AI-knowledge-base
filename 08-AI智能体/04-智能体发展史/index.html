    智能体发展史

    更新于 2026-11-03

    一句话定义：智能体发展史是三大思潮（符号主义、联结主义、行为主义）半个多世纪交织竞争与融合的历史——每一代范式都为解决上一代的核心局限而生，最终在大语言模型上汇流为现代智能体。

    理解这条"问题驱动"的演进线索：新范式带来能力飞跃的同时引入新局限，又为下一代埋下伏笔。这条历史脉络能解释当前智能体技术选型的深层原因。

    核心概念

    物理符号系统假说（PSSH，1976）

    Newell 与 Simon 提出，符号主义时代的理论基石。两个论断：

    1. 充分性：任何物理符号系统都具备产生通用智能的充分手段。
    2. 必要性：任何展现通用智能的系统本质上都是物理符号系统。

    它把"人类心智"这一模糊哲学问题转化为可工程化实现的问题，指引了从专家系统到自动规划的整个符号主义时代。

    专家系统（Expert System）

    符号主义最成功的应用，架构上体现"知识与推理分离"：

    • 知识库：领域专家知识，最常用产生式规则（IF-THEN）表示，复杂系统可达数百上千条。
    • 推理机：通用计算引擎，两种工作方式：
    • 正向链（数据驱动）：从已知事实匹配规则 IF，触发 THEN 并加入事实库，直至推出目标。
    • 反向链（目标驱动）：从假设目标出发，把规则 IF 变为子目标递归求证。

    MYCIN（斯坦福，1970s）：血液感染诊断 + 抗生素推荐，约 600 条规则，反向链推理，创新性引入置信因子（CF，-1~1）处理医学不确定性。评估中表现超过非专业医生。证明了"知识工程 + 符号推理"可在垂直领域达到专家水平。

    SHRDLU（1968-1970，Winograd）

    "积木世界"中的自然语言交互智能体，首次把语言解析、规划、记忆多个 AI 模块集成于统一系统：能做指代消解、上下文记忆、多步规划（如先移开障碍积木再叠放）、行为历史与动机问答。其历史地位：综合性智能的典范、"微观世界"研究方法的普及、以及引发的乐观与反思（能力严格局限于规则完备的封闭世界）。

    ELIZA（1966，Weizenbaum）

    基于规则的聊天机器人框架，最著名的 DOCTOR 脚本模仿心理治疗师。核心机制四步：关键词识别与排序 → 分解规则（通配符捕获句式）→ 重组规则（模板生成回应）→ 代词转换（I→you）。从不回答问题，只把用户陈述转化为开放式提问。

    实践揭示规则系统的根本局限：无语义理解（无法处理否定词）、无状态（无多轮上下文）、规则扩展性爆炸（规则冲突与优先级管理不可维护）。但它产生了著名的"ELIZA 效应"——用户对机械规则系统投射情感、误以为其有理解力，这对今天评估聊天产品仍是重要警示。

    心智社会（The Society of Mind，Minsky，1986）

    针对"单一集中推理引擎难以通向智能"的反思，明斯基提出："智能的魔力在于没有魔力。智能的力量来自巨大的多样性，而非任何单一完美原理。"

    • 智能体（此处定义）：极简单的、专门化的、"无心"的心智过程（如 LINE-FINDER、GRASP）。
    • 机构（Agency）：一组协同的智能体，通过去中心化的激活/抑制信号交互。
    • 涌现（Emergence）：智能行为不是被规划的，而是从大量简单单元的局部交互中自发产生——如"搭积木塔"任务中 BUILD-TOWER → BUILDER → ADD-BLOCK → FIND/GET/PUT 逐级激活，没有任何单元掌握全局规划。

    对多智能体系统（MAS）的三大启发：去中心化控制、涌现式计算（蚁群算法、粒子群优化）、智能体的社会性（通信语言、交互协议、协商策略、组织结构）。

    三大思潮

    思潮 核心信念 代表成果
    符号主义 智能源于符号操作与逻辑推理 SHRDLU、专家系统 MYCIN、深蓝
    联结主义 智能源于神经网络的分布式表示与学习 反向传播、CNN、Transformer、GPT
    行为主义 智能通过与环境的试错交互习得 TD-Gammon、AlphaGo（强化学习）

    核心原理

    符号主义的四大根本挑战

    1. 知识获取瓶颈：知识须由专家 + 知识工程师人工访谈、提炼、编码，成本高、难规模化，且专家的内隐直觉知识难以表达为规则。
    2. 常识问题：人类依赖的庞大常识背景（"绳子可拉不可推"）无法穷尽编码；Cyc 项目数十年成果仍有限。
    3. 框架问题：动作执行后，如何高效判断哪些事物未改变——为每个动作显式声明所有不变状态在计算上不可行。
    4. 系统脆弱性（Brittleness）：规则外的任何微小新情况都可能导致系统完全失灵；SHRDLU 的成功恰恰因为它活在封闭世界里。

    联结主义三原则

    1. 知识以连接权重形式分布式存储于神经元连接之间。
    2. 处理单元只做简单计算（加权输入 → 激活函数 → 输出）。
    3. 智能来自学习：通过反向传播等算法迭代调整权重。

    与符号主义的本质区别：符号主义把人类知识显式编码给机器，联结主义创造能自己学习知识的机器。

    强化学习框架

    要素：智能体、环境、状态 \(S\)、行动 \(A\)、奖励 \(R\)。每个时刻 \(t\) 循环三步：

    1. 观察：感知当前状态 \(S_t\)（\(t\) 时刻环境的局面）；
    2. 决策：按策略 \(\pi\)（从状态到行动的决策规则）选择行动 \(A_t\) 执行；
    3. 反馈：环境转移至 \(S_{t+1}\) 并反馈奖励 \(R_{t+1}\)，随后更新策略。

    目标是最大化累积奖励（回报）而非即时奖励，因而需要"远见"（如围棋弃子）。AlphaGo 通过数百万次自我对弈，不依赖人类棋谱学会了超越人类的策略。

    预训练-微调范式

    1. 预训练：在互联网级海量文本上自监督学习（"预测下一个词"），学到语言规律、事实知识与上下文逻辑——以高度压缩的隐式模型解决了符号主义的"知识获取瓶颈"。
    2. 微调：少量下游任务标注数据即可适配特定任务。

    规模跨越阈值后出现涌现能力：上下文学习（few-shot/zero-shot 无需改权重）与思维链推理（先输出推理步骤再作答）。LLM 由此兼具海量知识库 + 通用推理引擎双重角色。

    现代 LLM 智能体的模块化架构

    历史技术在此融合成闭环：感知模块接收环境输入形成观察 → 规划模块通过反思与自我批判分解任务，LLM 结合记忆模块推理决策 → 执行模块解析工具调用，从工具箱选择工具执行 → 工具结果 + 新环境状态构成新一轮观察，同时更新记忆，进入下一轮循环。

    经验与常见坑

    • 符号主义的教训对今天依然成立：任何依赖人工穷举规则/知识/流程的系统，都会在开放世界中遇到长尾失效——LLM 时代的提示词工程同样受"穷举不可扩展"约束。
    • ELIZA 效应提醒：用户会高估对话系统的理解力，产品设计需警惕由此产生的信任错位与伦理问题。
    • MYCIN 技术成功却未临床落地：高风险领域的阻碍不只技术，还有责任认定、可解释性与用户接受度。
