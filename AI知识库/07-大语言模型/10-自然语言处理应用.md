# 自然语言处理应用

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：自然语言处理（NLP）应用是把预训练文本表示接入下游任务的工程实践——典型代表是分析单个文本的情感分析、分析文本对关系的自然语言推断，以及对预训练 BERT 的微调。

在给定预训练文本表示（如词向量、BERT 表示）的前提下，可以将其与不同模型架构（MLP、CNN、RNN、注意力）组合，放入各类下游 NLP 任务。本章原资料的核心主线是：**针对下游任务如何设计模型**——当空间或计算资源有限时，基于 RNN/CNN/注意力的精心构建的小模型仍然可行；当算力充足时，微调 BERT 只需最少的架构改动即可覆盖广泛的任务，代价是要微调上亿参数。

## 任务分类

下游 NLP 应用按输出粒度可分为两大类：

| 粒度 | 任务类型 | 代表任务 |
|---|---|---|
| 序列级 | 单文本分类 | 情感分析、语言可接受性判断（CoLA） |
| 序列级 | 文本对分类/回归 | 自然语言推断（分类）、语义文本相似度 STS（回归，0~5 分） |
| 词元级 | 文本标注 | 词性标注（如 Penn 树库 II 标注集：NNP/POS/NN/VB/JJ） |
| 词元级 | 问答 | SQuAD v1.1 抽取式问答（预测答案片段的起止位置） |

## 情感分析

情感分析（sentiment analysis）研究文本中"隐藏"的情绪，本质是**把可变长文本序列转换为固定类别数**的文本分类任务，广泛应用于政治（公众情绪）、金融（市场情绪）和营销（产品评论）领域。

**数据集**：斯坦福大型电影评论数据集（IMDb, aclImdb）——训练/测试各 25000 条评论，正负标签均衡。典型预处理流程：按词分词 → 过滤出现少于 5 次的词建词表 → 截断/填充到固定长度（num_steps=500，用 `<pad>`）→ 构建 batch 迭代器（batch_size=64，共 391 个小批量）。

### 架构一：双向循环神经网络（BiRNN）

用预训练 GloVe 词向量（100 维）初始化嵌入层，词元表示送入双向 LSTM（2 隐层），**把最后一个隐层在初始和最终时间步的隐状态连结**（形状为 `4 * num_hiddens`）作为整条序列的表示，再经全连接层输出"积极/消极"两类。

- 关键细节：LSTM 要求时间维在第一维，输入需转置；预训练词向量在训练中冻结（`requires_grad = False`）以减少小数据集上的过拟合。
- 实测：lr=0.01、5 轮后 test acc ≈ 0.864。

### 架构二：textCNN（一维卷积）

把文本序列看成一维"图像"，用一维卷积捕捉局部特征（n 元语法）。三个要点：

1. **一维互相关**：卷积窗口沿时间维滑动；多输入通道的一维互相关**等价于单输入通道的二维互相关**（核的高度等于输入高度）。
2. **最大时间汇聚层**（max-over-time pooling）：类似一维全局汇聚，每个通道输出其跨时间步的最大值，允许不同通道有不同时间步数。
3. **textCNN 流程**：多个不同宽度的一维卷积核分别卷积 → 各通道最大时间汇聚 → 连结为向量 → 全连接输出（可用 Dropout 防过拟合）。

实现上有两个嵌入层：一个可训练（`embedding`）、一个冻结（`constant_embedding`），两者输出沿向量维连结后输入卷积。示例配置：GloVe 100d + 卷积核宽度 [3,4,5]、各 100 输出通道。输入 n 个 d 维词元时，宽度为 k 的核输出宽度 n−k+1。实测 test acc ≈ 0.861，训练吞吐高于 BiRNN。

## 自然语言推断（NLI）

自然语言推断（natural language inference）研究**假设（hypothesis）能否从前提（premise）中推断出来**，即判断一对文本的逻辑关系，也称识别文本蕴涵任务（RTE）。三分类：

- **蕴涵（entailment）**：假设可从前提推出。例：前提"两个女人拥抱在一起" → 假设"两个女人在示爱"。
- **矛盾（contradiction）**：假设的否定可从前提推出。例：前提"男子在运行编码示例" → 假设"该男子正在睡觉"。
- **中性（neutral）**：其余情况。例：前提"音乐家们正在表演" → 假设"音乐家很有名"。

**数据集**：斯坦福 SNLI 语料库，50 万以上带标签英语句子对（训练约 55 万对、测试约 1 万对），三类标签基本均衡。预处理要点：测试集必须复用训练集构建的词表；前提/假设分别截断填充到固定长度（如 num_steps=50）。

### 架构三：可分解注意力模型（注意力 + MLP）

Parikh 等人提出的"可分解注意力"模型不含循环层和卷积层，以更少参数在 SNLI 上达到当时最优。三步联合训练：

1. **Attend（对齐）**：把一个序列的词元与另一序列的每个词元做**软对齐**（加权平均，非硬对齐）。注意力权重 e_ij = f(a_i)ᵀ f(b_j)，其中 f 是共享 MLP。**分解技巧**：f 分别作用于 a_i 和 b_j，而非成对输入，使计算量从 mn 次（二次复杂度）降为 m+n 次（线性复杂度）——这是该模型的核心贡献。
2. **Compare（比较）**：把每个词元与其软对齐向量连结后送入函数 g（另一个 MLP）：v_A,i = g([a_i, β_i])。
3. **Aggregate（聚合）**：两组比较向量分别求和后连结，送入函数 h（MLP）输出三分类。

实测（GloVe 100d，num_hiddens=200）：test acc ≈ 0.824。

## 微调 BERT

为每个任务手工设计模型不可扩展。BERT 的价值在于：**对广泛的 NLP 应用只需最小的架构更改（额外加全连接层）**。微调时，额外层参数从零学习，BERT 全部参数参与微调；而预训练专用组件（MaskLM、NextSentencePred 的 MLP 参数）在微调中不更新（陈旧参数，需 `ignore_stale_grad=True`）。

| 任务 | 输入表示 | 输出头 |
|---|---|---|
| 单文本分类 | `<cls>` 位置的 BERT 表示编码整个序列 | 小 MLP 输出类别分布 |
| 文本对分类/回归 | `<cls>` + `<sep>` 分隔两段文本，片段索引区分 | 分类：同上；回归（STS 0~5 分）：连续值 + 均方损失 |
| 文本标注 | 每个词元的 BERT 表示 | 共享的全连接层逐词元输出标签 |
| 问答（SQuAD v1.1） | 问题为第一序列、段落为第二序列 | 两个独立全连接层分别预测答案片段的起止标量分数 s_i、e_i，softmax 成概率；预测时取分数最高的有效跨度 s_i + e_j（i≤j） |

**经验案例：SNLI 上微调 BERT**。前提+假设打包为一条 BERT 输入序列（片段索引区分），截断策略是反复删除较长文本的末尾词元，为 `<cls>` 和两个 `<sep>` 保留 3 个位置。分类器只取 `<cls>` 表示经两层 MLP 输出三分类。实测：bert.small（num_hiddens=256、4 头、2 层，max_len=128，batch_size=512）test acc ≈ 0.779；若换 bert.base（768/3072/12 头/12 层）并加大轮数，可到 0.86 以上。原始 BERT 有 1.1 亿（base）/3.4 亿（large）参数，微调成本高——这正是资源受限时小模型仍有价值的原因。

## 术语表

| 术语 | 含义 |
|---|---|
| 情感分析 | 将文本按情绪极性分类的文本分类任务 |
| IMDb 数据集 | 斯坦福大型电影评论数据集，训练/测试各 25000 条，正负均衡 |
| 最大时间汇聚 | 每通道取跨时间步最大值的一维全局汇聚，允许通道间时间步数不同 |
| 自然语言推断 | 判断前提与假设间逻辑关系：蕴涵/矛盾/中性 |
| SNLI | 斯坦福 NLI 语料库，50 万+ 带标签英文句对 |
| 可分解注意力 | Attend-Compare-Aggregate 三步 NLI 模型，无循环/卷积层，分解技巧带来线性复杂度 |
| 序列级/词元级任务 | 输出整条序列一个标签 vs. 每个词元各一个标签 |
| `<cls>` / `<sep>` | BERT 的分类标记与分隔标记 |
| 片段索引 | BERT 输入中区分第一/第二段文本的 0/1 编码 |

## 经验与常见坑

- **测试集词表必须复用训练集的**，否则模型对测试集新词元"未见过"，评估失真。
- 预训练词向量在小数据集上应**冻结**以减少过拟合（BiRNN）；textCNN 则用双嵌入层同时获得冻结与可训练两路表示。
- LSTM 输入要求时间维在前，词元序列需转置；CUDA LSTM 需 `flatten_parameters()` 避免警告与性能损失。
- 微调 BERT 时显存吃紧，优先调小 batch_size 和 max_len；截断句对时注意为特殊标记保留 3 个位置。
- 预训练专用头（MaskLM/NextSentencePred）的参数在微调中是陈旧的，训练循环需允许陈旧梯度，否则报错。

## ⚠️ 时效性说明

本条目源自《动手学深度学习》（d2l）时代（约 2020-2021）的内容。以"预训练 GloVe + 定制架构"做文本分类、微调整个 BERT 的范式，如今在应用层面已 largely 被更大规模的解码器-only 大模型 + 提示/检索方案取代；但其中的任务定义（NLI 三分类、STS、抽取式问答）、架构思想（软对齐、分解技巧、汇聚层）和微调方法论仍是理解现代 LLM 应用的基础。文中 test acc 数字为该特定实验配置下的结果，非当前最优水平。
