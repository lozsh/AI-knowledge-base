# 多模态 AI 应用：语音、图像理解与生成

/> 来源：公开课程资料自学整理（更新于 2026-11-03）
> 一句话概括：语音（Whisper/TTS/数字人）、图文对齐（CLIP）、图像生成（Stable Diffusion/ControlNet）三大支柱的原理直觉与工程模式——核心是"把不同模态映射到同一语义空间，再用语言模型调度"。

## 核心概念

- **Whisper**：OpenAI 开源语音识别模型，自回归式"用前文预测下一帧音频"——因为自回归，所以和 LLM 一样支持 Prompt 引导。
- **TTS / SSML**：文本转语音；SSML 是 W3C 标准的语音合成标记语言，可指定 voice/style/role。链路：文本 → 声学模型 → 音码器（Vocoder，如 HiFiGAN）→ 音频。
- **数字人**：不是单一模型，而是 ASR + LLM + TTS + 口型合成（D-ID/PaddleGAN）的组合方案。
- **CLIP**：用 4 亿"图片 + alt 文本"对做**对比学习**，把图和文映射到同一向量空间的多模态模型——这是"图文互通"的地基。
- **Stable Diffusion（扩散模型）**：三段式文生图——CLIP 文本编码 + UNet/Scheduler 在潜空间迭代去噪 + VAE 解码。
- **ControlNet**：在 SD 之外加一个控制模型，用边缘/姿态/深度/简笔画等"骨架图"精确约束生成结果——给生成过程一个"骨架"。
- **Visual ChatGPT / Task Matrix**：把视觉基础模型逐个封装成 Tool 交给 Agent 调度，实现"边聊边画"——多模态应用的通用架构是"LLM 当调度器"。

## 关键方法/原理

### 1. Whisper 的 Prompt 技巧（自回归的红利）
- 控制标点风格：给一段带标点的中文引导句。
- 消除中英混排的多余空格。
- 纠正专有名词：在 Prompt 里写出正确拼写（如 ChatGPT），模型会照着改。
- 长音频切片处理：上一片段转录的最后一句作为下一片段的 Prompt，保持跨片段连贯。

### 2. CLIP 零样本分类与图文检索
- 分类：列出候选文本，与图片算内积 + Softmax 即可，无需标注、无需重训。文本加 "a photo of a" 前缀更贴近训练分布。
- 检索：同一向量空间天然支持文搜图、以图搜图（配 FAISS 索引）。

### 3. Stable Diffusion 生成机制
- 流程：随机噪声（img2img 时为草稿图经 VAE 编码加噪）→ UNet+Scheduler 在 64×64 潜空间迭代去噪 → guidance_scale 控制向文本条件靠拢的程度 → VAE 解码成图。
- **负面提示语**：把"无条件向量"替换为负面文本向量，让生成远离它——机制层面的理解比"写个负面词"更深。
- 常见操作族：img2img（图生图）、Inpainting（局部重绘）、Upscaler（超分）。

### 4. 多模态产品体验（Midjourney 案例三原则）
- 用户社区当新手教程（抄别人的提示语是合法的入门方式）。
- 生成过程即时反馈（模糊→清晰的中间帧缓解等待焦虑）。
- 数据飞轮：一次出 4 张小图供选、变体按钮、收藏按钮都是隐式标注。
- 工程侧：GPU 适合批处理而非高并发——排队 + 凑批是这类产品响应慢的根源。

## 经验与常见坑

- Whisper API 按文件后缀识别格式（无后缀的 WAV 需重命名）；translation 接口只能翻成英文。
- CLIP 预训练语料是英文：**分类标签必须用英文**，中文标签效果崩。
- SD 显存紧张：enable_model_cpu_offload（组件用完即卸）+ xformers 加速（代价是质量略不稳）。
- SD 的 Prompt 超 77 token 可能输出黑图（safety checker 拦截）——长描述要压缩或分词权重处理。
- 中英混排 TTS 需指定 mix 模型（如 PaddleSpeech 默认只支持中文）。
- 数字人 = 四种能力的流水线，任何一环（识别错字、TTS 断句、口型不同步）都会破坏整体体验；逐环验证而非整体调。

## ⚠️ 时效性说明

- Whisper/SD/ControlNet/PaddleGAN 等为 2023 年课程时点的代表方案；此后语音、生图、视频生成迭代极快（端到端语音模型、DiT 架构生图等），但本篇的**机制层原理（自回归、对比学习对齐、潜空间去噪、LLM 调度工具）仍然耐用**。
