# LLM 应用开发核心模式：嵌入、语义检索与提示工程

<p class="note-date">更新于 2026-11-03</p>
> 一句话概括：LLM 应用开发的全部技巧，本质都是"如何把对的上下文放进提示语"——多轮靠重发历史，私有知识靠检索注入，复杂任务靠多步拆解。

## 核心概念

- **LLM 心智模型**：无状态的"文本续写机器"（Completion）+ 语义坐标系（Embedding）。模型没有记忆，没有实时数据，算术不可靠——这三条决定了几乎所有应用模式。
- **Embedding（文本向量）**：把任意文本映射为固定长度向量，语义相近则距离近；是大模型连接传统机器学习的桥梁。本质是"大模型替你做了特征工程"。
- **世界知识 vs 思维能力**：模型内含两种能力——语料中沉淀的知识（答事实问题靠它）与阅读理解推理能力（临时提供上下文即可触发）。**这是 RAG 成立的原理基础**。
- **幻觉（Hallucination）**：语料中相关文本太少时模型似是而非地编造（如中文语料占比低导致中文常识问答离谱）。
- **Token**：模型分词的最小单元（约 750 英文单词 ≈ 1000 token）；**同一内容中文耗 token 约为英文的 3–4 倍**，纯成本问题。
- **上下文窗口**：单次可处理的最大 token 数，输入+输出共享；模型无记忆，多轮对话靠客户端每轮重发全部历史（"双向收费"）。
- **温度（temperature）**：控制输出随机性（0–2），严肃场景设低、创意场景设高。

## 关键方法/模式

### 1. Embedding 的两种用法
- **零样本分类**：预先算标签文本（如"好评/差评"）的向量，样本向量与各标签比余弦相似度，无需训练即可到 95%+ 准确率。适合情感分析等简单分类快速启动。
- **Embedding + 传统机器学习**：把 Embedding 当特征喂给逻辑回归/随机森林，可利用标注信息超过纯距离法（新闻分类 86%+）。
- **局限**：词向量求平均丢词序——"not good, really bad" 与 "not bad, really good" 向量相同，只适用于不关心顺序的场景。

### 2. 语义检索
- 查询和文档都转向量、按余弦相似度召回——不要求关键词匹配，天然解决同义词问题（"自然淡雅背包"召回"小清新斜挎包"）。
- 海量数据用 Faiss（ANN 近似最近邻）或向量数据库（Pinecone/Weaviate/Milvus）加速。
- 延伸用途：推荐冷启动（无行为数据时靠语义相似度）、以文搜图/以图搜图（见多模态篇）。

### 3. "第二大脑"模式（RAG 的原型）
先建外部资料索引（Embedding + 向量库）→ 提问时先检索相关片段 → 把片段填入提示语模板（强调"只根据上下文回答，不知道就说不知道"）→ LLM 作答。解决知识时效性、私有数据、幻觉三个问题。

### 4. 多步提示语（Multi-Step Prompt）
把复杂任务拆成有序步骤（如写单元测试：①解释代码 → ②规划测试用例 → ③生成测试代码 → ④语法检查 + 失败重试）。原理是思维链：分步推理比一股脑塞需求好；中间产物作为下一步输入；配"结果数量不足就追加要求"的反馈循环。

### 5. 上下文压缩
- 长对话：把历史让 AI 总结成短文本放进新 Prompt，实现"无限轮数"。
- 长文档摘要：分段小结 → 再对小结小结的树状汇总（tree_summarize）。

### 6. 与 AI 协作写代码
不要求一次做对，每次靠近一步；先跑通最小路径验证可行性；报错原样贴回让 AI 修；用最简请求二分定位问题（如排查 JSON 格式）。没有数据集时，可用精确描述特征（品类、格式、风格）的提示语让 AI 造实验数据。

## 经验与常见坑

- **成本类**：
  - 多轮对话双向收费：10 轮 × 1000 token 的对话实际消耗约 5500 token；按 token 预算裁剪历史（保最近 N 轮或删最旧轮次）。
  - 生产环境提示语用英文，要求输出时说 "generate Chinese"。
  - API 限速：逐条调用会被限速，报错后继续调会延长惩罚；解法 = 指数退避（exponential backoff）+ 批量请求（批量也不能超每分钟 token 数）。
  - Embedding 结果别存 CSV（浮点转字符串浪费数倍空间），用 parquet；中间结果务必落盘，避免重复花钱重算。
- **质量类**：
  - 文本超长不能硬截断——截在半句会导致模型不听指令续写；截断后保证以完整句号结尾。
  - 评估看 Precision 与 Recall，类目不平衡时看 macro average，否则少数类全错整体准确率照样好看。
  - 模型快照：带日期后缀的模型（gpt-4-0314）不会随时间更新；锁定库版本，别盲信默认模型名。
- **提示语细节**：插入前缀+后缀文本时注意分隔符（少个换行符 AI 就会啰嗦续写）；logit_bias 设 ±100 屏蔽/强推 token 会产生别字或不可接受的慢，一般 ±1 内够用。
