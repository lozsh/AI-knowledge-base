# 大语言模型基础

<p class="note-date">正文修订于 2026-11-13</p>

读完这篇，你能沿着“文字 → Token → 上下文表示 → 下一 Token → 回答”解释模型怎样工作，并判断一次失败该查输入、生成、训练还是应用校验。

先考虑一个贯穿案例：你把“第二章周五复习，第三章尚未安排”交给笔记助手，让它生成一张复习卡。为什么模型可能写得很顺却补出不存在的日期？为什么上传笔记不代表它永久记住了？为什么调低温度仍然会错？这些问题要沿着计算路径解释，不能只归结为“模型不够大”。

> 前置知识：知道向量是一组数字、概率表示分布即可。以下小词表、数值和预算是教学构造，不是某款模型实测；历史语言模型放在文末选读。

## 先把一次调用和一次训练分开

语言模型给定前文，计算后续 Token 的条件概率。主流自回归文本模型常用 Decoder-only Transformer，但语言模型不只这一种架构或训练目标。

| 阶段 | 输入与工作 | 改变什么 |
|---|---|---|
| 预训练 | 从大规模文本构造预测目标，计算误差并更新参数 | 学到的表示、知识与能力 |
| 后训练 | 用任务示范、偏好或奖励继续优化 | 指令遵循、任务表现与行为倾向 |
| 普通推理 | 用已有参数处理本次输入并生成 | 本次中间表示和输出，不自动更新参数 |
| 应用处理 | 检索资料、调用工具、保存记录、验证答案 | 外部数据与执行状态，不等同于训练 |

“这次能依据笔记回答”通常意味着笔记进入了上下文。要下周仍能引用它，应保存原文并按需取回；不能期待普通聊天把笔记写入模型参数。

## 文字怎样变成模型输入

### Token 不是字数，也不是语义坐标

分词器把文本编码成离散单元 Token（词元）及其编号。一个词元可以是整词、子词、标点或字节片段；字符数、UTF-8 字节数和 Token 数没有跨模型固定比例。

例如“我用卡片复习概念”有 8 个汉字。若教学词表收录“我、用、卡片、复习、概念”，可以得到 5 个词元；若词表只收录单字，则得到 8 个。编号相邻不意味着含义接近。这里的最长匹配只是玩具规则，不是 BPE 的定义。

常见子词算法各有取舍：BPE 根据语料迭代合并片段；WordPiece 与 Unigram 使用不同学习和切分规则。三者不能直接互换，具体词表和切分结果取决于训练语料与实现。SentencePiece 是支持不同子词模型的工具，不是一种统一算法。实际使用必须让分词器、模型权重和聊天模板配套，不能笼统认定某个模型家族的所有版本都使用同一种分词器。

### 从编号查向量，再结合位置和上下文

Token Embedding（词元嵌入）是一张可学习的表：每个编号对应一行向量。假设词表有 11 项、每项 3 维，表有 33 个参数；一次输入取出 5 行，形成 \(5\times3\) 的表示，不意味着整个模型只有 15 个参数。

同一个 Token 最初可以查到同一行向量，进入模型层后，会因位置、可访问上下文不同而得到不同表示。这个内部词元表示，也不是可直接拿来检索整篇文档的向量；语义检索需要适合该任务的表示与评估。

聊天输入还包含角色、边界标记、系统要求和历史。只统计最后一条用户消息会低估实际输入。应用应保留原始资料与本轮实际提供的内容，方便追溯；不要为了省 Token 随意删掉代码缩进或字符串里的空格。

## Transformer 怎样加工这些表示

### 注意力：匹配之后汇集内容

自注意力让当前位置在允许范围内利用其他位置的信息。查询 Q、键 K、值 V 是不同参数投影产生的向量：Q 与 K 计算匹配分数，V 提供要汇集的内容。Q 不是用户问句，注意力也不会自动搜索硬盘。

\[
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V
\]

\(d_k\) 是查询与键的维度，\(M\) 是掩码；Softmax 对每个查询的一行分数归一化。缩放用来控制点积分数尺度，避免过早饱和。因果掩码把不可访问的未来位置设为负无穷；设成 0 不够，因为 \(e^0=1\)。

做一个可核算例：三个位置缩放后的分数为 2、1、0，其 Value 分别为 `[2,0]`、`[0,2]`、`[1,1]`。Softmax 权重约为 `[0.665,0.245,0.090]`，汇集结果约为 `[1.421,0.579]`。最后一个分数是 0，却仍贡献信息。权重 0.665 是混合系数，不是该资料有 66.5% 的概率正确。

多头注意力允许多组投影并行汇集，再拼接和投影。各头不必分别对应“语法、逻辑、指代”，也不是多个完整模型投票。注意力热力图不能独自证明最终答案的因果来源。

### 一个计算块还需要哪些部件

一种简化的前置归一化块可写成：

\[
Y=X+\operatorname{Attention}(\operatorname{Norm}(X)),\qquad
Z=Y+\operatorname{FFN}(\operatorname{Norm}(Y))
\]

这是一种结构示意，不是所有 Transformer 的精确实现图。

- **位置设计**让顺序参与计算。原始 Transformer 加正弦/余弦位置向量；RoPE 等方案在 Q/K 上引入位置相关旋转。位置编码与因果掩码各有职责。
- **FFN（逐位置前馈网络）**进一步变换已汇集的特征。同一层通常在各位置共享参数；内部可变宽，输出再回到残差路径的宽度。
- **残差连接**把子层结果与输入相加，有助于深层优化，但不保证所有信息永远无损保存。
- **归一化**处理每个位置特征的数值尺度，不检查语义真假。LayerNorm 的可学习缩放和偏移意味着最终输出不一定严格均值 0、方差 1；其他模型也可能采用 RMSNorm 等变体。

假设输入有 4 个 Token，每个位置保持 4 维，FFN 中间宽度为 8，词表有 10 项：嵌入是 \(4\times4\)，FFN 中间是 \(4\times8\)，块输出仍为 \(4\times4\)，词表输出头给各位置产生 10 个分数，即 \(4\times10\)。经过一个块是在加工表示，不是生成了一个新 Token。

### 没有独立编码器，也能利用提示词

Encoder-only 通常用双向上下文形成表示；Encoder–decoder 先编码源序列，再由解码端通过交叉注意力读取它；Decoder-only 把提示与回答放在同一序列中按因果规则处理。

回答位置在提示之后，因此可以利用前面的资料和要求。“只有解码器”描述连接方式，不等于“只有说话能力、没有理解能力”。这些结构不是任务禁令：生成模型也能输出分类标签，编码器表示也能进入更大的生成系统。

## 回答为什么逐 Token 生成

模型输出头给词表各项产生 Logits（未归一化分数）。生成器从分布中选择下一 Token，把它加入前缀，再计算下一步。若先选出错误日期，后续解释可能继续围绕它展开；基本自回归机制没有自动撤销错误的保证。

训练时整段原文已知，可以用因果掩码并行计算多个位置的预测。生成时下一步依赖刚选出的内容，通常逐步推进。位置并行、层间依赖与生成依赖是不同问题，不能用“Transformer 能并行”推出“整个答案同时生成”。

### 采样调的是选择倾向，不是事实

| 策略 | 做什么 | 不能保证什么 |
|---|---|---|
| 贪心 | 在当前分数下选最高项 | 整条序列最优或答案正确 |
| Temperature | 正温度下用 \(z/T\) 调整分布集中程度 | 补齐知识或修正高分错误 |
| Top-k | 保留排名靠前的 k 项 | 留下的项目都真实 |
| Top-p | 保留累计概率达到阈值的候选集合 | 保留词表的 p 比例 |

例如概率为 `[0.50,0.25,0.15,0.07,0.03]`，Top-p=0.8 要保留前三项，累计 0.90 后归一化。温度与过滤器的组合顺序、特殊值及支持范围由实现决定，没有跨接口统一优先级。某些接口将 temperature=0 约定为贪心，另一些要求关闭采样，不能把 0 直接代入温度公式。

固定种子、配置与输入有助于复现，但跨服务版本、硬件、数值后端仍可能变化。逐字一致也不是事实验证。需要精确算术时，让模型理解问题，由程序计算；需要审计时，保存认可的实际结果而不是下次重新生成。

### 停止原因也是结果的一部分

生成结束标记、命中停止字符串、达到输出上限、服务中断、转交工具是不同终止方式。输出到上限可能只写完题目而没有答案；提高温度不能修复截断。流式传输块也未必一块对应一个 Token。

应用要同时核对终止状态、字段完整性和内容。思维链文字可以帮助展示步骤，但可能解释错误或并非忠实反映内部计算；可见步骤越多不等于结论越可靠，验证仍需独立依据。

## 预测能力怎样从训练形成

### 预训练：原文提供监督目标

教学序列 `[我,用,卡片,复习,概念]` 可以构造“我→用”“我用→卡片”等预测。标准教师强制训练使用原文前缀：即使第一步预测错，第二步仍用正确原文，而不是把错误采样塞进同一训练样本。

单个目标 Token 的常见损失是 \(-\ln p\)。目标概率从 0.2 提高到 0.4，损失从约 1.609 降到 0.916；这不表示事实正确率翻倍。通过大量样本的梯度更新，模型可能形成可复用规律，也可能记住训练片段，两者并不互斥。

缩放规律研究参数、数据、计算与损失的经验关系。Chinchilla 等研究提示固定预算下要配合参数量与训练量；训练最省的配置不一定在大量推理调用下最省。经验幂律和某些基准的跃迁不构成所有任务统一的能力门槛，“更多参数”不能代替实际任务评测。

### 后训练：把续写能力塑造成助手行为

监督微调（SFT）用任务与合格回答继续训练；常见配置只计回答位置的损失，指令仍作为输入。经典奖励模型式 RLHF 用人类比较拟合评分器，再用强化学习优化受约束的策略；标准离线 DPO 则利用成对偏好与参考模型直接构造偏好损失，不单独训练奖励模型。

它们不是每个模型必须依次通过的三道工序，也不是质量排名。偏好更高、语气更自信、格式更像助手，都不能直接证明事实更准确。示范和评价应覆盖“有依据时回答”“缺资料时承认不足”“用户错误暗示时纠正”三类边界。

## 回到笔记助手：按失败发生的位置修

| 现象 | 先查什么 | 更合适的修复 |
|---|---|---|
| 没有使用本周新安排 | 新版是否进入有效输入 | 修检索、版本与输入组装 |
| 摘要漏掉“第三章未安排” | 压缩前后的条件差异 | 保留任务约束和原文出处 |
| JSON 合法却补出日期 | 内容是否得到资料支持 | 增加逐项证据校验与不足处理 |
| 问题有了、答案被截断 | 终止原因与输出预算 | 调整预算后重新核验完整性 |
| 换会话就忘记偏好 | 是否持久保存并取回 | 设计应用记忆，不靠 KV 缓存 |

KV 缓存保存计算中间状态以减少重复计算；前缀缓存复用匹配前缀。二者不自动扩大逻辑窗口，也不是长期用户档案。一次保守容量规划应合计指令、历史、资料、工具与生成余量；缓存命中部分仍占有效上下文位置。权重载荷还不同于运行内存：稠密模型粗估载荷可用“参数数×每参数字节”，运行时另加 KV 缓存、中间张量及框架开销；MoE 的总参数决定存储的一部分，激活参数更接近单步计算的一部分，但不能直接按激活量估计全部显存。

## 理解检查与生产起点

先试着解释下面三个反例：注意力分数设为 0 为什么不等于屏蔽？相同输入低温度反复输出错误为什么不算验证？模型知道第三章未安排，却输出一个日期，应该只增加参数量吗？答案分别是 Softmax 仍给正权重；一致性不同于真实性；应先检查指令、证据利用与校验流程，再用同样案例比较模型。

上线前至少记录完整模型/权重标识、分词与聊天格式、输入来源版本、终止状态和用量；测试资料缺失、旧新冲突、超长输入、拒答及工具失败。质量评价同时报告回答覆盖和已回答部分准确性，不能用一律拒答换取“100%正确”。

## 历史选读：为什么从计数走到上下文表示

### 统计语言模型与 N-gram

语言模型（Language Model）的根本任务是计算一个词序列出现的概率。由链式法则：

P(S) = P(w₁) · P(w₂|w₁) · P(w₃|w₁,w₂) ⋯ P(wₘ|w₁,…,wₘ₋₁)

直接估计这些条件概率不可行（长词序列在语料库中几乎不出现），因此引入**马尔可夫假设**：一个词的出现只依赖它前面有限的 n−1 个词。由此得到 N-gram 模型：

- Bigram（N=2）：P(wᵢ|w₁,…,wᵢ₋₁) ≈ P(wᵢ|wᵢ₋₁)；Trigram（N=3）：P(wᵢ|w₁,…,wᵢ₋₁) ≈ P(wᵢ|wᵢ₋₂,wᵢ₋₁)

概率用**最大似然估计（MLE）**即计数得出：P(wᵢ|wᵢ₋₁) = Count(wᵢ₋₁,wᵢ) / Count(wᵢ₋₁)。

下面是无句首、句尾边界标记的玩具语料，只用来展示计数；完整句子概率估计还要约定边界与初始分布。

**手算示例**：迷你语料库 "datawhale agent learns datawhale agent works"（共 6 词），用 Bigram 估算 P(datawhale agent learns) = P(datawhale)·P(agent|datawhale)·P(learns|agent) ≈ (2/6)·(2/2)·(1/2) ≈ 0.167。

N-gram 的两个致命缺陷：
1. **数据稀疏性（Sparsity）**：未见过的词序列概率为 0，平滑（Smoothing）只能缓解不能根除。
2. **泛化能力差**：词是孤立离散符号，无法理解语义相似性——见过 "agent learns" 不代表能算出 "robot learns" 的概率。

### 神经网络语言模型与词嵌入

Bengio 等人（2003）提出前馈神经网络语言模型（NNLM），核心思想两步：
1. **构建语义空间**：把每个词映射为高维连续向量，即**词嵌入（Word Embedding）**，语义相近的词在空间中位置相近。
2. **学习映射**：用神经网络学习"前 n−1 个词的词向量 → 下一个词的概率分布"。词嵌入在"预测下一个词"的训练中自动学到丰富语义。

度量词向量相似性最常用**余弦相似度**：similarity(a,b) = cos(θ) = (a·b)/(‖a‖‖b‖)，1 表示同方向、0 表示正交、−1 表示反方向；是否对应语义相关，还取决于向量的训练方式和评估任务。著名例子：vector('King') − vector('Man') + vector('Woman') ≈ vector('Queen')，说明词嵌入学到了"性别""皇室"这类抽象概念。

NNLM 改善了泛化能力，但**上下文窗口仍是固定的**（只看前 n−1 个词）。

### RNN 与 LSTM

循环神经网络（RNN）引入**隐藏状态（hidden state）**作为网络的短期记忆：每步读取当前输入并结合上一时刻的记忆，生成新记忆向后传递，从而打破固定窗口限制。

但标准 RNN 有**长期依赖问题**：序列长度等于网络深度，反向传播时梯度多次连乘，导致梯度消失/爆炸，学不到长距离依赖。

**LSTM**（长短期记忆网络）用**细胞状态（Cell State）**（一条独立于隐藏状态的信息通路）加三个**门控机制**缓解：遗忘门（决定从上一时刻细胞状态丢弃哪些信息）、输入门（决定当前输入中哪些新信息写入细胞状态）、输出门（决定细胞状态中哪些信息输出到隐藏状态）。
