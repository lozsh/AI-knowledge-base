# 大模型架构原理与技术演进

<p class="note-date">更新于 2026-11-03</p>
> 一句话概括：从 RNN 到 Transformer 再到 Mamba 的架构演进主线——为什么自注意力赢了，以及 Transformer 的关键构件和参数量怎么算。

## 核心概念

### 语言模型两大类
- **掩码语言模型 MLM**（BERT，Encoder Only）：双向看上下文，完形填空式，擅长理解；
- **自回归语言模型 ALM**（GPT，Decoder Only）：用上文预测下文，能吃无监督海量语料，生成任务上限更高。ChatGPT 的胜利公式：**自回归语言模型 + 充分无监督训练 + 大量代码训练 + 指令微调 SFT + RLHF**。

### 演进主线（为什么走到 Transformer）
1. **RNN**：隐藏状态 $h_t = f(W_{xh} x_t + W_{hh} h_{t-1} + b_h)$（$h_t$ 为 $t$ 时刻的隐藏状态，$W_{xh}$/$W_{hh}$ 为输入/循环权重矩阵），循环结构带"记忆"。两大死穴：串行计算无法并行；梯度消失/爆炸导致无法捕捉长距离依赖。
2. **LSTM/GRU**：用门控缓解梯度问题——LSTM 三门：遗忘门（弃旧）、输入门（写新）、输出门（控输出）；设计规律：Sigmoid 常作门控激活。
3. **Seq2Seq（Encoder-Decoder）**：统一"序列进序列出"范式，编码器把源语言投影到高维语义空间，解码器投影回目标空间。死穴：全部输入压进一个固定长度向量，长句丢信息。
4. **Attention 注意力**：解码器每一步对编码器全部输出"私人定制"一个上下文向量（Query 查询 Key/Value），解决长距离依赖。
5. **Transformer**（2017《Attention Is All You Need》）：彻底去掉递归、只用注意力，靠并行训练效率与效果双赢。
6. **Mamba/SSM**（2023）：线性复杂度挑战者（见下）。

## 关键方法/原理

### Transformer 关键构件
- **自注意力三步**：输入线性变换出 Q/K/V → Query 与 Key 点积并除以 $\sqrt{d_k}$（Key 的维度）缩放（scaled dot-product）→ Softmax 归一化成权重（实现时减 max 防溢出）后加权求和 Value。
- **Self-Attention vs Attention**：Attention 管输入-输出关联（如跨语言对齐）；Self-Attention 管输入内部词与词的关联（消歧：指认句中"道"指哪个"道"）。
- **多头注意力**（默认 8 头，每头 $d_{\text{model}}/h$，$d_{\text{model}}$ 为模型隐藏维度）：多组同构注意力并行学不同子空间特征，再拼接+线性变换——类似赛马机制，降低初始化随机性影响。
- **位置编码（Positional Encoding）**：RNN 串行自带顺序信息，Transformer 并行无状态，必须显式注入位置编号。
- **编码器层结构"1+2+1"**：位置编码 + 自注意力层 + FFN 前馈层，每个子层后接 **Add & Norm**（残差连接给梯度开多通路，承袭 ResNet；层归一化稳定训练）。FFN(x) = max(0, xW₁+b₁)W₂+b₂。
- **解码器多一层 Encoder-Decoder Attention**；自注意力用上三角掩码（mask 填 -inf）阻止看到未来词，保证自回归性。末尾 Linear 映射到词表维度 + Softmax。
- 词向量起点：**Word2Vec** 两种架构——CBOW（上下文预测中心词）与 Skip-Gram（中心词预测上下文，罕见词表现更好）；短板是静态向量无法处理一词多义 → **ELMo** 用双向 LSTM 按上下文动态调整词向量（但两方向独立训练仅拼接，非端到端）。

### 参数量与算力估算（训练前的账）
- 参数量：N ≈ vocab×embed（嵌入层）+ [4×embed²（Q/K/V/输出投影）+ 2×embed×FFN隐藏维] × 层数 + vocab×embed（输出层）。实例：vocab=100000、embed=512、hidden=2048、6 层 → 约 1.2 亿参数。
- **Scaling Law**：C ≈ 6ND（FLOPs ≈ 6×参数量×token 数，Decoder-only 前提）；性能随参数/数据/算力幂律提升，三者须同比例放大。
- 锚点数字：GPT-3 = 96 层 / 175B 参数 / 570GB 过滤后高质量数据（原始约 45TB）；1.2 亿参数 FP32 权重约 460MB。

### 涌现与规模的三种关系
- **Scaling Law**：平滑幂律，More Pain More Gain；
- **涌现能力（Emergent Ability）**：小规模无、过临界值后骤升（复杂多步任务明显，约 10^10 参数处）；门槛经验值：至少 68B，复杂任务最好超 100B；
- **U 形曲线效应**：中等规模被干扰任务拖入谷底，更大规模识别干扰后反超——勿过早放弃有价值的研究方向。
- 算力分配之争：OpenAI 优先加参数；**Chinchilla**（DeepMind）证明 70B+更多数据 ≈ 更大模型效果，大幅降推理成本；LLaMA 走"小参数+充分数据"路线验证可行。

### Mamba / 状态空间模型（SSM）
- 动机：自注意力 O(n²·d) 是长上下文的根本瓶颈；RNN 计算快但遗忘长依赖。
- SSM 核心方程：状态方程 h'(t) = Ah(t) + Bx(t)；输出方程 y(t) = Ch(t) + Dx(t)。A 用 **HiPPO 矩阵**初始化（多项式压缩历史）；连续→离散用零阶保持（Zero-order hold），步长 Δ 可学习。
- **双重表示**是关键洞察：同一 SSM 既可写成卷积形式（可并行训练）又可写成循环形式（推理快）——**训练用卷积、推理用循环**，兼得两者。
- **选择性 SSM**（Mamba 创新点）：让 B、C、Δ 依赖输入内容，模型可对信息取舍，弥补"小状态"弱于全量注意力的问题。
- 现状：线性复杂度、内存高效，但通用性/迁移学习待验证（曾被 ICLR 拒稿，缺大规模训练证据）；生产级参考：52B 的 Jamba。

## 经验与常见坑

1. **模型不是越大越好**：Megatron-Turing 5000 亿参数效果不如充分训练的 GPT-3；数据质量与训练充分度是第一位的；
2. Decoder Only 在完形填空上先天劣势，但在生成任务上反成优势——架构选择看任务范式；
3. 代码语料训练显著增强逻辑推理与思维连贯性（思维链与代码训练强相关），已是所有主流模型的标配做法；
4. U 形曲线警示：某个规模上效果变差不等于方向错误；
5. 少样本示例数量受最大上下文长度约束——这是倒逼"更长上下文"演进的根本动力之一；
6. RNN 系（含 Mamba 这类循环形式）推理快但"小状态"压缩历史，Transformer 全量注意力贵但保真——长序列选型是权衡而非替代。

## ⚠️ 时效性说明

- Mamba 的生产验证状态、Q*/具身智能等推测性内容仍在快速变化；
- 涌现门槛经验值（68B/100B）基于 2024 年前观察，后续研究对"涌现是否只是度量假象"有争议，作数量级参考。
