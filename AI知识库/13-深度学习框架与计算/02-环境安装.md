# 环境安装

> 来源：《动手学深度学习》（D2L）安装章节（wiki 化重写于 2026-11-03）

**一句话定义**：深度学习环境安装 = 用 Miniconda 隔离 Python 环境 → 按 GPU 有无安装对应版本的深度学习框架 → 配套安装辅助包与代码，即可跑通学习/实验代码。

深度学习实践的第一步不是写模型，而是搭一个可复现、不污染系统 Python 的运行环境。核心思路有三点：用 conda 做**环境隔离**（不同项目可绑定不同框架版本）；安装框架前先确认**硬件条件**（有无 NVIDIA GPU 及 CUDA 驱动，决定装 CPU 版还是 GPU 版）；最后安装课程/项目的配套包和示例代码，用 Jupyter Notebook 交互式运行。

## 标准安装流程（D2L 教程版）

### 1. 安装 Miniconda

从 Miniconda 官网下载对应操作系统的安装脚本并执行：

```bash
# macOS (Intel) / Linux，文件名随版本变化
sh Miniconda3-py39_4.12.0-MacOSX-x86_64.sh -b
sh Miniconda3-py39_4.12.0-Linux-x86_64.sh -b

# 初始化 shell，使 conda 命令可直接使用
~/miniconda3/bin/conda init
```

初始化后**关闭并重开终端**生效。

### 2. 创建并激活独立环境

```bash
conda create --name d2l python=3.9 -y   # 创建名为 d2l 的环境
conda activate d2l                       # 激活；退出用 conda deactivate
```

### 3. 安装框架（区分 CPU / GPU）

安装前先检查机器是否有 NVIDIA GPU 并装好 CUDA 驱动。没有 GPU 也能跑入门章节，但要完整实践建议尽早配置 GPU 并安装 GPU 版框架：

```bash
pip install torch==1.12.0
pip install torchvision==0.13.0
pip install d2l==0.17.6   # D2L 配套函数库
```

### 4. 下载示例代码并启动 Jupyter

```bash
mkdir d2l-zh && cd d2l-zh
curl https://zh-v2.d2l.ai/d2l-zh-2.0.0.zip -o d2l-zh.zip
unzip d2l-zh.zip && rm d2l-zh.zip
cd pytorch
jupyter notebook   # 浏览器打开 http://localhost:8888
```

## 经验与常见坑

- **每次使用前先 `conda activate d2l`**：跑书内代码、升级框架或 d2l 包之前都要激活环境，否则 pip 会装到错误的 Python 里。
- GPU 版安装失败多半是 CUDA 驱动与框架版本不匹配，先查驱动再选框架版本。
- Linux 下缺 `unzip` 用 `sudo apt install unzip` 安装。
- Windows 下需先把命令行定位到解压后的代码目录再运行 `jupyter notebook`。

## ⚠️ 时效性说明

- 本篇命令来自 D2L PyTorch 版（约 2022 年）：Python 3.9、PyTorch 1.12 / torchvision 0.13、d2l 0.17.6 均为当时的测试版本。**新项目请勿照搬这些版本号**，应以 PyTorch 官网当前版本的安装命令为准；现代实践也常改用 `uv`/`venv` 替代 conda。
- 流程思路（环境隔离 → 按硬件选版本 → 装配套包）仍然通用。
