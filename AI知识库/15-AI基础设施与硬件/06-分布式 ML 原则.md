# 分布式 ML 原则（Distributed ML Principles）

<p class="note-date">更新于 2026-11-05</p>

**一句话定义**：分布式机器学习的物理法则——五条不变量解释了为什么加 GPU 不总是线性提速、为什么通信而非计算常是隐藏瓶颈、为什么容错在大规模下是必需品而非奢侈品。

单机协调不需要解决的问题，在集群里全部出现：把模型切分到多设备能减轻内存压力，但必然增加同步权重的通信量；扩展到千节点能缩短训练时间，但 MTBF 同步下降，容错从运营奢侈品变成强制组件。工程本质是**并行化与协调的取舍**：硬件层拆解了"通信税"，本篇再叠加"规模可靠性税"。

## 核心原理：五条不变量

### 1. 普适扩展律

前沿模型的损失随算力、数据、参数按幂律改善：

```
L(C) ∝ C^(−γ)
```

由于损失**次线性**改善，每提升一档能力需要不成比例的更多算力。推论：在前沿能力上，规模是约束条件而非优化选项——收益递减正是从单机训练走向仓储级集群的根本驱动力。

### 2. 舰队定律（Fleet Law，分布式步时定律）

N 个 worker 完成一步训练的时间：

```
T_step(N) = T_compute/N + T_comm(N) + T_sync(N) − T_overlap
```

其中 0 ≤ T_overlap ≤ T_comm + T_sync。扩展效率是三项的赛跑：可并行计算（理想切分下随 N 缩小）、通信开销、同步开销。优化手段对应各术语——梯度累积改变有效 batch 与收敛区间、压缩降低通信量（可能引入数值误差）、通信隐藏与流水线化最大化重叠。

### 3. 带宽-延迟取舍（α-β 模型）

```
T(n) = α + n/β
```

小消息（如 MoE 路由元数据）延迟主导，大消息（梯度）带宽主导。优化须对症：**延迟主导区**合并小消息摊销 α，**带宽主导区**压缩大消息改善 β。

### 4. Young-Daly 检查点定律

最优 checkpoint 间隔平衡写入成本与故障重做损失：

$$\tau_{\text{opt}} = \sqrt{2 \cdot T_{\text{write}} \cdot \text{MTBF}_{\text{system}}}$$

checkpoint 不是免费的：集群越大 MTBF 越低，检查点必须越频繁，因此需要高带宽存储（burst buffer）防止 I/O 反噬训练时间。

### 5. 开销位移定律（Displacement of Overhead）

分布式系统的开销无法消灭，只能在计算、通信、协调（C3 三分法）之间**转移**：消掉一个必然抬高另一个。

- 异步训练消除协调栅栏（T_sync→0），但引入梯度陈旧性，表现为更多迭代次数（T_compute↑）。
- 流水线并行减少通信量，但增加流水线气泡时间（T_sync↑）。
- 分布式系统没有免费午餐，C3 分类法揭示账单落在哪里。

## 经验与常见坑

- **不要线性外推加速比**：Fleet Law 中通信与同步项不随 N 缩小，扩展收益天然递减。
- **容错随规模从可选变必选**：MTBF 与节点数成反比，万卡集群按小时级出故障设计。
- **每条优化都要问"开销搬去哪了"**：评估任何分布式技术时，用 C3 三分法找它新增的那一项成本。
