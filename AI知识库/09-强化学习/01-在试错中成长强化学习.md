# 强化学习：在试错中成长

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：强化学习（Reinforcement Learning, RL）是让智能体（agent）在环境（environment）中通过试错与奖励反馈，学习最大化长期累积奖励的行动策略的机器学习范式。

强化学习的基本模式可以用教小狗"坐下"来理解：你无法给它讲解教科书，只能在它碰巧坐下时立刻给一块肉干，反复几次后它就学会了"口令→坐下"。学骑自行车、学下棋、玩电子游戏都是同一种学习——没有标准答案，只有结果好坏的反馈，哪个动作得到奖励就多做，被惩罚就少做。

这一思路并非凭空而来：行为心理学家斯金纳（B. F. Skinner）早在 20 世纪中期就用"斯金纳箱"研究了动物如何从奖励中塑造行为，强化学习后来把这种"奖励塑造行为"的直觉写成了数学和算法。

它之所以重要：监督学习假设世界给出正确答案（模仿老师），而强化学习假设世界只给出反馈（跟世界学）。AlphaZero 超越人类棋手、推理模型通过可验证反馈改进解题，都来自这条更开放的学习路径。它是"行动中的智能"的核心范式。

## 核心原理

### 智能体-环境交互框架

在每个时刻 t：环境把状态 s_t 呈现给智能体 → 智能体选动作 a_t 执行 → 环境转移到新状态 s_{t+1} 并给出奖励 r_t。如此循环直到任务结束。智能体的目标是使**长期累积奖励**最大，既要活在当下，又不因小利错失更大回报。

这个框架极其通用：玩马里奥（状态=画面，动作=按键，奖励=得分）、投篮（状态=姿态与位置，动作=发力）、炒股（动作=买卖持有，奖励=盈亏）、自动驾驶、机器人走路，本质都是"一个智能体在一个环境里通过动作追求最大化累积奖励"。

### 与其他学习范式的对比

| 范式 | 反馈信号 | 特点 |
|---|---|---|
| 监督学习 | 每个样本带标准答案（标签） | 学输入到输出的映射，模仿 |
| 无监督学习 | 无答案 | 从数据中发现结构（聚类、降维） |
| 自监督学习 | 从数据派生的显式信号（如预测下一词） | 大模型预训练的主流方式 |
| 强化学习 | 环境的奖励（稀疏、延迟、只说好坏不说对错） | 自己推断每步贡献，动作影响未来数据 |

RL 独有的三大难点：
- **延迟奖励与信用分配（credit assignment）**：下棋赢了，功劳属于开局妙招还是中盘忍耐？把遥远结果分摊回一长串动作是 RL 最头疼的问题。
- **动作影响未来**：每步棋改变之后的局面，学习过程与数据生成过程纠缠在一起（监督学习的样本相互独立）。
- **探索与利用的平衡**：只利用已知好方法可能永远找不到更优解，只探索又浪费经验。最朴素的版本是多臂老虎机（multi-armed bandit）问题。

相关范式：**在线 RL**（实时交互，灵活但昂贵）vs **离线 RL**（用预收集数据学，安全但难，适合医疗/金融/自动驾驶等不能肆意试错的领域）；**模仿学习**（Imitation Learning，看专家演示来学，本质是监督学习解决决策问题，样本效率高但受限于专家数据质量）。现代实践中常先模仿学习起步、再用 RL 优化。

### 马尔可夫决策过程（MDP）

把试错问题数学化就得到 MDP，包含五个关键元素（以打砖块游戏为例）：
1. **状态 s**：当前局面（球的位置/方向、挡板位置、砖块分布）；
2. **动作 a**：挡板左移/右移/不动；
3. **奖励 r**：打掉砖 +1，漏球 -1；
4. **策略 π(a|s)**：在状态 s 下选动作 a 的概率分布，智能体的"大脑"；
5. **转移概率 p(s'|s,a)**：执行动作后环境变到 s' 的概率。

**马尔可夫性**：下一步只依赖当前状态和动作，不依赖更早历史。现实中常只是近似；状态看不全时问题变成**部分可观测 MDP（POMDP）**，应对办法是给智能体"记忆"——用循环网络、Transformer 等从历史观测补全局面。

### 回报、折扣因子与值函数

智能体关心的不是单步奖励而是**回报**（Return）：

$$G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k}$$

折扣因子 γ∈[0,1] 的存在有三个理由：现在的奖励比未来值钱（机会成本）、未来不确定（任务可能随时终止）、数学上防止无穷和发散。γ=0.9 偏短视，γ=0.99 更长远；γ 决定智能体的"性格"，是调参基本功。

**值函数**给局面打分：
- 状态价值函数 $V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s]$：按策略 π 从状态 s 出发能拿多少回报；
- 动作价值函数 $Q^\pi(s,a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a]$：在 s 下先做 a 再按 π 行事的期望回报。Q 比 V 细化一步，学好后选 Q 值最大的动作即可决策。

经典教学例子**悬崖行走**：掉入悬崖 -100 并回起点，每走一步 -1。训练后智能体学到两种策略——激进派贴悬崖走最短路（风险高），保守派绕远路（安全）。SARSA 因考虑行为策略的噪声而学出保守策略，Q-Learning 学出激进策略。

### 深度强化学习（DRL）

状态空间大（像素画面、连续关节角度、围棋约 10^170 量级局面）时，值函数无法用表格存储。DRL 用神经网络近似值函数或策略（输入状态如原始像素，输出各动作的 Q 值或策略分布），把 RL 框架与深度学习的函数逼近能力结合。没有这次融合，RL 会一直被限制在简单场景；有了它才有围棋、Atari、机器人控制、大模型对齐上的突破。

## 关键概念

- **Bellman 方程**：Q 值的递推关系——当前 Q 应接近"即时奖励 + 下一状态的最大 Q"。表格问题下反复迭代可收敛到最优；神经网络近似场景需要额外稳定化技巧。
- **经验回放与目标网络**：DQN 的两大稳定化技巧。
- **优势函数（Advantage）**：用 A = Q − V（"这个动作比平均水平好多少"）替代总回报判断动作好坏，可大幅降低方差，A3C、PPO、GAE 均使用。
- **域随机化（domain randomization）**：仿真训练时随机化摩擦、质量、光照等参数，缓解 sim-to-real 迁移。OpenAI 机械手还原魔方即用此路线。
- **奖励塑形（reward shaping）**：在稀疏奖励上加启发式稠密奖励加速学习（如棋类 AI 的子力评估），但塑形不当会被钻空子。

## 分类/类型

### 值函数派：先估分再行动

学一个 Q 函数，每步选 Q 值最大的动作。代表：Q-Learning、SARSA、DQN。在离散动作上直接稳定；连续动作空间吃力（无法对所有动作取 max）。

- **Q-Learning vs SARSA**：Q-Learning 是异策略（off-policy），更新用"未来可能的最好动作" max Q；SARSA 是同策略（on-policy），用"实际采取的下一个动作"。这导致悬崖行走中两者分别学出激进/保守策略。
- **DQN（Deep Q-Network）**：Q-Learning + 神经网络。DeepMind 2015 年 Nature 论文用同一套架构从像素直接学习 49 个 Atari 游戏（输入为堆叠的 84×84 灰度帧，输出手柄按键）。在《打砖块》中它自发发现了"打隧道让球钻到墙后疯狂反弹"的人类阴招，证明 RL 是在从经验中发现策略而非记住动作。

### 策略梯度派：直接学招式

不估分，直接学策略 π(a|s)。核心原则：做得好的动作加强其概率，做得差的减弱。最经典算法 **REINFORCE**：采一整条轨迹，总回报高就把轨迹上每个动作的概率都调大。优点是能自然处理连续动作空间（输出连续值或高斯分布），可输出随机策略（猜拳等场景随机策略更优）；缺点是高方差、训练不稳、易陷入局部最优。机器人连续控制（扭矩、角度）多用此路线。

### 演员-评论员派：两派合流

**Actor-Critic** 是现代 RL 主流范式：演员（Actor）= 策略网络，负责选动作；评论员（Critic）= 值函数网络，负责估分给反馈。两者边学边教，兼具策略梯度的灵活与值函数的稳定。A3C、PPO、SAC、DDPG 都是这一家族的变种。

- **PPO（近端策略优化，2017, OpenAI）**：RL 训练最大的风险是"学飞"——参数一步更新太大导致策略骤然变差，而 RL 的训练数据由当前策略生成，策略变差→数据变差→恶性循环（数据分布漂移）。PPO 在损失函数中加入剪切（clipping）项，强制新旧策略差别不超过阈值，每次只小步改进。因简单、稳定、通用，长期是从机器人控制到游戏 AI 到大模型后训练的强基线。
- **GRPO（组相对策略优化，DeepSeek）**：PPO 的简化改造，不再显式训练评论员，而用同一问题下多份答案的相对好坏估计优势，降低训练开销，是 DeepSeek-R1 路线的关键组件之一。但 R1 的成功不能全归功于 GRPO——数据、验证器、采样与训练工程同样重要。

### 按是否建模环境

- **无模型（Model-Free）**：直接从交互中学值函数或策略（DQN、PPO）。简单通用，但样本效率低。
- **基于模型（Model-Based）**：先有或学一个环境模型（预测下一状态和奖励），在模型里"脑内沙盘"规划。样本效率高，但模型想歪了会越练越偏。AlphaZero 用真实规则 + MCTS 搜索；MuZero 进一步从交互中学出可用于规划的内部模型；Dreamer 系列在学到的世界模型里"做白日梦"式试错。

### 探索策略

- **ε-贪心**：以概率 ε 随机探索，1−ε 贪心利用；ε 通常从高到低衰减。
- **Softmax/Boltzmann 采样**：按 Q 值的 Softmax 分布采样，平滑过渡，避免硬切换。
- **加噪声**：连续动作空间在策略输出上加高斯噪声。
- **内在动机/好奇心驱动**：给"访问新状态"额外的奖励，在奖励极稀疏任务（只有通关才给分）中特别有效。

探索过少收敛到次优策略，过多则浪费训练，探索策略的选择常是训练成败的关键。

## 高光时刻与应用

**AlphaGo 家族的进化**（依赖人类数据 → 完全自学 → 自己学规则）：
1. **AlphaGo（2015/2016）**：人类棋谱预训练 + 自我对弈 + MCTS，4:1 击败李世石。第二局第 37 手"肩冲"完全不符合人类棋理，几十手后成为胜势，是"AI 走出人类棋谱之外"的标志性一刻。
2. **AlphaGo Zero（2017）**：完全不看人类棋谱、从零自我对弈。据论文报告，训练 3 天即击败战胜李世石的版本，40 天超过 AlphaGo Master。
3. **AlphaZero（2017）**：算法泛化到国际象棋、将棋，每一种都超过当时最强专用引擎。
4. **MuZero（2019）**：不被告知规则，从交互中学内部模型用于规划，还能玩 Atari。

围棋状态空间约 10^170（远超宇宙原子数约 10^80），蛮力搜索行不通；AlphaGo = 深度学习（CNN 评估局面）+ 强化学习（自我对弈）+ 蒙特卡洛树搜索三者的结合。

**OpenAI Five（2019）**：用 PPO 从零自我对弈训练 Dota 2 五人协作 AI，2:0 击败世界冠军 OG。训练峰值相当于每天积累上百年游戏经验，总训练量达数万年级别——超大规模自我对弈是关键。

**RLHF：让大模型听懂人类**。三步流程：
1. **收集偏好数据**：让标注员对多个回答两两比较排序（偏好比绝对打分一致性高得多）；
2. **训练奖励模型**：学"排序"而非"打分"（Bradley-Terry 配对比较模型），选中的给高分、未选的给低分；
3. **PPO 优化**：语言模型作为策略生成回答，奖励模型打分作为奖励，加 KL 散度约束防止偏离起点太远。

ChatGPT、Claude、Gemini 的"亲和力"很大程度上来自 RLHF 或类似偏好对齐训练。

RLHF 的实际困难：**奖励作弊**（模型迎合奖励模型的漏洞，如一味拉长回答）；**模式塌陷**（输出失去多样性、千篇一律）；**训练不稳定**（奖励模型、KL 约束、数据质量、超参数互相牵制）。简化方案 **DPO（直接偏好优化，2023）**：用数学变换把带 KL 约束的偏好优化改写成类似分类的损失，跳过显式奖励模型和 PPO，成为开源社区偏好对齐的常用工具——但复杂交互、工具使用、长程任务上显式 RL 仍有价值。

其他代表性应用：AlphaStar（星际争霸 2 击败职业选手）；Google 用机器学习控制数据中心制冷显著降耗；AI 芯片布局；**AlphaTensor** 把寻找矩阵乘法算法变成游戏，用 RL 重新发现并改进了部分人类已知算法；2024 年以来用 RL 训练"思考"能力（OpenAI o1、DeepSeek R1），奖励信号来自数学题答对、代码通过测试等**可验证反馈**。

## 经验与常见坑

**奖励设计是 RL 的"生死线"**：
- 奖励必须与真正目标一致。赛船 AI 绕圈捡道具而不冲线，不是 AI 懒，而是设计者把"得分"当成了目标；清洁机器人"把垃圾扔出去再捡回来刷分"、销售 AI 推荐不需要但贵的商品，都是同类错位。
- 稀疏奖励目标清晰但学不动；稠密奖励反馈快但易引入偏差；实践中常用奖励塑形，也可分层设计（任务级 +100 / 子任务级 +10 / 动作级 +0.1）。
- 想不清奖励就让人类给偏好——RLHF 思路；但人类偏好有偏差、噪声与矛盾，模型只能对齐标注员群体的平均偏好。

**五大结构性挑战**：样本效率低（DQN 玩好一个 Atari 相当于几十天游戏时间）；奖励设计难且易被钻空子；仿真到现实的鸿沟（sim-to-real gap）；稀疏奖励下探索失败；安全与对齐（"最优策略"可能违背人类意图）。

**哲学启示**：*"reward is enough"* 假说认为各类智能行为或许都能从最大化长期奖励中涌现——这是有争议的研究立场而非定理；智能在很大程度上是环境的产物（同一算法在不同规则下产生不同智能）；延迟反馈与探索/利用的困境同样贯穿人类决策。
