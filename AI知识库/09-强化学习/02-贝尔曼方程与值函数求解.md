# 贝尔曼方程与值函数求解

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：贝尔曼方程把"一个状态的长期价值"写成"即时奖励加上后继状态价值的折扣和"的递推关系，它是几乎所有强化学习算法（动态规划、蒙特卡罗、时序差分、Q-Learning、DQN、Actor-Critic）共同的数学地基。

## 概述

[强化学习概览](01-在试错中成长强化学习.md)已经介绍了 MDP 五元组 $(s, a, r, p, \pi)$、回报与折扣因子的直觉。本篇往下挖一层：**有了 MDP 之后，怎么把"试错"变成可解的数学问题**。整条故事线是：

$$\text{贝尔曼方程（递推关系）} \rightarrow \text{动态规划（已知模型时求解）} \rightarrow \text{无模型方法（模型未知时估计）} \rightarrow \text{TD 学习与 Q-Learning}$$

贝尔曼方程的价值在于**把全局问题局部化**：不需要看完整条轨迹才知道一个状态值多少钱，只需要知道"走一步得到什么 + 下一状态值多少钱"。这一步分解，是强化学习区别于穷举搜索的核心。

## 核心原理

### 两个价值函数（承接概览篇）

- **状态价值函数**：按策略 π 从状态 s 出发的期望回报
  $$V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s]$$
- **动作价值函数**：在 s 下先做动作 a、再按 π 行事的期望回报
  $$Q^\pi(s,a) = \mathbb{E}_\pi[G_t \mid s_t = s,\ a_t = a]$$

两者关系：$V^\pi(s) = \sum_a \pi(a|s)\, Q^\pi(s,a)$。Q 比 V 细化一步——V 回答"这个局面怎么样"，Q 回答"这个局面下每步棋各值多少"，所以学会 Q 就能直接决策：**选 Q 最大的动作**。

### 贝尔曼期望方程

把回报定义 $G_t = r_t + \gamma G_{t+1}$ 代入期望，就得到递推：

$$V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} p(s'|s,a)\Big[r(s,a,s') + \gamma V^\pi(s')\Big]$$

$$Q^\pi(s,a) = \sum_{s'} p(s'|s,a)\Big[r(s,a,s') + \gamma\, \mathbb{E}_{a'\sim\pi} Q^\pi(s',a')\Big]$$

直觉读法：**"我在这里值多少 = 我这一步能拿多少 + 我去到的地方值多少（打折扣）"**。这是"期望"版本——描述的是"按策略 π 行事能拿多少"，策略本身不动。

### 贝尔曼最优方程

我们真正想要的是最优策略对应的价值。定义 $V^*(s) = \max_\pi V^\pi(s)$，则：

$$V^*(s) = \max_a \sum_{s'} p(s'|s,a)\Big[r(s,a,s') + \gamma V^*(s')\Big]$$

$$Q^*(s,a) = \sum_{s'} p(s'|s,a)\Big[r(s,a,s') + \gamma \max_{a'} Q^*(s',a')\Big]$$

与期望版的唯一区别是 $\max_a$ 替代了 $\sum_a \pi(a|s)$：**最优策略下，每一步都走当前最好的动作**。最优方程的妙处：它只关于 V 和 Q 自身，不含策略——解出 $Q^*$ 就同时解出了最优策略（argmax 即可）。在折扣因子 $\gamma < 1$ 的条件下，最优方程存在唯一解，这是整个 RL 收敛性的理论基石。

### 已知模型：动态规划求解

如果转移概率 $p$ 和奖励 $r$ 都已知（如棋类规则、仿真环境），贝尔曼方程就是一组可迭代的方程组，两大经典解法：

| | 策略迭代（Policy Iteration） | 值迭代（Value Iteration） |
|---|---|---|
| 循环结构 | 策略评估（解贝尔曼期望方程到收敛）→ 策略改进（贪心 argmax）交替 | 每步直接用贝尔曼**最优**方程做一次 max 更新 |
| 每轮成本 | 评估要多次扫描，但策略通常几轮就收敛 | 每轮只扫一遍，总体迭代次数多一些 |
| 适用 | 策略空间小、评估便宜的问题 | 大状态空间下的工程默认 |

两者殊途同归：都收敛到 $V^*, \pi^*$。动态规划的局限也很明显——**现实中 $p(s'|s,a)$ 通常未知**（你知道围棋规则，但不知道"用户会怎么回复"），且对大状态空间做全量扫描不现实。这把舞台让给了无模型方法。

## 关键概念

### 无模型三兄弟：MC、TD、Q-Learning

模型未知时，只能从采样数据估计价值。三种估计思路构成一条递进链：

**蒙特卡罗（MC）**：跑完整条轨迹，用实际回报 $\hat{G}_t$ 作为 $V(s_t)$ 的估计。无偏，但要等一整局结束才能学——下棋赢了才知道前面每步的"存款余额"，方差极大。

**时序差分（TD）**：核心洞察是不用等结局，**用"下一步的估计"bootstrapping 自己**。TD 误差：

$$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$$

更新：$V(s_t) \leftarrow V(s_t) + \alpha\, \delta_t$，其中 α 是学习率。直觉：$\delta_t$ 就是"预期与现实（往前看一步）的差"，用它修正当前估计。TD 有偏（依赖尚不准的 $V(s_{t+1})$）但方差小、可在线更新、无需等终止——它是 RL 的" SGD 时刻"。

**Q-Learning**：把 TD 思想搬到 Q 函数上，并用 $\max$ 替换对下一动作的期望，直接估计 $Q^*$：

$$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha\Big[\underbrace{r_t + \gamma \max_{a'} Q(s_{t+1},a')}_{\text{TD 目标}} - Q(s_t,a_t)\Big]$$

在表格型问题、满足采样充分等条件时，Q-Learning 保证收敛到 $Q^*$（Watkins, 1989；收敛证明是 RL 理论的经典结果）。

### 同策略与异策略（on-policy / off-policy）

Q-Learning 更新里的 $\max_{a'}$ 用的是"**未来可能的最好动作**"，而智能体实际探索时可能走的是别的动作——**学习的东西 ≠ 行为的东西**，这叫异策略（off-policy）。SARSA 则用"**实际采取的下一个动作**" $Q(s_{t+1}, a_{t+1})$，学什么就做什么，同策略（on-policy）。

后果在[悬崖行走](01-在试错中成长强化学习.md)例子中最直观：Q-Learning 学出贴悬崖的最短激进路径（它学的是"理想化最优"，不含探索噪声）；SARSA 把 ε-贪心探索的失足风险算进了 Q 值，学出绕远路的保守策略。两者都"对"，取决于你要理想最优还是鲁棒最优。

### 探索与利用：ε-贪心及其变体

再好的求解框架，也要回答"采样时去哪"：

- **ε-贪心**：以概率 ε 随机选动作，以 $1-\epsilon$ 选当前 Q 最大动作。ε 常从高（如 1.0）衰减到低（如 0.01），先多探索后多利用。简单、常用，但探索是"瞎探索"（不区分动作好坏）。
- **Softmax / Boltzmann**：按 $Q$ 值的 softmax 分布采样，好动作概率大但都保留机会，避免硬切换。
- **乐观初始化**：把所有 Q 初值设偏高，逼着智能体先把每个动作试一遍（"没试过的大概很好"）。
- **内在动机 / 好奇心**：给"访问未见状态"发额外奖励，解决极稀疏奖励下"永远撞不到正反馈"的探索死局。

ε-贪心 + Q-Learning 的组合有一个优雅性质：只要每个 (s,a) 对被无限次访问且学习率满足 Robbins-Monro 条件，就收敛到 $Q^*$——**探索保证了数据覆盖，TD 更新保证了收敛**。

## 术语表

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| 贝尔曼期望方程 | Bellman expectation equation | 按固定策略 π 时价值的递推关系，用于策略评估 |
| 贝尔曼最优方程 | Bellman optimality equation | 最优价值的递推关系，内含 max 算子，解出即得最优策略 |
| 策略迭代 | Policy Iteration | "评估到收敛 + 贪心改进"交替的 DP 解法 |
| 值迭代 | Value Iteration | 每步用最优方程 max 更新的 DP 解法 |
| 自举 | Bootstrapping | 用自己的估计值（如 $V(s_{t+1})$）更新另一个估计，TD 的核心特征 |
| TD 误差 | TD error | $\delta_t = r + \gamma V(s') - V(s)$，预期与一步现实之差 |
| 同策略 | On-policy | 行为策略与被评估/改进的策略是同一个（SARSA） |
| 异策略 | Off-policy | 从一个探索性策略的数据中学另一个目标策略（Q-Learning、DQN） |
| Robbins-Monro 条件 | — | 学习率序列满足 $\sum \alpha_t = \infty, \sum \alpha_t^2 < \infty$，保证随机逼近收敛 |

## 经验与常见坑

- **γ = 1 的陷阱**：无折扣只在任务保证终止时可用；环形状态 + γ=1 会让贝尔曼方程无界，迭代直接发散。有截断式终止（如时间上限）时另说。
- **TD 目标别求梯度**：深度 RL 中 $r + \gamma \max Q(s',a';\theta)$ 是"回归目标"而不是损失的一部分，对它停止梯度是 DQN 及其后继的通用纪律——把目标也放进梯度会让训练追逐自己的影子。
- **自举 vs 无自举的取舍**：MC 无偏高方差，TD 有偏低方差。n-step 返回和 TD(λ) 是两者之间的滑杆；实践中 TD 类（自举）通常赢在样本效率，但在值函数不准时会传播偏差。
- **off-policy ≠ 免费**：Q-Learning/DQN 可以重用旧数据，但数据分布与当前策略差太远时，max 外推会把 Q 值越估越高（overestimation），这正是 Double Q-Learning / Double DQN 要治的病。
- **DP 仍有用武之地**：规则已知的博弈、仿真控制里，值迭代/策略迭代至今是基线；AlphaZero 的 MCTS 本质上也是"在已知规则模型里做规划"的近亲。

## ⚠️ 时效性说明

贝尔曼方程（1957，Bellman）与 TD 学习（1988，Sutton）是稳定四十年的经典数学，无时效问题。工程细节（学习率调度、ε 衰减节奏）随任务而变。注意：本篇讲的是**表格型/已知模型**的经典框架；神经网络近似下这些收敛保证不再严格成立，稳定化技巧见[经典强化学习算法谱系](03-%E7%BB%8F%E5%85%B8%E5%BC%BA%E5%8C%96%E5%AD%A6%E4%B9%A0%E7%AE%97%E6%B3%95%E8%B0%B1%E7%B3%BB.md)。
