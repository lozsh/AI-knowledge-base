# 计算机视觉

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：计算机视觉（CV）让机器从图像中"看出"内容——分类之外，还包括目标检测（是什么 + 在哪里）、语义分割（每个像素属于什么）、风格迁移（换画风）等任务，深度 CNN 是这些任务的主流技术底座。

本条目覆盖把 CNN 从图像分类推向下游任务的完整技术栈：先讲提升泛化的两件通用武器（图像增广、微调），再讲目标检测的关键机制（边界框、锚框、IoU、NMS）及代表模型（SSD、R-CNN 系列），然后是语义分割（转置卷积、FCN）、风格迁移，最后是两个 Kaggle 实战套路。

## 关键概念

### 图像增广（data augmentation）

对训练图像做随机变换，生成"相似但不同"的样本，降低模型对位置、颜色等属性的依赖。对 AlexNet 的成功必不可少。常用方法：

- **翻转**：随机左右翻转最常用；上下翻转视语义而定（如文字、天/地场景不可用）。
- **随机裁剪**：随机裁出原始面积 10%~100%、宽高比 0.5~2 的区域再缩放，降低对目标位置的敏感度（与池化的作用互补）。
- **颜色扰动**：随机改亮度、对比度、饱和度、色调（ColorJitter）。
- **组合**：用 Compose 串联多种增广。

实践要点：**只在训练时用随机增广，预测时用确定性预处理**。CIFAR-10 上用随机左右翻转训练 ResNet-18（Adam，lr=0.001）：test acc 0.854。

### 微调（fine-tuning / 迁移学习）

目标数据集通常远小于 ImageNet（收集标注昂贵），而预训练模型的浅层特征（边缘、纹理、形状）是通用的。微调四步：

1. 在源数据集（ImageNet）上预训练得到源模型；
2. 目标模型复制源模型的全部设计与参数，**输出层除外**（输出层与源标签绑定）；
3. 新建随机初始化的输出层，类别数 = 目标类别数；
4. 在目标数据集上训练：输出层从头学，其余层微调。

关键技巧：微调层用**小学习率**，新输出层用 **10 倍学习率**。热狗识别实验（ResNet-18，仅千余张图）：微调 test acc **0.939**，从头训练仅 0.843。另一变体是**冻结特征层**（requires_grad=False）只训新输出头，更省时省显存。ImageNet 预训练模型的标配预处理：RGB 各通道减均值 (0.485, 0.456, 0.406)、除标准差 (0.229, 0.224, 0.225)。

### 目标检测基础：边界框、锚框、IoU

目标检测 = 同时输出类别与位置。**边界框**（bounding box）两种等价表示：左上-右下角坐标 (x1,y1,x2,y2) 与中心+宽高 (cx,cy,w,h)，可互相换算。

**锚框**（anchor box）：以每个像素为中心，按缩放比 s∈(0,1] 和宽高比 r>0 生成候选框（宽 hs√r、高 hs/√r）。全部组合会产生 whnm 个框，计算爆炸，实践只取含 s1 或 r1 的组合，每像素 n+m−1 个。

**交并比（IoU）**：两框交集面积 / 并集面积（即杰卡德系数），取值 [0,1]，是衡量框相似度的通用指标。

**训练标注**：给每个锚框分配真实边界框——贪心算法：反复取 IoU 矩阵中的最大元素完成分配并删除对应行列，直到每个真实框都被分配；剩余锚框仅当其最大 IoU 超过阈值（如 0.5）才分配，否则标为**背景（负类）**。每个正类锚框标两个标签：类别 + **偏移量**（对中心差和宽高比做变换：`(xB−xA)/wA/σx` 与 `log(wB/wA)/σw`，默认 σx=σy=0.1、σw=σh=0.2，使偏移分布更均匀易拟合）。掩码变量保证负类偏移不参与损失。

**非极大值抑制（NMS）**：预测时大量重叠框指向同一目标。按置信度降序排列，每次取最高者作基准，删除与其 IoU 超阈值的其余框，重复直到处理完，输出互不相似的框。（改进方向：Soft-NMS 用衰减代替硬删除。）

### 多尺度检测

以每像素生成锚框代价太高（561×728 图、每像素 5 框即 200 万+）。替代方案：利用 CNN 的**分层特征图**——小目标用大特征图上的小锚框多采样，大目标用小特征图上的大锚框少采样。同一空间位置的特征图单元感受野相同，恰好可用来预测以该位置为中心的锚框；深层特征图感受野大，天然对应大目标。

## 分类/类型

### 目标检测模型

**SSD（单发多框检测）**：基础网络（如截断的 VGG/ResNet）+ 多个多尺度特征块串联，每个尺度同时生成锚框并预测其类别与偏移量。类别预测层是保持分辨率的 3×3 卷积，输出通道数 = a(q+1)（a 为每单元锚框数，q 为类别数，含背景）；边界框预测层输出 a×4 通道。训练损失 = 类别交叉熵 + 偏移 **L1 损失**（掩码过滤负类）。改进选项：平滑 L1 损失（零点附近二次、其余线性）、**焦点损失** `−α(1−pj)^γ log pj`（压低易分样本权重，聚焦难例）。教材 TinySSD（输入 256×256）在 5 个尺度上共生成 5444 个锚框。

**R-CNN 系列**（两阶段路线）：

| 模型 | 核心改进 | 瓶颈 |
|---|---|---|
| R-CNN (2014) | 选择性搜索选约 2000 个提议区域，每个区域单独过 CNN 抽特征，再分别训 SVM 分类器 + 线性回归回归框 | 每区域一次前向传播，计算量巨大，慢 |
| Fast R-CNN (2015) | 整图只做一次 CNN 前向传播；引入 **RoI 池化层**把形状各异的提议区域特征统一到固定尺寸（划分 h2×w2 子窗口各取最大值，输出形状直接指定，区别于普通池化） | 提议区域仍靠选择性搜索（外部组件） |
| Faster R-CNN (2015) | 用**区域提议网络（RPN）**端到端地替换选择性搜索：3×3 卷积 + 每像素多锚框，预测"含目标/背景"二分类与框，NMS 后得到提议区域 | 精度与速度兼顾 |
| Mask R-CNN (2017) | RoI 池化 → RoI 对齐（双线性插值保留空间信息），额外接全卷积网络预测像素级掩码，支持实例分割 | — |

### 语义分割与全卷积网络

三个易混概念：**图像分割**只按像素相关性分组、无语义保证（可能把狗分成"黑嘴"和"黄身"两块）；**语义分割**给每个像素分语义类别；**实例分割**还要区分同一类别的不同个体（两条狗分属两个实例）。

**Pascal VOC2012** 是最重要的语义分割数据集之一（21 类，标签是同尺寸彩色图，颜色即类别）。预处理特点：输入与标签像素一一对应，所以**用随机裁剪（裁相同区域）而非缩放**；尺寸不足的样本过滤掉。

**转置卷积**（transposed convolution）：常规卷积用核"缩小"输入，转置卷积用核"广播"输入以放大特征图，逆转下采样。要点：

- 填充作用于**输出**（padding=1 会裁掉输出边缘），步幅作用于中间结果；步幅 s、填充 s/2、核 2s 时恰把高宽放大 s 倍。
- 与同超参数的卷积层 f 组合（g 为对应转置卷积），g(f(X)) 恢复 X 的形状（数值不同）。
- 名字来源：卷积可写成矩阵乘 y=Wx，转置卷积即乘 W⊤，等价于交换卷积的正反向传播。

**FCN（全卷积网络）**：预训练 ResNet-18 去掉全局池化与全连接 → 1×1 卷积把通道变到类别数（21）→ 转置卷积（stride 32, kernel 64, padding 16）恢复到输入尺寸，输出通道即对应像素的类别预测。转置卷积层用**双线性插值核初始化**（等效于经典上采样），训练效果远好于随机初始化。VOC 上训练 5 epoch：test acc 0.848。

### 风格迁移

将风格图像的画风应用于内容图像（Gatys et al., 2016）。**合成图像是唯一被更新的"模型参数"**，预训练 VGG-19 冻结抽特征：靠近输出的层（实验取第 25 层）作内容层，各卷积块首层（0,5,10,19,28）作风格层。损失 = 三项加权和：

1. **内容损失**：内容特征上的平方误差；
2. **风格损失**：风格层输出经**格拉姆矩阵**（通道两两内积，除以元素数归一化）表达通道间相关性，比较合成图与风格图的格拉姆矩阵平方误差；
3. **全变分损失**：Σ|xi,j − xi+1,j| + |xi,j − xi,j+1|，抑制高频噪点。

实验权重 content:style:tv = 1 : 1e3 : 10，Adam 500 轮。这是后来生成式模型（扩散模型等）"图像到图像"创作的思想先声。

## 经验与常见坑

- **验证集不打乱、不加随机增广**；调参选好模型后，最终提交前要把训练集与验证集合并重新训练，用尽全部标注数据。
- 增广强度与图像尺寸匹配：CIFAR-10（32×32 小图）用 Resize(40)+随机裁剪回 32；ImageNet 系大图（224×224）用 scale=(0.08,1)、宽高比 3/4~4/3 的随机裁剪 + 颜色扰动。
- 狗品种识别实战套路：数据集是 ImageNet 子集 → 预训练 ResNet-34 冻结特征 + 自定义输出头（Linear 1000→256→120），只训输出头，省时省显存。
- 目标检测的批处理要求每图边界框数量一致：不足的用非法框填充（类别 −1，掩码过滤）。
- FCN 预测整图时，若尺寸不能被 32 整除，可裁成 32 倍数的块分别前向，重叠区域取输出平均。

## ⚠️ 时效性说明

- SSD、R-CNN 系列是 2014-2017 年的经典方法，工业界至今仍在用 Faster R-CNN/Mask R-CNN，但实时场景已大量让位于 YOLO 系列、DETR（Transformer 检测器，见 [[../06-注意力机制与Transformer/03-Transformer 架构.md]]）。
- 手写 NMS/RoI 池化等实现仅作教学示意；实际项目直接用 torchvision.ops 等框架 API。
- Gatys 式风格迁移（逐图优化合成图像）很慢，已被前馈式风格化网络与扩散模型取代（见 [[../10-生成式模型与多模态/01-扩散模型.md]]）。
- 教材中 `pretrained=True` 的 torchvision 加载方式在新版本中已改为 `weights=...` 写法。
