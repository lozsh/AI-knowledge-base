# 现代卷积神经网络

<p class="note-date">更新于 2026-11-05</p>

**一句话定义**：现代 CNN 是从 AlexNet（2012）到 ResNet/DenseNet 的一系列里程碑架构，每个模型都曾主导计算机视觉，多数是 ImageNet 竞赛（2010 年起，监督学习进展的风向标）优胜者，其演进脉络是"更深、更简洁、更易训练"。

LeNet 证明了 CNN 可行，但在 1990 年代初到 2012 年间，神经网络多数时候被 SVM 等方法超越。传统视觉流水线依赖手工特征（SIFT、SURF、HOG、visual words bag），领域共识是"数据与特征比学习算法更重要"。2012 年 AlexNet 一举打破格局，归因于两个长期缺失的成分：

- **数据**：2009 年李飞飞团队发布 ImageNet（100 万张图、1000 类，Google 图搜预筛 + 亚马逊众包标注），规模前所未有。
- **硬件**：CNN 的计算瓶颈（卷积、矩阵乘法）天然可并行，与 GPU 的高吞吐矩阵运算高度契合。GPU 由数百至上千个小核组成（NVIDIA 按 warp 分组），靠核心数量取胜——Ampere 架构单芯片达 312 TFlops，而 CPU 至今不足 1 TFlops；且功耗随时钟频率呈二次方增长，多小核比少大核划算，GPU 内存带宽也高约 10 倍。AlexNet 原版用两块 3GB 显存的 GTX580 训练。

## 分类/类型（按时间线）

### AlexNet（2012）—— 深度学习的引爆点

首个在大规模视觉竞赛中击败手工特征方法的大型网络，8 层（5 卷积 + 3 全连接）。与 LeNet 的关键差异：

- **更深更宽**：卷积核 11×11（ImageNet 图像比 MNIST 大 10 倍以上）→ 5×5 → 3×3；通道数是 LeNet 的 10 倍。
- **ReLU 取代 Sigmoid**：Sigmoid 在输出接近 0/1 时梯度几乎为 0（饱和区），参数初始化不当时训练失效；ReLU 正区间梯度恒为 1，计算也更简单。
- **容量控制**：两个 4096 维全连接层（参数近 1GB，原版需双 GPU 分摊，现代显存已不需要）配 Dropout(0.5)；训练时用大量数据增强（翻转、裁切、变色）。

Fashion-MNIST 上测试（图像放大到 224×224）：test acc 0.883。AlexNet 代码只比 LeNet 多几行，但学术界花了很多年才接受这一结果。

### VGG（2014）—— 块设计的开端

牛津 VGG 组提出，核心思想是用**可复用的块**构造网络（类比芯片设计中晶体管 → 逻辑元件 → 逻辑块）。VGG 块 = 若干 3×3 卷积（padding 1，保持分辨率）+ ReLU + 2×2 最大池化（步幅 2，分辨率减半）。VGG-11 配置：5 个卷积块，通道逐块翻倍 64→128→256→512→512，卷积层数 (1,1,2,2,2)，后接与 AlexNet 相同的全连接块。

关键发现：**深层窄卷积（多层 3×3）优于浅层宽卷积**。Fashion-MNIST 上通道数 ÷4 的简化版 test acc 0.920（优于 AlexNet），但计算量和显存需求大得多。

### NiN（2013）—— 去掉全连接层

网络中的网络（Network in Network）针对"卷积提特征 + 全连接处理"这一共同模式提出：在每个像素位置用 1×1 卷积充当**逐像素全连接层**，为网络增加每像素非线性。NiN 块 = 1 个普通卷积 + 2 个 1×1 卷积（各带 ReLU）。模型末端完全取消全连接层：最后一个 NiN 块输出通道数 = 类别数，接**全局平均汇聚层**直接生成 logits——显著减少参数、缓解过拟合，但训练时间可能变长。深刻影响了后续设计（GoogLeNet、ResNet 的收尾方式都源于此）。Fashion-MNIST test acc 0.790。

### GoogLeNet（2014）—— 并行多尺度

回答"多大卷积核最合适"：不如都用。**Inception 块** = 4 条并行路径，输出在通道维连结：

1. 1×1 卷积
2. 1×1 卷积降通道 → 3×3 卷积
3. 1×1 卷积降通道 → 5×5 卷积
4. 3×3 最大池化 → 1×1 卷积调通道

中间两条路径先用 1×1 卷积压通道以降低复杂度。整个网络 9 个 Inception 块分 3 个模块串联（通道分配比 64:128:32:32 等来自 ImageNet 大量实验），末端同 NiN 用全局平均池化。以较低计算复杂度达到当时最优精度，一度是 ImageNet 上最有效的模型族。Fashion-MNIST（96×96 输入）test acc 0.886。

### ResNet（2015）—— 残差连接

何恺明等提出，夺得 2015 年 ImageNet 冠军，是计算机视觉中最流行的架构。理论动机：只有当更复杂的函数类**嵌套**包含较简单的函数类时（F1 ⊆ F2 ⊆ …），加深网络才保证不劣化；让新增层容易学成恒等映射 f(x)=x 即可实现这一点。

**残差块**：两个 3×3 卷积（各接 BN + ReLU），输入跳过卷积直接加在最后 ReLU 之前，网络只需拟合**残差映射 f(x)−x**（拟合恒等映射时把权重学成 0 即可，远比直接拟合 f(x) 容易）。通道数或分辨率变化时，用额外的 1×1 卷积（步幅 2）调整输入形状再相加。

ResNet-18：7×7 卷积(stride 2) + 最大池化开头，4 个模块各 2 个残差块（通道 64→128→256→512，模块间空间减半），全局平均池化收尾。Fashion-MNIST test acc 0.893。后续版本把"卷积-BN-激活"改为"BN-激活-卷积"（pre-activation），更深层用 bottleneck 结构。

### DenseNet（2017）—— 稠密连结

ResNet 的逻辑扩展（类比泰勒展开：ResNet 只取线性项 + 非线性项，DenseNet 保留所有高阶项）：跨层连接不做相加，而是在**通道维连结**：`x → [x, f1(x), f2([x, f1(x)]), …]`，每层与之前所有层相连。

- **稠密块**：卷积块采用"BN-ReLU-卷积"顺序，每块输出固定通道数，称为**增长率**（growth rate，典型 32），块内通道线性累加。
- **过渡层**：1×1 卷积减半通道 + 步幅 2 平均池化减半分辨率，控制复杂度。

优点：参数比 ResNet 小；缺点：显存消耗大、计算成本高。Fashion-MNIST test acc 0.885。

## 核心概念：批量规范化（Batch Normalization）

Google 研究员 Ioffe & Szegedy 于 2015 年提出（随 GoogLeNet 工作），使训练 100 层以上网络成为可能。动机：输入特征标准化（均值 0 方差 1）对训练至关重要，但中间层输出的分布随训练漂移、量级不稳。做法是在**每次训练迭代中用当前小批量统计量标准化**，再做可学习的缩放与偏移：

$$\mathrm{BN}(x) = \gamma \odot \frac{x - \hat{\mu}_B}{\sqrt{\hat{\sigma}_B^2 + \epsilon}} + \beta$$

- µ̂_B、σ̂_B 为小批量均值/标准差；γ（拉伸）、β（偏移）为可学习参数，初始化为 1 和 0。
- 全连接层：置于仿射变换与激活之间，`h = φ(BN(Wx+b))`；卷积层：置于卷积后、激活前，**每个通道独立**做 BN（在 m·p·q 个元素上统计）。
- 训练模式用小批量统计（引入噪声，实际起到正则化作用），**预测模式用移动平均估计的全量统计**——与 Dropout 一样是训练/预测行为不同的层。
- 批量大小很关键：batch=1 时减均值后全为 0，学不到东西；实践中 50~100 的中等批量最有效。

"减少内部协变量偏移"这一原始解释后来广受质疑（用词不当、只是模糊直觉）；2017 年 NeurIPS Test of Time Award 演讲曾以此批评深度学习实践如"炼金术"。但 BN 的有效性毋庸置疑，几乎所有图像分类器都在用。加了 BN 的网络可以用大得多的学习率（BN-LeNet 实验中 lr 从 0.9 提到 1.0 仍稳定，且可删去卷积层偏置参数）。

## 经验与常见坑

- **通用设计范式**：开头大卷积核快速降分辨率 → 中段堆块（空间递减、通道递增）→ 全局平均池化 → 全连接输出。
- 复现论文架构做小数据实验时，通道数按比例缩减（如 ÷4）、输入分辨率降低（96 或 224）是常用手段。
- 入门教学常用的 Fashion-MNIST 快速对照（10 epoch）：VGG-11 0.920 > ResNet-18 0.893 > GoogLeNet 0.886 > DenseNet 0.885 > AlexNet 0.883 > NiN 0.790。
- 高级 API 的 BatchNorm 实现比手写版快数倍（编译为 C++/CUDA）。

## ⚠️ 时效性说明

- GoogLeNet 原版省略了后续补充的稳定训练组件；原论文的"内部协变量偏移"解释已不被视为 BN 有效的原因。
- 2020 年后 Vision Transformer（见 [[../06-注意力机制与Transformer/03-Transformer 架构.md]]）在大规模数据上与 CNN 分庭抗礼，但 ResNet 系仍是工业界视觉骨干网络的默认起点；BN 在小批量/检测等场景也常被 GroupNorm、LayerNorm（见 [[../06-注意力机制与Transformer/03-Transformer 架构.md]]）替代。
