# 图像增广与迁移学习实践

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：图像增广用随机变换"凭空"扩充训练样本的多样性，微调把 ImageNet 级预训练学到的通用视觉特征迁移到小数据集——两者是小数据视觉项目的第一组合拳，通常比换模型结构收益更大。

[计算机视觉](03-计算机视觉.md)已给出两种技术的概要与实验数字，本篇深化：每种增广手段的适用边界与失效场景、增广的"训练/预测不对称"原则、微调生效的特征层级解释、学习率分组与冻结的工程细节、以及一套可执行的实践清单。

## 核心原理

### 1. 图像增广：手段清单与适用边界

增广的本质是**向数据注入"类别不变"的先验**：变换后的图像标签不应改变。每种手段都对应一条先验假设，假设不成立就会伤精度。

| 手段 | 注入的先验 | 何时不可用 |
|---|---|---|
| 随机左右翻转 | 类别与左右无关 | 文字、logo、有朝向语义的目标（如区分左右鞋） |
| 随机上下翻转 | 类别与上下无关 | 几乎所有自然图像（天/地、建筑、动物都有重力方向） |
| 随机裁剪（面积 10%~100%、宽高比 0.5~2 再缩放） | 目标位置/尺度不应敏感 | 目标本身很小或依赖与背景的相对位置时慎用强裁剪 |
| 亮度/对比度扰动 | 光照条件不影响类别 | 医学影像等依赖绝对灰度的任务 |
| 饱和度/色调扰动 | 颜色不影响类别 | 以颜色为核心特征的任务（成熟度判断、皮肤病变） |

机制上，随机裁剪与池化互补：池化让卷积特征对小的平移不敏感，裁剪则直接生成目标处于不同位置的样本。**组合用 `Compose` 串联**（翻转 + 颜色扰动 + 形状扰动叠加，样本多样性指数级增长）。

### 2. 训练/预测不对称原则

- **训练**：只用随机增广；**预测**：用确定性预处理（固定缩放 + 中心裁剪）。预测时混入随机性会让评估不可复现。
- 数据集选择的对照实验设计：Fashion-MNIST 的目标位置和大小已规范化（增广收益小），CIFAR-10 的颜色、尺度差异明显（增广收益大）——教材用后者演示：ResNet-18 + 随机左右翻转 + Adam(lr=0.001)、10 epoch，test acc 0.854。
- 增广强度与图像分辨率匹配：CIFAR-10（32×32 小图）先 `Resize(40)` 再随机裁回 32；ImageNet 系 224×224 大图用 `scale=(0.08,1)`、宽高比 3/4~4/3 的随机裁剪 + 全套颜色扰动。
- **只在训练集上做随机增广**；验证/测试集不打乱、不做随机变换，否则模型选择会被噪声误导。

### 3. 微调为什么有效：特征层级解释

CNN 的特征是分层的（见[现代CNN模型演进详解](04-%E7%8E%B0%E4%BB%A3CNN%E6%A8%A1%E5%9E%8B%E6%BC%94%E8%BF%9B%E8%AF%A6%E8%A7%A3.md)）：

- **浅层**学边缘、颜色、纹理——几乎所有视觉任务通用；
- **中层**学部件组合（眼睛、轮子、叶脉）——大部分通用；
- **深层**学完整物体语义——与源任务（ImageNet 1000 类）绑定，迁移性弱。

因此微调的默认策略是：**复制源模型全部设计与参数（输出层除外），新输出层随机初始化从头学，其余层以小学习率微调**。目标数据集越小，这个策略相对从头训练的优势越大（从头训练还会因数据不足而过拟合）。

### 4. 微调的工程细节

- **学习率分组**：微调层用小学习率 $\eta$（如 5e-5），新输出层用 $10\eta$——预训练参数已在好的解附近，大学习率反而把它推离；新层是随机初始化，需要大步快走。
- **冻结变体**：特征层 `requires_grad=False` 只训输出头。更省时间显存、防止小数据把通用特征带偏，是数据极小或算力紧张时的首选（也是"线性探测"评估预训练质量的方法）。
- **预处理必须与预训练一致**：ImageNet 预训练模型的标配是 RGB 各通道减均值 (0.485, 0.456, 0.406)、除标准差 (0.229, 0.224, 0.225)——这是 ImageNet 训练集统计量，换了自己的均值方差通常掉点。
- **输入尺寸**：训练时随机裁剪到 224×224（随机面积与宽高比再缩放）；测试时缩放到 256 再中心裁 224（测试侧确定性）。
- 热狗识别对照实验（ResNet-18，仅千余张图，权重衰减 0.001）：微调 test acc **0.939** vs 从头训练 **0.843**；且从头训练要用 10 倍学习率仍明显更差。

### 5. 实践清单（按顺序检查）

1. 数据 < 1 万张 → 优先考虑微调而非从头训练；
2. 训练集做随机增广（左右翻转 + 随机裁剪为底线，再按语义加颜色扰动），验证/测试只做确定性预处理；
3. 用预训练模型对应的 Normalize 参数与输入尺寸；
4. 分参数组：骨干 lr = η，新头 lr = 10η；数据极小则冻结骨干；
5. 增广越多训练集"表观损失"越高是正常现象，以验证集为准；
6. 调参定稿后，把训练集与验证集合并、用同样配置重训，再提交/上线（用尽全部标注数据）。

## 关键概念

| 术语 | 含义 |
|---|---|
| 图像增广 | 对训练图像做随机变换生成"相似但不同"的样本，提升泛化 |
| 类别不变变换 | 变换不改变标签的先验；每种增广手段对应一条，失效即伤精度 |
| 微调 | 复制预训练参数（除输出层）并小学习率继续训练的迁移学习方式 |
| 学习率分组 | 微调层小 lr、新输出层大 lr（常用 10 倍）的分参数组训练 |
| 冻结特征层 | `requires_grad=False` 只训新头，防小数据带偏通用特征 |
| ImageNet 标准化 | 均值 (0.485,0.456,0.406)、标准差 (0.229,0.224,0.225)，预训练模型配套 |
| 确定性预处理 | 预测阶段固定缩放 + 中心裁剪，保证结果可复现 |

## 经验与常见坑

- **增广不是越多越好**：每条增广都是先验假设，在任务语义上不成立的变换（如给数字识别加上下翻转）会直接损失精度；先加安全的（翻转、轻裁剪），逐项验证收益。
- 随机裁剪的 `scale` 下限不宜过小（大图 0.08 是实践值）：裁出太小的碎片可能完全丢失目标。
- 微调时忘了替换/重置输出层是常见错误——输出层带着源任务（1000 类）的记忆，必须重新随机初始化到目标类别数。
- 用了预训练模型却自己"发明"归一化参数（比如直接除 255、不搞清 RGB/BGR 通道序），是掉点的隐形坑。
- 评估阶段误开 `shuffle=True` 或随机增广，会导致每次评估结果不同、无法判断改动是否有效。
- 小数据集上"训练损失高于验证损失"是增广的正常表现，不是 bug；判断过拟合看验证曲线。

## ⚠️ 时效性说明

- 本篇方法至今是视觉实践标准配置；近年的扩展方向（RandAugment、MixUp/CutMix 等自动/混合增广）不在原书范围。
- 微调思想在大模型时代发展为"预训练-适配"范式（提示学习、LoRA 等参数高效微调，见 [../12-模型训练与优化/08-模型后训练.md](../12-%E6%A8%A1%E5%9E%8B%E8%AE%AD%E7%BB%83%E4%B8%8E%E4%BC%98%E5%8C%96/06-%E6%A8%A1%E5%9E%8B%E5%90%8E%E8%AE%AD%E7%BB%83.md)）；"冻结特征 + 训新头"即早期的线性探测。
- 自监督预训练（对比学习、MAE）出现后，视觉预训练不再依赖 ImageNet 人工标签，但"浅层通用、深层任务相关"的迁移逻辑不变。
