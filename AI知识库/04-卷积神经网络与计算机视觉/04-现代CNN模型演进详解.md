# 现代 CNN 模型演进详解

<p class="note-date">更新于 2026-11-05</p>

**一句话定义**：2012–2017 年的现代 CNN 演进不是孤立的模型列表，而是一条因果链——AlexNet 证明"学特征"可行，VGG 把网络抽象成块，NiN 砍掉全连接层，GoogLeNet 用并行多尺度回答"核多大合适"，BN 解决深层可训练性，ResNet 用残差连接让"加深必不劣化"成立，DenseNet 把跨层连接推到极致。

[现代卷积神经网络](02-现代卷积神经网络.md)已给出各模型的概要、动机与实验精度，本篇补充：每个模型的**逐层结构细节、关键设计的量化对比、设计决策背后的"为什么"**。

## 核心原理

### 1. 演进的因果逻辑（先记这条主线）

| 阶段 | 要解决的问题 | 代表设计 | 留给后人的遗产 |
|---|---|---|---|
| AlexNet (2012) | 证明深度学习能打败手工特征 | 大核 + ReLU + Dropout + 数据增广 | "深 + 数据 + GPU"范式 |
| VGG (2014) | AlexNet 没有给出可复用的设计模板 | 可复用 VGG 块（3×3 卷积栈 + 池化） | "块设计"抽象 |
| NiN (2013) | 卷积提特征 + 全连接处理会丢空间结构 | 1×1 卷积 = 逐像素全连接；全局平均池化收尾 | 无全连接的收尾范式 |
| GoogLeNet (2014) | 多大卷积核最合适？ | Inception 四路并行 + 1×1 降维 | 并行多尺度结构 |
| BN (2015) | 深层网络训练不稳定、难收敛 | 小批量统计标准化 | 深层可训练性（见下） |
| ResNet (2015) | 加深网络不保证更好（函数类不嵌套） | 残差连接，拟合 f(x)−x | 百层网络成为可能 |
| DenseNet (2017) | 残差只保留了"线性项" | 跨层通道连结，保留所有高阶项 | 特征复用、小参数量 |

### 2. AlexNet：为什么是这些超参数

- **首层 11×11 卷积核**：ImageNet 图像的高宽是 MNIST 的 10 倍以上，需要大窗口一步捕获大尺度目标；第二层降到 5×5，之后 3×3。第 1/2/5 层卷积后接 3×3、步幅 2 的最大池化。
- **ReLU 替代 Sigmoid 的梯度论证**：Sigmoid 在输出接近 0/1 的饱和区梯度几乎为 0，参数初始化不当时大量参数得不到更新；ReLU 正区间梯度恒为 1，且免求幂、计算便宜。
- **容量控制组合拳**：两个 4096 维全连接层（参数近 1GB）各配 Dropout(0.5)；训练时用翻转、裁切、变色等增广扩充有效样本量（后来发展为完整的图像增广体系，见[图像增广与迁移学习实践](05-%E5%9B%BE%E5%83%8F%E5%A2%9E%E5%B9%BF%E4%B8%8E%E8%BF%81%E7%A7%BB%E5%AD%A6%E4%B9%A0%E5%AE%9E%E8%B7%B5.md)）。
- **双 GPU 数据流设计**：原版因 GTX580 只有 3GB 显存而把网络拆到两块 GPU 各存一半；现代显存充裕后此设计已无必要——一个"被硬件逼出来的架构细节随硬件进步消失"的典型例子。

### 3. VGG：3×3 小核栈的量化账

VGG 块 = n 个 3×3 卷积（padding 1，保分辨率）+ ReLU + 2×2 最大池化（步幅 2，分辨率减半）。VGG-11 配置 `conv_arch = ((1,64),(1,128),(2,256),(2,512),(2,512))`，原始 VGG-16/VGG-19 把前两块也加深为 2/2 层。

**为什么堆 3×3 而不是一个大核**：两层 3×3 卷积的感受野等于一层 5×5（$2\times3-1=5$），三层 3×3 等效 7×7，但：

1. **参数更少**：两层 3×3 参数 $2\times9C^2=18C^2$，一层 5×5 是 $25C^2$，省约 28%；
2. **非线性更多**：多过一次 ReLU，表达能力更强。

代价是计算与显存开销远超 AlexNet——VGG 是"用算力换通用模板"的设计。

### 4. NiN：1×1 卷积的两种等价理解

NiN 块 = 1 个用户设定窗口的普通卷积 + 2 个 1×1 卷积（各带 ReLU）。1×1 卷积可以看作：

- **逐像素全连接层**：把空间维的每个像素当样本、通道维当特征，在每个位置独立做一次 MLP；
- 不改变高宽，只混合通道信息（与之相对，普通卷积同时混合空间与通道）。

NiN 的收尾设计影响深远：最后一个块的输出通道数 = 类别数，直接接**全局平均汇聚层**生成 logits，完全取消全连接层——参数量骤降、过拟合缓解。GoogLeNet、ResNet 的收尾都继承于此。

### 5. GoogLeNet：Inception 块的通道账

Inception 块四条并行路径（输出按通道连结，高宽不变）：

1. 1×1 卷积 → $c_1$ 通道；
2. 1×1 降到 $c_2[0]$ → 3×3 卷积 → $c_2[1]$；
3. 1×1 降到 $c_3[0]$ → 5×5 卷积 → $c_3[1]$；
4. 3×3 最大池化 → 1×1 卷积 → $c_4$。

**1×1 降维是块能算得起的关键**：以第一个 Inception 块（输入 192 通道）为例，路径 2/3 先把通道压到 $96/192=1/2$ 和 $16/192=1/12$，再做 3×3/5×5 卷积。若直接用 192 通道做 5×5 卷积到 32 通道，计算量是先压到 16 再卷的约 12 倍。四路通道分配比 64:128:32:32 等数字来自 ImageNet 上的大量调参实验，本身无理论公式。

整个网络：7×7 卷积(stride 2) 开头 → 1×1+3×3 两个卷积 → 9 个 Inception 块分 3 个模块（模块间最大池化减半分辨率）→ 全局平均池化。

### 6. ResNet：函数类嵌套与残差拟合

**理论动机**：设架构决定函数类 $\mathcal{F}$，我们找 $\mathcal{F}$ 内最优的 $f^*_\mathcal{F} = \arg\min_{f\in\mathcal{F}} L(\mathbf{X},\mathbf{y},f)$。加深得到更大的函数类 $\mathcal{F}'$ 时，若 $\mathcal{F} \not\subseteq \mathcal{F}'$，$f^*_{\mathcal{F}'}$ **不保证**更接近真函数 $f^*$（可能更差）。只有**嵌套**关系 $\mathcal{F}_1 \subseteq \cdots \subseteq \mathcal{F}_6$ 才能保证"加深不劣化"。让新加的层容易学成恒等映射 $f(x)=x$，就能构造出嵌套函数类。

**残差块**：两个 3×3 卷积（各接 BN+ReLU），输入跳过卷积直接加在最后 ReLU 之前，网络拟合**残差映射** $f(x)-x$。理想映射接近恒等时，把上层加权运算的权重和偏置学成 0 即可——拟合"恒等的细微波动"远比直接拟合整个映射容易。通道数或分辨率变化时，捷径上加 1×1 卷积（步幅 2）对齐形状。

ResNet-18 逐层：7×7 卷积(stride 2, 64 通道) + 3×3 最大池化 → 4 个模块各 2 个残差块（通道 64→128→256→512，每个模块第一个块步幅 2 降分辨率）→ 全局平均池化 → 全连接。后续变体：更深网络用 bottleneck（1×1 降维 → 3×3 → 1×1 升维）；"卷积-BN-激活"改为 pre-activation（BN-ReLU-卷积），梯度通路更顺。

### 7. DenseNet：泰勒展开视角的稠密连结

ResNet 把函数分解为 $f(x) = x + g(x)$（线性项 + 非线性项，类比泰勒展开只取到一阶）；DenseNet 保留**所有高阶项**，跨层连接从相加改为**通道连结**：

$$x \rightarrow [x,\ f_1(x),\ f_2([x, f_1(x)]),\ f_3([x, f_1(x), f_2([x, f_1(x)])]),\ \ldots]$$

- **稠密块**：卷积块采用"BN-ReLU-卷积"顺序，每块输出固定通道数 = **增长率**（growth rate，典型 32），块内通道线性累加（$k$ 个块后通道 = $k \times$ 增长率 + 输入通道）；
- **过渡层**：1×1 卷积把通道减半 + 步幅 2 平均池化把分辨率减半，在稠密块之间控制复杂度。

对比：参数量比 ResNet 小（特征强复用），但连结导致显存占用与计算成本更高，这也是工业界 ResNet 更普及的原因之一。

## 核心概念：BN 如何改变"可训练性"

BN 的定义、公式与训练/预测行为差异已在[现代卷积神经网络](02-现代卷积神经网络.md)讲清，此处补充演进视角的三个要点：

- **BN 是 GoogLeNet 工作的直接副产品**（Ioffe & Szegedy, 2015），它把"能训练 100 层以上网络"从难题变成常规操作，与 ResNet 残差连接共同构成现代深层网络的两大支柱；
- 从优化角度看，BN 平滑了损失面的 Lipschitz 常数，使大学习率变得安全——BN-LeNet 实验中学习率从 0.9 提到 1.0 仍稳定收敛；
- 原论文"消除内部协变量偏移"的动机解释后来广受质疑（后续研究认为与有效的原因关联更弱），但有效性无可争议。

## 模型对比速查表

| 模型 | 核心构件 | 全连接层 | 参数规模感 | 精度关键点 |
|---|---|---|---|---|
| AlexNet | 11/5/3 大核 + ReLU | 2×4096（近 1GB 参数） | 巨大 | 首证学特征 > 手工特征 |
| VGG-11 | 3×3 栈 + 池化的块 | 与 AlexNet 同 | 很大 | 块设计模板、小核堆深 |
| NiN | 卷积 + 2×1×1 | 无（全局平均池化） | 小 | 逐像素 MLP、参数骤降 |
| GoogLeNet | Inception 四路并行 | 无 | 中 | 多尺度 + 1×1 降维控成本 |
| ResNet-18 | 残差块 + 捷径 | 1 个输出层 | 中 | 恒等映射易学、加深不劣化 |
| DenseNet | 稠密块 + 过渡层 | 1 个输出层 | 小 | 特征复用、显存换参数 |

（入门教学常用的 Fashion-MNIST 10 epoch 快速对照：VGG-11 0.920 > ResNet-18 0.893 > GoogLeNet 0.886 > DenseNet 0.885 > AlexNet 0.883 > NiN 0.790，NiN 偏低与其对学习率敏感、简化设置有关。）

## 术语表

| 术语 | 含义 |
|---|---|
| 函数类嵌套 | $\mathcal{F}\subseteq\mathcal{F}'$ 时加深才保证不劣化，是 ResNet 的理论出发点 |
| 残差映射 | 拟合 $f(x)-x$ 而非 $f(x)$，捷径相加使恒等映射可平凡达成 |
| 增长率（growth rate） | DenseNet 稠密块中每个卷积块输出的固定通道数，通道线性累加 |
| 过渡层 | DenseNet 中 1×1 卷积减半通道 + 步幅 2 平均池化减半分辨率 |
| 全局平均汇聚 | 每个通道取整个空间均值直接出 logits，替代全连接层（NiN 首创） |
| pre-activation | 把 BN-ReLU 放到卷积之前的残差块变体，梯度直通更顺畅 |
| bottleneck | 1×1 降维→3×3→1×1 升维的残差块变体，深网络（ResNet-50+）用它控成本 |
| 感受野等效 | 两层 3×3 的感受野等于一层 5×5，但参数更少、非线性更多 |

## 经验与常见坑

- 复现经典架构跑小数据时，通用缩表手段：通道数按比例缩减（如 ÷4）、输入降到 96×96、epoch 拉满——各模型相对优劣大体保持。
- VGG/NiN/GoogLeNet 的精度数字**不能直接横比**：输入分辨率、通道缩减、学习率调度各不相同；比较时保持实验设置一致。
- DenseNet 显存容易爆：通道连结让每层输入随深度增长，小显存卡先减增长率或减块数。
- 残差块的 1×1 捷径卷积只在"形状必须变"时存在；徒手实现时最常见错误是捷径与主路形状没对齐就相加。
- BN 层的偏置是冗余参数（后面会归一化掉），配 BN 的卷积层可设 `bias=False`。

## ⚠️ 时效性说明

- 本篇聚焦 2012–2017 年的经典架构；EfficientNet、ConvNeXt 及 Vision Transformer 等后续演进不在本篇范围（Transformer 见 [注意力机制与Transformer · Transformer 架构](../06-%E6%B3%A8%E6%84%8F%E5%8A%9B%E6%9C%BA%E5%88%B6%E4%B8%8ETransformer/02-Transformer%20%E6%9E%B6%E6%9E%84.md)）。
- "内部协变量偏移"作为 BN 有效原因的解释已不被学界接受；现行解释偏向损失面平滑与训练噪声正则化。
- Fashion-MNIST 上的精度数字只用于教学对照，不代表 ImageNet 级任务上的真实排序。
