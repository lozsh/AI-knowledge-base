# 卷积神经网络

> 来源：原资料（wiki 化重写于 2026-11-03）

**一句话定义**：卷积神经网络（CNN）是一类为图像等网格结构数据设计的神经网络，靠卷积层的"局部连接 + 权值共享"以远少于全连接网络的参数量，自动学习空间特征。

全连接多层感知机把图像展平成一维向量，丢弃了空间结构：一张百万像素图片，即使隐藏层只有 1000 维，一层就需 10^6 × 10^3 = 10^9 个参数，训练不可行。CNN 则利用图像固有的两条先验——**平移不变性**（同一物体出现在图中任何位置都应被识别）与**局部性**（相邻像素关联强、远距像素关联弱）——系统化地构造网络，参数量从数十亿降到几百，且卷积天然适合 GPU 并行。CNN 长期主导图像分类、目标检测、语义分割，也渗透到音频、文本等一维序列甚至图结构与推荐系统。

## 核心原理

### 从全连接到卷积：两条归纳偏置

将全连接层写成对二维输入 X、隐藏表示 H 的形式：`[H]i,j = U + Σ [V]i,j,a,b [X]i+a,j+b`，即每个隐藏像素是全图像素的加权和。随后施加两条约束：

- **平移不变性**：物体在输入中平移，只引起隐藏表示的平移 → 权重不依赖位置 `[V]i,j,a,b = [V]a,b`，得到 `[H]i,j = u + Σ [V]a,b [X]i+a,j+b`。这就是**卷积**：系数 [V]a,b 对 (i,j) 邻域加权求和。参数量大幅下降。
- **局部性**：信息收集不应偏离 (i,j) 太远 → 令 |a| > Δ 或 |b| > Δ 时 [V]a,b = 0，求和限制在 (2Δ+1)² 窗口内，即卷积层。

代价：特征变为平移不变、每层只含局部信息。若先验与现实不符（图像不满足平移不变），模型可能欠拟合——这是归纳偏置的典型权衡。

### 互相关 vs 严格卷积

数学上卷积定义为 `(f*g)(i,j) = Σ f(a,b) g(i−a,j−b)`（翻转 + 求重叠）。深度学习框架实际执行的是**互相关**（用 +a,+b 差位，不翻转核）。由于卷积核是从数据学出来的，两者对模型输出无实质影响（学到的核互为翻转），实践中沿用"卷积"这一叫法。

### 通道（channel）

彩色图像是 H×W×3 三维张量。输入多通道时，卷积核需带相同数目的输入通道（形状 ci×kh×kw），各通道分别做二维互相关再求和；多输出通道时核形状为 **co×ci×kh×kw**，每个输出通道对应一个完整核。通道也称**特征映射**（feature map）——底层通道常对应边缘、纹理等响应。

## 关键概念

### 二维互相关与卷积层

卷积窗口从左上角起滑动，窗口内元素与核按元素相乘再求和得一个输出值。卷积层两个可学习参数：卷积核权重 + 标量偏置。经典应用：用核 `[[1, -1]]` 可检测垂直边缘（+1 为白→黑边，−1 为黑→白边）；转置输入后该核失效——**核是方向特异的**。更复杂的核无法手工设计，而是从"输入-输出"对中用平方误差 + 梯度下降学出（如学 [1,-1] 核，10 轮迭代 loss 从 ~4 降到 0.022）。

### 输出尺寸、填充与步幅

设输入 nh×nw、核 kh×kw、填充 (ph,pw)、步幅 (sh,sw)，输出形状为：

```
⌊(nh − kh + ph + sh)/sh⌋ × ⌊(nw − kw + pw + sw)/sw⌋
```

- **无填充无步幅**时退化为 (nh−kh+1)×(nw−kw+1)。
- **填充（padding）**：在边界补 0。连续卷积会累积丢失边缘像素（如 240×240 图经 10 层 5×5 卷积缩到 200×200）；取 ph=kh−1、pw=kw−1 可保持输入输出同尺寸。核尺寸习惯取**奇数**（1/3/5/7），这样两侧对称填充，且输出 [i,j] 恰好以输入 [i,j] 为中心。
- **步幅（stride）**：每次滑动多个元素，用于降采样；若 ph=kh−1 且输入边长被步幅整除，输出为 (nh/sh)×(nw/sw)。

### 1×1 卷积

kh=kw=1 的卷积不提取空间相邻关系，唯一计算发生在**通道维**：等价于在每个像素位置施加一个 ci→co 的全连接层（权重共 co×ci + 偏置，跨像素共享）。常用于**升降通道数、控制模型复杂度**（后续 Network in Network / ResNet 瓶颈层的基础）。

### 感受野（receptive field）

某层任意元素 x 的感受野 = 前向传播中可能影响 x 计算的所有元素。感受野可大于输入实际尺寸，且随网络加深而扩大——需要检测更大范围特征时，就构建更深的网络。

### 汇聚层（pooling）

固定形状窗口滑动，对窗口取最大值（最大汇聚）或平均值（平均汇聚），**无可学习参数**。目的：降低卷积对位置的过度敏感 + 降低空间分辨率。要点：

- 框架默认步幅 = 窗口大小；也支持填充与自定义步幅。
- **逐通道独立运算**，输出通道数 = 输入通道数（不像卷积在通道上求和）。
- 例：边缘检测输出接 2×2 最大汇聚后，模式平移一个像素仍能识别。

## 分类/类型（LeNet：第一个成功的 CNN）

LeNet（LeNet-5）由 Yann LeCun 于 1989 年在 AT&T 贝尔实验室提出（1998 年论文），用于手写数字识别，曾广泛用于银行支票/ATM 系统，性能与当时主流的 SVM 相当。

结构（输入 28×28 单通道）：

| 部分 | 组成 | 通道变化 | 空间变化 |
|---|---|---|---|
| 卷积编码器 | Conv 5×5(padding 2) + Sigmoid + AvgPool 2×2(s=2) | 1 → 6 | 28×28 → 14×14 |
| | Conv 5×5 + Sigmoid + AvgPool 2×2(s=2) | 6 → 16 | 10×10 → 5×5 |
| 全连接块 | Flatten → Linear 120 → 84 → 10 | — | 400 → 120 → 84 → 10 |

时代特征：激活用 Sigmoid、汇聚用平均池化（ReLU 与最大池化当时尚未流行）；原版最后一层为高斯激活，现代复现中省去。Fashion-MNIST 上训练（lr=0.9，10 epoch，batch 256，Xavier 初始化 + SGD + 交叉熵）：loss 0.469，train acc 0.823，test acc 0.779。

关键代码模式（二维互相关）：

```python
def corr2d(X, K):
    h, w = K.shape
    Y = torch.zeros((X.shape[0]-h+1, X.shape[1]-w+1))
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            Y[i, j] = (X[i:i+h, j:j+w] * K).sum()
    return Y
```

多输入通道 = 各通道分别互相关后求和；多输出通道 = 对每个输出通道的核重复上述再堆叠；1×1 卷积可等价改写为 reshape 后的矩阵乘法。

## 经验与常见坑

- 卷积层虽参数少，但**计算量不小**（每个参数参与更多乘法），训练通常需要 GPU；小批量数据要先搬上显存。
- 设计惯例：随层数加深，空间分辨率逐层下降、通道数逐层增加（"空间换通道"）。
- 归纳偏置双刃剑：图像若不满足平移不变性（如物体朝向/位置有强先验），CNN 可能难拟合数据。
- 网络里常见排列：卷积层 → 非线性激活 → 汇聚层，重复堆叠后接全连接层输出。

## ⚠️ 时效性说明

- LeNet 使用 Sigmoid + 平均池化是 1990 年代的历史选择，现代网络一律用 ReLU + 最大池化。
- 原文成文时 CNN 在视觉任务占主导；如今 ViT 等基于注意力的架构（见 [[../06-注意力机制与Transformer/01-注意力机制.md]]）在部分视觉基准上已与 CNN 竞争，但 CNN 在小数据、端侧部署场景仍占优。
