# 安全与隐私

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：ML 系统的安全 = 保护机密性/完整性/可用性免受**主动对抗**（越界访问、投毒、提取、操纵）；隐私 = 限制敏感信息**即使系统正常工作**也可能被泄露或推断的风险。二者共同决定 ML 系统能否部署——不是上线后补的功能，而是决定系统"能不能用"的前提条件。

传统数据库被攻破，攻击者偷走记录；ML 模型被攻破，攻击者可以从模型里"抽"出记住的训练样本，或在训练数据里埋下只在特定触发器下激活的后门。ML 不只是存储数据——它**压缩、记忆并执行**数据，这让学习到的决策边界本身成为攻击面。信息泄露不变量（原则 17）：模型输出总是携带训练数据的影子，只要模型有用，完美隐私在数学上不可能——**隐私因此不是一堵一次性砌好的墙，而是每次查询都在消耗的预算**。

## 安全 vs 隐私：两个问题分开问

| 维度 | 安全（Security） | 隐私（Privacy） |
|------|-----------------|----------------|
| 目标 | 防未授权访问/破坏/中断 | 限制敏感信息暴露 |
| 威胁模型 | 主动对抗者（内/外部） | 诚实但好奇的观察者、被动泄露 |
| 典型关切 | 模型窃取、投毒、逃逸攻击 | 数据泄露、重识别、记忆化 |
| 代表攻击 | 对抗输入致误分类 | 模型反演重构训练数据 |
| 代表防御 | 访问控制、对抗训练 | 差分隐私、联邦学习 |

二者可以互相增强（少存敏感数据 = 缩小攻击面），也可冲突（DP 噪声降效用；加密妨碍审计）。生产系统往往需要组合使用，使"保护模型不暴露数据、保护数据不毁审计"同时成立。

**量化代价**：DP 加噪有直接效用税（1000 人平均工资、ε=1、敏感度 20 万美元 → Laplace 噪声尺度 20 万 → 均值误差 ~200 美元；n=100 时涨到 2000——小数据集上 DP 不稳定）；多租户隔离税（H100 上 MIG 硬件隔离使 1000 tok/s 降到 850，**损失 15% 吞吐**）。

## 三起经典安全事件的 ML 启示

- **Stuxnet（2010，供应链）**：四个零日漏洞经 USB 穿透气隙网络，篡改离心机控制参数同时向操作员报告正常读数——系统在"看起来健康"时已被破坏。ML 对应：往可信仓库投毒模型/数据不需要打崩推理服务器，静默移动决策边界就能达成同样效果且躲过监控。防御：模型工件密码签名、不可变溯源日志、部署前自动后门扫描。
- **Jeep Cherokee（2015，隔离不足）**：车机娱乐系统与安全关键的 CAN 总线共享网络路径，远程可操控发动机/刹车/变速箱，触发史上首次汽车网络安全召回（140 万辆）。ML 对应：推理 API 与安全关键执行器共享网络路径的系统（自动驾驶、工业 IoT、医疗设备）继承同一漏洞类别。防御：推理面/控制面严格网络分段、密码 API 认证、沙盒执行、失效安全默认。
- **Mirai 僵尸网络（2016，弱端点）**：60 万台默认口令 IoT 设备组成 1.2 Tbps DDoS。ML 对应升级：被攻破的智能摄像头可窃取人脸库、语音助手可抽出对话记录、联邦学习中的设备可投毒训练数据。防御：零信任边缘（HSM 设备唯一密钥、安全启动、TLS 1.3、行为监控）。

## 威胁建模

**四要素威胁模型**：资产（什么必须保密/完整/可用）、边界（信任在哪里变化：训练数据↔模型注册表、用户提示↔系统指令、多租户共享加速器）、对手（能力与动机）、控制（什么机制改变攻击者的经济学）。没有这四项，风险矩阵退化为恐惧清单。

**优先级矩阵**（可能性 × 影响）：高可能高影响（联邦学习数据投毒、提示注入）→ 立即自动化防御；低可能高影响（硬件侧信道）→ 高价值部署才做深度工程准备；高可能低影响（公开 API 模型提取）→ 限流与 API 设计即可；都低（低可能低影响）→ 持续跟踪、暂缓投资。

**威胁向量三轴**：访问类型（黑盒 API / 灰盒 / 白盒全知——越透明越要靠鲁棒训练与运行时监控而非隐蔽性）、知识水平（零知/部分/全知）、攻击时机（训练时投毒 → 部署时篡改 → 推理时对抗/提取 → 部署后更新与反馈回路）。防御三原则：**纵深防御**（多层独立）、**最小攻击面**（限 API 能力、截断输出、加密资产、训练/推理隔离、审计）、**失效安全默认**（拒绝可疑输入、异常即停训、吊销风险凭证、隔离被攻破组件）。

## 模型专属攻击向量

### 模型窃取（机密性）

两种目标、两套防御：**精确工件窃取**（拿到 checkpoint/注册表/设备镜像 → 直接复制权重——工件安全失败，需签名、加密、访问控制）；**近似行为窃取**（黑盒查询 API 记录标签/logits/嵌入 → 训练代理模型——接口安全失败，需限流、输出截断、查询审计、水印、定价）。

- **BERT 提取案例**：200 万条精心构造查询（约 50 美元查询费）训出与受害模型 97%+ 一致的学生模型——置信分数和 logits 是高信息泄漏源。
- **LLM 提取**：仅凭公开 API 可恢复 OpenAI ada/babbage 的输出投影矩阵（RMSE ~10⁻⁴、成本 $1–12），并恢复 gpt-3.5 的隐藏维度——看似无害的 top-k logits 返回是显著泄漏向量。
- **内部窃取**：Tesla 起诉前员工拷贝 Autopilot 源码库——受保护资产是整个工程栈（训练代码、特征管线、仿真资产），内部访问绕过一切 API 层防御。
- **防御经济学**：四杠杆协同——降低每次响应的信息量（置信度舍入到 2 位小数、只返回 top-5 类消除 99.5% 分布条目）、限制查询量（配额阶梯：免费 100/天 → 付费 1 万/天 → 企业认证）、抬高边际成本（定价使 n·p_query > C_train，如训练 $5M、需 1 亿次查询 → 定价 >$0.05/次）、检测测量行为（异常分数 = f(查询量, KL 散度, 查询间隔规律性)，自适应限额 limit_base·exp(−γ·score)）。实测组合可把代理模型保真度从 90% 压到 72%，正常用户 top-5 精度几乎不受影响（99.2% vs 99.3%）。

### 数据投毒（训练完整性）

形式化为双层优化：外层攻击者选 S_poison 最大化模型在目标集上的损失，内层系统在 S∪S_poison 上训练——每评估一个防御都要解完整内层训练，故计算昂贵。分类：可用性攻击（整体降精度）、目标攻击（特定输入出错）、**后门攻击**（平时 99%+ 干净精度、触发输入 99%+ 攻击成功率——精度指标检测不出来）、子群体攻击（危害公平敏感场景）。投毒杠杆极高：污染 0.1% 训练数据可降精度 10–50%；0.01% 即可植入后门且跨重训/迁移存活。防御：管线端到端安全（输入验证、完整性校验、异常检测）+ 鲁棒训练（降权/过滤异常样本）。

### 对抗攻击（推理鲁棒性）

Stop 标志贴 <10% 面积的黑白贴纸 → 85%+ 被分类为限速标志，人类 100% 看出是停车标志。几何本质：在网络高维非线性决策边界上找最小扰动 δ（‖δ‖≤ε_adv）把输入推过边界。白盒（梯度直接攻击）/黑盒（迁移攻击成功率 60–80%）谱系。Perspective API 案例：加错拼、字符替换就让明显辱骂文本得低毒分——**训练管线没被投毒，部署的决策面本身脆弱**。

### LLM 专属攻击

服务接口把指令、用户内容、检索文档、工具权限、秘密混在一个 token 流里——控制面与数据面的边界天然脆弱。系统设计应**分离五个对象**：系统指令（控制面）、不可信内容（用户输入与外部文本只是数据不是权威）、检索文档（是证据但不能改写策略/工具权限）、工具权限（外部动作需显式授权边界）、秘密（不出现在模型可见上下文）。三大失败模式：提示注入（无参数化查询式的原生边界可依赖）、训练数据提取（规模越大记忆越多，防御 = 训练前去重/PII 过滤 + DP + 输出侧敏感模式拦截）、越狱（RLHF/宪法 AI/护栏模型都是统计性覆盖而非形式化约束，对抗后缀/角色扮演/多轮升级可绕过——需纵深：自批评 + 独立护栏模型 + 限流 + 人工复核）。

## 硬件层安全

软件防御全部依赖一个假设：执行环境可信。硬件攻击打破它。四个部署决策：

1. **处理器隔离**：Meltdown/Spectre 类漏洞利用乱序执行的缓存副作用跨隔离域读数据，波及 1995 年后几乎所有处理器，修补导致 5–30% 性能损失——对 ML 影响最重的是数据加载管线，需打补丁后重新调优。GPU 内存层次中的推测预取是否有类似时序泄漏，仍是开放问题。
2. **物理访问**：换传感器（生物识别可被替换以窃取标识）、改导航模块、植入休眠硬件木马（制造阶段插入，特定条件触发）。
3. **故障注入**：定时电压跌落/时钟毛刺/激光击打诱导位翻转。实测：激光使微控制器跳过 ReLU 的分支指令，强制神经元输出恒为零——小的计算故障变成语义故障。
4. **侧信道**：功耗/电磁/时序/声学信号泄漏内部状态。密码验证的功耗曲线在正确字节处平稳、错误字节处跳变，差分功耗分析几分钟提取密钥；ML 推理同理——ReLU 前激活正负的电流差异可推断稀疏模式与层结构，无需任何 API 访问。历史呼应：ENGULF 行动用电话听加密机声音推密钥。
5. **泄漏接口**：生产设备遗留的 JTAG/SWD 调试口可被直接读内存提权重；智能灯泡调试口泄漏 Wi-Fi 凭据。每个诊断/更新/通信接口都是安全边界。
6. **供应链与假货**：Supermicro 争议（虽有争议）暴露结构性问题——组织缺乏对制造/装配/分销的可见性来证明部署硬件=认证硬件。硬件漏洞不能远程打补丁，**预防远比修复便宜**。

## 当 ML 成为攻击工具

深度学习把专家级攻击变成可学习的分类任务：传统侧信道分析需人类密码分析员花数月对齐示波器轨迹，CNN 可从原始功耗轨迹直接映射到密钥（SCAAML：从 STM32 微控制器功耗轨迹恢复完整 128 位 AES 密钥）。同样适用：LLM 钓鱼（语法正确率 99%+ vs 传统 19%，点击率 30%+）、侦察自动化、漏洞挖掘、检测逃逸。**攻防不对称**：防御受部署约束（延迟预算、合规），攻击者训练管线边际成本极低。理解攻击即防御的基础（渗透测试、红队、ML 专属红队——对抗提示工程、投毒模拟、模型提取尝试）。

## 纵深防御架构

四层堆栈（每层假设下一层未失守）：

- **数据层**：加密存储、差分隐私、溯源追踪、审计日志；
- **模型层**：对抗训练、输入验证、模型水印、限流；
- **系统层**：OS 隔离、网络分段、RBAC、完整性检查、输入/输出监控、事件响应与回滚；
- **硬件层**：TEE、安全启动、HSM、PUF。

### 隐私保护技术谱系

| 技术 | 保证 | 开销 | 适用 |
|------|------|------|------|
| 差分隐私 | 形式化 (ε,δ) | 中-高（生产级） | 敏感数据训练 |
| 联邦学习 | 结构性（数据不出端） | 中（生产级） | 跨设备/跨机构 |
| 同态加密 | 强（加密计算） | 高（实验级，慢 1000–10000×） | 不信任环境的小模型推理 |
| 安全多方计算 | 强（分布式） | 很高（实验级） | 互不信任机构联合训练 |
| 合成数据 | 弱（单独使用时） | 低-中（新兴） | 数据共享/基准测试 |

联邦学习**不是天然的隐私保护**：梯度更新本身泄漏信息（梯度反演可高保真重构原始图像/文本）。正确组合 = FL + **安全聚合**（服务器只见聚合不见个体）+ 合适威胁模型的 DP（Gboard 模式）。⚠️ 鲁棒性-隐私权衡：对抗训练提高鲁棒性可能加大成员推断易感性（决策边界更贴合训练流形）。

### 运行时监控

- **输入验证**：低层检查（尺寸/类型/范围）+ 语义过滤（人脸检测、语音活动检测 SAD<10ms）+ 分布检查（颜色直方图对比训练分布）；生成模型做提示词过滤。⚠️ 提示过滤不充分——Adversarial Nibbler 显示"隐性对抗提示"表面良性却生成违规内容，必须配后置内容分析。
- **输出监控**：置信度、预测熵、类分布偏离预期即触发降级（人工复核/回退基线）；LLM 输出用 Llama Guard / ShieldGemma 类护栏分类器。
- **完整性检查**：加载前 SHA-256 校验 + RBAC + 异常访问审计；真正的供应链控制要求**每个可部署工件**（数据、依赖锁文件、预处理代码、容器镜像、部署证明）都能关联到同一发布记录。
- **响应与回滚**：回滚到已验证版本（需版本化模型存储）、金丝雀发布（ML 失败常是统计性的——后门模型可能通过单元测试只在真实流量下暴露）、限流遏制、取证（生成式系统需五类证据：提示、检索文档、工具调用、护栏分类器决策、秘密访问日志）。

### 硬件信任原语

| 机制 | 回答的信任问题 | ML 用途 | 代价 |
|------|---------------|---------|------|
| TEE（TrustZone/SGX/Secure Enclave） | 敏感计算能否在不可信主机上安全运行 | 模型/生物特征推理隔离（Apple Face ID 范式） | SGX EPC 仅 ~128MB，ResNet-50 FP32 权重就占 80%，超限后延迟 5ms→500ms；TrustZone 切换 0.6–2μs |
| Secure Boot | 系统是否从被验证的代码启动 | 边缘设备防运行前篡改、模型替换 | 密钥管理复杂、启动延迟数十至数百 ms |
| HSM | 密钥能否在不暴露的硬件中生成使用 | 模型签名、联邦学习设备身份、向 TEE 密封模型密钥 | 吞吐比 GPU 低 ~10×，$20K–100K/台，FIPS 认证 12–24 个月 |
| PUF | 设备能否证明不可克隆的硬件身份 | 边缘模型绑定设备加密、防"提走一个模型全局沦陷" | 环境敏感需纠错，可被 ML 建模攻击 |

安全分级延迟对比：明文 20ms → AES-256 加密传输 20.5ms（近免费）→ 全同态加密 200 秒（架构上不可行）。TEE（Intel SGX / NVIDIA H100 机密计算）在两者之间：低得多的延迟换不同信任假设。

## 差分隐私

**定义**：(ε,δ)-DP——对只差一条记录的相邻数据集 D、D′ 与任意输出集 S：Pr[A(D)∈S] ≤ e^ε·Pr[A(D′)∈S] + δ。ε 是隐私预算（可分配、可组合、会耗尽）；δ 是灾难性失败概率（常取 <1/n）。ε 越小越强：ε=0.1 强保护（精度掉 10–15%）、ε=1 中等（5–10%）、ε=10 弱（损失极小）。

- **机制**：Laplace 机制 f̃=f(D)+Lap(Δf/ε)（纯 ε-DP，噪声尺度=敏感度/预算）；Gaussian 机制（需 (ε,δ)-DP，σ ≥ Δ₂f·√(2ln(1.25/δ))/ε，深度学习首选因梯度天然 ℓ² 有界）。
- **DP-SGD**：逐样本梯度裁剪到范数 C → 加噪 → 聚合。代价：逐样本裁剪破坏加速器批级并行，训练通常需 2–5× 计算量。
- **预算组合**：隐私损失跨操作**累积**——10 个模型各 ε=1，总损失≈10（简单组合）；RDP/矩会计更紧（示例：DP-SGD 100 epoch 实际 ε≈2.3 vs 朴素组合 23）。⚠️ 生产失败模式：把 ε 当一次性标签而非会计系统——月度重训两年，名义 ε=1 实际累积 ε=24。
- **经验前沿**：MNIST 在个位数 ε 下保持较好精度；CIFAR-10 从零训练 (8,10⁻⁵) 约 73–81.4%；ImageNet 借 JFT-4B 预训练可达 86.7%@(8,8·10⁻⁷)。曲线非线性——小 ε 区每收紧一点代价陡增，**每个部署都要做任务专属的 ε 扫描**。
- **部署决策框架**：用 DP 当且仅当——(1) 政策/合同/审计要求形式化边界；(2) 成员推断是现实威胁；(3) 数据集 >5 万样本（小数据集 DP 效用崩溃，改用联邦学习+安全聚合）；(4) 任务能容忍 5–15% 精度损失；(5) 算力预算支持 2–5× 开销。主要威胁是存储泄露时用加密而非 DP；资源受限时仅对聚合查询做 DP。

## 成熟度模型

按"当前哪个边界未受保护"逐层推进（是依赖结构不是时间表）：

1. **访问与配置边界**——谁碰得到数据/权重/部署/日志？最小权限、服务身份、加密传输、审计日志；
2. **数据与隐私边界**——训练/微调/输出能被学走什么？隐私会计、输出限制、安全聚合、敏感数据隔离；
3. **模型完整性边界**——如何证明这是验证过的模型与数据路径？签名工件、注册表控制、发布门禁、回滚路径；
4. **对抗与滥用边界**——自适应攻击者能提取/推断/诱导什么？查询监控、限流、鲁棒性评估、红队；
5. **治理与证据边界**——部署后要证明哪些义务？合规映射、事故记录、留存策略、可复现的控制检查。

领域路径不同：医疗先做隐私会计与治理证据；金融先做访问控制+模型完整性+滥用监控；自动驾驶先做对抗鲁棒性与事故证据。

## 经验与常见坑

- **隐蔽性不安全**（Kerckhoffs 原则）：黑盒提取 1–10 万次查询即可 90% 复原，对抗样本跨架构迁移 60–80% 成功——必须假设攻击者全知，靠限流/输出扰动/水印/异常检测防御。
- **以为用了 DP 库就安全**：ε 参数选择与跨重训/调参/A-B 的预算追踪缺失，实际超出保证数量级。
- **以为联邦学习天然隐私**：成员推断在生产联邦模型上 70–90% 准确率，梯度反演可重构训练样本——需叠加安全聚合 + DP。
- **只防大规模泄露、轻视外科手术式投毒**：0.01–0.1% 的污染杠杆极高，攻击经济学极端有利于对手。
- **组件级防御 ≠ 系统级安全**：API 防得再严，模型可从未加密的 CI 快照、无鉴权端点或公开注册表流走——必须做全生命周期威胁建模。
- **分布式攻击面超线性增长**：n 节点 ≈ O(n²) 攻击向量（全连接拓扑）；128 GPU 集群攻陷一节点即可注入毒化梯度；1 万联邦客户端中 1% 被攻破即可协同投毒。
