# 多层感知机

<p class="note-date">更新于 2026-11-06</p>

**一句话定义**：多层感知机（MLP，Multi-Layer Perceptron）= 多个全连接层堆叠 + 层间非线性激活函数——用隐藏层把"表示学习"和"线性预测"分开，是深度学习最基础的网络结构。

## 核心原理：为什么需要隐藏层和非线性

线性模型隐含**单调假设**：某特征增大必然导致输出增大或减小。它对"收入越高还款概率越高"大体成立，但很快失效：体温与死亡率的关系在 37°C 两侧方向相反；猫狗分类中，单个像素的强度无法线性决定类别——像素的重要性以复杂方式取决于其上下文。

**加入隐藏层**：把前 $L-1$ 层（$L$ 为网络总层数）看作"表示学习"，最后一层看作应用于该表示的线性预测器。全连接层堆叠：$H = XW^{(1)} + b^{(1)}$，$O = HW^{(2)} + b^{(2)}$（$X$ 为输入批量，$H$ 为隐藏层输出，$O$ 为最终输出，$W$、$b$ 为各层的权重与偏置，上标 $(1)$、$(2)$ 标记第 1、2 层）。

**必须非线性**：仿射函数的仿射函数仍是仿射函数——$O = (XW^{(1)} + b^{(1)})W^{(2)} + b^{(2)} = X(W^{(1)}W^{(2)}) + (b^{(1)}W^{(2)} + b^{(2)})$，可合并为等价单层模型，隐藏层毫无意义。所以在仿射变换后必须逐元素应用**激活函数** $\sigma$（希腊字母 sigma，下文统一指激活函数）：

$$H = \sigma(XW^{(1)} + b^{(1)}), \quad O = HW^{(2)} + b^{(2)}$$

**通用近似定理**：即使只有一个隐藏层，给定足够神经元和正确权重，MLP 也能对任意函数建模——神经网络像 C 语言，能表达任何可计算程序，但"想出符合规范的程序"才是最难的。且单隐藏层能学 ≠ 应该用单隐藏层学：更深（而非更宽）的网络更容易逼近许多函数。

## 核心概念：激活函数

| 函数 | 公式 | 值域 | 导数 | 特点与用途 |
|---|---|---|---|---|
| ReLU | $\max(x, 0)$ | $[0, \infty)$ | 负为 0、正为 1（$x=0$ 处默认取 0） | 最受欢迎：实现简单、求导表现好、**减轻梯度消失** |
| pReLU | $\max(0, x) + \alpha \cdot \min(0, x)$（$\alpha$ 为可学习的负区系数） | $(-\infty, \infty)$ | — | 负区加可学习线性项，信息不完全截断 |
| sigmoid | $\dfrac{1}{1+e^{-x}}$ | $(0, 1)$ | $\sigma(x)(1-\sigma(x))$，最大值仅 0.25 | 挤压函数；平滑的阈值单元近似；现主要用于输出层（二元分类概率，可视为 softmax 特例）；隐藏层已被 ReLU 取代；RNN 门控中仍用 |
| tanh | $\dfrac{1-e^{-2x}}{1+e^{-2x}}$ | $(-1, 1)$ | $1 - \tanh^2(x)$，0 处最大值 1 | 关于原点中心对称；0 附近近似线性 |

工程注记：ReLU 在 $x=0$ 精确不可导，默认取左导数 0——"如果微妙的边界条件很重要，我们很可能是在研究数学而非工程"，可忽略。

## 代码模式

从零实现（隐藏层 256 单元，两个权重随机初始化、偏置置零）：

```python
num_inputs, num_outputs, num_hiddens = 784, 10, 256
W1 = torch.randn(num_inputs, num_hiddens, requires_grad=True) * 0.01
b1 = torch.zeros(num_hiddens, requires_grad=True)
W2 = torch.randn(num_hiddens, num_outputs, requires_grad=True) * 0.01
b2 = torch.zeros(num_outputs, requires_grad=True)

def net(X):
    H = relu(X.reshape((-1, num_inputs)) @ W1 + b1)
    return H @ W2 + b2
loss = nn.CrossEntropyLoss(reduction='none')  # 训练循环与 softmax 回归完全一致

# 简洁实现
net = nn.Sequential(nn.Flatten(), nn.Linear(784, 256), nn.ReLU(),
                    nn.Linear(256, 10))
```

## 核心原理：前向传播、反向传播与计算图

- **前向传播**：按计算图从输入到输出逐层计算（存储中间结果）；
- **反向传播**：利用**链式法则**沿计算图反向计算梯度，深度学习框架据此自动求导。实现反向传播时框架需保留前向传播的中间值——这是训练比推断更耗内存的根本原因；
- 训练 = 前向 + 反向 + 优化器更新，推断只需前向。

## 数值稳定性与参数初始化

**不稳定梯度的风险**：$L$ 层网络的梯度是 $L-l$ 个矩阵 $M$ 的乘积（$l$ 为当前层序号）——矩阵特征值有大有小，连乘后可能**梯度爆炸**（更新过大破坏收敛）或**梯度消失**（更新过小无法学习）。

- **梯度消失的元凶**：sigmoid 导数最大仅 0.25，输入远离 0 时梯度趋 0——多层连乘后梯度几乎必然消失。这正是 ReLU 系成为默认选择的原因（虽然从神经科学角度看不太合理）；
- **梯度爆炸的演示**：100 个 $\mathcal{N}(0,1)$（均值 0、方差 1 的高斯分布）随机矩阵连乘，结果数值达 $10^{26}$ 量级——初始化不当的深网络根本无从收敛。

**打破对称性**：若把某层所有参数初始化为同一常数 $c$，前向时隐藏单元产生相同激活，反向时得到相同梯度，迭代永远无法打破对称——隐藏层的行为如同只有一个单元。（仅靠小批量 SGD 打不破这种对称，必须引入随机性。）**所以必须随机初始化**。

**Xavier 初始化**（Glorot & Bengio, 2010）：对无非线性层 $o_i = \sum_j w_{ij}x_j$（$o_i$ 为第 $i$ 个输出，$w_{ij}$、$x_j$ 为连接权重与输入），前向要保方差需 $n_{\text{in}}\sigma^2 = 1$，反向保梯度方差需 $n_{\text{out}}\sigma^2 = 1$——两者不可兼得，取折中：

$$\sigma^2 = \frac{2}{n_{\text{in}} + n_{\text{out}}}$$

高斯版：从 $\mathcal{N}\!\left(0, \dfrac{2}{n_{\text{in}}+n_{\text{out}}}\right)$ 采样；均匀版：$U\!\left(-\sqrt{\dfrac{6}{n_{\text{in}}+n_{\text{out}}}}, \sqrt{\dfrac{6}{n_{\text{in}}+n_{\text{out}}}}\right)$。虽然"无非线性"的假设常被违反，实践中仍然有效。现代框架内置十几种初始化启发式；精心设计的初始化甚至可以不靠架构技巧训练 10000 层网络。

## 经验与常见坑

1. **忘了激活函数 = 白加隐藏层**：仿射套仿射仍是仿射，堆再多层都等价于单层线性模型——每层仿射变换后必须跟一个非线性激活；
2. **权重初始化成同一常数**：对称性永远打不破，隐藏单元同进同退，行为等价于每层只有一个单元——必须随机初始化（小批量 SGD 救不了）；
3. **隐藏层用 sigmoid 深训必遇梯度消失**：其导数最大仅 0.25，层数一多连乘后梯度趋零——隐藏层默认选 ReLU 系；
4. **ReLU 在 0 处不可导不必纠结**：边界条件默认取左导数 0，属于"研究数学而非工程"的细节；
5. **MLP 的训练循环零改动**：从 softmax 回归换成 MLP，损失函数与训练循环完全一致，改的只有网络定义——排查训练异常时可先确认问题不在网络结构。
