# 线性神经网络

<p class="note-date">更新于 2026-11-05</p>

**一句话定义**：线性回归和 softmax 回归都可以看作单层神经网络——它们是理解神经网络训练全流程（数据 → 模型 → 损失 → 优化）的最小完整样例，也是一切深度模型的出发点。

本篇覆盖：线性回归的数学原理与两种解法（解析解/梯度下降）、从零实现与框架简洁实现的完整训练代码骨架、softmax 回归与交叉熵损失（含信息论解释与数值稳定性技巧）、Fashion-MNIST 数据集。

## 核心原理：线性回归

### 模型

回归（regression）是为输入-输出关系建模的方法，回答"多少"的问题（房价、住院天数、销量）。线性回归基于两个假设：① 目标是特征的加权和（线性关系）；② 噪声比较"正常"（服从正态分布）。

$$\hat{y} = \mathbf{w}^\top \mathbf{x} + b$$

- **权重 w**：决定每个特征对预测的影响；
- **偏置 b**：所有特征为零时的预测值（截距），没有它模型表达能力受限；
- 严格说这是**仿射变换**：线性变换（加权和）+ 平移（偏置）；
- 全数据集的矩阵形式：ŷ = Xw + b，X ∈ ℝ^(n×d) 每行一个样本（b 靠广播机制相加）。

### 损失函数：平方误差

$$\mathcal{L}(\mathbf{w}, b) = \frac{1}{n}\sum_{i=1}^{n} \frac{1}{2}\left(\mathbf{w}^\top \mathbf{x}^{(i)} + b - y^{(i)}\right)^2$$

1/2 常数只为求导后系数为 1。训练目标 argmin L(w,b)。

### 两种解法

1. **解析解**：把 b 并入 w（X 加一列全 1），损失 ∥y − Xw∥² 只有一个临界点，令梯度为零得 w* = (X⊤X)⁻¹X⊤y。线性回归是深度学习里罕见的特例——解析解对问题限制太严，无法推广。
2. **小批量随机梯度下降（minibatch SGD）**：每次迭代随机抽一个小批量 B，沿负梯度方向更新：

$$(w, b) \leftarrow (w, b) - \eta \cdot \frac{1}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \nabla_{(w,b)}\, l^{(i)}$$

   **批量大小 |B| 和学习率 η 是超参数**——手动预先指定、不在训练中更新，靠验证集上调参。即使函数真的线性且无噪声，有限步数也只能逼近最小值而非精确达到。深度网络损失面有多个最小值，实践者很少追求训练集上的全局最优——更难的是**泛化**（在未见数据上低损失）。

> 术语提醒：d2l 坚持"预测（prediction）"而非"推断（inference）"——统计学里 inference 指基于数据集估计参数，深度学习的用法是术语误用，与统计学家交谈时易误解。

### 高斯噪声假设 ⇒ 平方损失的正当性

设 y = w⊤x + b + ε，ε ∼ N(0, σ²)。似然 P(y|x) 是正态密度；最大化对数似然、去掉与 w,b 无关的项后，剩余部分**正是均方误差**（解不依赖 σ）。结论：**高斯噪声假设下，最小化均方误差等价于极大似然估计**。

### 线性回归 = 单层神经网络

输入层 d 个特征 → 一个计算神经元 → 1 个输出。层数计算不计输入层，故是"单层神经网络"；每个输入连接每个输出的变换叫**全连接层**（fully-connected / dense layer）。生物学对应：树突（输入）→ 突触权重（加权）→ 细胞核（求和）→ 轴突（输出+非线性）。但注意：飞机受鸟类启发，鸟类学却不是航空创新的主要驱动力——当今深度学习灵感更多来自数学、统计与计算机科学。

### 矢量化

用 Python for 循环逐元素相加 10000 维向量约 0.17 秒，用张量运算符约 0.0004 秒——**矢量化带来数量级加速**，还减少出错可能。能放进线性代数库的计算就不要手写循环。

## 代码模式：训练循环（最重要的骨架）

从零实现五件套（现代框架已自动化这些组件，但理解原理才能自定义模型/层/损失）：

```python
# 1. 数据：合成 y = Xw + b + ε
def synthetic_data(w, b, num_examples):
    X = torch.normal(0, 1, (num_examples, len(w)))
    y = torch.matmul(X, w) + b + torch.normal(0, 0.01, (num_examples,1))
    return X, y

# 2. 小批量迭代器：打乱 + 切片
def data_iter(batch_size, features, labels):
    indices = list(range(len(features)))
    random.shuffle(indices)
    for i in range(0, len(features), batch_size):
        sel = torch.tensor(indices[i:i+batch_size])
        yield features[sel], labels[sel]

# 3. 模型 / 损失
def linreg(X, w, b): return torch.matmul(X, w) + b
def squared_loss(y_hat, y): return (y_hat - y.reshape(y_hat.shape))**2 / 2

# 4. 优化器（除以 batch_size 使步长与批量大小无关；记得清零梯度）
def sgd(params, lr, batch_size):
    with torch.no_grad():
        for p in params:
            p -= lr * p.grad / batch_size
            p.grad.zero_()

# 5. 训练循环：前向 → 损失求和 → 反向 → 更新
w = torch.normal(0, 0.01, (2,1), requires_grad=True)  # 随机初始化
b = torch.zeros(1, requires_grad=True)
for epoch in range(num_epochs):
    for X, y in data_iter(batch_size, features, labels):
        l = loss(linreg(X, w, b), y)   # l 形状是 (batch_size,1)
        l.sum().backward()             # 求和成标量再反向
        sgd([w, b], lr, batch_size)
```

框架简洁实现（组件各就各位，`nn.Linear(2, 1)` 就是全连接层）：

```python
net = nn.Sequential(nn.Linear(2, 1))
net[0].weight.data.normal_(0, 0.01); net[0].bias.data.fill_(0)
loss = nn.MSELoss()
trainer = torch.optim.SGD(net.parameters(), lr=0.03)
# 训练循环同上：net(X) 前向 → loss 反向 → trainer.step() 更新 → trainer.zero_grad()
```

数据读取换用 `data.TensorDataset` + `data.DataLoader(..., shuffle=True)`，比手写迭代器高效得多（可处理存于文件/流的数据）。注意经验：ML 中通常不关心恢复"真参数"，只关心预测准；深度网络里能实现高精度预测的参数组合很多，SGD 通常能找到其中一个。

## 核心原理：softmax 回归

### 分类问题的表示

分类回答"哪一个"。类别无自然顺序时（猫/鸡/狗）用**独热编码**：y ∈ {(1,0,0), (0,1,0), (0,0,1)}。有自然顺序时（年龄分组）转回归保留整数格式才有意义。

### 模型：单层网络 + softmax

每类一个仿射函数输出未规范化的预测（logit）：**o = Wx + b**（W ∈ ℝ^(q×d)），再用 softmax 把 o 变成概率：

$$\hat{y}_j = \frac{\exp(o_j)}{\sum_k \exp(o_k)}$$

为什么要 softmax 而不直接把 o 当概率：o 的总和不为 1、且可能为负，违反概率公理。softmax 求幂保证非负、除以总和保证归一、保持可导。它不改变 o 的大小次序（argmax ŷ = argmax o），且**虽然 softmax 是非线性函数，softmax 回归的输出仍由仿射变换决定——它仍是线性模型**。

小批量矢量化：O = XW + b（O ∈ ℝ^(n×q)），softmax 按行执行。

> **全连接层的参数开销**：d 输入 q 输出的全连接层参数量为 O(dq)，实践中可能高得惊人；可用超参数 n 将开销降到 O(dqn)（分流方法）。

### 损失：交叉熵（最大似然）

对独热标签，负对数似然化为 l(y, ŷ) = −Σⱼ yⱼ log ŷⱼ——只留下正确类那一项。代入 softmax 定义可推出**漂亮的梯度**：

$$\partial_{o_j} l = \text{softmax}(\mathbf{o})_j - y_j$$

即梯度 = 预测概率 − 真实标签，与线性回归中"梯度 = ŷ − y"完全同构（这不是巧合：任何指数族分布的对数似然梯度都是这个形式）。

### 信息论解释

- **熵** H[P] = −Σⱼ P(j) log P(j)：编码从分布 P 抽取的数据所需的最少"纳特"数（1 纳特 = 1/log 2 ≈ 1.44 比特，纳特用自然对数底）；
- **信息量** = −log P(j)：事件概率越低，发生时"惊异"越大；熵是概率匹配真实数据生成过程时信息量的期望；
- **交叉熵** H(P,Q)：主观概率为 Q 的观察者看到按 P 生成的数据时的预期惊异；P = Q 时最小，等于 H(P)。交叉熵分类目标的两面：① 最大化观测数据似然；② 最小化传达标签所需的惊异。

## 经验与常见坑

- **softmax 数值稳定性（最重要的实现细节）**：oₖ 很大时 exp(oₖ) 会**上溢**（inf），oⱼ − max 后大负值会**下溢**（0），log(0) = −inf，反向传播几步后满屏 nan。技巧：softmax 前先对所有 oₖ 减去 max(oₖ)——减常数不改变 softmax 结果；更好的做法是**把未规范化的预测直接传入交叉熵损失**（PyTorch 的 `nn.CrossEntropyLoss`），在损失内部合并计算 softmax 与 log（LogSumExp 技巧），log(exp(·)) 相互抵消，彻底避开数值问题。
- **交叉熵取标签概率的实现**：`y_hat[range(len(y_hat)), y]` 用 y 做花式索引一行取正确类概率，避免低效 for 循环。
- **sum 沿轴与 keepdim**：`X.sum(0, keepdim=True)` 保持轴数（形状 (1,3)），便于后续广播。
- **训练-评估分离**：测试集只用于评估精度（accuracy = 正确预测数/预测总数），绝不参与训练。
- **softmax 之名是误称**：真正的 soft-softmax 是 RealSoftMax(a,b) = log(eᵃ + eᵇ)，当 λ→∞ 时 λ⁻¹RealSoftMax(λa, λb) → max(a, b)。

## 代码模式：Fashion-MNIST 分类全流程

**数据集**：Fashion-MNIST（10 类服饰灰度图，28×28×1，训练 60000 / 测试 10000），比 MNIST 复杂、比 ImageNet 轻量，是分类入门标准基准。10 类：t-shirt、trouser、pullover、dress、coat、sandal、shirt、sneaker、bag、ankle boot。

```python
trans = transforms.ToTensor()  # PIL → 32位浮点，除以 255 归一到 [0,1]
mnist_train = torchvision.datasets.FashionMNIST(root="../data", train=True,
                                                transform=trans, download=True)
train_iter = data.DataLoader(mnist_train, batch_size, shuffle=True)

# 从零版模型：图像先 reshape 展平为向量，再仿射 + softmax
def net(X):
    return softmax(torch.matmul(X.reshape((-1, W.shape[0])), W) + b)

# 简洁版：直接用框架层，CrossEntropyLoss 内含 softmax + log（数值稳定）
net = nn.Sequential(nn.Flatten(), nn.Linear(784, 10))
loss = nn.CrossEntropyLoss(reduction='none')
trainer = torch.optim.SGD(net.parameters(), lr=0.1)

# 预测：取概率最大的类别
preds = net(X).argmax(axis=1)
```

训练超参数：学习率 0.1、10 个 epoch 左右即可在 Fashion-MNIST 上达到 80%+ 精度。训练循环与线性回归完全一致——**读取数据 → 定义模型与损失 → 优化算法训练**，几乎所有深度学习模型都复用这一流程。

## ⚠️ 时效性说明

本篇 API 以 PyTorch 当前长期稳定用法为准（`torchvision.datasets.FashionMNIST` 等）；MNIST 作为基准已过于简单，新研究不再使用；"全连接层参数开销可用 O(dqn) 降维"是分流式设计的早期表述，现代大模型中这一思想演化为 MoE、低秩分解等技术。
