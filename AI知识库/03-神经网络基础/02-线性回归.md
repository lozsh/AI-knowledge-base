# 线性回归

<p class="note-date">更新于 2026-11-06</p>

**一句话定义**：线性回归是最基础的回归模型——用输入特征的加权和加上偏置来预测连续数值，它是理解神经网络训练全流程（数据 → 模型 → 损失 → 优化）的最小完整样例，也是一切深度模型的出发点。

## 核心原理

### 模型

回归（regression）是为输入-输出关系建模的方法，回答"多少"的问题（房价、住院天数、销量）。线性回归基于两个假设：① 目标是特征的加权和（线性关系）；② 噪声比较"正常"（服从正态分布）。

$$\hat{y} = \mathbf{w}^\top \mathbf{x} + b$$

- **权重 $w$**（决定每个特征对预测的影响的系数）；
- **偏置 $b$**（所有特征为零时的预测值，即截距），没有它模型表达能力受限；
- 严格说这是**仿射变换**：线性变换（加权和）+ 平移（偏置）；
- 全数据集的矩阵形式：$\hat{y} = Xw + b$，其中 $X \in \mathbb{R}^{n \times d}$（$n$ 个样本、$d$ 个特征的设计矩阵）每行一个样本（$b$ 靠广播机制相加）。

### 损失函数：平方误差

$$\mathcal{L}(\mathbf{w}, b) = \frac{1}{n}\sum_{i=1}^{n} \frac{1}{2}\left(\mathbf{w}^\top \mathbf{x}^{(i)} + b - y^{(i)}\right)^2$$

1/2 常数只为求导后系数为 1。训练目标是 $\arg\min\, \mathcal{L}(w, b)$（寻找使损失最小的参数）。

### 两种解法

1. **解析解**：把 $b$ 并入 $w$（$X$ 加一列全 1），损失 $\lVert y - Xw \rVert^2$ 只有一个临界点，令梯度为零得 $w^* = (X^\top X)^{-1} X^\top y$。线性回归是深度学习里罕见的特例——解析解对问题限制太严，无法推广。
2. **小批量随机梯度下降（minibatch SGD）**：每次迭代随机抽一个小批量 $\mathcal{B}$，沿负梯度方向更新：

$$(w, b) \leftarrow (w, b) - \eta \cdot \frac{1}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \nabla_{(w,b)}\, l^{(i)}$$

   **批量大小 $|\mathcal{B}|$ 和学习率 $\eta$ 是超参数**——手动预先指定、不在训练中更新，靠验证集上调参。即使函数真的线性且无噪声，有限步数也只能逼近最小值而非精确达到。深度网络损失面有多个最小值，实践者很少追求训练集上的全局最优——更难的是**泛化**（在未见数据上低损失）。

> 术语提醒：深度学习惯例说"预测（prediction）"而非"推断（inference）"——统计学里 inference 指基于数据集估计参数，深度学习的用法是术语误用，与统计学家交谈时易误解。

### 高斯噪声假设 ⇒ 平方损失的正当性

设 $y = w^\top x + b + \epsilon$，其中噪声 $\epsilon \sim \mathcal{N}(0, \sigma^2)$（均值为 0、方差为 $\sigma^2$ 的正态分布）。似然 $P(y \mid x)$ 是正态密度；最大化对数似然、去掉与 $w, b$ 无关的项后，剩余部分**正是均方误差**（解不依赖 $\sigma$）。结论：**高斯噪声假设下，最小化均方误差等价于极大似然估计**。

### 线性回归 = 单层神经网络

输入层 $d$ 个特征 → 一个计算神经元 → 1 个输出。层数计算不计输入层，故是"单层神经网络"；每个输入连接每个输出的变换叫**全连接层**（fully-connected / dense layer）。生物学对应：树突（输入）→ 突触权重（加权）→ 细胞核（求和）→ 轴突（输出+非线性）。但注意：飞机受鸟类启发，鸟类学却不是航空创新的主要驱动力——当今深度学习灵感更多来自数学、统计与计算机科学。

### 矢量化

用 Python for 循环逐元素相加 10000 维向量约 0.17 秒，用张量运算符约 0.0004 秒——**矢量化带来数量级加速**，还减少出错可能。能放进线性代数库的计算就不要手写循环。

## 代码模式：训练循环（最重要的骨架）

从零实现五件套（现代框架已自动化这些组件，但理解原理才能自定义模型/层/损失）：

```python
# 1. 数据：合成 y = Xw + b + ε
def synthetic_data(w, b, num_examples):
    X = torch.normal(0, 1, (num_examples, len(w)))
    y = torch.matmul(X, w) + b + torch.normal(0, 0.01, (num_examples,1))
    return X, y

# 2. 小批量迭代器：打乱 + 切片
def data_iter(batch_size, features, labels):
    indices = list(range(len(features)))
    random.shuffle(indices)
    for i in range(0, len(features), batch_size):
        sel = torch.tensor(indices[i:i+batch_size])
        yield features[sel], labels[sel]

# 3. 模型 / 损失
def linreg(X, w, b): return torch.matmul(X, w) + b
def squared_loss(y_hat, y): return (y_hat - y.reshape(y_hat.shape))**2 / 2

# 4. 优化器（除以 batch_size 使步长与批量大小无关；记得清零梯度）
def sgd(params, lr, batch_size):
    with torch.no_grad():
        for p in params:
            p -= lr * p.grad / batch_size
            p.grad.zero_()

# 5. 训练循环：前向 → 损失求和 → 反向 → 更新
w = torch.normal(0, 0.01, (2,1), requires_grad=True)  # 随机初始化
b = torch.zeros(1, requires_grad=True)
for epoch in range(num_epochs):
    for X, y in data_iter(batch_size, features, labels):
        l = loss(linreg(X, w, b), y)   # l 形状是 (batch_size,1)
        l.sum().backward()             # 求和成标量再反向
        sgd([w, b], lr, batch_size)
```

框架简洁实现（组件各就各位，`nn.Linear(2, 1)` 就是全连接层）：

```python
net = nn.Sequential(nn.Linear(2, 1))
net[0].weight.data.normal_(0, 0.01); net[0].bias.data.fill_(0)
loss = nn.MSELoss()
trainer = torch.optim.SGD(net.parameters(), lr=0.03)
# 训练循环同上：net(X) 前向 → loss 反向 → trainer.step() 更新 → trainer.zero_grad()
```

数据读取换用 `data.TensorDataset` + `data.DataLoader(..., shuffle=True)`，比手写迭代器高效得多（可处理存于文件/流的数据）。注意经验：ML 中通常不关心恢复"真参数"，只关心预测准；深度网络里能实现高精度预测的参数组合很多，SGD 通常能找到其中一个。

## 经验与常见坑

- **ML 中通常不关心恢复"真参数"**：只关心预测准；深度网络里能实现高精度预测的参数组合很多，SGD 通常能找到其中一个。
- **矢量化优先**：逐元素 for 循环比张量运算慢几个数量级，还容易出错——能放进线性代数库的计算就不要手写循环。
- **小批量 SGD 的步长与批量解耦**：梯度更新时除以 batch_size，使学习率的含义不随批量大小变化；每次反向传播前记得 `p.grad.zero_()`，否则梯度会累积。
- **损失求和再反向**：逐样本损失形状是 `(batch_size, 1)`，必须先 `.sum()`（或求均值）成标量再 `backward()`。

## ⚠️ 时效性说明

本篇 API 以 PyTorch 当前长期稳定用法为准（`nn.Linear`、`nn.MSELoss`、`torch.optim.SGD` 等）；解析解 $w^* = (X^\top X)^{-1} X^\top y$ 只适用于小规模低维数据，高维场景实践中一律走 SGD 及其变体。
