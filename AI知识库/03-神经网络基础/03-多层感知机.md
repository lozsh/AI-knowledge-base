# 多层感知机

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：多层感知机（MLP）= 多个全连接层堆叠 + 层间非线性激活函数，是第一个"真正的"深度网络；围绕它引出深度学习训练的核心课题——模型选择、过拟合与正则化（权重衰减、dropout）、数值稳定性与初始化、分布偏移。

## 核心原理：为什么需要隐藏层和非线性

线性模型隐含**单调假设**：某特征增大必然导致输出增大或减小。它对"收入越高还款概率越高"大体成立，但很快失效：体温与死亡率的关系在 37°C 两侧方向相反；猫狗分类中，单个像素的强度无法线性决定类别——像素的重要性以复杂方式取决于其上下文。

**加入隐藏层**：把前 L−1 层看作"表示学习"，最后一层看作应用于该表示的线性预测器。全连接层堆叠：H = XW⁽¹⁾ + b⁽¹⁾，O = HW⁽²⁾ + b⁽²⁾。

**必须非线性**：仿射函数的仿射函数仍是仿射函数——O = (XW⁽¹⁾+b⁽¹⁾)W⁽²⁾+b⁽²⁾ = X(W⁽¹⁾W⁽²⁾) + (b⁽¹⁾W⁽²⁾+b⁽²⁾)，可合并为等价单层模型，隐藏层毫无意义。所以在仿射变换后必须逐元素应用**激活函数** σ：

$$H = \sigma(XW^{(1)} + b^{(1)}), \quad O = HW^{(2)} + b^{(2)}$$

**通用近似定理**：即使只有一个隐藏层，给定足够神经元和正确权重，MLP 也能对任意函数建模——神经网络像 C 语言，能表达任何可计算程序，但"想出符合规范的程序"才是最难的。且单隐藏层能学 ≠ 应该用单隐藏层学：更深（而非更宽）的网络更容易逼近许多函数。

## 关键概念：激活函数

| 函数 | 公式 | 值域 | 导数 | 特点与用途 |
|---|---|---|---|---|
| ReLU | max(x, 0) | [0, ∞) | 负为 0、正为 1（x=0 处默认取 0） | 最受欢迎：实现简单、求导表现好、**减轻梯度消失** |
| pReLU | max(0,x) + α·min(0,x) | (−∞, ∞) | — | 负区加可学习线性项，信息不完全截断 |
| sigmoid | 1/(1+e⁻ˣ) | (0, 1) | σ(x)(1−σ(x))，最大值仅 0.25 | 挤压函数；平滑的阈值单元近似；现主要用于输出层（二元分类概率，可视为 softmax 特例）；隐藏层已被 ReLU 取代；RNN 门控中仍用 |
| tanh | (1−e⁻²ˣ)/(1+e⁻²ˣ) | (−1, 1) | 1 − tanh²(x)，0 处最大值 1 | 关于原点中心对称；0 附近近似线性 |

工程注记：ReLU 在 x=0 精确不可导，默认取左导数 0——"如果微妙的边界条件很重要，我们很可能是在研究数学而非工程"，可忽略。

## 代码模式

从零实现（隐藏层 256 单元，两个权重随机初始化、偏置置零）：

```python
num_inputs, num_outputs, num_hiddens = 784, 10, 256
W1 = torch.randn(num_inputs, num_hiddens, requires_grad=True) * 0.01
b1 = torch.zeros(num_hiddens, requires_grad=True)
W2 = torch.randn(num_hiddens, num_outputs, requires_grad=True) * 0.01
b2 = torch.zeros(num_outputs, requires_grad=True)

def net(X):
    H = relu(X.reshape((-1, num_inputs)) @ W1 + b1)
    return H @ W2 + b2
loss = nn.CrossEntropyLoss(reduction='none')  # 训练循环与 softmax 回归完全一致

# 简洁实现
net = nn.Sequential(nn.Flatten(), nn.Linear(784, 256), nn.ReLU(),
                    nn.Linear(256, 10))
```

## 模型选择、欠拟合与过拟合

**训练误差 vs 泛化误差**：泛化误差是模型在"同分布无限多新样本"上的期望误差——永远无法精确计算，只能用独立测试集估计。三个思维实验说明差距：① 学生背往年考题 vs 理解原理；② 查表法可完美记住训练集，但 28×28 灰度图有 256⁷⁸⁴ 种可能——比宇宙原子还多，不可能存全表；③ 公平硬币分类器泛化误差恒为 1/2，但在小样本上"总猜多数类"的训练误差可以更低（数据增加后两者才趋同）。理论基础：格里文科-坎特利定理（训练误差收敛到泛化误差的速率）与 VC 维理论。

**独立同分布（i.i.d.）假设**：训练/测试数据从同一分布独立抽取。现实中几乎所有应用都存在轻度违背（跨医院、时间相关性），通常仍能工作；但严重违背（用大学生人脸数据训练、用于疗养院）注定失效。**深度网络为何能泛化仍是未解的理论难题**。

**模型复杂度的经验因素**：可调整参数数量（自由度）、参数取值范围、训练样本数量。经验法则：能轻松解释任意事实的模型是复杂的，表达能力有限但解释良好的模型更可能有用（与波普尔可证伪性标准相关）。

**模型选择与交叉验证**：验证集用于模型选择/调参，测试集只许用一次。数据稀缺时用 **K 折交叉验证**：分 K 份轮流做验证，取平均（训练 K 个模型，误差估计对数据划分的依赖更小）。

**诊断**：训练/验证误差都高 → 欠拟合（加数据也难救，需更大模型）；训练误差远低于验证误差 → 过拟合（更多数据是首选解）。多项式拟合的直观例子：一阶多项式欠拟合、高阶多项式过拟合、恰当阶数刚好。

## 正则化之一：权重衰减（L2）

在损失上加 λ/2·‖w‖²（注意通常不罚偏置 b——b 只控制偏移不带来方差性）。直觉：**权重小 → 函数更平滑**，输入变化不会引起输出剧烈波动，不易把噪声当模式。

- 贝叶斯解释：L2 正则等价于对权重施加高斯先验的最大后验估计（L1 则对应拉普拉斯先验）；
- λ=0 退化为原损失；λ 过大会把权重压得过小导致欠拟合；用验证集选；
- 简洁实现：`trainer = torch.optim.SGD(net.parameters(), lr=lr, weight_decay=wd)`，同一训练器可对不同参数组设不同 weight_decay（例如只罚权重不罚偏置）。

## 正则化之二：暂退法（Dropout）

**动机**：好的预测模型应对输入的微小扰动不敏感（平滑性）。毕晓普 1995 年证明：对输入加噪声的训练等价于 Tikhonov 正则化。斯里瓦斯塔瓦等人 2014 年把这一思想推广到网络内部层——**训练时在计算后续层之前向每层注入噪声**。原始论文的类比：dropout 破坏层间的"共适应性"，如同有性生殖破坏共适应的基因。

**标准做法**（无偏注入）：每个中间活性值 h 以暂退概率 p 被置零，其余除以 (1−p)：

$$h' = \begin{cases} 0, & \text{概率 } p \\ \frac{h}{1-p}, & \text{其他}\end{cases} \qquad E[h'] = h$$

效果：每次迭代相当于训练一个原始网络的随机子网，输出层无法过度依赖任何单个神经元。

```python
def dropout_layer(X, dropout):
    mask = (torch.rand(X.shape) > dropout).float()
    return mask * X / (1.0 - dropout)

# 简洁实现：每个 nn.Dropout 层可指定不同概率
net = nn.Sequential(nn.Flatten(), nn.Linear(784, 256), nn.ReLU(),
                    nn.Dropout(dropout1), nn.Linear(256, 10))
```

要点：**测试时不用 dropout**（不丢弃也不缩放）；例外是有研究者测试时启用 dropout 来估计预测不确定性——多次遮罩预测一致则说明网络稳定。dropout 通常只用在隐藏层之间。经验：全连接网络中 dropout 是防止过拟合的常用手段，与权重衰减、控制模型容量配合使用。

## 核心原理：前向传播、反向传播与计算图

- **前向传播**：按计算图从输入到输出逐层计算（存储中间结果）；
- **反向传播**：利用**链式法则**沿计算图反向计算梯度，深度学习框架据此自动求导。实现反向传播时框架需保留前向传播的中间值——这是训练比推断更耗内存的根本原因；
- 训练 = 前向 + 反向 + 优化器更新，推断只需前向。

## 数值稳定性与参数初始化

**不稳定梯度的风险**：L 层网络的梯度是 L−l 个矩阵 M 的乘积——矩阵特征值有大有小，连乘后可能**梯度爆炸**（更新过大破坏收敛）或**梯度消失**（更新过小无法学习）。

- **梯度消失的元凶**：sigmoid 导数最大仅 0.25，输入远离 0 时梯度趋 0——多层连乘后梯度几乎必然消失。这正是 ReLU 系成为默认选择的原因（虽然从神经科学角度看不太合理）；
- **梯度爆炸的演示**：100 个 N(0,1) 随机矩阵连乘，结果数值达 10²⁶ 量级——初始化不当的深网络根本无从收敛。

**打破对称性**：若把某层所有参数初始化为同一常数 c，前向时隐藏单元产生相同激活，反向时得到相同梯度，迭代永远无法打破对称——隐藏层的行为如同只有一个单元。（小批量 SGD 打不破这种对称，dropout 可以。）**所以必须随机初始化**。

**Xavier 初始化**（Glorot & Bengio, 2010）：对无非线性层 oᵢ = Σⱼ wᵢⱼxⱼ，前向要保方差需 n_in σ² = 1，反向保梯度方差需 n_out σ² = 1——两者不可兼得，取折中：

$$\sigma^2 = \frac{2}{n_{\text{in}} + n_{\text{out}}}$$

高斯版：从 N(0, 2/(n_in+n_out)) 采样；均匀版：U(−√(6/(n_in+n_out)), √(6/(n_in+n_out)))。虽然"无非线性"的假设常被违反，实践中仍然有效。现代框架内置十几种初始化启发式；精心设计的初始化甚至可以不靠架构技巧训练 10000 层网络。

## 环境与分布偏移

许多部署失败源于没想清楚"数据从哪来、输出到哪去"。最危险的场景：**模型部署本身扰乱数据分布**——贷款模型发现"穿牛津鞋与低违约相关"后开始按鞋放贷，顾客学会穿牛津鞋，模型被自己破坏。更尖锐的例子：预测犯罪的模型把更多警力派往某地区→更多犯罪被发现→模型更确信该地区危险（反馈循环）。

三种分布偏移（若无 p_S 与 p_T 关系的假设，恢复性能在理论上不可能）：

| 类型 | 假设 | 适用场景 |
|---|---|---|
| 协变量偏移（covariate shift） | P(y\|x) 不变，P(x) 变 | x 导致 y 时自然成立（真实照片训练、卡通图片测试） |
| 标签偏移（label shift） | P(x\|y) 不变，P(y) 变 | y 导致 x 时成立（疾病流行率变化，症状由疾病引起）；基于标签的方法倾向处理低维对象，常更有利 |
| 概念偏移（concept shift） | 标签定义本身变了 | 时髦语、诊断标准、职位名称的地域/时代变化（美国"软饮"称呼的地域分布） |

**经验风险最小化的暗坑**：训练目标（经验风险）与真实风险之间隔着分布偏移。应对手段从简单的（要求"正确"的数据）到困难的（强化学习、因果建模、算法公平性）不等。批归一化等技术与修正测试期统计量（correcting test-time statistics）相关；检测协变量偏移可用判别器区分训练/测试样本。

## 经验与常见坑（Kaggle 房价实战）

真实数据比合成数据脏得多，完整流程值得记录：

1. **下载与缓存**：数据集下载逻辑做成带缓存目录的函数，避免重复下载；
2. **预处理**：数值特征用均值填补缺失（有时按 neighborhood 分组填中位数更准）、标准化（μ=0, σ=1，否则优化会因不同特征尺度差异而低效）；离散特征 `pd.get_dummies` 独热化（对训练集+测试集联合处理保证类别对齐）；训练集/测试集特征按列对齐（`features = pd.concat((train.iloc[:, 1:-1], test.iloc[:, 1:]))`）；
3. **损失用 log MSE**：预测房价的对数与真实价格的对数之差——因为我们更关心**相对误差**（30 万估成 40 万 与 300 万估成 400 万 应同等惩罚，而平方误差会偏爱高价位房子）；
4. **K 折交叉验证选超参**：数据只有千余条样本，K 折平均比分一次更稳；
5. **流程**：先建基线（线性/MLP），在验证曲线上看是否过拟合，再迭代调超参（学习率、epoch、隐藏层宽度、正则强度）。
