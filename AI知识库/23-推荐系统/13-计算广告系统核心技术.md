# 计算广告系统核心技术

/> 来源：公开课程资料自学整理（整理于 2026-11-03）
> 一句话概括：围绕"pCTR × bid = eCPM"这一统一公式，串起广告生态与 RTB 流程、CTR 预估模型（Google FTRL / Facebook GBDT+LR）、拍卖机制（一价/二价）、竞价与预算控制、归因模型与受众扩展——计算广告的机制设计与工程实践主线。

## 核心概念

### 1. 广告生态与 RTB 流程

- **三方角色**：发布商（卖流量）、广告商（买流量、有目标）、受众。广告系统 = 三方利益的平衡与最大化——这是它区别于纯搜索/推荐的本质。广告可视为"特殊的搜索（搜索广告）或特殊的推荐（展示广告）"，但广告商要有发言权（定向、出价、效果工具）。
- **中间平台分工**（实际大平台常兼任多角色）：SSP 供应侧平台（聚合发布商流量）、DSP 需求侧平台（代广告商出价）、ADX 广告交易平台（撮合）、DMP 数据管理平台（供数据）。
- **一次 RTB（实时竞价）八步**：用户访问 → SSP/ADX 向 DSP 发请求（用户/页面/上下文）→ DSP 查 DMP 补画像 → 返回广告+出价 → 拍卖 → 定价 → 展示 → 反馈（点击/购买）回流 DSP。**每个环节的不精确都会累积放大为最终相关性损失**。
- 用户追踪基础是 Cookie（与域名绑定），跨站隔离催生 Cookie 整合/匹配（把不同收集方归并为同一人）。
- ⚠️ 2026 视角：第三方 Cookie 已被 Chrome/Apple 废除，转向 Privacy Sandbox、ID 联盟、第一方数据与上下文定向；国内以设备 ID + 平台内闭环数据为主。

### 2. CTR 预估（Feedback Prediction）

- 问题：预测 pCTR / pCVR——发布商收入保证（计费基于它）与广告商定向的共同核心。
- **挑战一：数据极不均衡**。广告 CTR 比自然内容低 10~1000 倍，正例常只有负例的 1/100~1/1000。应对：采样/加权——但**负采样会给参数估计带来偏差，必须做校准（Calibration）**，否则计费系统性多收/少收。
- **挑战二：本质是排序而非单点分类**；DSP 中还要与出价、胜率联合建模。
- 评估：不均衡数据下 accuracy 无意义。**AUC**（只看相对排序）+ **NE 归一化交叉熵**（以观测 CTR 为分母，补 AUC 不关心绝对值的缺陷）——绝对值对计费至关重要。

**Google 方案（KDD'13）：在线 LR + FTRL**
- 百亿级样本/特征、极稀疏，传统 LR 训练不动 → **FTRL（Follow The Regularized Leader）**在线逐样本更新：历史梯度重权 + 参数不偏离历史（稳定）+ L1 稀疏约束三项合一；逐维度自适应学习率（按历史梯度平方和倒数衰减，免手工调参）。
- 工程调优精髓：布隆过滤器做特征准入（AUC 仅降 0.008%，内存省 60%）、紧凑浮点格式再省 75% 内存。
- **失败的实验同样宝贵**：Hashing Trick（没省内存、精度反降、不可解释，Google 不用）、Dropout 无显著效果、参数 Normalization 无效——负结果与正结果同等价值。

**Facebook 方案（ADKDD'14）：GBDT + LR 两层架构**
- 社交广告场景（无 query），候选多、竞争烈。
- 第一层：连续特征过 GBDT，取**叶节点编号当新特征**——同时获得非线性组合与特征筛选；第二层：叶特征上训 LR，可 SGD 在线学习。此"非线性变换 + 线性分类器"思想启发了后来的深度 CTR 模型。
- 特征经验：**广告历史信息的层级聚合统计是最重要的特征来源**。

**建模套路（跨公司通用）**
- **层次建模**：广告商 → 推广计划 Campaign → 单一广告三层实体，上层信息向下滑、同类横向借——数据稀疏时的统计借力。
- **具体 + 泛化双能力**：既要对具体关键词精确匹配（记忆），又要跨层级泛化借鉴——Wide & Deep 的思想源头；纯深度抽象特征在搜索/广告上不如 CV 有效。
- ⚠️ 2026 视角：演进链 FM/FFM → Wide&Deep/DeepFM/DIN → 多任务（MMoE/ESMM，同时估 CTR/CVR）→ 序列建模 + 多模态特征 + 预训练 ID embedding；FTRL 的遗产（在线学习、稀疏化、校准意识）仍活在生产系统。

### 3. 拍卖机制

- **统一排序公式**：排序分 = **pCTR × bid**（按点击计费时即期望收入 eCPM）。拍卖、出价、索引提取全用这一个公式，模型误差经它放大为收入误差。
- **第一价位竞拍（First-Price）**：最高者胜、按自己出价付费。缺陷：不知对手出价 → 博弈不稳定（报价虚高或缓慢压价），打击广告主积极性。
- **第二价位竞拍（GSP，广义第二价）**：按 pCTR×bid 排序，赢家只付次高价。理论性质：**按真实估值出价是占优策略（讲真话/激励相容）**，2002 年 AdWords 起成为互联网广告主流。多位置变体按"下一位 eCPM / 自己 pCTR"折算付费。
- 技术难点——**竞价全景（Bid Landscape）预测**：估计赢率随出价变化的分布（常假设对数正态）；根本困难是**只观测到赢的出价（截尾数据）**，输的局看不到对手价格，估计天然有偏。
- ⚠️ 2026 视角：头部交易所 2019 年起回归**第一价竞拍**（配合 header bidding），二价"讲真话"性质在多次套利下失效；但二价的计费公式思想仍广泛用于平台内竞拍与底价设计。

### 4. 竞价与预算控制

**竞价策略两条研究路线**
- 博弈论建模（理论漂亮、假设多，主要在学术界）；统计决策（把环境当不确定因素，学"上下文→出价"函数，工业界青睐）。
- 搜索 vs 展示差异：搜索按**关键词**事先出价；展示无关键词、每次展示实时出价，且常 CPM 计费（赢了就付），必须把预算剩余纳入统一建模。

**单计划最优出价**
- **真理基准：无预算约束时，最优策略 = 按真实价值出价 = pCTR × 点击价值（truthful bidding）**。
- 加预算约束后不再最优，两条路线：
  - 线性出价（价值 × 动态系数）：灵活好用，缺理论支撑；
  - **约束最优化框架**：max 收益 s.t. 成本 = 预算，**拉格朗日乘数法**化无约束求闭式解；推出的一/二价最优出价是 pCTR、流量、预算的**非线性**函数——线性策略并非最优。
- 多计划联合（含风险控制/收益方差约束）：EM 求解，只得局部最优。

**预算控制（Budget Pacing）两条路线**
- **节流 Throttling**：不改出价，对每个竞价请求做"接/不接"二元决策——本质是"预算内最大化总价值"的带约束线性优化。**实战共识：节流比改价更简单有效**，因为它不依赖精确的 pCTR 与 Bid Landscape 预测。
- **反馈控制改价**：DSP 内加控制模块，实时监测赢率/CTR 反馈调整出价（控制论思路），更灵活但依赖预测质量。
- **频率上限（Frequency Cap）**：限同一广告对同一用户的曝光次数，防预算烧完 + 防用户厌烦；工业普遍使用但"重复曝光是否真降效"缺乏理论支撑。

**底价（Reserve Price，发布商视角）**
- 动机：非黄金广告位竞争不充分、价格被压低，底价人为抬高竞争水位。
- 二价下三情形：底价 > 最高价（流拍）；**第二价 < 底价 < 最高价（发布商多赚 底价−原二价，最理想）**；底价 < 第二价（无影响）。
- 设置方法：最优拍卖理论（Myerson 思路，假设出价对数正态，实验收益 +10%+）；RTB 下分布假设常不成立 → 改用**决策树式自适应**（底价低于最高出价则保持/提高，反之降低）。
- 坑：底价过高打击竞争、反噬市场。

### 5. 归因模型（Attribution）

- 问题：一次转化在用户触达过的多个广告间**分配贡献**。根本难点：**没有 Ground Truth，全靠假设**；且规则可被 DSP 博弈（专投"本来就会转化的人"骗取贡献）。
- 经验规则（工业主流，均无理论支撑）：
  - **Last Touch**：最后一个广告拿 100%（CTR/CVR 默认基于它）；缺陷是鼓励保守投放、"劫持"已意向用户；
  - **First Touch**：首次曝光拿 100%，鼓励品牌广撒网；
  - 平衡型：Linear 线性均分、Position Based 首尾加权、Time Decay 时间递减。
- 基于模型（KDD'11）：Bagged LR——"是否看过广告 X"为特征、转化为标签，正系数即贡献（Bagging 保证系数非负可解释）；概率解法把贡献拆为直接作用 + 广告间联合作用（交互项/夏普利思想雏形）。
- ⚠️ 2026 视角：核心问题升级为**增量度量（incrementality/lift）**——随机对照实验（holdout、geo-lift）与 MMM 营销组合建模，对抗"广告本来就不影响转化"的归因自欺；隐私时代用平台侧聚合归因（SKAdNetwork 类）替代用户级归因。

### 6. 受众定向与扩展（Lookalike）

- 显式定向两模式：关键词（意图定向，难在枚举不全且与成本强相关）；人口属性（中小广告商无力自行研究）。"广告主只设预算和目标、人群选择交给平台"——今天智能投放的前身。
- **受众扩展（LinkedIn KDD'16）两段式混合**：先做与计划无关的"类似"扩展铺量（冷启动可用、质量一般），计划积累数据后切与计划相关的扩展提质量——线上展示/CTR/总收益均 +10% 以上。
- "类似"算法：把"找最相关 K 个实体"当**监督学习**——正例 = 用户常一起投放的实体，负例 = 其余；特征 = 文本（词袋/N-gram）+ 社交图相关度 + 余弦相似度。
- 广告提取架构：广告按倒排索引存储（复用搜索系统），索引键按 **Quality Score**（高于阈值的 CTR 保证）排布——"先保点击率下限再乘出价"；定向条件（女性∧北京）作索引键做布尔与提取；索引需支持快速更新（pCTR、投放条件随时变）。
- ⚠️ 2026 视角：lookalike 演进为双塔 embedding 召回 + 图神经网络；显式人群包选择退居品牌投放，全面走向自动定向/自动创意。

## 经验与常见坑

- 一切模型误差都经"pCTR × bid"放大成收入误差；计费场景必须做绝对校准，AUC 只解决排序、NE 补绝对值。
- 负采样降成本必有偏，校准层不可省。
- 工业负结果与正结果同样值得入库：hashing trick、dropout、纯深度抽象特征（广告场景）都曾被验证无效。
- 在预测不准的现实里，**对预测依赖低的方案鲁棒性更高**：节流胜过改价控制、truthful bidding 是天然基准、决策树式底价自适应。
- 二价"讲真话"的前提会被多方套利侵蚀——机制设计要随生态演化重审（一价→二价→回归一价）。
- 层次建模（广告商→计划→广告）+ 记忆/泛化双能力，是从 LR 时代延续到深度学习时代的不变方法论。
- Last Touch 归因天然激励"劫持已意向用户"，评估渠道效果时要知道自己用的是哪套假设。
- 底价过高打击竞争反噬市场；差异化底价是数据量与收益的权衡。

## ⚠️ 时效性说明

- ⚠️ Cookie 追踪生态消亡；RTB 开放市场收缩，平台内闭环 + 第一方数据成为主流。
- ⚠️ CTR 模型已迭代数代（多任务、序列建模、多模态、预训练 embedding）；oCPX 把 pCTR×pCVR 内化进平台出价，广告主只给目标成本。
- ⚠️ 头部交易所回归第一价竞拍；自动出价（auto-bidding，PID 控制/强化学习）成为新主线，Myerson 虚拟价值与预算平滑的对偶框架取代朴素二价理论。
- ✅ 仍然耐用：eCPM 统一公式、校准意识、层次建模、层级聚合统计特征、Budget Pacing 思想、归因假设意识、两段式人群扩展。
