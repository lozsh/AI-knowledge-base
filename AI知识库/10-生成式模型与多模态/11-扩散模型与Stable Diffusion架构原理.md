# 扩散模型与 Stable Diffusion 架构原理

/> 来源：公开课程资料自学整理（整理于 2026-11-03）
> 一句话概括：扩散模型把"作画"变成"去噪"——UNet 预测噪声、采样器减去噪声、VAE 压缩省算力、CLIP 注入文本指令，四件套组成 Stable Diffusion。

## 核心概念

### 扩散模型：加噪与去噪的对称游戏
- 灵感来自热力学扩散：清水滴入碘伏逐渐均匀。图像上：**干净图片逐步加噪 → 纯噪声图**；反过来**从纯噪声逐步去噪 → 高质量图片**。AI 绘画的精髓就是实现这个逐步去噪的过程。
- **时间步 t**（1~1000）衡量加噪程度：t 越小越接近原图，越大越接近纯噪声。加噪过程是参数化马尔可夫链——每步只依赖上一步结果和当前 t。
- 加噪公式：`x_t = √α_t · x_{t-1} + √(1-α_t) · ε`（ε 为随机高斯噪声）；可推导出**从原图 x0 一次计算直接得到任意第 t 步的加噪结果**（ᾱ_t 为 α_1~α_t 连乘），这是训练高效的关键。
- **去噪 = UNet 预测噪声 + 采样器去除噪声**。UNet 预测的是"上一步添加的噪声值 ε"，不是上一步图像本身——所以同一个 UNet 可以搭配任意采样器。
- 训练循环（六步）：抽一张图 → 随机选时间步 t → 随机生成高斯噪声 → 用公式一次算出 x_t → (x_t, t) 喂给 UNet 预测噪声 → 预测噪声与真实噪声算 **L2 损失**回传梯度。循环至损失收敛。
- 推理循环：随机高斯噪声出发 → UNet 预测当前噪声 → 采样器减噪 → 重复，直到 t=0。
- **扩散 vs GAN**：GAN 是生成器/判别器对抗训练（左右互搏）；扩散是学习一个去噪过程。扩散在内容精致度、风格多样性、可控性上全面胜出，是当前主流。

### Stable Diffusion 三件套
SD 的技术源头是**潜在扩散模型（LDM）**论文，解决原始扩散模型两大短板：①不能听 prompt 指令；②在图像空间加噪去噪太耗显存。

| 模块 | 职责 | SD1.x 参数量 |
|---|---|---|
| VAE | 把 512×512 图像压缩到 64×64×4 潜在表示；解码还原。加噪/去噪全在潜在空间进行 | 0.084B |
| UNet | 在潜在空间预测每步要去除的噪声；输入还有时间步 t 编码和 prompt 文本表征 | 0.86B |
| CLIP 文本编码器 | 把 prompt 编码为文本表征，经交叉注意力注入 UNet | 0.123B |

- VAE 压缩率约 8 倍（边长），64×64 潜在表示解码回 512×512，因此 SD 无需超分模块即可出 512×512 图。
- **VAE 决定画质上限**：小脸、复杂细节的重建是 VAE 弱项（8 倍降采样丢失细节）；生成小脸模糊可能是 VAE 解码器的锅，换更好的 VAE 或微调 VAE 可改善。

### UNet 内部：文本和 t 从哪里进来
- SD 的 UNet：编码器 12 个模块 + 中间模块 + 解码器 12 个模块，编解码器之间有跳跃连接。
- 编码器主体是 CADB（CrossAttnDownBlock2D）模块，每个 CADB ≈ 两层 Transformer（ResNetBlock → 自注意力 → 交叉注意力 → FeedForward）。
- **prompt 文本表征走交叉注意力，提供 K、V；Q 来自图像自注意力输出**——这就是"文本指挥图像"的注入点。
- **时间步 t 的编码作用于 ResnetBlock2D**，告知 UNet 当前噪声强度。

### 文本引导：无分类器引导（CFG）
- 有分类器引导（Classifier Guidance）：额外训练一个加噪图像分类器，每步去噪用其梯度修正——需额外训练且控制力弱，已被淘汰。
- **无分类器引导（CFG）**：每步 UNet 预测两次——条件预测（带 prompt）+ 无条件预测（空字符串），再插值：
  `最终噪声 = w × 条件预测 + (1-w) × 无条件预测`
- w 即 WebUI 的 **CFG Scale**：越大图越听 prompt 的话，常用 3~15（默认 7 左右）；过大会过饱和、失真；w=0 则文本完全不起作用。代价是计算量几乎翻倍。
- 训练时以约 10% 概率把 prompt 换成空字符串（无条件训练），给模型保留"创造力"，也使无条件预测成为可能。
- **Negative Prompt 的原理**：把上式中的"无条件预测"换成反向描述词的预测，即 `w × 条件预测 + (1-w) × 反向预测`，w>1 时即可压制不想要的内容。

### 采样器：怎么"减"噪声
- 每个采样器本质是不同的 `x_{t-1}` 计算公式，数学上是解 SDE/ODE 的不同数值解法（有些方法上百年前就发明了）。
- 训练时的马尔可夫链有 1000 步，但推理可以大步跳跃：如 20 步采样 ≈ 每步跨 50 个时间步。**步数越少每步跨度越大，快但可能损质量**。
- 采样器家族速记：
  - 老派 ODE 解法：Euler（最简）、Heun（更准更慢）、LMS；
  - **祖先采样器（带 a）**：Euler a、DPM2 a 等，每步注入新噪声，结果有随机性、不可复现；
  - **Karras 后缀**：采用 Karras 论文的噪声调度，去噪尾声步长变小，提升画质；
  - DPM/DPM++ 系列（2022）：专为扩散模型设计的新一代求解器；
  - DDIM、PLMS：初代 SD 附带，已过时。
- 经验选择：**快而好 → DPM++ 2M Karras，20~30 步**；高质量慢速 → DPM++ SDE Karras（10~15 步）；要稳定可复现 → 避开一切 SDE/祖先采样器。

### 图生图（img2img）与重绘强度
- 文生图从随机噪声开始；图生图改为**对原图先加噪（步数由"重绘强度"控制），再从加噪结果去噪**。
- 铁律：**去噪步数必须与加噪步数一致**。去噪少 → 图"不干净"；去噪多 → 与原图相似度折损。
- 全图风格化（真人转漫画/油画）= 图生图 + 一个擅长目标风格的 SD 模型做去噪。

## 术语表

| 术语 | 含义 |
|---|---|
| 时间步 t | 加噪程度的整数刻度（1~1000），训练/推理的基本坐标 |
| UNet | 预测噪声的神经网络，输入输出同分辨率，源自图像分割架构 |
| 采样器 | 根据 UNet 预测的噪声从 x_t 恢复 x_{t-1} 的算法（ODE/SDE 数值解法） |
| 潜在空间 / 潜在表示 | VAE 压缩后的低维空间 / 数据在该空间的特征向量 |
| 重参数化技巧 | VAE 中 z = e^σ·ε + μ，让梯度能穿过随机采样操作 |
| CLIP | 图文对比学习模型，其文本编码器负责理解 prompt |
| 交叉注意力 | Q 来自图像、K/V 来自文本的注意力，prompt 注入通道 |
| CFG Scale | 无分类器引导权重，控制图像对 prompt 的服从度 |
| 祖先采样器 | 每步注入随机噪声的采样器（名字带 a），结果不可复现 |
| CLIP Skip = 2 | 用 CLIP 文本编码器倒数第二层特征——最后一层为对齐图像会丢失原始语义，倒数第二层更"听话" |

## 经验与常见坑
- 采样步数 ≠ 训练的 1000 步：WebUI 里的 Steps 是推理去噪的跳跃步数，20~30 通常够。
- 祖先采样器（Euler a 等）同样种子也难复现，做对比实验要选非祖先采样器。
- 负面提示词不是玄学：它替换的是 CFG 公式中的无条件分支，理解原理才能用得好。
- 小脸崩坏先怀疑 VAE，再怀疑模型；换 VAE 有时立竿见影。
- LoRA 微调通常不动 VAE 权重，但 VAE 依然决定重建上限。

## ⚠️ 时效性说明
- 整理基于 SD1.x 时代课程（2023）：SDXL 改用了更大分辨率与双 CLIP 等新结构；此后 SD3/Flux 采用 DiT（Transformer 替代 UNet）路线，"UNet 是唯一选择"已不成立，但 VAE+扩散+文本交叉注入的心智模型仍通用。
