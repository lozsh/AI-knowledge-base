# AI 绘画提示词工程与可控生成（Prompt / ControlNet）

<p class="note-date">更新于 2026-11-03</p>
> 一句话概括：prompt 是指令级控制，ControlNet 是构图级控制——先学好"咒语"语法与参数，再上结构控制大杀器。

## 核心概念

### Prompt 的控制力阶梯（初阶 → 高阶）
1. **直接描述**：`a happy dog and a cute girl`，加风格词 `watercolor style` 即可整体换风格；
2. **质量标签**：`best quality, masterpiece` 等社区约定标签提升画质（对 SD1.x 系模型有效，属于"条件反射"式的训练数据偏见）；
3. **负面提示词（Negative Prompt）**：填入不想出现的特征（`lowres, bad anatomy, extra digits...`），原理是用反向描述词替换 CFG 公式中的无条件分支；
4. **文本权重语法**：`(word)` 默认 ×1.1，`((word))` ×1.21，或直接 `(dog:1.2)` 精确指定；**建议不超过 1.3**，过大会画面崩坏；
5. **LoRA 引入**：`<lora:模型文件名:权重>`，权重 0~1，相当于给模型穿"新服饰"换风格。

- 社区黑话"抽卡"：固定 seed + 反复微调 prompt 多次生成直到满意。SD 对长 prompt 的语义组合能力有限，元素多了会丢（如两人同框只剩一人）——用权重语法或 ControlNet 补救。

### CFG Scale（提示词相关性）
- 范围 1~30，默认 7。越大越贴 prompt，但过高会过饱和、失真；过低则文本几乎不起作用。配合扩散模型一篇的 CFG 原理理解：它就是无分类器引导的插值权重 w。

## 关键方法/原理

### ControlNet：构图级控制
prompt 控制不了构图、姿态、手部结构——ControlNet 用额外的结构条件（线稿、姿态点、深度图、分割图等）精确约束生成。

#### 架构设计（理解三个问题）
1. **结构怎么搭**：拷贝 SD UNet 的 12 个编码器模块 + 1 个中间模块的权重作为 ControlNet 的主干，再加 **14 个零卷积层**做信息出入口；
2. **控制条件怎么进**：控制图（如 512×512 线稿）先用一个小型网络转成 64×64 特征，对齐 SD 潜在表示的维度，经零卷积后与 UNet 输入相加；
3. **两模型怎么交互**：ControlNet 13 个输出特征经零卷积后，逐层加到 SD UNet 对应的特征上。

#### 零卷积（zero convolution）的巧思
权重初始化为 0 的卷积层。训练第一步 ControlNet 的所有输出都是 0，加到 SD 特征上等于没加——**最大程度保住预训练 SD 的能力**，随训练推进控制力从零逐渐生长。这是"往强预训练模型上挂插件不伤本体"的通用范式。

#### 训练要点
- **SD 权重全程冻结**：一是插件不该影响本体，二是可学习参数减半以上省算力；
- UNet 输入 = 带噪潜在表示 + t 编码 + prompt 表征 + ControlNet 控制信号；
- 训练时 prompt 置空的概率从标准 SD 的 10% 提高到 **50%**——迫使模型更多依赖控制信号而非文本；
- **每种控制条件单独训练一个权重**（Canny、HED、OpenPose、深度图、分割图……社区有 20 余种）。

#### ControlNet 1.1 的两个杀手级功能
- **指令级修图**（instruct-pix2pix 思路）：prompt 写 "make it winter" 即可换季节/换衣服，保轮廓。训练数据是特殊成对数据：原图 + 修改指令 → 修改后图；
- **Tile 功能**：切块生成超高分辨率图像时，识别每块内容与 prompt 的相关性，无关块（如背景树叶）就降低 prompt 影响只补细节——避免"每块一个帅哥"的鬼畜拼图，也可做 8 倍超分（效果优于 Real-ESRGAN 纯超分）。

## 经验与常见坑
- 手部/脸部崩坏的组合拳：负面提示词（bad hands、extra fingers 等）+ 面部修复/ADetailer 插件 + ControlNet（手部关键点、深度）约束。
- prompt 权重语法是 WebUI（A1111）的方言，不同工具语法不通用。
- 固定随机种子才能做 prompt 的对照实验，否则分不清是词的作用还是噪声的作用。
- ControlNet 条件图分辨率要与生成分辨率匹配；条件与 prompt 冲突时，50% 空文本训练的模型更偏向听条件的。
- "best quality, masterpiece" 这类质量词对 SD1.x 有效是因为训练数据生态，对新架构模型未必有效，不要无脑堆。

## 术语表

| 术语 | 含义 |
|---|---|
| Prompt / 提示词 | 文本指令，经 CLIP 编码后引导图像内容 |
| Negative Prompt | 反向提示词，替换 CFG 无条件分支以压制不想要的特征 |
| 抽卡 | 固定参数反复生成、凭运气挑好图的行为 |
| ControlNet | 冻结 SD 主干 + 拷贝 UNet 编码器 + 零卷积的条件控制插件 |
| 零卷积 | 权重初始化为 0 的卷积，保证插件初始时不干扰预训练模型 |
| OpenPose | 人体关键点检测模型，常用作姿态控制条件 |
| Tile | ControlNet 1.1 的分块细节补充/超分功能 |
| instruct-pix2pix | "原图+指令→改图"的成对数据训练范式 |
| 重绘强度（Denoising Strength） | 图生图中对原图加噪的程度，控制改动力度 |

## ⚠️ 时效性说明
- 权重语法 `(word:1.2)`、`<lora:...>` 是 A1111 WebUI 语法；ComfyUI 等节点式工具表达方式不同。
- ControlNet 1.0/1.1（2023 初）的结论；后续有 ControlNet 的 SDXL 版本、T2I-Adapter、IP-Adapter 等变体，但"冻结主干 + 拷贝编码器 + 零卷积"的核心设计仍是理解这类插件的原型。
- 质量标签生态随模型代际变化明显，SD3/Flux 时代自然语言长 prompt 取代 tag 堆砌。
