# 扩散模型

> 来源：原资料《第11章 从噪声中创造：扩散模型》（wiki 化重写于 2026-11-03）

**一句话定义**：扩散模型（Diffusion Model）是一类生成模型，通过"给数据逐步加噪声、再训练神经网络学会逐步去噪"的方式，从纯随机噪声中一步步生成出逼真的图像、视频、音频等连续数据。

扩散模型是 2020 年代生成式 AI（Stable Diffusion、Midjourney、DALL·E、Sora、AlphaFold 3 等）背后最主流的技术核心。它解决的问题是：图像、视频、分子坐标这类高维连续数据千变万化，如何凭空"想出来"一张逼真的新图？它的答案是分而治之——不做一次性的"从噪声到成图"，而是把生成拆成几百上千次"只去一点点噪声"的小步骤，每一步都是一个简单的回归任务。

它重要的原因有三点：训练目标极其简单稳定（一个 MSE 损失，没有 GAN 的对抗崩溃）；生成质量高且多样；天然支持条件生成（加文字条件就是文生图，加姿势条件就能控制动作）。2022 年 Stable Diffusion 开源后，扩散模型把"AI 绘画"送进了普通人的日常，并随后扩张到视频、音频、3D、分子设计等领域。

## 简史

- **2015（思想源头）**：斯坦福 Sohl-Dickstein 等人在《Deep Unsupervised Learning using Nonequilibrium Thermodynamics》中提出"逐步加噪、学习反向去噪"的物理直觉（类比墨水扩散的熵增及其逆过程）。当时 GAN 如日中天，这篇论文沉睡了五年。
- **2020（DDPM 唤醒）**：伯克利 Jonathan Ho 等发表《Denoising Diffusion Probabilistic Models》（DDPM）。关键贡献不是新结构，而是一次漂亮简化：把复杂的变分推断目标推导成"预测噪声 + MSE 回归"。生成质量开始追近 GAN，且训练稳定得多。
- **2022（大众年）**：隐空间扩散（Latent Diffusion，慕尼黑大学 CompVis 的 Rombach 等人）把计算成本压到消费级 GPU 可承受；4 月 OpenAI 发布 DALL·E 2（闭源）；Midjourney 以 Discord 机器人形态出圈；8 月 Stability AI 与 CompVis、Runway、LAION 协作公开发布 Stable Diffusion（开放权重），几周内引爆全网社区生态。
- **2024（扩张到时间与生命科学）**：2 月 OpenAI 发布 Sora（底层思路与扩散 Transformer/DiT 相关，把视频切成时空词元处理）；同年 AlphaFold 3 改用扩散模型生成原子坐标，把结构预测推进到蛋白质与小分子、核酸的相互作用预测。
- **其后**：流匹配（Flow Matching）和一致性模型开始挑战经典扩散形式，采样更快、数学更简洁；"从噪声走向数据"的大思想保留，具体路线持续演进。

## 核心原理：加噪与去噪

**直觉**：一张清晰照片反复撒"雪花点"，几百步后变成纯噪声——这叫前向过程（加噪），固定、不学习。反向过程（去噪）训练一个神经网络学会"每一步去掉一点噪声"，从纯噪声出发重复几百步，就能"长出"一张新图。

⚠️ 常见误解：模型不是从噪声里"找回原来那张图"——生成时那张图根本不存在。模型学到的是：在每种模糊程度下，真实图像大概该往哪个方向变更清楚。像雕塑家凭经验一刀刀判断，而不是把石头里藏好的像挖出来。

**前向过程**：把清晰图 $\boldsymbol{x}_0$ 分 $T$ 步（通常 $T\approx1000$）加噪成纯噪声 $\boldsymbol{x}_T$：

$$\boldsymbol{x}_t = \sqrt{1-\beta_t}\,\boldsymbol{x}_{t-1} + \sqrt{\beta_t}\,\boldsymbol{\epsilon}, \quad \boldsymbol{\epsilon}\sim\mathcal{N}(\boldsymbol{0},\boldsymbol{I})$$

其中 $\beta_t$ 是每步噪声强度。系数 $\sqrt{1-\beta_t}$、$\sqrt{\beta_t}$ 的设计让方差保持稳定。前向过程没有可学参数；且因每步都是独立高斯，**任意中间时刻的 $\boldsymbol{x}_t$ 可从 $\boldsymbol{x}_0$ 一步直接算出**（无需迭代），这使训练非常高效。

**反向过程**：给定带噪图 $\boldsymbol{x}_t$，预测前一步 $\boldsymbol{x}_{t-1}$。巧妙之处在于不必直接学这个分布，只需让网络**预测加进去的噪声**——知道噪声是什么，减掉一小部分即可。这把"凭空画一只猫"的大问题，转化成"这张半糊的图里哪些部分像噪声"的小问题。

## 训练：一个 MSE 就够了

训练流程异常简洁：

1. 从训练集取一张干净图 $\boldsymbol{x}_0$；
2. 随机选时间步 $t\in\{1,\dots,T\}$；
3. 随机采样噪声 $\boldsymbol{\epsilon}$，按前向公式得到 $\boldsymbol{x}_t$；
4. 让网络 $\boldsymbol{\epsilon}_\theta(\boldsymbol{x}_t, t)$ 预测该噪声；
5. 用 MSE 损失训练：

$$\mathcal{L} = \mathbb{E}_{\boldsymbol{x}_0,t,\boldsymbol{\epsilon}}\left[\|\boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta(\boldsymbol{x}_t, t)\|^2\right]$$

没有判别器、没有对抗博弈、没有模式塌陷风险——目标朴素到"预测噪声、算误差、更新参数"，但正因如此训练曲线平滑、易于随数据和算力扩大规模。这是扩散模型能同时做到"稳"和"清"的核心，另两点是：分而治之（1000 次小步去噪远比一次成图好学）和自然支持条件生成。

**采样（生成）**：从纯高斯噪声 $\boldsymbol{x}_T$ 出发，反复"预测噪声→减去一部分"共 $T$ 步得到 $\boldsymbol{x}_0$。每步一次前向传播，这是扩散模型生成慢的主因（原始 DDPM 约 1000 步）。加速路线：DDIM（2020，约 50 步）→ Euler/Heun 等 ODE 求解器 → DPM-Solver（2022，15~20 步）→ 一致性模型（2023，一步出图，质量略降但对实时场景价值大）。

## 去噪网络：U-Net 与 DiT

| | U-Net（早期主流） | DiT / 扩散 Transformer（当代高端主流） |
|---|---|---|
| 结构 | U 型 CNN：下采样→上采样，带跳跃连接 | 把图像切成小块当作词元，用 Transformer 处理 |
| 优势 | 天然适合图像、参数和计算省、效率高 | 全局视野（每个位置看到整图）、易规模化、与 LLM 架构统一 |
| 劣势 | 局部视野有限，全局结构靠下采样 | 计算开销更大 |
| 代表 | 早期 Stable Diffusion | Sora、Stable Diffusion 3、Flux |

趋势：高端模型越来越多用 DiT（更能从规模化中受益）；轻量和编辑场景中 U-Net 仍长期存在。

## 文生图：让文字操控图像

- **文字条件注入**：提示词经文本编码器（常用 CLIP，其图文共享向量空间使"文字向量天然接近对应图像向量"）编码成向量，通过**交叉注意力**（query 来自图像特征，key/value 来自文字特征）注入每一步去噪，让生成向描述靠拢。
- **无分类器引导（CFG）**：只喂条件，模型倾向画"真实但不听话"的图（要戴墨镜的柴犬，墨镜没了）。CFG 在训练时随机去掉文字条件，推断时把有条件与无条件预测做线性外推：

$$\tilde{\boldsymbol{\epsilon}} = \boldsymbol{\epsilon}_\theta(\boldsymbol{x}_t, \varnothing) + w\left(\boldsymbol{\epsilon}_\theta(\boldsymbol{x}_t, c) - \boldsymbol{\epsilon}_\theta(\boldsymbol{x}_t, \varnothing)\right)$$

  即沿"条件 − 无条件"方向把生成再推一把。$w$ 越大越听话但越僵硬套路化，越小越自然但可能跑题（Stable Diffusion 的 "CFG Scale" 滑块就是它，常用 $w\approx7.5$）。
- **隐空间扩散（Latent Diffusion）**：直接在像素空间做扩散极贵（512×512 彩图近 80 万维）。做法：先用预训练 VAE 把图像压到小几十倍的隐空间（如 64×64×4），全部 $T$ 步加噪/去噪都在隐空间完成，最后解码器一次性还原。质量几乎不打折、算力降几十倍——这是 Stable Diffusion 能在消费级显卡上跑起来的关键。

## 关键概念

| 术语 | 含义 |
|---|---|
| 前向/扩散过程 | 固定的逐步加噪，把 $\boldsymbol{x}_0$ 变成 $\boldsymbol{x}_T$，无可学参数 |
| 反向/去噪过程 | 待学习的逐步去噪，核心是"预测噪声"这一回归任务 |
| DDPM | 2020 年的去噪扩散概率模型，把训练目标简化为 MSE，扩散模型爆发的起点 |
| CLIP | 图文对比学习模型，把文字和图像映射到同一向量空间，是文生图的语义桥梁 |
| 交叉注意力 | 图像位置"查询"文字特征的条件注入机制 |
| CFG | 无分类器引导，有条件/无条件预测的线性外推，控制生成对提示词的服从度 |
| 隐空间扩散 | 先 VAE 压缩再在隐空间做扩散，Stable Diffusion 的核心效率来源 |
| DiT | 扩散 Transformer，图像/视频切块作词元、用 Transformer 去噪的骨干网络 |
| DDIM / DPM-Solver / 一致性模型 | 三代采样加速路线：大步走→高阶 ODE 求解器→一步出图 |

## 图像编辑与控制

- **图生图（Image-to-Image）**：不从纯噪声、而从"加了部分噪声的原图"开始去噪。噪声强度是一个连续旋钮：加得多偏离原图，加得少贴近原图。典型应用：照片转艺术风格、白天改夜晚、素描上色。
- **局部重绘（Inpainting）**：圈出区域只重生成该区域——每步去噪都把"不想改的部分"替换回原图值。用于去路人、修老照片、换衣服；Photoshop"生成式填充"即基于此。
- **向外扩展（Outpainting）**：局部重绘的反面，让模型脑补画面外的区域（竖图补成横图）。
- **ControlNet（2023）**：额外加一个控制网络，接受骨架图（控姿势）、Canny 边缘图（草图填色）、深度图（控 3D 结构）、分割图（控布局）等辅助输入，把扩散模型从"随机创作工具"升级为精准设计工具。
- **LoRA（Low-Rank Adaptation，2021）**：不更新全模型参数，只在注意力层注入低秩修改模块，几十张图即可学会一个新概念/角色/风格；LoRA 文件仅几 MB（完整模型几 GB），社区有成千上万个可下载，是开源扩散生态繁荣的关键。详见 [13-LoRA与定制化图像生成](13-LoRA与定制化图像生成.md)。

## 应用版图

- **图像生成**：开源路线（Stable Diffusion，可微调、可插件化）与闭源路线（DALL·E、Midjourney、Imagen，一体化体验）并行。
- **视频生成**：视频是"时间上多出一维的图像"，让去噪网络同时处理时空两个维度。核心难点是**时间一致性**（物体稳定、错误会累积，狗第 3 秒长出第五条腿整段就废了）与**音画一致**。代表：Sora、Veo、可灵、Vidu、Runway、Pika。
- **3D 与分子**：3D 网格、分子坐标、蛋白质结构都是连续浮点数，正是扩散擅长的高维连续数据。3D 资产生成、药物分子生成（生成"自然界从未存在"的候选分子再筛选）、蛋白质结构预测（AlphaFold 3 用扩散生成原子坐标，预测蛋白质与小分子/核酸的相互作用）、新材料设计。
- **音频/语音/动作**：音乐生成（Suno、Udio）、语音克隆（ElevenLabs，便利与深度伪造风险并存）、机器人动作序列生成。
- **科学计算**：分子构象采样替代昂贵物理模拟、流体动画、气象预测的生成式多路径演化（天气预报本质是一组可能未来的分布）。

## 与其他生成范式的融合

- **流匹配（Flow Matching）**：更优雅的训练框架，学一个从简单分布到数据分布的连续流场，扩散可视为其特例；训练更稳、采样更快，新一代图像模型已采用。
- **一致性模型**：从任意噪声水平一步跳到干净图，速度逼近 GAN，是实时应用的关键突破。
- **扩散 × 自回归**：扩散语言模型（Diffusion-LM）把扩散用于文本；自回归图像生成（Parti 等）把图像切词元用 GPT 方式逐个生成。两者互补，混合路线在特定场景更合适。
- **物理建模**：扩散本身源自对布朗运动、热扩散的描述，天然适合建模物理过程。

## 经验与常见坑

- **只喂条件模型不听话**：要用 CFG 并调好权重；过大僵硬、过小跑题。
- **生成慢是结构性代价**：多步采样是与 GAN 单步生成的本质差距，实时场景需蒸馏采样/一致性模型。
- **文字描述天然不精确**：说不清"左手抬到肩、右转十五度"，要改用 ControlNet 等多模态输入控制。
- **提示词学不会没见过的概念**：特定角色/风格要靠 LoRA 微调，不能靠提示词硬凑。

## 挑战与伦理

- **技术挑战**：推断速度仍慢于 GAN；精细可控性靠多模态输入持续改进；视频的时间一致性与跨模态对齐（嘴型对语音、动作对节拍）尚未达到工业级随取随用。
- **深度伪造**：仿声诈骗、伪造政治人物发言、换脸视频已成现实问题。检测手段（水印、模型指纹、统计检测）与伪造是长期攻防，法律规管与公众媒介素养可能比纯技术更重要。
- **版权**：训练数据授权、风格模仿是否侵权仍在诉讼与立法演化中。
- **偏见**：模型反映训练数据偏见（早期文生"CEO"几乎都是白人男性），完全消除几乎不可能，需保持批判思维。
- **真实性危机**："眼见为实"的信任基础正被瓦解，社会需要数字签名、内容溯源等新信任机制。

## 哲学层面的三个追问

- **创造力是什么**：《太空歌剧院》用 Midjourney 迭代 900+ 版本获科罗拉多州博览会一等奖引发激辩。扩散输出严格说是训练数据分布的组合，但人类创造（梵高学浮世绘、毕加索借鉴非洲面具）也是"已知基础上的重组"——创造力更像光谱而非二元概念。
- **生成是否等于理解**：模型能组合"柴犬、墨镜、打字"这些概念，是一种有限但真实的理解（统计结构层面）；但对概念指代的世界（生物学、文化意义）一无所知。
- **创作者的未来**：技艺门槛被 AI 大幅降低后，创作者价值转向思想——独特视角、理念、故事。类比摄影术：它没有让画家失业，而是把绘画从"精确记录"解放出来，催生了印象派。

## ⚠️ 时效性说明

- 原文成稿于 2024 年前后：Sora 当时仅发布演示视频未开放；各家模型版本、能力边界变化很快，具体产品名（Veo 3、Flux、可灵等）以最新信息为准。
- 流匹配、一致性模型等新路线正在部分场景替代经典 DDPM 形式，"扩散思想"保留但具体技术形式持续演进。
- 版权诉讼、深度伪造监管等法律问题仍在演化，不同国家/地区路径不同。
