# LLaMA 3 模型设计、训练配方与开源生态

<p class="note-date">更新于 2026-11-03</p>
> 一句话概括：LLaMA 3 靠"海量数据 + 代码与工具调用数据配方 + SFT/PPO/DPO 三段后训练"把开源模型推到可用级，其设计选择（Decoder-Only、指令微调、上下文扩展）是理解开源大模型的标准样本。

## 核心概念

- **LLaMA 系列**：Meta 的开源（开放权重）大语言模型家族，是开源生态的锚点。Base 版负责文本续写，Instruct 版经过指令微调负责对话/工具调用——两者用途不同，不能混用。
- **Next Token Prediction（NTP，下一词预测）**：生成的底层机制——token 化 → 向量表征 → 预测下一词概率分布 → 循环采样直到停止条件。模型本身**无状态**：多轮对话能力来自把历史拼进输入，而非模型"记得"。
- **指令跟随（Instruction Following）**：模型按自然语言指令调用工具、执行任务的能力，是插件、智能体、RAG 的共同基础。
- **指令微调（Instruction Tuning）**：用人类对话数据 + 工具使用数据训练，让模型学会分解指令并调用工具。零样本能力来自微调数据中大量"仅指令、无示例"的样本。
- **结构化输出能力**：模型能稳定输出 JSON 后，才可能嵌入现有系统的任意模块——这是 LLaMA 3 后训练重点投入的方向，也是它能直接当 ReAct 智能体用的原因。

## 关键训练配方（据公开技术报告）

### 数据配方
- 预训练语料以 **15T+ token** 计，规模是 LLaMA 2 的数倍；数据质量（去重、清洗、配比）与数量同等重要。
- **大量代码数据**：不仅为写代码，更为了提升结构化推理能力（代码是最"讲逻辑"的语料）。
- **合成多工具调用数据**：专门构造 ≥2 个工具组合调用的样本，使模型开箱即可做 ReAct 式智能体。
- 指令微调数据刻意包含"只有指令没有示例"的样本 → 奠定零样本（Zero-shot）能力。

### 后训练三段式
| 阶段 | 作用 |
|---|---|
| SFT（监督微调） | 用高质量对话数据教会基本对话与指令格式 |
| PPO（近端策略优化） | RLHF 经典路线，用奖励模型对齐人类偏好 |
| DPO（直接偏好优化） | 直接用偏好对数据优化，绕开显式奖励模型，更轻量 |

### 模型与上下文设计
- 参数规模梯度化：8B / 70B（LLaMA 3）→ 405B（3.1，对标闭源旗舰）→ 3.2 的 1B/3B 端侧小模型与 11B/90B 视觉模型。**梯度覆盖**是开源策略核心：端侧到数据中心各取所需。
- 上下文长度演进：LLaMA 2 的 4K → LLaMA 3 的 8K → 3.1 的 128K。社区微调版（llama3-gradient）曾做到 1M 级。
- 多模态路线（3.2 Vision）：**文本模型 + 视觉适配器**，图像编码器输出经跨注意力（Cross-Attention）注入语言模型；训练分三阶段——图文配对预训练 → 高质量领域微调 → SFT + 安全 + 偏好对齐。这种"适配器外挂"是给已有文本模型加视觉的低成本通用做法。

## 开源生态要点

- **部署**：Ollama 等一键拉起本地模型（base 与 instruct 标签区分用途）；HuggingFace 是权重与模型卡的分发中心。
- **典型本地组合**：Ollama（推理）+ LangChain/LlamaIndex（编排）+ Chroma（向量库）+ BGE-M3 等开源嵌入模型。
- **选型心智模型**：简单 FAQ 问答用小模型组合即可（省钱、数据不出域）；复杂推理与工具调用才需要大参数模型或闭源 API。开源小模型两个硬伤：上下文短、推理弱。
- 推理模型方向（OpenAI o1 类）代表"多步推理产品化"，开源模型随后跟进——**CoT 从提示技巧变成了训练目标**。

## 经验与常见坑

- **Base 版 ≠ Instruct 版**：文本续写用 base；指令/对话/工具调用用 Instruct。用错版本会得出"模型很笨"的错误结论。
- 生成必须设 max tokens 等停止条件，否则可能停不下来。
- 正文中的版本规格是快照事实，实际以各版本技术报告为准（见下方时效性说明）。
- 判断一个开源模型"能不能做智能体"，看它的后训练是否含工具调用数据，而不是只看参数量。
- 语言数据枯竭、token 边际收益递减是行业共识：下一步的增量在多模态、空间与动作智能（VLA 方向），而非单纯堆语言 token。

## ⚠️ 时效性说明

以下为 2024 年的事实快照，使用前需核实最新版本：
- 规格数字：LLaMA 3（8B/70B，8K 上下文，15T token 预训练）→ 3.1（405B，128K 上下文）→ 3.2（1B/3B 文本 + 11B/90B Vision）→ 3.3（70B）。版本迭代极快。
- 文中示例工具链：Ollama（llama3:text）、graphrag==0.1.1（API 已大改）、nomic-embed-text、Python 3.11——具体 API 用法不要照搬。
- OpenVLA（7B，基于 LLaMA 2 微调）为当时具身智能开源代表。
