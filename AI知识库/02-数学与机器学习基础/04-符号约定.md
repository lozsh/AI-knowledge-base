# 符号约定（ML Systems）

> 来源：《机器学习系统》教材 Notation 章（wiki 化重写于 2026-11-03）

**一句话定义**：机器学习系统横跨 ML（计算机科学/统计学）与 Systems（体系结构/硬件）两个领域，同一字母在两边含义冲突（如 B 在 ML 是 batch size、在硬件是 bandwidth），本章建立一套消歧符号约定，并给出铁律方程、退化方程、能耗推论的标准记法。

选例说明冲突之真实：语句"Increasing B improves throughput"，ML 研究者读作"增大 batch size 提升吞吐"，硬件工程师读作"增大带宽提升吞吐"——两者都对，但 ML Systems 需要这两个概念出现在同一个方程里，因此必须统一约定。

## 核心原理：铁律方程（Iron Law of ML Systems）

$$T = \frac{D_{\text{vol}}}{BW} + \frac{O}{R_{\text{peak}} \cdot \eta_{\text{hw}}} + L_{\text{lat}}$$

每个符号都刻意避开标准 ML 术语：

| 符号 | 定义 | 单位 | 为什么这样选 |
|---|---|---|---|
| T | 时间（wall-clock） | 秒 | 无歧义 |
| D_vol | 数据量（搬运的字节数） | 字节 | 避免与 D（数据集大小/训练 token 数）冲突，下标消歧 |
| BW | 带宽 | 字节/秒 | 物理用 B 表带宽，但 ML 论文普遍用 B 表 batch size——保留 ML 惯例，带宽改用 BW |
| O | 运算总量 | FLOPs | 比写"Ops"在公式里干净 |
| R_peak | 峰值算力 | FLOP/s | Roofline 模型传统用 P 表峰值性能，但 ML 用 P 表参数量——保留 ML 惯例 |
| η_hw | 硬件利用率（0–1） | — | 避免与学习率 η 冲突 |
| L_lat | 固定延迟（kernel 启动、网络 RTT） | 秒 | 下标区别于损失函数 ℒ |

符号选错会让句子产生歧义："Reducing D improves performance" 可读作"减少训练样本数加速训练（可能掉精度）"，也可读作"减少搬运数据量（压缩/量化）加速推断"。用本约定可精确写出："通过 FP32→INT8 量化把 D_vol 降到四分之一，而 D（训练数据）不变。"

**下标排版规则**：多字母量取描述性下标时（如 BW_disk、BW_network、D_vol、R_peak、L_lat、η_hw、E_move），根与下标都放进 \text{}；否则数学模式会把每个字母渲染成斜体变量、间距塌缩，看起来像乘积而不是标签。

## 退化方程（Degradation Equation）

模型上线后精度的静默退化：

$$\text{Accuracy}(t) \approx \text{Accuracy}_0 - \lambda \cdot \mathcal{D}(P_t \| P_0)$$

| 符号 | 定义 | 备注 |
|---|---|---|
| Accuracy(t) / Accuracy₀ | 部署 t 时间后的精度 / 部署时初始精度 | 标量 |
| λ | 模型对分布偏移的敏感度 | 与架构相关（不是波长） |
| P_t / P₀ | 当前数据分布 / 训练时数据分布 | 不是参数量——参数量用 P（整数） |
| 𝒟(P_t‖P₀) | 统计散度（KL、总变差、Wasserstein 等） | ≥0；花体 𝒟 避免与 D=数据集大小冲突 |
| τ | 漂移阈值 | 𝒟(P_t‖P₀) > τ 时触发重训 |

## 能耗推论（Energy Corollary）

$$E_{\text{total}} \approx D_{\text{vol}} \times E_{\text{move}} + O \times E_{\text{compute}}$$

其中 E_move 是每字节搬运能耗（焦耳/字节），**通常主导总能耗（E_move ≫ E_compute）**；E_compute 是每 FLOP 运算能耗。

## 深度学习符号（遵循 Goodfellow et al. 2016，加系统侧消歧）

| 符号 | 定义 | 备注 |
|---|---|---|
| B | Batch Size | 永远不是带宽 |
| P | 参数量 | 永远不是峰值 FLOP/s |
| D | 数据集大小（样本数或 token 数） | 字节量用 D_vol |
| S | 序列长度 | |
| d / d_head | 隐藏维度 / 注意力头维度 | |
| N_L / N_heads / H_KV | 层数 / 注意力头数 / KV 头数（GQA、MQA） | |
| ℓ | 层索引 | 用 ℓ 不用 L——L 与 loss、latency 冲突 |
| ℒ | 损失函数 | |
| η | 学习率 | 硬件效率用 η_hw |
| θ | 模型全部可学习参数 | |
| p(x) / p(y\|x) | 通用分布 / 条件分布（小写 p） | 避免与 P（参数量）冲突；退化方程的 P₀/P_t 专用 |
| Pr(E) | 事件概率（如 Pr(batch=0)） | 分布用 p(x)，事件用 Pr(·) |

局部例外：矩阵运算方程内可局部用 A、B、C 作操作数（如 GEMM：C = αAB + βC），这是局部线代惯例，不是对 B=batch size 的全局覆盖。

## 性能、服务与内存符号

| 符号 | 定义 | 单位 |
|---|---|---|
| I | 运算强度（每字节搬运的 FLOPs），Roofline 的自变量 | FLOP/byte |
| I_ridge | Roofline 拐点 = R_peak / BW（用显式形式，不用星号简写） | FLOP/byte |
| R_attain | 可达算力 = min(R_peak, I×BW) | FLOP/s |
| MFU | 模型 FLOP 利用率 = 有效 FLOP/s ÷ 可用峰值 FLOP/s | 无量纲（用缩写避免过载 η） |
| r_comp | 压缩比 = 未压缩/压缩后（压缩后大小 = M/r_comp） | 无量纲 |
| Q_req | 在途请求数（避免与分布式设备数 N 冲突） | 请求数 |
| λ_arr | 请求到达率（下标区别于退化敏感度 λ 和故障率） | 请求/秒 |
| T_lat | 系统内端到端排队/服务时延（Little's Law 用），区别于铁律固定项 L_lat | 秒 |
| T_svc(B) / μ_eff(B) | 服务一批的时长 / 有效服务率 ≈ B/T_svc(B) | 秒；请求/秒 |
| ρ_serv | 服务利用率（裸 ρ 保留给通信-计算比） | 无量纲 |
| M_total / M_weights / M_gradients / M_optimizer / M_activations | 总内存 / 权重 / 梯度 / 优化器状态（动量、方差、主权重）/ 激活内存 | 字节 |
| s_elem | 每元素存储字节数 | 字节/元素 |

## 单位与精度

- **单位制**：全文 SI 单位，数字与单位间空格（100 ms、2 TB/s）；
- **数据量**：只用十进制 SI 前缀——KB=10³、MB=10⁶、GB=10⁹、TB=10¹²（不用二进制前缀）；
- **算力**：区分总量与速率——FLOPs 表运算总量（GFLOPs、TFLOPs），FLOP/s 表吞吐（1 TFLOP/s = 10¹² FLOPs 每秒）；运算强度是比值单位 FLOP/byte；
- **精度格式**：FP64（8 字节）、FP32（4 字节）、TF32（19 位计算格式，常按 FP32 存储）、FP16（2 字节标准范围）、BF16（2 字节宽动态范围）、FP8（1 字节，E4M3/E5M2）、FP4、INT8、INT4（更低整数精度沿用 INTn 命名）。

## 快速对照：常见冲突的裁决

| 符号 | ML 含义 | Systems 含义 | 本约定 |
|---|---|---|---|
| B | Batch Size | Bandwidth | Batch Size；带宽用 BW |
| P | Parameters | Peak FLOP/s | Parameters；峰值速率用 R_peak |
| D | Dataset Size | Data Volume | Dataset Size；字节用 D_vol |
| L | Loss | Latency | 损失用 ℒ；延迟用 L_lat |
| η | 学习率 | 效率 | 学习率；效率用 η_hw |

**总原则：单字母优先给 ML 惯例，系统侧概念加下标或多字母符号**——反映主要读者（学系统的 ML 从业者），并保持与浩繁 ML 文献的兼容。
