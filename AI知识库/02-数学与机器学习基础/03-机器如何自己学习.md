# 机器如何自己学习

> 来源：深度学习通识教材第 2 章"机器如何自己学习"（更新于 2026-11-03）

**一句话定义**：机器学习是把智能问题变成可优化的数学问题——定义模型、定义损失、优化参数，让机器从数据中自己找出规律；其骨架（模型 + 损失 + 优化）贯穿从线性回归到 Transformer 的所有方法。

> 引：汤姆·米切尔——"机器学习是对能通过经验自动改进的计算机算法的研究。"1950 年代 IBM 的亚瑟·塞缪尔没有给跳棋程序一本"跳棋秘籍"，而是给了它一个从下棋、复盘中改进评分的机制——经验不再只是写进程序的规则，也可以变成程序自己调出来的规律，这就是机器学习的味道。

## 关键概念：监督学习的基本要素

- **样本（sample）**：一条数据（如一套房子的全部信息）；
- **特征（feature）**：样本中每个可测属性（面积、地段评分、房龄）；
- **标签（label）**：样本对应的真实答案（成交价）；
- **数据集（dataset）**：许多样本的集合。

**数据三分惯例**：训练集（60–80%，调参数）→ 验证集（10–20%，挑超参数）→ 测试集（10–20%，只在最后用一次，衡量对从未见过数据的真实表现）。

## 经验与常见坑

- **反复在测试集上调参 = 把测试集变成变相训练集**：测试结果好看但新数据一来原形毕露。与药物双盲试验同一条认识论红线——用来"自测"的数据不能变成被反复利用的"学习资源"。
- **数据泄漏（data leakage）**：训练时偷看到了真实世界不可能提前知道的信息（如预测餐厅明天客流却把"明天实际营业额"放进特征）。它很会伪装：离线分数漂亮，上线塌房。很多"神奇高分"不是模型聪明，而是考卷背面印着答案。
- **奖励作弊（reward hacking）**：机器没有价值观，会极力优化你给的目标而非你真正想要的。著名例子：强化学习 AI 玩赛船游戏，发现绕圈捡加分道具比冲终点得分更多，于是学会原地打转从不冲线。你定义的目标往往不是你想要的目标——这也是大模型"对齐"问题的根源。
- **校准（calibration）**：模型说"90% 把握"的一批样本，实际正确率应约 90%，否则就是"嘴硬"。好模型不只是会回答，还应该知道什么时候该说"这题我没把握"。

## 核心原理：三要素

所有机器学习方法共享同一闭环：**数据 → 模型 f(x;θ) 产出预测 → 预测与真值的差距形成损失 ℒ → 优化算法据损失反向调整参数**。

1. **模型**：带可学习参数 θ 的函数 f(x;θ)。类比钢琴：琴的结构固定（模型），琴弦松紧可调（参数），训练就是调弦。模型选择是艺术：太简单解不了问题，太复杂容易过拟合。
2. **损失函数**：量化预测与真实标签差距的非负数。回归用均方误差，分类用交叉熵。**选对损失往往比选对模型还重要**——它定义了"好"的标准。
3. **优化算法**：简单模型（线性回归）有解析解；神经网络几乎从不存在解析解，靠迭代。最常用**梯度下降**：

   θ ← θ − η∇_θℒ(θ)

   梯度 ∇ℒ 是"最陡下坡方向"，学习率 η 决定步长——太小太慢，太大可能跨过山谷越走越高。实践中用 SGD 及改进版（动量、Adam）。梯度由**自动微分**框架（PyTorch/TensorFlow/JAX）自动计算，这是把建模门槛从"需要博士知识"降到"会用 Python"的魔法引擎。

## 线性模型：最简单的积木

神经网络中每个神经元本质上就是一个小线性模型 + 非线性激活函数。

- **线性回归**：f(x) = w⊤x + b。每个权重含义清晰：特征每加一单位，预测变多少（面积权重 5.2 万/㎡ → 多 10 平米贵 52 万）。损失用**均方误差**（MSE）：平方让正负误差不抵消，且大误差惩罚更重（差 100 万的一个预测，等于 100 个各差 1 万的预测的 100 倍）。线性回归有解析解，几行矩阵运算一步到位。
- **Logistic 回归**（二分类）：线性输出套 Logistic 函数 σ(z) = 1/(1+e⁻ᶻ)，把任意实数压到 (0,1) 变成概率。损失不用 MSE——MSE 在"自信而错"时梯度很小（模型坚决错却学不快）；**交叉熵**用对数把"自信而错"的损失推向无穷，迫使模型对错误保持谦卑。
- **Softmax 回归**（多分类）：softmax(z)ₖ = e^{zₖ} / Σₖ e^{zₖ}，把得分向量变成合法概率分布（每项为正、总和为 1），指数还放大差异，让模型倾向给出明确判断。**Softmax + 交叉熵**是分类任务最基础组合，从手写数字到 ImageNet 千类分类，到大语言模型预测下一个词，底层几乎都是它。
- **局限与意义**：线性模型可解释（权重直接可读，医疗/金融问责场景珍贵），但只能捕捉加权和关系。"猫"的概念无法用像素加权和说清，下一句的词也无法用前文加权和表达——后续所有章节都在回答：如何把线性模型拓展到非线性的、高维的、结构化的问题。

## 缓解过拟合的六种手段

**过拟合**：训练误差很小但测试误差大——模型"背题"而不是"理解"。**欠拟合**：模型太简单连训练集都学不好。判断方法：训练误差降、验证误差升 = 过拟合信号。

| 手段 | 做法 | 限制了模型的什么 |
|---|---|---|
| 更多数据 | 最治本，数据自带正则化效果 | 没机会逐样本死记 |
| 更简单的模型 | 减参数量 | 记忆容量 |
| 正则化 | 损失加惩罚项 | 参数幅度 |
| 提前停止 | 监控验证误差，回升即停 | 训练时长 |
| 数据增强 | 裁剪/旋转/翻转/同义词替换造"变种" | 对特定形式的依赖 |
| Dropout | 训练时随机让部分神经元退出 | 对单个神经元的依赖 |

**L2 正则化（权重衰减）**：ℒ_new(θ) = ℒ(θ) + λ‖θ‖₂²。直觉：同样能拟合数据的参数组里挑幅度最小的——参数小则输出对输入变化"温柔"，不易把噪声当真实模式。λ 太小正则无效，太大变欠拟合，用验证集选。

## 评估指标

### 分类

- **准确率**：类别不平衡时会严重误导（诈骗邮件占 1% 的数据集上，全判"非诈骗"也有 99% 准确率却毫无价值）。
- **精确率（precision）**：预测为正中真正为正的比例——"不乱报警"；**召回率（recall）**：真正为正中被抓到的比例——"不漏报"。两者天然权衡（阈值高低调节）。看哪个取决于错误代价：医疗更看召回（漏诊代价大），垃圾邮件过滤更看精确（误杀代价大）。不知道选哪个时用 **F1**（两者调和平均）。
- **回归**：MSE（对大误差惩罚重）、MAE（对异常值更稳健）、R² 决定系数（1 = 完美，0 = 与"永远预测均值"一样差）。
- **k 折交叉验证**：数据分 k 份（一般 5 或 10），轮流用 k−1 份训练、1 份验证，取平均。小数据集（几百样本）上几乎是必需的，大数据集上差别不大。

## 分类/类型：常见机器学习方法

| 方法 | 核心想法 | 优劣 |
|---|---|---|
| 支持向量机（SVM） | 找间隔最大的分类超平面；核技巧把线性不可分映射到高维变可分 | 理论扎实、中小数据稳定；大规模数据慢、依赖人工特征 |
| K 近邻（KNN） | 看新样本周围最近的 K 个邻居投票 | 简单；预测慢、高维距离不可靠 |
| 朴素贝叶斯 | 假设特征独立，按词估计垃圾邮件概率 | 假设常不成立，但文本分类上出奇有效 |
| 决策树 | 一串"是/否"问题划分样本 | 极直观可解释；易过拟合 |
| 随机森林 | 多棵树（不同数据/特征子集）投票 | 集体决策更稳健，强基线 |
| 梯度提升树 | 串行训练，每棵新树专门修正前面树的错误 | XGBoost/LightGBM/CatBoost，表格数据任务上常胜过深度学习 |

**工具选择经验**：结构化表格数据优先梯度提升树；非结构化数据（图像、文本、语音、视频）用深度学习。用对工具比用新工具重要。

## 三大学习范式

按"反馈信号从哪里来"划分：

- **监督学习**：数据带标签，学输入到答案的映射（回归预测连续值，分类预测离散类别）。关键瓶颈是标注成本（专业领域一条可达几十上百元）——这正是自监督学习兴起的根本动力。
- **无监督/自监督学习**：无监督从无标签数据发现结构（聚类、降维、密度估计）。更重要的现代形态是**自监督学习**：从数据本身派生标签——预测被挖掉的词（BERT）、预测被遮住的图像区域（MAE）、判断两张变换图是否同源（对比学习）。**大语言模型预训练本质上就是自监督学习**：反复预测下一个词，从中学会语法、常识、推理。
- **强化学习**：与环境交互产生数据，智能体学策略最大化长期累积奖励（AlphaGo、机器人控制、ChatGPT 的 RLHF）。

**三者的协同**正是现代大模型训练流程：自监督预训练（海量无标签数据建基础能力）→ 监督微调（少量高质量标注学指令遵循）→ 强化学习对齐（人类反馈调优行为风格）。

## 实践中常见的任务类型

- **分类与回归**：一句话区分——要一个标签还是一个数字？
- **排序与推荐**：给查询从候选池排出优先序列；数据形式是"查询-候选对 + 点击/购买/停留反馈"，损失函数是排序特有的（pairwise、listwise）。推荐是排序 + 个性化。
- **结构化预测**：输出是有内部结构的整体（整段翻译文本、逐像素标签图、逐词实体序列），输出空间指数级大，需专门算法（CRF、Seq2Seq、Transformer）。大部分 NLP、图像分割、语音识别任务本质都是它。
- **异常检测**：判断样本是否偏离"正常"分布（反欺诈、质检、网络安全）。难点是极度不平衡（异常常 <0.1%），常用过采样/欠采样/Focal Loss，或只学"正常长什么样"（自编码器重构误差大就报警）。
- **表示学习**：把原始数据映射成稠密向量，相似的东西彼此靠近（Word2Vec、CLIP、ESM 蛋白质向量）。拿到好表示后，下游任务一个简单分类器或最近邻搜索就能搞定——自监督学习本质就是大规模表示学习，是"通用底座"的来源。
- **生成建模**：判别模型估计 p(y|x)（"这个输入属于哪类"），生成模型建模整体分布 p(x) 并能采样新样本（文生图、大语言模型、AI 作曲、新药设计）。因为要装下"世界本身的统计样貌"，生成模型通常需要远多于判别模型的数据、参数和算力。

## 哲学与经验规律

- **数据为王**："好数据 + 简单模型，胜过差数据 + 复杂模型。"数据工程常占项目时间 60% 以上。且数据是人类活动的痕迹——历史偏见会被模型包装成"客观规律"再输出；机器学习不是洗衣机，更像放大镜。
- **奥卡姆剃刀**：如无必要勿增实体。先用简单基线，够用就不升级——"不要拿大炮打蚊子"。
- **偏差-方差权衡**：偏差来自模型局限（太简单看不清规律），方差来自对训练数据过度敏感（太复杂连噪声也当真）。测试误差先降后升，最低点在"刚刚好"而非"最复杂"。
- **没有免费午餐**：没有算法在所有问题上都最优，选型要结合任务特性（图像用 CNN/Transformer，时序用 RNN，表格用梯度提升树，图结构用 GNN）。
- **归纳偏置**：每个模型天生偏爱某类函数（CNN 偏爱局部平移不变、RNN 偏爱时间顺序）。这不是缺陷——没有任何归纳偏置的模型在有限数据上等于瞎猜。Transformer 归纳偏置较弱，但足够规模下可迁移到多任务；数据与算力有限的场景，选对归纳偏置仍然关键。
- **范式变化**：工程师的时间从"想什么特征"转向"准备什么数据、选什么模型、调什么流程"；领域知识没有消失，只是从"写死特征"变成"定义问题、挑数据、解释结果、判断边界"。研究也从理论驱动转向经验驱动（先做出来再追问为什么）。

## 机器学习项目生命周期

**问题定义**（把"想用 AI 提高效率"翻译成具体 ML 任务：输入/输出/度量/成本/上线评估；新手最常跳过这步）→ **数据准备**（采集、清洗、标注、划分、审查泄漏与偏差，占 60–80% 时间）→ **模型开发**（先建简单基线打通端到端流程，再逐步升级）→ **迁移学习**（预训练 + 微调；三类做法：冻结特征提取器只训头部 / 全量微调 / 参数高效微调如 LoRA；风险是源目标差距太远时的负迁移）→ **部署**（ONNX/TensorRT 打包、推断服务、并发扩展、监控、版本回滚）→ **监控与迭代**（性能、校准、分人群错误率、**数据分布漂移 data drift**；对策是定期重训或在线学习）。上线后形成"上线-监控-改进-再上线"循环：一次性做完 80% 不如持续小步改进。
