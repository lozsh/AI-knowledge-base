# 两派视角、理论与概率图模型：贝叶斯主线上的机器学习

<p class="note-date">更新于 2026-11-03</p>
> 一句话概括：频率派与贝叶斯派对"概率是什么"的分歧贯穿机器学习全部方法论；计算学习理论回答"能学到什么程度"，验证与评估回答"学得好不好"，概率图模型与推断（变分/MCMC/EM）则是贝叶斯主线的工程实现。

## 核心概念

### 两大视角：概率是什么
| 维度 | 频率学派 | 贝叶斯学派 |
|---|---|---|
| 概率定义 | 独立重复试验中频率的极限 | 事件的可信程度（degree of belief），主观可修正 |
| 参数 | 固定不变的常量，谈参数分布无意义 | 参数本身是随机变量，有分布 |
| 数据 | 随机变量，由参数支配生成 | 对假设（信念）的修正证据 |
| 核心方法 | 最大似然估计 MLE | 贝叶斯定理：后验 ∝ 似然 × 先验 |
| 适用场景 | 可大量重复的试验 | "一锤子买卖"（不可重复事件、个别诊断） |
| 代表流派 | 统计学习理论（SVM） | 概率图模型 |

- "九死一生"笑话：蹩脚频率派把 10 例 9 死 1 生当成精确概率——小样本频率没有极限意义。
- 贝叶斯定理 P(H|D)=P(D|H)P(H)/P(D) 的哲学意义：**刻画数据对信念的影响**——先验经似然修正为后验。"戈培尔谎言"例子：低先验的谎言在"人们相信宣传"的高似然下，后验可被反复推高。
- 最大后验估计 MAP = 带先验的最大似然；MLE 是先验均匀分布时的特例。

### 计算学习理论：到底能学到什么程度
- 出发点：**若无法通过算法获得训练集之外的信息，学习任务不可行**。5 个训练样本 + 3 个测试点、8 种可能映射——单靠样本无法确定真实规律，唯一确定的是不确定性。
- 解法：不求对特定问题给出最优解，而求**概率意义上的通用保证**。
- 袋球类比：样本中红球比例 ν（可观测训练误差）近似总体比例 μ（泛化误差），大偏差概率随样本量指数衰减（Hoeffding 不等式一类）。
- 相关概念：PAC（概率近似正确）学习；**VC 维**（模型能打散的最多样本数）刻画模型容量与过拟合风险。

### 模型的分类与设计
- **参数模型 vs 非参数模型**：能否用有限固定数目的参数完全刻画。参数模型（线性回归、神经网络）参数少、每个有明确统计意义，但依赖超强的先验假设（数据服从特定分布族）；非参数模型（KNN、核方法、高斯过程）让数据自己说话。心智模型：**参数模型的便捷来自先验假设的强度**。
- 两大设计定律：**没有免费午餐**（脱离具体问题谈"最强算法"无意义，所有算法在全部问题上平均性能相同）；**奥卡姆剃刀**（解释力相同时选更简单的假说——正则化的哲学根据）。

### 学习-练习-考试三阶段
1. **模型拟合**：训练集拟合普通参数；
2. **模型选择**：验证集调超参数、筛模型；
3. **模型评价**：测试集估计真实泛化性能（只用一次）。
- 数据不够分三份时：验证/测试合并，或用交叉验证。

### 偏差-方差分解
泛化误差 = **噪声 + 偏差 + 方差**：
- 偏差：模型假设与真实规律的差距（线性模型拟合平方关系 → 高偏差 → 欠拟合）；
- 方差：数据扰动对模型的影响（模型太复杂 → 高方差 → 过拟合）；
- 训练误差是泛化误差的**乐观估计**；训练集 100% 正确率常是过拟合征兆（完美拟合噪声 = "精准画出一只猫"）。

### 评估指标（二分类）
- 精度 accuracy 的陷阱：类别不平衡时严重失真（73% 留存率下"全预测留存"就有 73% 精度；欺诈检测"全预测正常"达 99.999% 但毫无意义——目标是找出极少数异常）。
- 工具链：**混淆矩阵**（TP/FP/FN/TN）→ 精确率（查准）、召回率（查全）、F1、ROC-AUC。
- **假阳性 vs 假阴性代价不同**：医学"宁可错判不能放过"——对应统计学第一类/第二类错误。
- 经典贝叶斯直觉题：检查准确率 95%、发病率 1%，阳性下真实患病概率仅 16%——**基率（先验）主导小概率事件的后验**。

## 关键方法/原理

### 线性回归的演化地图（模型体系总纲）
线性回归三特点：**线性、全局性、数据不变性**。主流模型都是逐一打破这三个假设：
- 破"线性"：**属性非线性（基函数：多项式/样条）→ 参数非线性（神经网络的自适应基函数）→ 全局非线性（广义线性模型/链接函数）**。
- 破"全局性"：**结构化局部（核函数：每样本管一亩三分地）→ 非结构化局部（KNN 等基于距离的学习）→ 分布式表示（深度学习）**。
- 破"数据不变性"：特征预处理（缩放、降维、流形学习）。
- 正则化对应参数先验（L2≈高斯先验、L1≈拉普拉斯先验）——频率派收缩方法的贝叶斯解读。

### 正则化 = 系数收缩
- 损失函数加 λ·g(‖w‖ₚ) 惩罚大参数——"以偏差的增加换方差的下降"。L1→**LASSO**（系数压到 0，兼做特征选择）；L2 平方→**岭回归**（整体缩小不归零）；统计学名叫**收缩方法**（shrinkage）。

### 概率图模型：贝叶斯主线的建模语言
- 动机：输入输出之间有可见/不可见的中间变量，要算输出分布就得把它们纳入框架；**图 = 表达多变量条件独立关系的简洁语言**。概率图 = 概率论（条件独立）+ 图论（结构）。
- 两大族：**贝叶斯网络**（有向图，因果/依赖方向）与**马尔可夫随机场**（无向图，相互约束）。
- **朴素贝叶斯是最简单的概率图**：类别节点指向所有属性节点的星型图，图形本身声明条件独立性。
- **贝叶斯网络 = 有向无环图（DAG）**：有向 = 因果不可颠倒；无环 = 变量不能自己决定自己。本质功能：**联合分布分解为各节点给定父节点的条件概率之积**，参数量从指数级降到局部。
- 直觉示例（"傻瓜贝叶斯网络"）：廊外灯亮 + 狗在院子 → 推断家中是否有人。灯亮不能确定有人（可能是客约访），狗在院子也不能确定（邻居喂食）——多路证据在图上汇聚成后验。
- 条件独立三种图结构：链式 A→B→C、分叉 A←B→C、汇聚 A→B←C（**"解释消除"**：父节点先验独立、给定共同子节点后变相关——最反直觉）。
- MRF：边表示势函数（相容度），联合分布 ∝ 团态势函数之积，适合"约束"而非"因果"；高斯网络：条件独立 = 偏相关为零。

### 动态模型：隐马尔可夫 HMM 与高斯过程
- 打破独立同分布、引入时间维度：图节点按时间连起来 = 动态贝叶斯网络，最简单实现即 HMM。
- **马尔可夫链**：状态全可见，参数只有转移概率；**HMM**：状态隐藏，只能看到依赖状态的输出（罐子问题：看不见换罐子，只看见摸出的球）。
- 三大经典问题：评估（前向算法）、解码（Viterbi）、学习（Baum-Welch，即 EM 特例）。
- 连续状态版：线性动态系统（卡尔曼滤波）；无限维推广：**高斯过程**——无穷多个高斯变量叠加成函数空间上的分布，任意有限取点子集联合高斯；贝叶斯优化的数学基础。

### 推断与学习
- **精确推断**（变量消除）：逐个消去变量化简求和；图结构好（树/低树宽）时可行，一般网络指数复杂度。
- **确定性近似——变分推断**：用简单分布族逼近复杂后验，把推断变成优化问题。
- **随机近似——MCMC**：只需后验期望/最大后验取值、且归一化常数难算（如 Beta 分布常数）时，**构造马尔可夫链采样，用样本分布代替难解的后验**；只需按比例计算密度，无需归一化。
- **EM 算法**：隐变量 = 数据的不完整性。E 步用当前参数算隐变量期望，M 步最大化期望更新参数，循环至收敛。直觉：参数 θ 与隐状态 Z 互相依赖，像联动的齿轮交替估计——本质坐标上升。**只保证收敛到局部最优**，对初始化敏感；高斯混合 GMM 是标准应用。
- 结构学习：图结构未知时，基于约束（条件独立检验）或基于评分（搜索 + BIC 等打分）学习拓扑。

### 小样本学习
- 动机：人看一两只猫就会认猫，机器却要海量图片；数据不足 → 维度灾难与过拟合。
- 三种典型方法：**数据增强/生成**（造数据）、**迁移学习/度量学习**（借相关任务知识或学"距离"本身）、**元学习**（学会学习，用任务分布训练快速适应能力）。

## 经验与常见坑
- 用训练误差估计泛化误差必然过于乐观；反复用测试集调参会让它退化为变相训练集。
- 不平衡数据只看 accuracy 是最常见的入门错误——先看类别分布再选指标。
- 参数模型小数据稳定、大数据受限；非参数模型反之——先估数据量再选模型族。
- 贝叶斯结果依赖先验：先验选偏、数据又少时后验被带偏——先验是责任不是免费的午餐。
- 汇聚结构（共同结果）的"解释消除"在人为解释因果时最易被忽略。
- MCMC 样本自相关，需丢弃预热期（burn-in），收敛诊断靠经验。
- EM 多起点重启对抗局部最优；HMM 强依赖马尔可夫假设，状态定义不合理则系统性失准。

## ⚠️ 时效性说明
- 本篇反映 2019 年前后的格局。VC 维/PAC 对深度网络泛化的解释力至今有限（开放问题），但作为思维框架耐用。
- 概率图模型在工业感知类应用占比已下降，但思想广泛融入现代方法：VAE = 神经网络 + 变分推断，扩散模型 = 层级高斯链，贝叶斯深度学习同源。
- "数据和特征决定上限"在感知任务（深度学习自动学特征）上不完全成立，在表格数据上仍是金科玉律。
- 小样本学习部分早于 LLM 时代；当今 few-shot 一词多指 LLM 上下文学习，含义已迁移。
