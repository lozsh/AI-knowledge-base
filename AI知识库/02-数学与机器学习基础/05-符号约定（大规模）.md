# 符号约定（大规模分布式版）

> 来源：《大规模机器学习系统》教材 Notation 章（wiki 化重写于 2026-11-03）

**一句话定义**：大规模机器学习系统教材的符号约定——基础部分（铁律方程、退化方程、深度学习与性能/服务符号）与《机器学习系统》版一致（见 [04-符号约定](04-符号约定.md)），本篇重点补充**分布式系统符号**：Fleet Law、α-β 通信模型、LogGP、扩展效率、容错与检查点、3D 并行、Fleet 容量因子等。

> ⚠️ 与 04 号条目内容高度重合（铁律方程、退化方程、能耗推论、单位与精度等），本篇只做增量记录，避免重复维护两份相同符号表。

## 核心原理：Fleet Law（分布式步时定律）

$$T_{\text{step}}(N) = \frac{T_{\text{compute}}}{N} + T_{\text{comm}}(N) + T_{\text{sync}}(N) - T_{\text{overlap}}$$

| 符号 | 定义 | 单位 | 备注 |
|---|---|---|---|
| N | 设备数（加速器，不是主机节点数） | 整数 | 不是参数量（参数量用 P） |
| T_step(N) | 规模 N 下一训练步的 wall-clock 时间 | 秒 | |
| T_compute | 单设备前向+反向计算时间 | 秒 | |
| T_comm(N) | 集合通信时间（AllReduce、AllGather 等），随 N 增长 | 秒 | |
| T_sync(N) | 每步未被重叠掩盖的同步/协调开销 | 秒 | |
| T_overlap | 被计算掩盖的通信时间，减少有效开销 | 秒 | |
| ρ | 通信-计算比 = T_comm(N)/(T_compute/N) | 无量纲 | 接近或超过 1 即通信受限扩展（裸 ρ 专用于此） |

## α-β 通信模型

$$T(n) = \alpha + \frac{n}{\beta}$$

| 符号 | 定义 | 单位 | 备注 |
|---|---|---|---|
| T(n) | 传输 n 字节消息的时间 | 秒 | |
| α | 网络固定延迟（每条消息的固定开销） | 秒 | 不是学习率——靠上下文消歧 |
| β | 链路有效带宽 | 字节/秒 | |
| n | 消息大小（如梯度张量） | 字节 | |
| n* | 交叉点 = α·β | 字节 | n < n* 时延迟主导，n > n* 时带宽主导 |

## LogGP 扩展

把 α-β 模型细化：区分网络延迟、处理器开销与长消息注入间隔。命名沿用标准 LogGP 短名，但冲突最高的项加描述性下标：

| 符号 | 定义 | 单位 |
|---|---|---|
| T_long(n) | n 字节长消息的传输时间 | 秒 |
| L_LogGP | LogGP 网络延迟参数（加下标避免与裸 L 冲突） | 秒 |
| o_send / o_recv | 发起/完成消息的处理器-NIC 开销 | 秒 |
| g | 相邻两次消息注入的最小间隔 | 秒 |
| G | 长消息每字节间隔（区别于链路带宽 β） | 秒/字节 |

## 扩展效率

$$\eta_{\text{scaling}} = \frac{T_1}{N \times T_N} \leq 1$$

η_scaling 是达到理想线性加速比的比例（1.0 为理论上限）；T₁ 是单设备基线时间，T_N 是 N 设备时间。

## 容错与可靠性

独立同分布组件、指数失效分布下，N 组件系统可靠性：

$$R_{\text{system}}(t) = e^{-N\lambda t}$$

最优检查点间隔（Young-Daly 公式），平衡 I/O 成本与返工成本：

$$\tau_{\text{opt}} = \sqrt{2 \cdot T_{\text{write}} \cdot \text{MTBF}_{\text{system}}}$$

**两个易错点**：① 公式用系统级 MTBF（整个作业的故障间隔），误代入单组件 MTBF 会把 τ_opt 高估 √N 倍；② 量纲要一致——工业界 MTBF 以小时报告，与秒级写入时间混算需换算 MTBF_s = MTBF_h × 3600。

| 符号 | 定义 | 单位 |
|---|---|---|
| R_system(t) | t 时刻前全系统无故障的概率 | 概率 |
| λ | 单组件故障率；系统级为 Nλ | 次/小时 |
| FIT | 工业标准故障率单位（每 10⁹ 设备小时的故障数）：λ_hour = FIT × 10⁻⁹ | — |
| MTBF / MTTF / MTTR | 平均故障间隔 / 平均无故障时间 / 平均修复时间 | 小时 |
| τ_opt / T_write | 最优检查点间隔 / 持久化模型状态的写入时间 | 秒 |

## 3D 并行维度

$$N_{\text{total}} = d \times p \times t$$

| 符号 | 定义 | 备注 |
|---|---|---|
| d | 数据并行度（模型副本数） | 与隐藏维度 d 同符号，靠上下文消歧 |
| p | 物理流水线阶段数（按模型深度切分） | |
| t | 张量并行度（层内按模型宽度切分） | 与时间 t 同符号，靠上下文消歧 |
| m | 微批数量（填满-排空流水线用） | |
| b_pipe | 流水线气泡占比（GPU 空转时间比例；避免裸 b） | 无量纲 |
| V | 每物理阶段分配的交错虚拟块数（虚拟流水线） | |
| M | 通信消息载荷大小（梯度/模型状态/激活） | 字节 |

## Fleet 容量因子

集群级容量计算 = 本地模型效率 × 扩展效率 × 运营有效吞吐的复合：

| 符号 | 定义 | 备注 |
|---|---|---|
| f_compute | 有效计算时间占比 = (T_compute/N)/T_step(N) | 分布化之后还剩多少是真正算题的 |
| f_overhead | 开销占比：流水线气泡、检查点、故障恢复、维护等非生产时间 | |
| η_goodput | 有效吞吐比 = 1 − f_overhead | 分配的 wall time 中产出有用训练工作的比例 |
| R_eff | 有效集群吞吐 = (N·R_peak) × MFU × η_scaling × η_goodput | FLOP/s |

## 压缩通信经济学

比较编解码开销与减少载荷省下的通信时间：T_compressed = T_encode + T_transfer(M/r_comp) + T_decode。若编解码开销超过节省的传输时间，压缩不划算。

M_KV：自回归服务的 KV-Cache 内存占用（字节）。

## 新增冲突点与单位

分布式上下文引入的新冲突：

| 符号 | ML 含义 | 分布式含义 | 约定 |
|---|---|---|---|
| N | — | 设备数（加速器，非主机节点） | 分布式语境下 N 专指设备数 |
| α | — | 网络延迟 | 上下文消歧 |
| λ | 退化敏感度 | 故障率 | 语境依赖：退化用敏感度，可靠性用故障率 |
| d | 隐藏维度 | 数据并行度 | 语境消歧 |
| t | 时间 | 张量并行度 | 语境消歧 |
| τ | 漂移阈值 | 检查点间隔/延迟 | 不裸用：τ_ckpt 通用检查点间隔、τ_opt Young-Daly 最优、τ_stale 梯度陈旧度 |

补充单位约定：网络吞吐按惯例双轨报告——InfiniBand/以太网规格用 bits/s（Gbps），应用层吞吐用 bytes/s（GB/s），首次出现时注明；可持续性语境下功率可用显式下标（P_IT、P_dynamic、P_average），裸 P 始终保留给参数量。
