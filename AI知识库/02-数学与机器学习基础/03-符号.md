# 符号

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：一套贯穿全知识库的数学符号约定，覆盖数字表示、集合论、函数运算符、微积分、概率与信息论、复杂度六类。

查阅本知识库中的公式前，先对齐符号约定：**斜体小写**（x）表示标量、**粗体小写**（**x**）表示向量、**粗体大写**（**X**）表示矩阵、花体/粗体大写（𝕏）表示张量与集合。

## 术语表

### 数字与集合论

| 符号 | 含义 |
|---|---|
| x（斜体标量） | 标量 |
| **x**（粗体小写） | 向量 |
| **X**（粗体大写） | 矩阵 |
| 𝕏（花体/粗体大写） | 张量 |
| I | 单位矩阵 |
| $x_i$ 或 $[x]_i$ | 向量 $x$ 的第 $i$ 个元素 |
| $X_{ij}$ 或 $[X]_{ij}$ | 矩阵 $X$ 第 $i$ 行第 $j$ 列元素 |
| 𝕏 | 集合 |
| ℤ / ℝ | 整数集合 / 实数集合 |
| ℝⁿ | n 维实数向量集合 |
| ℝ^(a×b) | a 行 b 列实数矩阵集合 |
| A ∪ B / A ∩ B / A \ B | 并集 / 交集 / 相对补集（B 关于 A） |

### 函数和运算符

| 符号 | 含义 |
|---|---|
| f(·) | 函数 |
| log(·) / exp(·) | 自然对数 / 指数函数 |
| 1_𝕏 | 指示函数 |
| (·)⊤ / X⁻¹ | 转置 / 矩阵的逆 |
| ⊙ | 按元素相乘（Hadamard 积） |
| [·, ·] | 连结（concatenation） |
| \|𝕏\| | 集合的基数 |
| ‖·‖_p / ‖·‖ | Lp 范数 / L2 范数 |
| ⟨x, y⟩ | 向量点积 |
| Σ / Π | 连加 / 连乘 |
| := | 定义 |

> ⚠️ 注意区分：**范数**（norm）衡量向量/矩阵的大小，**正则化**（regularization）是训练时的约束手段——部分资料把 Lp 范数误译为"Lp 正则"，两者不是一回事。

### 微积分

| 符号 | 含义 |
|---|---|
| dy/dx | y 关于 x 的导数 |
| ∂y/∂x | y 关于 x 的偏导数 |
| ∇_x y | y 关于 x 的梯度 |
| ∫_a^b f(x) dx | f 在 [a, b] 区间上的定积分 |
| ∫ f(x) dx | f 的不定积分 |

### 概率与信息论

| 符号 | 含义 |
|---|---|
| P(·) | 概率分布 |
| z ∼ P | 随机变量 z 服从分布 P |
| P(X \| Y) | 条件概率 |
| p(x) | 概率密度函数 |
| 𝔼_x[f(x)] | 函数 f 对 x 的数学期望 |
| X ⊥ Y | X 与 Y 独立 |
| X ⊥ Y \| Z | 给定 Z 时 X 与 Y 条件独立 |
| $\mathrm{Var}(X)$ / $\sigma_X$ | 方差 / 标准差 |
| Cov(X, Y) / ρ(X, Y) | 协方差 / 相关系数 |
| H(X) | 随机变量 X 的熵 |
| $D_{\mathrm{KL}}(P \Vert Q)$ | P 与 Q 的 KL 散度 |

### 复杂度

| 符号 | 含义 |
|---|---|
| O(·) | 大 O 标记（渐进上界） |
