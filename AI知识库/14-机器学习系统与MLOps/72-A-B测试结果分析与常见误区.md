# A/B 测试结果分析与常见误区

/> 来源：公开课程资料自学整理（更新于 2026-11-03）
> 一句话概括：拿到数据不等于拿到结论——先做合理性检验确认实验按设计执行，再正确解读显著性；多重检验、学习效应、辛普森悖论、组间独立性被破坏是四大高频误区，各自有明确的机理和对策。

## 核心概念

- **结果可信的顺序**：样本量达标 → 合理性检验（Sanity Check）通过 → 显著性分析。任何一步不通过，后面的分析都是垃圾进垃圾出（Garbage in, garbage out）。
- **统计显著 vs 实际显著**：统计显著只说明两组指标不同；业务决策还要求差值 δ ≥ δ_收支平衡（变化收益抵消成本）。考虑收益成本时用置信区间法：差值 CI 整体都要大于 δ_收支平衡。
- **不显著 ≠ 无差异**：两种可能——(1) 变化确实无效；(2) 变化有效但实验 Power 不足没检测到。只有提高 Power 重试后仍不显著，才能下"事实上相同"的结论。

## 关键方法/原理

### 1. 分析结果前的合理性检验
- **两组样本量比例**：预设 50/50，实际比例应落在 0.5±1.96×SE 的置信区间内（按二项分布算 SE）。偏离 → 分组/工程有 Bug（样本比例不匹配问题，Sample Ratio Mismatch）。
- **两组特征分布相似性**：年龄、性别、地域、活跃度等特征在两组的分布应一致。不相似 → 会导致辛普森悖论。
- 检验不通过时：排查实施流程（工程 Bug）+ 按维度切分数据定位（时间、操作系统、设备类型），解决后重跑实验，不要硬分析。

### 2. 显著性分析方法选择
| 指标类型 | 方法 |
|---|---|
| 概率类（转化率等）| Z 检验 / 比例检验 |
| 均值类（人均时长等，大样本近似正态）| T 检验 |
| 分布复杂（OEC、长尾）| Bootstrapping |

- P 值法与置信区间法大部分情况等价，任选其一；涉及收益成本权衡时必须用置信区间法。
- 不显著时的 Power 提升 6 法：
  - **增大样本量**：延长测试时间（最常用、最简单）｜提高测试流量占比（省时间；小流量起步也降低试错成本和"新功能曝光"风险）｜A/B/n 测试合并共同对照组（对照组相同的多个实验共用 1 个对照组，提高每组样本量）。
  - **减小方差**：剔除离群值（Capping 阈值，如只保留 95% 取值范围）｜改用取值范围更窄的指标（概率类比均值类方差小：点击者量<点击量、购买率<人均花费）｜倾向评分匹配 PSM（两组特征越相似方差越小）｜触发阶段计算指标（只算触达用户，去除噪音分母）。

### 3. 四大误区：机理 + 对策

**误区一：多重检验问题（Multiple Testing Problem）**
- 机理：同时做 n 个检验时，至少一个假阳性的概率 FWER = 1-(1-α)^n。α=5% 时 20 个检验的 FWER 高达 64%。
- 四种表现形式：① A/B/n 多实验组；② 多个评价指标；③ 细分分析（Segmentation，按国家/设备/用户分层各算一次）；④ 实验进行中反复查看结果。
- 对策：①-③ 用 Bonferroni 校正（α/n，简单但保守，小 n 适用）或 **BH 法**（Benjamini-Hochberg，按 P 值排序差异化调整，大 n 首选；Python `statsmodels.multipletests`）；④ 靠纪律——样本量达标前不看结果。
- OEC 把多指标合成一个，从源头减少检验次数。

**误区二：学习效应（Learning Effect）**
- 机理：老用户对明显变化（改版、新交互）需要适应期。新奇效应（Novelty Effect）= 短期虚高（大红按钮初期点击率涨后回落）；改变厌恶（Change Aversion）= 短期虚低（找不到功能先流失后回升）。
- 检测：① 按天画实验组指标时间线——有学习效应时会单调漂移后趋稳（注意：是看实验组自身趋势，不是每天比两组大小，后者又犯多重检验）；② 只比较两组的新用户——新用户无适应问题，若新用户不显著而总体显著，大概率是学习效应。
- 根治：延长实验时间让效应消退后再比较。

**误区三：辛普森悖论（Simpson Paradox）**
- 机理：两组在某个细分领域内分布不均时，总体比较与细分比较结论可能相反（数学上 (a+c)/(b+d) 与各分段的加权结构可反向）。本质是特征分布检验没做。
- 对策：预防靠分析前合理性检验；发现后优先重跑实验；重跑仍不均 → 查工程问题；紧急时以细分结果为准（但要做多重检验校正）。

**误区四：实验组/对照组独立性被破坏（违反 SUTVA）**
- 机理：各组实验单位的行为只应受本组体验影响。三类高危业务：① 社交/通讯（网络效应：实验组用户的内容/行为经好友关系影响对照组）；② 共享经济双边市场（供需动态平衡：实验组需求增加吸走供给，对照组体验变差，效果被高估）；③ 共享固定资源（预算固定：实验组效果好吃掉对照组预算，效果被高估）。
- 对策（原则：分离排除干扰）：地理分离（按城市分，选相似可比的市场）｜资源分离（各组资源分配比例 = 样本量比例）｜时间分离（switchback：同组用户交替给实验/对照体验，注意周中/周末周期性对齐比较）｜聚类分离（社交网络按互动紧密程度聚成 cluster，以 cluster 为实验单位随机分组，实施复杂）。

### 4. A/B 测试不适用场景与替代方法
- 不适用三场景：变量无法控制（用户自主选择，如"是否换 App"——用激励诱导会引入自选择偏差）｜重大事件发布（新品发布会、换商标——无法小流量灰度，分品牌更不行）｜用户量太少（凑不够最小样本量）。
- 替代方法：
  - **PSM（倾向评分匹配）**：从历史数据中人工构造可比的两组。流程：选同期同类用户 → 特征入逻辑回归算倾向评分 → 最邻近匹配 → 只比较匹配后的相似部分。案例：家庭订阅 vs 个人订阅留存差，裸比较 28% 的提升经 PSM 校正后真实因果效应只有 13%，其余是用户本身差异。
  - **用户研究**：深度体验研究（眼动/日记，信息深、人少）→ 焦点小组（居中）→ 调查问卷（人多、信息浅）。

### 5. 规范 A/B 测试完整流程（案例串讲 checklist）
1. 业务问题 → 目标 + 量化假设（原因→结果）
2. 定评价指标（明确触发条件、时间窗口、精确分子分母）+ 护栏指标；用历史数据算指标波动范围
3. 选实验单位（用户可察觉变化 → 用户 ID）
4. 算样本量（α=5%、Power=80%、δ、σ²_pooled）→ 实验时长（≥一个完整周期）
5. 跑实验：样本量达标前不看结果
6. 合理性检验：样本量比例 + 特征分布
7. 显著性分析：P 值 / 差值置信区间；业务决策叠加实际显著性
8. 显著且业务显著 → 全量推广；不显著 → 提高 Power 重试或放弃该变化

## 术语表

| 术语 | 英文 | 含义 |
|---|---|---|
| 合理性检验 | Sanity Check | 验证实验实施与设计一致（样本比例、特征分布）|
| 样本比例不匹配 | Sample Ratio Mismatch (SRM) | 实际两组样本比例偏离设计值，说明实验有 Bug |
| 多重检验问题 | Multiple Testing Problem | 多次检验放大假阳性，FWER=1-(1-α)^n |
| 家族错误率 | FWER (Family-wise Error Rate) | 多次检验中至少出现一个第一类错误的概率 |
| Bonferroni 校正 | Bonferroni Correction | α 改为 α/n，简单保守 |
| BH 法 | Benjamini-Hochberg Procedure | 控制错误发现率 FDR，按 P 值排序差异化校正，大 n 首选 |
| 学习效应 | Learning Effect | 老用户适应新变化的短期行为异常 |
| 新奇效应 | Novelty Effect | 学习效应的积极面：短期虚高 |
| 改变厌恶 | Change Aversion | 学习效应的消极面：短期虚低 |
| 辛普森悖论 | Simpson Paradox | 细分分布不均导致总体与细分结论相反 |
| SUTVA | Stable Unit Treatment Value Assumption | 实验单位相互独立、互不干扰的前提 |
| 倾向评分匹配 | PSM (Propensity Score Matching) | 用模型在历史数据中构造可比两组的非实验因果推断方法 |
| 时间分离实验 | Switchback | 同一组用户按时段交替体验实验/对照 |

## 经验与常见坑

- **知道问题为什么发生、能发现问题，与知道解决办法同样重要**：多重检验有四种面目，只记住"A/B/n 要校正"一种，就会在细分分析时中招。
- 每天比较两组大小 = 每天做一次检验：既犯多重检验，又容易把周期性波动误判为实验效果。看趋势只看实验组自身随时间的变化。
- 双边市场（打车、电商供给侧）的 A/B 测试效果天然被高估，不能直接拿对照组做基准。
- 辛普森悖论理论上无法彻底避免：总有未被观测的维度在起作用，所以合理性检验要在每次细分分析前都做。
- 统一框架之下，随机分组实施细节和平台是工程问题，各公司差异大；方法论（本篇内容）跨公司跨平台通用。
