# 部署原则（Deployment Principles）

> 来源：《机器学习系统》教材第四部分导言（更新于 2026-11-03）

**一句话定义**：生产中的机器学习系统面临传统软件没有的威胁——静默衰减（silent degradation）；本篇用五条不变量（验证差距、统计漂移、训练-服务偏差、延迟预算、偏差反馈）定义部署可靠性的"物理规律"。

## 概述

代码正确、基准测试优秀，系统仍会失败。与"逻辑错就崩溃"的传统程序不同，当世界偏离训练分布时，ML 系统仍会生成**自信、格式正确但错误**的输出。部署后数据环境脱离工程师控制，因此可靠性不是一次性的发布关卡，而是围绕数据·算法·模型（D·A·M）协同设计的**持续控制循环**。

## 原则 9：验证差距（The Validation Gap）

**不变量**：传统软件用单元测试断言精确等式 f(x) = y；机器学习的验证只能使用统计边界：

```
Pr(f(X) ≈ Y) > 1 − ε
```

**含义**：
- 正确性无法被直接证明，只能被统计性地限定；且随着生产数据偏离设定边界时的数据，这些边界会逐渐被侵蚀。
- 部署不是单向传输，而是**控制循环**：没有测试套件能覆盖所有真实输入，生产系统必须监控自身不确定性，并在漂移到已知性能包线之外时**优雅地失败**。

## 原则 10：统计漂移不变量（Statistical Drift）

**不变量**：随世界偏离训练分布，准确率按衰减方程下降：

```
Accuracy(t) ≈ Accuracy₀ − λ · 𝒟(P_t ‖ P₀)
```

其中 Accuracy₀ 是部署时性能，𝒟(P_t‖P₀) 是当前分布与训练分布的统计距离，λ 是模型对分布偏移的敏感度。

- 经典场景：2020 年借款人行为训练的信用评分模型，两年后通胀、利率、贷款政策都变了——系统照常输出评分，但输入与结果的统计关系已变，真实准确率在下降，而错误日志保持安静。
- ⚠️ 这是一阶线性化，只捕捉小偏移的主要影响；大漂移时关系依赖模型，可能是非线性的。

**含义**：可观测性必须从系统指标（延迟、错误率）扩展到**统计指标（分布距离）**。没有漂移监控，系统可以在"一切正常"的表象下持续产出不可靠的预测。

## 原则 11：训练-服务偏差定律（Train-Serve Skew）

**不变量**：若服务期间计算的函数 f_serve 与训练期间学习的函数 f_train 不同，有效准确率随偏差成比例下降：

```
ΔAccuracy ∝ 𝔼[|f_serve(x) − f_train(x)|]
```

（精确依赖关系取决于损失函数、决策边界几何与生产分布，但无法解释的偏差会破坏线下验证估计生产行为的前提。）

偏差来源：不一致的预处理逻辑、不同的库实现、陈旧的 feature 值、两条代码路径间的环境状态差异。细微差异也会累积：PIL 与 OpenCV 的 resize、FP64 与 FP32 归一化，都可能造成标准监控检测不到的静默准确率下降。

**含义**：**特征一致性是严格的架构要求，而非最佳实践。** Feature Store 不是缓存，而是通过集中化特征定义与检索来减少偏差的**一致性引擎**；但团队仍须验证新鲜度、时间点正确性（point-in-time correctness）、预处理与运行时的奇偶性（parity）。

## 原则 12：延迟预算不变量（Latency Budget）

**不变量**：延迟敏感服务中，硬约束是按 P95/P99/P99.9 或应用截止时间定义的服务级别目标（SLO）**尾部延迟**；吞吐量是在该约束内优化的变量。延迟预算方程：

```
L_lat,total = L_net + L_pre + L_infer + L_post + L_queue ≤ SLO
```

**含义**：服务系统必须做**尾部容忍设计**（动态批处理、对冲请求 hedged requests），并愿意牺牲整体吞吐量来满足队列中最早请求的截止时间。时间不可妥协：检测准确率 99% 但单张扫描要 30 秒的医学影像系统会迫使医生回归人工审查；响应 200ms 而非 50ms 的自动驾驶感知模型无法及时刹车——**统计正确性来得太晚就毫无价值**，超过延迟上限在功能上等同于没有返回预测。

## 原则 13：偏差反馈不变量（Bias Feedback）

**不变量**：当模型输出影响其未来输入的分布时，预测错误会在决策周期中累积。对简化的自强化反馈循环，组 g 在 k 个部署周期后的差距按指数增长：

```
Δg(k) ≈ Δg(0) · α_fb^k
```

其中 Δg(0) 是初始组间差距，α_fb 是放大因子（由模型决策重塑下游数据的强度决定）。α_fb > 1 时反馈循环自强化；α_fb ≤ 1 时动态稳定或阻尼。（⚠️ 真实部署可能是非线性或饱和的。）

- 经典场景：贷款审批模型对历史上服务不足社区的申请人拒绝率更高 → 被拒者无法建立信用记录 → 未来申请更弱 → 拒绝率进一步升高。模型在训练分布上的准确率稳定，但它服务的人群已被自己的决策重塑。

**含义**：**公平性不是部署后的审计，而是部署控制循环的稳定性约束。** 系统必须像监控延迟百分位一样严格监控分组细分指标——群体偏差对总体准确率不可见，正如尾部延迟违规对平均延迟不可见。

## 术语表

| 术语 | 含义 |
|---|---|
| 静默衰减 | 代码与基础设施不变、世界在变，系统持续输出错误但无报错的失效模式 |
| 分布漂移 | 生产数据分布偏离训练分布（对应原则 10） |
| 训练-服务偏差 | 训练与线上计算的函数不一致（对应原则 11） |
| SLO / SLA | 服务级别目标（内部）/ 协议（外部合同） |
| 数据级联/反馈循环 | 模型决策重塑未来输入分布（对应原则 13） |
