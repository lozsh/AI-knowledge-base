# 循环神经网络

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：循环神经网络（RNN）是带有隐状态（hidden state）的神经网络，通过"当前输入 + 上一时刻隐状态 → 新隐状态"的循环计算，把序列的历史信息压缩进一个固定维度的向量里，从而建模序列数据。

前面章节处理的是表格数据和图像：图像靠 CNN 利用像素的空间位置，样本之间默认独立同分布。但文本、语音、视频帧、股价、用户浏览行为都是**有序的**——词序打乱句子就失去意义；而且很多任务不仅要"读"序列，还要"续写"序列（预测 2, 4, 6, 8, ... 的下一个数）。RNN 就是为这类数据设计的架构：CNN 擅长空间信息，RNN 擅长序列信息。它是语言模型（尤其字符级语言模型）的经典实现载体。

⚠️ 在 NLP 主流中，RNN 已被 Transformer 取代（见"时效性说明"），但其"隐状态 + 循环计算"的思想、以及梯度消失/爆炸的分析，仍是理解序列建模的基础。

## 核心原理

### 1. 序列模型的统计工具

预测时间步 t 的观测值就是估计条件分布 `x_t ~ P(x_t | x_{t-1}, ..., x_1)`。输入数量随 t 增长，不可直接处理，有两种近似策略：

- **自回归模型（autoregressive）**：只看最近 τ 步 `x_{t-1}, ..., x_{t-τ}`，参数量不随 t 变化。
- **隐变量自回归模型（latent autoregressive）**：维护一个对历史的摘要 `h_t = g(h_{t-1}, x_{t-1})`，用 `x̂_t ~ P(x_t | h_t)` 预测。RNN 正是这一策略的实例化。

假设序列动力学不变（平稳性），整段序列的概率可分解为各步条件概率的连乘 `P(x_1,...,x_T) = ∏_t P(x_t | x_{t-1},...,x_1)`。

- **马尔可夫条件**：τ 步近似精确时成立；τ=1 即一阶马尔可夫模型，可用动态规划沿马尔可夫链精确计算。
- **因果方向**：未来不能影响过去，`P(x_{t+1} | x_t)` 比 `P(x_t | x_{t+1})` 更容易估计，应沿时间正向建模。
- **内插 vs 外推**：在已有观测之间估计容易，超出观测范围预测（外推）难得多；训练时要尊重时间顺序，不要用未来数据训练。

**k 步预测的误差累积**：多步预测只能把模型自己的预测当输入（`x̂_{606} = f(x_{602},x_{603},x_{604},x̂_{605})`），误差逐步累积，预测很快衰减为常数。实验中 4 步预测尚可，16 步以后基本无用——类似"未来 24 小时天气预报准，再远精度骤降"。

### 2. 文本预处理流水线

文本是最常见的序列数据，预处理四步：

1. 读入文本为字符串行列表；
2. **词元化（tokenize）**：按词（word）或字符（char）拆分为词元（token）；
3. 构建词表（vocab）：按词频把词元映射为从 0 开始的索引，低频词可丢弃（min_freq），未登录词映射为 `<unk>`；可保留特殊词元 `<pad>`（填充）、`<bos>`/`<eos>`（序列起止）；
4. 文本 → 索引序列供模型使用。

以时光机器语料库为例：约 3 万词的文本，按字符词元化后共 170580 个字符，词表仅 28（26 字母 + 空格 + `<unk>`）——字符级的优势是词表极小。

### 3. 语言模型与 n 元语法

语言模型的目标是估计序列联合概率 `P(x_1, x_2, ..., x_T)`，按链式法则分解（如 `P(deep, learning, is, fun) = P(deep)P(learning|deep)P(is|deep,learning)P(fun|deep,learning,is)`）。直接用词频统计条件概率会遭遇**组合爆炸**：长词组合绝大多数在语料中从未出现。

- **n 元语法（n-gram）**：借马尔可夫假设截断依赖长度，一元/二元/三元语法分别只依赖前 0/1/2 个词。参数需存储 `|V|^n` 量级，指数增长。
- **拉普拉斯平滑**：给所有计数加小常数 `ε`，缓解零计数问题，但只是补丁。
- **齐普夫定律（Zipf's law）**：第 i 常用词的频率 `n_i ∝ 1/i^α`，词频在双对数坐标上近似直线衰减（第 10 常用词频不足第 1 的 1/5）。n 元组同样服从齐普夫定律。这意味着靠计数+平滑建模必然高估尾部频率——**必须转向深度学习模型**。

**读取长序列的两种方式**（语料太长需切成 n 个时间步的子序列，从随机偏移开始切）：

- **随机采样**：每个小批量的子序列随机抽取，批间不一定相邻，每个迭代需重新初始化隐状态；
- **顺序分区**：相邻小批量的子序列在原序列上相邻，隐状态可跨小批量传递（用 detach 分离梯度以控制计算量）。

### 4. RNN 的循环计算

从含单隐藏层的 MLP 出发（`H = φ(XW_xh + b_h)`，`O = HW_hq + b_q`），加上隐状态就得到 RNN：

$$H_t = \phi(X_t W_{xh} + H_{t-1} W_{hh} + b_h)$$
$$O_t = H_t W_{hq} + b_q$$

- `X_t ∈ R^{n×d}`（批量 n，输入维度 d），`H_t ∈ R^{n×h}`，`W_xh ∈ R^{d×h}`，`W_hh ∈ R^{h×h}`，`W_hq ∈ R^{h×q}`。
- 计算 `X_t W_xh + H_{t-1} W_hh` 等价于"拼接 X_t 与 H_{t-1}"乘"拼接 W_xh 与 W_hh"。
- **参数共享**：所有时间步复用同一组参数，参数量不随时间步增加——这是与把序列展开成普通网络的关键区别。
- **隐状态 ≠ 隐藏层**：隐藏层是输入到输出路径上的层；隐状态是循环引入的、由历史数据计算出的"记忆"，用作当前步的额外输入。

**字符级语言模型**：输入序列与标签序列错开一位（输入 "machin"，标签 "achine"），每个时间步对输出做 softmax + 交叉熵。词元最简单的表示是**独热编码（one-hot）**：索引 i 映射为第 i 位为 1 的词表长度向量；批量形状（时间步数 × 批量大小 × 词表大小）便于逐时间步循环更新隐状态。

### 5. 困惑度（Perplexity）

评价语言模型的指标：序列平均交叉熵损失的指数

$$\mathrm{PPL} = \exp\left(-\frac{1}{n}\sum_{t=1}^{n} \log P(x_t \mid x_{t-1},\ldots,x_1)\right)$$

可理解为"下一个词元实际选择数的调和平均"：

- 最好情况（完美预测）= 1；
- 最坏情况（预测概率为 0）= ∞；
- 均匀分布基线 = 词表大小（字符模型上界为 28，实际模型必须远低于它才有意义）。

## 关键概念

| 术语 | 含义 |
|---|---|
| 隐状态 H_t | 循环层维护的"记忆"，由历史输入递归计算而来，区别于隐藏层 |
| 自回归 | 用序列自己的过去预测自己的未来（`P(x_t \| x_{t-1},...)`） |
| n 元语法 | 基于马尔可夫假设、只看前 n−1 个词的截断语言模型 |
| 齐普夫定律 | 词频 ∝ 1/秩^α，长尾分布，注定计数式建模失效 |
| 困惑度 | 平均交叉熵的指数，语言模型标准评价指标 |
| 独热编码 | 词元索引 → 单位向量，最简单的词元表示（可被学习式 embedding 替代） |
| 预热期（warm-up） | 生成文本时先喂前缀只更新隐状态、不产出预测的阶段 |
| BPTT | 通过时间反向传播：把 RNN 沿时间展开后应用链式法则 |
| 梯度裁剪 | 把梯度范数限制到阈值 θ 以内，防梯度爆炸 |

## 经验与常见坑

**梯度裁剪**是 RNN 训练的标配。T 个时间步的反向传播产生 O(T) 的矩阵乘法链，容易梯度爆炸/消失。裁剪公式（保持方向、只缩放范数）：

$$g \leftarrow \min\left(1, \frac{\theta}{\|g\|}\right) g$$

注意：**梯度裁剪只防爆炸，不解决消失**。

**训练要点**（在时光机器上从零实现的完整流程）：

- 随机采样 → 每个迭代周期重新初始化隐状态；顺序分区 → 周期开始初始化一次，小批量间用 `detach()` 分离隐状态梯度（把梯度计算限制在一个小批量的时间步内，否则计算图会无限拉长）；
- 参数更新前先裁剪梯度，保证个别爆炸的批量不会让训练发散；
- 用困惑度而非原始损失来监控（不同长度序列可比）；
- 预测前缀要经过预热期；未训练的模型只会输出乱码（如 `'time traveller aaaaaaaaaa'`），训练 500 轮后可生成接近原文的句子（顺序分区困惑度约 1.0，随机采样约 1.5；高级 API 实现约 1.3 且快得多，框架对循环算子做了优化）。

**BPTT 的三种梯度计算策略**：

1. **完全计算**：精确但计算不可行，且 W_hh 的高次幂导致数值不稳定（特征值 <1 消失、>1 发散 → 梯度消失/爆炸）；
2. **常规截断（truncated BPTT）**：τ 步后截断求和，实践中默认做法，偏向短期依赖，还附带轻度的正则化效果；
3. **随机截断**：用期望为 1 的随机变量 ξ_t 替换部分梯度项，理论上无偏，但方差抵消收益，实践不比常规截断好。

隐状态梯度满足递推 `∂L/∂h_t = W_hh^⊤ (∂L/∂h_{t+1}) + W_qh^⊤ (∂L/∂o_t)`，问题核心就出在 `W_hh^⊤` 的连乘上。LSTM/GRU 通过门控机制进一步缓解（见现代循环神经网络）。

## ⚠️ 时效性说明

- RNN 及其变体曾是序列建模（语言模型、机器翻译、语音识别）的主流，但**在 NLP 领域已被基于自注意力的 Transformer 全面取代**——RNN 难并行、长程依赖弱；Transformer 见注意力机制与 Transformer 相关条目。
- 字符级语言模型、"统计 n 元语法 + 拉普拉斯平滑"在今天主要用于教学理解；现代语言模型用子词词元化（BPE 等）与大规模预训练。
- 词元表示已普遍用可学习的 embedding 替代独热编码。
