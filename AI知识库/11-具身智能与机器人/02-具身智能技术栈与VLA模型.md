# 具身智能技术栈与 VLA 模型

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：具身智能的技术栈是把「长程规划 + VLA 实时控制」双层架构压进毫秒到秒级时间预算的工程体系——硬件已基本够用，真正的鸿沟在算法层的实时性与泛化。

当 Agent 从对话框走向物理世界，延迟与多模态的挑战被放大到极限：语音说错可以重说，网页点错可以回退，而机器人动作的后果**不可逆**——一次碰撞就可能损坏物体或机器人本身。本篇拆解机器人控制的技术栈分层与 VLA（Vision-Language-Action）模型的架构设计；模型谱系与学习范式见[01-具身智能与机器人](01-具身智能与机器人.md)，训练与仿真见[12-机器人学习范式与仿真到现实](03-%E6%9C%BA%E5%99%A8%E4%BA%BA%E5%AD%A6%E4%B9%A0%E8%8C%83%E5%BC%8F%E4%B8%8E%E4%BB%BF%E7%9C%9F%E5%88%B0%E7%8E%B0%E5%AE%9E.md)。

## 核心原理

### 硬件不是瓶颈，算法才是

一个有力的反证来自 XLeRobot 项目：成本不到 1000 美元的双臂轮式机器人，在人类通过 VR 头显遥操作（延迟约 100–200ms，已接近物理交互的响应要求）时，已能流畅完成大量家庭任务；需要灵巧手的任务，宇树机器人在人类遥操作下也能完成。传感器分辨率、执行器精度、控制频率在当前低成本平台上已足以支撑实用任务。

**这个论断有明确边界**：遥操作反证真正说明的是「低成本硬件 + 人类的智能」足以完成以视觉反馈为主的家庭操作任务。触觉传感的缺失、灵巧手的可靠性与成本至今仍是公认硬件短板——一旦任务重度依赖精细力控与触觉反馈，硬件就未必不是瓶颈。

### 双层架构：规划与控制的分离

复杂家庭任务需要在两个时间尺度上决策：

| 层 | 频率 | 职责 | 例子 |
|---|---|---|---|
| 长程规划（long-horizon planning） | 0.1–1Hz | 「做什么」：拆解高层指令为子目标序列，理解环境语义、推理任务依赖 | 「把厨房打扫干净」→ 清理台面 → 装载洗碗机 → 擦拭表面 |
| VLA 控制 | 1–10Hz | 「怎么做」：根据当前画面和指令持续输出控制信号 | 走到水槽前、拿起抹布、擦拭台面 |

这种「高层慢决策 + 底层快执行」与语音场景的「快慢思考」结构同源，但**切分维度不同**：这里拆的是「谋划全局 / 实时执行」，不是语音端到端方案里「思考 / 表达」的解耦——两种「双 X 架构」不能混为一谈。

关键提醒：实时性矛盾并没有凭空消失，而是被**下推到 VLA 控制层**，靠动作分块摊薄（见下）。机器人场景当前的主要矛盾已转移到训练与泛化。

### 控制频率鸿沟与动作分块

- 传统机器人控制要求 **50–1000Hz** 的控制频率；VLA 单次推理只有约 **1–10Hz**——差距可达两个数量级。
- 原版 OpenVLA 是典型反面教材：每次推理只输出一个动作（约 6Hz 单步自回归），动作卡顿是它被诟病的主要短板。
- **动作分块（Action Chunking）**是为弥补差距而生的通用技术，最早由 ACT（Zhao et al., 2023）提出，π₀、OpenVLA-OFT 等广泛采用：模型一次推理生成未来一小段时间的动作序列（π₀ 典型配置：0.5–1 秒的动作块，50Hz 控制频率下即 25–50 个动作），控制线程按高频依次执行，模型在后台异步生成下一批。
- 类比：像视频缓冲——只要推理时间小于这批动作的执行时间，运动就连续流畅。
- **绕不开的权衡：分块是拿反应性换平滑性**。块越长，延迟摊得越薄、运动越连贯，但模型在这段时间里「看不到」新画面，对突发变化（物体被挪走、有人伸手挡住）越迟钝。

### VLA 模型解剖与两条动作表示路线

VLA 可以看作「VLM + 动作输出」：视觉-语言模型负责「看懂」和「想清楚」，VLA 在此基础上还要「动手」——真正的挑战在「动手」层。三个代表模型：

| 模型 | 路线 | 架构要点 |
|---|---|---|
| RT-2（Google，闭源） | 离散动作 token | 大规模预训练 VLM 直接微调；连续动作离散化为 token，像生成文本一样逐个自回归输出；借预训练泛化获得对新物体/新指令的零样本迁移 |
| OpenVLA（开源） | 离散动作 token | Llama 2 7B 骨干 + DINOv2/SigLIP 视觉编码器统一架构；先在 Open X-Embodiment（20 多种机器人平台的真实演示）预训练学通用操作模式，再针对特定平台少量数据微调；社区第一次可以在其基础上复现和改进 |
| π₀（Physical Intelligence） | 连续轨迹生成 | flow matching（流匹配，与扩散模型同源的连续生成方法）从随机噪声出发多步迭代「去噪」，直接生成一段平滑连续的动作轨迹 |

动作表示的真正分野不在 RT-2 与 OpenVLA 之间（两者表示本质相同，差异在**开放性与工程选择**：一个闭源一个开源），而在**离散 token 与连续轨迹**之间。打个比方：离散 token 像从菜单中逐步选择「向左 5 度」「向前 3 厘米」，连续轨迹像画家先勾出整条曲线、再逐笔修正成型。连续路线天然与动作分块结合，在灵巧操作等对精度和流畅度要求高的任务上表现更好。

### 长程规划层：从通用 VLM 到具身思考模型

通用 VLM 已具备不错的具身思考能力。Google DeepMind 的 **Gemini Robotics-ER 1.5** 专门针对具身思考（Embodied Reasoning：理解物理世界中物体的位置、运动和因果关系）优化，在 15 个学术基准（Point-Bench、RefSpatial、RoboSpatial、BLINK 等）上平均 **62.8%**，超过 GPT-4o（60.6%）和 Gemini 2.5 Pro（59.3%）。核心能力：高级空间理解与物体定位、时序推理（预测「如果推倒这个杯子会怎样」的动作因果）、任务编排（高层指令分解为小步骤），并原生支持 thinking 与工具调用。

实战形态（XLeRobot + RoboCrew 导航实验）：摄像头图像叠加角度刻度标注，只给模型三个工具——前进、左转、右转；任务「找到厨房并走到那里」，模型以 0.5–1Hz 频率决策：识别走廊、房门、家具，「厨房可能在左侧」就左转，「前方有冰箱」就继续前进。这揭示了 VLM 规划层的能力边界：空间推理和任务分解已不错，但**复杂环境中的鲁棒性和多步推理的一致性**仍有明显提升空间。

### 快慢接口：文本契约与潜空间桥

双层架构里，慢规划器与快控制器之间传什么？默认答案是文本（子目标指令），好懂、好调试，但把慢模型「脑中」丰富的中间状态压成了几句话。两条改进路线：

- **纯文本契约**（Computer Use 场景已验证）：慢 Agent 每次操作附带滚动更新的状态摘要，快 Agent 据此实时回应用户——解耦后语音回应快约 15 倍而成功率不降，抽掉文本通道成功率立刻归零。
- **潜空间桥（Latent Bridge）**：让快速反应小模型（每秒十几个动作）和慢推理大模型（每秒一次思考）都冻结不动，只训练它们之间一个几千万参数的小「桥」，把慢模型的隐层结论直接投影成几个「潜 token」拼进快模型输入——绕开「想法 → 文字 → 再理解」的往返。在多个 Atari 游戏上比文本通道高出 26%–82%，每步只多约 5ms。
- **诚实的边界**：快慢协作有没有用，取决于任务瓶颈在「想不想得到」还是「来不来得及反应」（相关性 r≈0.9）。纯拼反应速度的任务，再好的桥也只是徒增延迟。

## 术语表

| 术语 | 含义 |
|---|---|
| VLA（Vision-Language-Action） | 输入图像 + 语言指令、输出机器人动作的多模态模型；可视为「VLM + 动作输出」 |
| 长程规划 | 把高层指令拆解为子目标序列的慢决策层（0.1–1Hz） |
| 动作分块（Action Chunking） | 一次推理生成未来一段动作序列、高频回放执行，摊薄推理延迟的技术 |
| 控制频率 | 机器人每秒更新动作指令的次数；传统要求 50–1000Hz |
| 遥操作（Teleoperation） | 人类通过 VR/手柄等远程实时操控机器人，也用于采集演示数据 |
| 具身思考（Embodied Reasoning） | 理解物理世界中物体位置、运动与因果关系的能力 |
| 流匹配（Flow Matching） | 与扩散同源的连续生成方法，π₀ 用来直接生成平滑动作轨迹 |
| Open X-Embodiment | 跨 20 多种机器人平台的真实操作演示数据集，跨具身预训练的数据基础 |
| 潜空间桥（Latent Bridge） | 冻结快慢模型、只训中间小桥，把慢模型隐层投影为潜 token 的接口技术 |
| Sim2Real Gap | 仿真训练的策略迁移到真实环境的性能落差 |

## 经验与常见坑

- **「硬件不是瓶颈」别引用过头**：它只对以视觉反馈为主的家庭操作任务成立；力控、触觉、灵巧手场景硬件仍是硬短板。
- **动作块不是越长越好**：反应性换平滑性是硬权衡，任务环境动态程度决定块长上限。
- **离散 vs 连续路线按任务选**：语言强绑定、需复用 VLM 生态选离散 token；精细灵巧操作、高频流畅控制选连续轨迹 + 动作分块。
- **每任务一训是当前 RL 的常态**：RL 训练的 VLA 单任务分数再高，也多是逐任务分别训练，不等于统一模型能零样本泛化。
- **端到端统一架构的「移动靶子」问题**：一个模型既当最强推理者又当实时控制者，两种能力都在快速演进，统一路线就得反复重训才跟得上；解耦路线（可换大脑）与统一路线（更紧的边想边动）是产业分野，不是谁取代谁。
- **遥操作数据质量依赖操作者技能**：廉价采集的另一面是不熟练操作者会污染数据，采集阶段需要质量筛选机制。
