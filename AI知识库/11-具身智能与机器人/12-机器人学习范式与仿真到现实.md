# 机器人学习范式与仿真到现实

<p class="note-date">更新于 2026-11-03</p>

**一句话定义**：机器人学习的主战场已从实时控制转向「数据从哪来、模型如何跨任务跨平台泛化」——模仿学习（行为克隆）提供地基，RL 在其上补泛化，仿真环境做练习场，域随机化 + 视觉对齐是迁移到真机的工程桥梁。

VLA 面临两大结构性挑战：扩展 SFT 需要大规模人工操作轨迹（收集成本极高且多样性受限），而基于有限场景训练的模型遇到未见过的任务、环境或物体时性能显著下降。本篇讲清这条训练流水线的每一环；架构与控制层见[11-具身智能技术栈与VLA模型](11-具身智能技术栈与VLA模型.md)。

## 核心原理

### 三种学习范式的当前分工

- **模仿学习（行为克隆，Behavior Cloning）**：当前 VLA 控制层的训练主流——直接从大量人类演示中学「看到什么就做什么」，OpenVLA、RT-2、π₀ 均属此类。本质是 SFT 性质：OpenVLA 在近百万条机器人演示轨迹上行为克隆训练。优点是数据效率高、能学到精细动作；上限受限于演示质量与覆盖面。
- **强化学习**：在模仿学习之上补充。RL 训练的 VLA 能在单个任务上表现很好，但往往泛化不足——「一个任务训练一次」，每遇新任务还得重新收集数据、重新训练。
- **预训练 + 微调**：先在跨平台数据集（Open X-Embodiment 等）上学通用操作模式（「抓取」「放置」在不同机器人之间相通），再针对特定平台少量微调——把 LLM 时代的扩展逻辑搬到机器人。

### RL 增强 VLA：SimpleVLA-RL 的配方

受 DeepSeek-R1 用 RL 提升推理能力启发，SimpleVLA-RL（基于 veRL 框架）探索 RL 能否增强 VLA 的逐步动作生成。配方极简：**只用二元结果奖励（成功 1 / 失败 0）**，配三项探索增强：

1. **动态采样**：过滤全成功/全失败组，确保梯度稳定（全同奖励组方差为零，贡献不出梯度）；
2. **更高裁剪界 [0.8, 1.28]**：鼓励探索，偏离参考策略更多仍受奖励；
3. **更高温度（1.6）**：生成多样化轨迹。

效果（LIBERO 基准，GRPO 算法）：
- 300 步训练提升约 30%，最终报告 97.6%；
- **冷启动实验最有说服力**：每个任务仅 1 条轨迹 SFT 时成功率 17.3%，加 RL 后达 **91.7%**（+74.4 个百分点，相对提升约 430%）——数据极稀缺时 RL 价值最大；
- **涌现「推切」（pushcut）**：RL 自主发现人类演示中从未出现过的新动作模式。标准演示路径是「接近 → 抓取 → 垂直抬起 → 水平移动 → 放下」，RL 发现「接近 → 抓取 → 保持低位 → 水平推动 → 完成」更优——省去抬起步骤，更快且对定位精度要求更低。证明 **RL 能超越模仿学习，发现人类没想到的策略**；
- 泛化提升体现在三个维度：空间泛化（布局迁移）、物体泛化（未见形状纹理）、目标泛化（新任务描述）。

**结果奖励 vs 过程奖励的取舍**：结果奖励信号稀疏但探索自由度大（「推切」正是因此被发现）；过程奖励（每步即时反馈）收敛快，但可能把策略锁死在演示空间内。经验法则：中间步骤正确性容易定义时用过程奖励；最优路径未知时结果奖励更有潜力。动态采样过滤还自然形成了课程学习——只保留成功率适中的任务训练，先易后难。

### 仿真环境：从评估考场到训练操场

仿真环境与评估环境的三点本质区别：**交互频率远高**（数百万次 vs 数千次）、**需要随机化**（防止死记硬背特定配置）、**必须提供即时反馈**。评估侧积累的资产可直接转成训练信号：一套定义清晰的验证器/Rubric 本质上就是可验证奖励（RLVR）的奖励函数——**判分脚本直接就是奖励脚本**。

训练对仿真环境多提两个硬要求：
- **可靠的 reset 语义**：数百万个 episode，每个都必须重置到确定、干净的初始状态，否则梯度信号被上一轮残留状态污染；
- **吞吐**：要在可接受的墙钟时间内喂给模型上百万次交互，并行度和单实例开销直接决定训练是否可行。

**仿真保真度谱**（从快到真）：

| 层级 | 代表 | 特点 |
|---|---|---|
| Mock API / 单元测试级 | — | 百万次/小时，完全可控 |
| MCP 工具沙盒 | AWorld（GAIA 任务） | 26 个 MCP 服务器、126 个工具函数；分布式把 7695s 串行压到 525s（14.6 倍） |
| 移动/Web 模拟器 | AndroidWorld、OSWorld | 116 个真实应用任务；OSWorld 用虚拟机快照实现可重置 |
| GPU 并行物理仿真 | Isaac Gym/Isaac Lab | 千级并行实例，精度略妥协 |
| 高精度物理引擎 | RoboTwin2（SAPIEN）、MuJoCo | 碰撞检测 + 物理仿真，单实例 CPU |

具身代表 RoboTwin2：双臂操作任务，观测为三视角 RGB + 14 维关节状态，动作为 14 维控制向量（各臂 7 自由度），随机化物体位置/朝向/外观，靠动作分块（一次 25 个连续动作）实现实时控制。

### Sim2Real 鸿沟与域随机化

仿真无法完全还原真实的物理、视觉与硬件特性，差距分三层：**物理层**（物理近似误差）、**视觉层**（渲染不真实、传感器噪声缺失）、**控制层**（执行器动力学简化）。

**域随机化（Domain Randomization）**的核心思想：训练时把这些参数大范围随机打乱，逼策略学出对各种变化都稳的通用表征——**训练分布极度多样化，真实世界只是「其中一个样本」**。典型参数范围：

| 类别 | 参数示例 |
|---|---|
| 物理随机化 | 摩擦系数 0.1–1.0、物体质量 ±50%、关节刚度变化 |
| 视觉随机化 | 光照强度 0.2–2.0、材质颜色随机、摄像头位置 ±5cm |
| 动力学随机化 | 控制延迟 0–50ms、噪声水平 ±10%、执行器响应变化 |

成功先例：OpenAI Dactyl（手内方块重定向，后续用自动域随机化 ADR 实现单手解魔方）、ETH Zurich ANYmal（四足机器人雪地/碎石复杂野外地形鲁棒行走）。

### 落地两环节与零样本迁移流水线

把域随机化落到真机，绕不开两个工程环节：

1. **随机化范围的标定**——范围不能拍脑袋：太窄覆盖不了真实变化，太宽训练难度陡增、学出「什么都能应付但什么都不精」的次优策略。实践：先从真实环境数据**实测标定**关键参数分布（摩擦系数、电机响应延迟），在该范围内采样；真机明显掉点再逐步扩大范围，直到 sim-to-real gap 收敛。
2. **视觉对齐**——精确校准仿真与真实的摄像头位姿（环境对齐），并把真实拍摄的背景随机替换进仿真渲染（greenscreen 背景替换），让仿真画面尽量贴近真机所见。

完整的零样本 RGB Sim2Real 流水线（LeRobot + ManiSkill，纯 RGB 不依赖深度/力传感器，训练后直接部署真机 SO100 机械臂）：

1. **环境对齐**：调整仿真/真实摄像头位置，可视化叠加验证图像对齐；
2. **背景替换**：真实环境背景图随机裁剪叠加进仿真渲染；
3. **域随机化**：机器人颜色、物体纹理、光照、摄像头视场角 + 物理参数；
4. **RL 训练**：PPO、1024 个并行仿真环境、2500–4000 万步，仿真成功率 >90%——**单张 4090 约 1 小时**；
5. **真实部署**：真机零样本（不做任何额外调整）完成约 2.5cm 立方体抓取（15Hz 控制）。

成功关键：**精确环境对齐 + 视觉域随机化 + 物理参数随机化，三者缺一不可**。

## 术语表

| 术语 | 含义 |
|---|---|
| 行为克隆（BC） | 从人类演示直接学「看到什么就做什么」的模仿学习，SFT 性质 |
| 结果奖励 | 只按最终成败给反馈（1/0），稀疏但探索自由度大 |
| 过程奖励 | 每步即时反馈，密集但可能限制策略跳出演示空间 |
| RLVR | 可验证奖励强化学习——判分脚本直接当奖励函数 |
| 动态采样 | 过滤全成功/全失败 rollout 组，避免 GRPO 零方差死局 |
| 域随机化（DR） | 训练时大范围随机化物理/视觉/动力学参数，逼出鲁棒表征 |
| 自动域随机化（ADR） | 随策略进步自动扩大随机化范围，课程式从易到难 |
| Greenscreen 背景替换 | 把真实背景图叠加进仿真渲染，弥合视觉 Gap |
| reset 语义 | 每个 episode 重置到确定初始状态的能力，训练可信度的前提 |
| 零样本 Sim2Real | 仿真训练的策略不做任何真机微调直接部署 |

## 经验与常见坑

- **随机化范围拍脑袋定是常见翻车点**：实测标定起步、真机掉点再扩，别一步到「最大范围」。
- **环境失真 → 应试策略**：仿真里的环境响应跟真实不一致（固定套路回话、错误信息对不上），模型学到一套只在仿真里管用的策略，一上线就露馅——RL 项目最常见的翻车方式不是算法不行，是练习场不像。
- **忽视 reset 语义会污染梯度**：残留状态让「这轮的失败」可能是「上轮的锅」，训练信号失真。
- **保真度不是越高越好**：高保真环境计算开销大；适度随机化提升泛化，过度随机化让任务过难。选层级看任务瓶颈在物理精度还是交互规模。
- **分布外必掉点**：真实物体形状/大小/材质超出训练分布时成功率显著下降——零样本迁移有明确的作用半径，宣传视频里的「通用」要打折听。
- **结果奖励训不出「守规矩」**：纯结果奖励会反向激励抄近路（跳过验证、走危险路径），真实部署需要额外的路径约束信号。
- **数据和环境比算法重要**：现成 RL 算法（PPO/GRPO）会用就行，真正拉开差距的是仿真环境保真度与训练数据质量。

## ⚠️ 时效性说明

SimpleVLA-RL 的 LIBERO 分数与冷启动数字、ManiSkill/LeRobot 流水线的训练效率（单张 4090 约 1 小时）、RoboTwin2 配置均为 2025–2026 年报告值；「RL 训练的 VLA 泛化不足」这一判断也在快速变化——逐任务 RL → 统一模型 RL 是当前明确的演进方向，引用前请核对最新进展。
