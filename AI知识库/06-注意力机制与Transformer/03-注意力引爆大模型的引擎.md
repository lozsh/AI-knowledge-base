# 注意力：引爆大模型的引擎

<p class="note-date">更新于 2026-11-05</p>

**一句话定义**：注意力机制是"根据当前查询，有选择地参考所有位置信息并加权聚合"的神经网络组件，它（以自注意力的形式）构成了 Transformer 的核心，也是大模型时代的架构基石。

今天的大语言模型、图像生成模型、多模态模型大多共享同一个底层架构——Transformer，而 Transformer 的核心正是注意力机制。2017 年 Google 的论文《Attention Is All You Need》提出 Transformer，摒弃了当时 NLP 主流的循环与卷积结构；此后 BERT、GPT 系列、ChatGPT、Claude、Gemini 等重要系统都沿这条架构路线扩展。

## 核心原理

### 从 RNN 的困境说起

RNN 靠隐状态逐步传递信息，处理长文本时暴露两个严重问题：

- **长距离依赖弱**：信息从序列开头流到末尾要经过大量矩阵乘法和非线性变换，信号衰减（对应梯度消失）。LSTM 的门控只是缓解而非根治，几百词的依赖仍难捕捉。典型例子："The animal didn't cross the street because it was too tired" 中 "it" 指代 "animal"，跨距一长 RNN 就判断不了。
- **无法并行**：第 t+1 步依赖第 t 步的隐状态，只能串行计算。GPU 的大规模并行优势完全施展不开，在万亿词元级训练数据的时代，这种串行效率是灾难。

注意力的解法：跳出"一步一步传"的模式，让模型**一次性看到所有位置，自己决定关注哪些**——就像人读长文时根据当前问题（"第三段说了什么"）有选择地跳读。

### 用字典查询理解 QKV

把注意力想象成柔性字典查询：键（Key）是词条标签，值（Value）是词条内容，查询（Query）是正在找的词。普通字典要求精确匹配；注意力则让 query 与每个 key 比相似度，越相似的 key 对应的 value 权重越大，按权重加权求和得到"综合答案"：

Attention(q, K, V) = Σᵢ αᵢ·vᵢ，  αᵢ = softmax(score(q, kᵢ))

最常用的相似度是点积（方向越接近点积越大）。为防止维度 d 大时点积过大导致 softmax 梯度消失，除以 √d，得到 Transformer 最核心的公式——**缩放点积注意力**：

Attention(Q, K, V) = softmax(QKᵀ/√d)·V

直观理解：QKᵀ 生成一张 N×N 的"谁该看谁"关系表。任意两个位置都能直接联系是它的力量；上下文越长这张表膨胀越快（O(N²)），是它的麻烦。

**"软"在哪里**：softmax 让每个 key 都拿到非零权重（相关的权重大、不相关的小），且每一步连续可导，可以端到端用梯度下降训练。硬性"只选最相关的一个"不可微，无法用主流方法训练——这正是必须用柔性注意力的原因。

### 早期应用：机器翻译

2014 年 Bahdanau 等人把注意力引入编码器-解码器翻译模型：解码器每生成一个目标词时，以当前解码状态为 query，源句各位置为 key/value，动态决定参考哪些源词。这解决了"整句话压缩进一个固定向量、长句信息损失严重"的问题，长句翻译质量大幅提升。此后注意力成为机器翻译标配，但仍只是 RNN 的辅助，直到 2017 年 Transformer 把它推上主角。

### 自注意力与多头

**自注意力（self-attention）**：query、key、value 全部来自同一个序列。每个位置 xᵢ 经三个可学习矩阵变换出 qᵢ = W_Q xᵢ、kᵢ = W_K xᵢ、vᵢ = W_V xᵢ，再用 qᵢ 与所有 kⱼ 算相似度加权聚合所有 vⱼ。效果：每个位置的输出综合全序列信息，任意两位置一步直连——一举解决 RNN 的长距离依赖（1 到 100 不再需要 99 步传递）和并行性（所有位置同时算）两大痛点。没有自注意力，今天的大语言模型很难以这样的规模出现。

**多头自注意力（multi-head）**：一次注意力只能从一个视角看序列，而词的含义有多层（语法、语义、指代、位置）。多头让每组独立的 W_Q、W_K、W_V 各产生一套注意力权重和输出，拼接后经线性变换输出——好比不同专家从各自角度分析同一文本再综合意见。原始论文用 8 头，后来常用 12/16/32 或更多；每头维度相应变小，总参数量不随头数线性增长。

## 关键概念

### Transformer 积木：一个层的四个部件

| 部件 | 作用 |
|---|---|
| 多头自注意力 | 聚合跨位置信息，任意两位置直接交互 |
| 前馈网络（FFN） | 每个位置独立过两层全连接网络做"深加工"；Transformer 大部分参数在 FFN 里 |
| 残差连接 | 输入直接加到输出上，让梯度畅通回传 |
| 层规范化（LayerNorm） | 稳定训练 |

串联顺序：x → 层规范化 → 多头自注意力 → 残差相加 → 层规范化 → 前馈网络 → 残差相加 → x′。这个标准化积木堆叠 N 次（典型 12/24/96 层甚至更多）就是 Transformer 主体。标准化带来的工程优势：可反复堆深、便于超参搜索、模型缩放和分布式训练。

**位置编码**：自注意力对位置不敏感——打乱词序，计算结果完全一样（"我打他"和"他打我"无法区分）。必须显式注入位置信息，方案演化见下。

### 三种架构范式

同样的积木，组合方式不同，对应三类任务：

- **仅编码器（理解类）**：代表作 BERT（2018）。注意力无方向限制，真正双向；用"填空"（遮住 15% 的词做预测）预训练。在分类、问答、命名实体识别等理解任务上曾碾压此前方法，2018-2020 年及其变体（RoBERTa、ALBERT、ELECTRA）是 NLP 主力。
- **仅解码器（生成类）**：代表作 GPT 系列。从左到右逐词预测下一个词，用**因果掩码**（把"向后看"的打分置为负无穷，softmax 后权重变 0）保证训练时不偷看后文、同时仍可并行。GPT-1（1.17 亿参数）→GPT-2→GPT-3→GPT-4 每次扩规模都解锁新能力；当代大模型（Claude、Llama、Gemini、Qwen、DeepSeek）多为此范式——因为生成任务最通用，且可用提示词灵活切换任务。
- **编码器-解码器（转换类）**：原始 Transformer 架构，编码器理解输入、解码器生成输出，中间靠**交叉注意力（cross-attention）**让解码器查询编码器结果。适合翻译、摘要、语音识别（Whisper）等边界清晰的输入→输出任务，代表作 T5、BART。

三种范式底层积木完全相同，只是组合方式和训练目标不同。

### 位置编码的演化

| 方案 | 代表 | 特点 |
|---|---|---|
| 正弦/余弦编码 | 原始 Transformer（2017） | 固定编码：值域有界、相对距离可利用、理论可外推 |
| 可学习绝对编码 | BERT | 每位置一个可训练向量；不能外推到训练长度之外 |
| 相对位置编码 | T5、Transformer-XL | 把相对距离 i−j 编码进注意力，外推更稳 |
| 旋转位置编码 RoPE | 当代多数大模型（LLaMA 等） | 把位置编码为对 query/key 的旋转，点积自然带相对位置；配合 YaRN 等可支持更长上下文 |

### 注意力机制的工程变体

- **省显存**：多查询注意力 MQA（所有头共享 K/V）、分组查询注意力 GQA（组内共享 KV，Llama 2/3 采用），主要压缩推断时的 KV 缓存。
- **降复杂度**：稀疏注意力（局部窗口 + 全局标记 + 随机连接，Longformer、BigBird、Mistral，可到 O(N log N) 或 O(N)）；线性注意力（Performer、Linformer，直接近似到 O(N)，但有精度损失）。
- **改计算方式**：FlashAttention（2022）不改数学目标，重排计算顺序让中间结果留在 GPU 高速缓存（SRAM）里，显著提速省显存——"工程优化改变可能边界"的典范。

### 现代优化方向

- **混合专家（MoE）**：把 FFN 拆成多个"专家"，路由器每个词元只激活一两个，总参数量巨大但每次前向只算一小部分（"大而不贵"）。DeepSeek-V3、Mixtral、Switch Transformer 采用。MoE 拆的是 FFN 而非注意力——因为 FFN 是"胖"的部分。
- **KV 缓存（KV Cache）**：自回归生成时已算过的 K/V 不变，缓存后每生成新词只算新位置的 K/V，与缓存匹配——避免重复劳动，是大模型能实时响应的关键。代价是显存（要存所有已生成位置的 K/V），是推理服务的主要瓶颈之一，衍生出缓存压缩、共享、量化等技术。
- **层规范化位置**：原始论文是后规范化（Post-LN），深层网络训练不稳；现代主流是前规范化（Pre-LN），可训更深的网络（Llama、GPT 系列采用）。

## 经验与常见坑

- **为什么用 softmax**：权重归一化成分布，防止权重爆炸或消失；且 softmax 温度敏感——打分差距悬殊则注意力集中（精确匹配），打分接近则分散（综合考量），模型可自适应选择。
- **FFN 才是参数大头**：典型配置 FFN 维度 = 4 倍注意力维度。知识编辑实验发现 FFN 常是事实知识的载体（类比人脑海马体），但知识整体是分布式的，遍布注意力、残差流和整套回路。
- **长上下文的"中间丢失"**：即使有 RoPE，模型面对远超训练长度的输入时可能出现只关注开头结尾、忽略中间的现象，需长上下文继续训练、位置编码微调等技巧。
- **可解释性仍在前沿**：注意力可视化（部分头学语法/指代/实体边界）、探针实验（浅层学表层特征、深层学抽象语义）、回路分析（Anthropic、OpenAI；国内 OpenMOSS 的 SAE/字典学习路线如 Llama Scope）都在试图拆解内部机制，但离"真正理解"还很远。上下文学习的机制也未有定论，一个流行假设是模型参数里隐式编码了"如何从例子中学习"的元能力。

## ⚠️ 时效性说明

- 2017-2026 时间线：2017 Transformer → 2018 BERT/GPT-1 → 2019 GPT-2 → 2020 GPT-3/ViT/AlphaFold 2 → 2021 CLIP/Codex → 2022 ChatGPT/文生图革命 → 2023 GPT-4/Llama 开源 → 2024 Sora/o1/百万词元上下文 → 2025 DeepSeek R1 与智能体产业化 → 2026 前后竞争转向编程、长任务、工具使用与安全。
- 架构竞争未结束：Mamba（状态空间模型，O(N) 复杂度，RNN 的现代化版本）、RWKV、RetNet 等尝试结合 RNN 效率与 Transformer 表达力，尚未替代 Transformer，但证明注意力不是唯一的序列建模方式。
- 八位原作者大多离开 Google：Shazeer 创办 Character.AI（2024 年 Google 以约 27 亿美元授权协议请回）、Gomez 创办 Cohere、Polosukhin 转向 NEAR Protocol 等。人才流动是 Google 起大早却未独占大模型商业化的原因之一。
- Transformer 的"通用悖论"：它放弃了 CNN 的空间先验和 RNN 的时序先验，"一无所长"反而让它在数据和算力足够时最容易跨任务迁移——Bitter Lesson 的又一次应验。应用已覆盖视觉（ViT、Swin、DINO）、语音（Whisper、Conformer）、多模态（CLIP、GPT-4V）、生物（AlphaFold）、机器人（RT-1、PaLM-E）。
