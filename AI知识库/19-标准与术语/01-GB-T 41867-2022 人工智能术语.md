# GB/T 41867-2022《信息技术 人工智能 术语》

> 来源：国家标准 GB/T 41867-2022（wiki 化重写于 2026-11-03）

**一句话定义**：GB/T 41867-2022 是中国人工智能领域的国家标准术语表，2022-10-12 发布、2023-05-01 实施，由全国信息技术标准化技术委员会（SAC/TC 28）归口，将人工智能术语划分为基础、机器学习、自然语言处理、伦理/可信四大类共 75 条。

该标准对应国际标准 ISO/IEC 22989:2022（Information technology — Artificial intelligence — Concepts and terminology）的思路，为中文技术文献、合同、法规和学术写作提供权威的术语-定义对应关系。每个术语条目含中文名、英文名、定义和注释（部分条目标注了来源，如 ISO/IEC 2382:2015、GB/T 5271 系列、GB/T 3358.3、GB/T 23703.2、GB/T 36464.3、ISO 17100、ISO 24613-1 等）。

标准结构：第 1 章范围、第 2 章规范性引用文件、第 3 章术语和定义（3.1 基础术语 9 条 / 3.2 机器学习术语 37 条 / 3.3 自然语言处理术语 17 条 / 3.4 伦理与可信术语 12 条），正文后附中文索引和英文索引。

## 术语表

### 3.1 基础术语（9 条）

| 编号 | 中文术语 | 英文 | 定义（含注要旨） |
|---|---|---|---|
| 3.1.1 | 分布式人工智能 | distributed artificial intelligence | 由多个智能系统/智能体协同求解问题的 AI 形态。注：相关形态包括分布式问题求解、多智能体系统等 |
| 3.1.2 | 人工智能；AI | artificial intelligence; AI | 〈学科〉与人工智能系统（3.1.8）相关的研究领域/学科分支 |
| 3.1.3 | 人工智能服务器 | artificial intelligence server | 能够提供人工智能计算能力的服务器设备。注1：一体化形态，AI 算法与硬件集成，是提供 AI 算力的硬件设备。注2：从算力角度看，是执行 AI 算法负载的硬件设备，属于服务器的一种 |
| 3.1.4 | 人工智能集群 | artificial intelligence cluster | 在统一管理下，为人工智能计算任务协同工作的节点集合。注1：包括 AI 计算节点、AI 网络、AI 存储等。注2：其中网络节点既可以是 AI 网络节点，也可以是承担其他功能的通用网络节点 |
| 3.1.5 | 人工智能加速处理器；人工智能加速芯片 | artificial intelligence accelerating processor / accelerating chip; AI 加速器 | 专门面向人工智能算法优化的处理器，能高效执行人工智能算法运算的硬件 |
| 3.1.6 | 人工智能加速模块 | artificial intelligence accelerating module | 以某种形式集成人工智能加速器、并配套必要部件的功能单元。注：可能以板卡、模组等形式存在于 AI 系统中 |
| 3.1.7 | 人工智能组合 | artificial intelligence portfolio | 面向人工智能应用的多个要素的集合，共同构成满足用户需求的整体。注：包括人工智能部件、计算节点/系统、系统服务等 |
| 3.1.8 | 人工智能系统 | artificial intelligence system | 针对人类设定的目标，能够感知环境、借助学习/推理等手段处理信息并产生输出的系统。注1：作为一类技术载体，先进形式包括专家系统、机器人、知识图谱等。注2：AI 系统是人工智能相关技术的核心载体 |
| 3.1.9 | 异构资源池 | heterogeneous resource pool | 由不同类型、不同架构的计算资源组成，统一管理和调度的资源集合。注1：例如将不同架构的计算资源组织起来，根据任务特征（负载、时延、吞吐等）为 AI 系统分配合适的资源、调度与优化。注2：包括中央处理器（CPU）、图形处理器（GPU）、神经网络处理器（NPU）、现场可编程门阵列（FPGA）、数字信号处理器（DSP）、专用集成电路（ASIC）等 |

### 3.2 机器学习术语（37 条）

| 编号 | 中文术语 | 英文 | 定义（含注要旨） |
|---|---|---|---|
| 3.2.1 | 贝叶斯网络 | Bayesian network | 基于贝叶斯统计推断的有向图概率模型 |
| 3.2.2 | 半监督机器学习 | semi-supervised machine learning | 利用少量有标注数据与大量无标注数据共同训练模型的学习方式 |
| 3.2.3 | 测试数据；评估数据 | test data; evaluation data | 用于检验（评估）训练后模型性能的数据。注：与训练数据、验证数据互斥 |
| 3.2.4 | 长短时记忆网络；LSTM 网络 | long short-term memory network; LSTM network | 能学习长期依赖信息的循环神经网络，通过门控机制控制信息的保留与遗忘。注：用于解决长序列训练中的梯度消失、梯度爆炸等问题 |
| 3.2.5 | 迭代 | iteration | 重复执行的过程，每次重复使结果更接近目标。注：如从第 k 个批次到下一个批次，训练直到满足条件。［来源：ISO/IEC 2382:2015］ |
| 3.2.6 | 分类模型 | classification model | 〈机器学习〉根据输入数据，预测其所属离散类别标签的机器学习模型 |
| 3.2.7 | 过拟合 | overfitting | 〈机器学习〉模型对训练数据拟合过度、泛化能力差的现象。注1：表现：训练数据上误差小而新数据上误差大；常见于训练数据过少、模型复杂度过高。注2：可通过增加训练数据、正则化、简化模型等手段缓解（对照欠拟合） |
| 3.2.8 | 回归模型 | regression model | 根据输入数据，预测连续数值输出的模型 |
| 3.2.9 | 回归分析 | regression analysis | 为因变量与自变量之间建立数量关系的分析方法。［来源：GB/T 3358.3—2009］ |
| 3.2.10 | 机器学习 | machine learning | 通过计算自动从数据中学习规律并用于预测/决策、无需显式编程的方法 |
| 3.2.11 | 机器学习模型 | machine learning model | 描述输入与输出之间映射关系的计算结构。示例：用线性函数 y=θ₀+θ₁x 拟合数据，训练后得 y=3+7x。注：机器学习模型由训练过程得到 |
| 3.2.12 | 机器学习算法 | machine learning algorithm | 用于求解机器学习模型的算法，通过对数据的训练得到模型参数。示例：对 y=θ₀+θ₁x，θ₀ 为截距（x=0 时 y 的值）、θ₁ 为斜率，算法通过数据求出这两个参数 |
| 3.2.13 | 卷积神经网络；深度卷积神经网络 | convolutional neural network; CNN / deep CNN; DCNN | 使用卷积运算的神经网络，通过卷积核提取局部特征，擅长处理图像等网格结构数据 |
| 3.2.14 | 连接权重（连接强度；突触权重） | connection weight (connection strength; synaptic weight) | 神经元之间连接的强度参数，决定信号传递的权重。［来源：GB/T 5271.34—2006］ |
| 3.2.15 | 联邦学习 | federated machine learning | 多个参与方在数据不出本地的前提下，通过交换模型参数/中间结果协同训练全局模型的方法，目的是保护数据隐私 |
| 3.2.16 | 逻辑推理 | logical inference | 从前提（已知事实、假设等）出发，按逻辑规则得出结论的推断过程 |
| 3.2.17 | 模式识别 | pattern recognition | 利用计算机对事物、现象进行自动识别与分类的技术。［来源：GB/T 5271.28—2001］ |
| 3.2.18 | 模型训练 | model training | 使用训练数据、通过学习算法不断调整模型参数的过程 |
| 3.2.19 | 模型优化 | model optimization | 通过调整参数、结构等手段，提升模型在精度、效率、资源占用等方面的表现。注：如神经网络压缩、剪枝、量化、蒸馏等 |
| 3.2.20 | （批）训练 | batch training | 以批次为单位进行训练：一个批次的数据做一次参数更新。［来源：ISO/IEC 2382:2015］ |
| 3.2.21 | 偏差 | bias | 系统性误差的度量（统计意义：期望值与真值之差）。［来源：ISO/IEC 2382:2015］ |
| 3.2.22 | 欠拟合 | underfitting | 模型未能充分学习训练数据规律，在训练数据和新数据上表现都差的现象。注：常见原因：模型过于简单、训练不充分等；表现为无法捕捉数据中的基本规律 |
| 3.2.23 | 迁移学习 | transfer learning | 把从一个任务/领域学到的知识迁移应用到另一个任务/领域的训练方法 |
| 3.2.24 | 前馈神经网络 | feedforward neural network; FFNN | 神经元分层排列、信号单向从输入层经隐层向输出层传递（无回路）的神经网络 |
| 3.2.25 | 强化学习；RL | reinforcement learning; RL | 智能体通过与环境交互试错、依据奖励反馈调整行为来学习最优策略的机器学习方法 |
| 3.2.26 | 神经网络；人工神经网络 | neural network; artificial neural network | 模拟生物神经元连接结构的计算模型，通过调整连接权重学习输入到输出的映射。注1：训练过程即不断调整权重的过程。注2：神经网络的实现既可用硬件（专用芯片）也可用软件模拟 |
| 3.2.27 | 深度学习；深度神经网络学习 | deep learning / deep neural network learning | 使用多层（深层）神经网络进行学习的方法。注：层数越深，模型表达能力越强（可学习的特征层次越丰富） |
| 3.2.28 | 生成对抗网络；GAN | generative adversarial network; GAN | 由生成器与判别器两个神经网络组成的系统，二者通过对抗训练共同提升。注：生成器生成样本试图骗过判别器，判别器学习区分真实样本与生成样本 |
| 3.2.29 | 数据标注 | data labeling | 为数据添加标签、注释的过程 |
| 3.2.30 | 推理 | inference | 利用已训练的模型或逻辑规则，从输入得出输出的过程。注1：AI 领域中推理包括模型推理（前向计算）、逻辑推理、数据推理、规则推理等。注2：辨析——这里的"推理"侧重推断计算过程，与逻辑推理（3.2.16）的严格逻辑推演有所区别 |
| 3.2.31 | 微调 | fine-tuning | 在预训练模型基础上，用特定任务数据继续训练，使模型参数适应下游任务的方法。注：通常所需数据量远小于从头训练 |
| 3.2.32 | 无监督机器学习 | unsupervised machine learning | 仅使用无标注数据训练模型的机器学习 |
| 3.2.33 | 循环神经网络；RNN | recurrent neural network; RNN | 具有循环连接、能处理序列数据的神经网络：前一时刻的状态参与当前时刻的计算 |
| 3.2.34 | 训练数据 | training data | 用于训练（学习）模型参数的数据集合 |
| 3.2.35 | 验证数据；开发数据 | validation data; development data | 训练过程中用于调整超参数、选择模型的数据集合。注1：验证数据与训练数据、测试数据互斥；k 折交叉验证中各子集轮流充当验证角色。注2：用于监控是否过拟合、执行早停等，防止超参数调整过拟合到测试集 |
| 3.2.36 | 隐马尔可夫模型；HMM | hidden Markov model; HMM | 描述含隐含状态的马尔可夫过程的统计模型：通过可观测序列推断隐状态序列。注1：双重随机过程——隐状态转移是马尔可夫链，每次转移产生一个观测。注2：典型应用如语音识别。［来源：GB/T 5271.29—2006］ |
| 3.2.37 | 有监督机器学习 | supervised machine learning | 使用有标注数据（含期望输出）训练模型的机器学习 |

### 3.3 自然语言处理术语（17 条）

| 编号 | 中文术语 | 英文 | 定义（含注要旨） |
|---|---|---|---|
| 3.3.1 | 词位 | lexeme | 词汇的最小抽象单位（词条）。［来源：ISO 24613-1:2019］ |
| 3.3.2 | 词性标注 | part-of-speech tagging | 为文本中的词标注词性类别（名词、动词、形容词等）的过程 |
| 3.3.3 | 对话管理 | dialog management | 控制对话流程、维护对话状态、决定系统下一步回应的技术 |
| 3.3.4 | 关系抽取 | relationship extraction | 从文本中识别实体之间语义关系的过程 |
| 3.3.5 | 光学字符识别；OCR | optical character recognition; OCR | 将图像（扫描件、照片等）中的文字转换为机器可读文本的技术 |
| 3.3.6 | 机器翻译；MT | machine translation; MT | 利用计算机将文本从一种自然语言自动翻译成另一种自然语言。［来源：ISO 17100:2015］ |
| 3.3.7 | 命名实体识别；NER | named entity recognition; NER | 从文本中识别具有特定意义的实体指称并判定其类别的过程。注1：实体是现实世界中可区别命名的事物。注2：如"北京大学"是机构类命名实体。注3：类别通常包括人名、地名、机构名等（可扩展时间、数量等） |
| 3.3.8 | 情感识别 | emotion recognition | 通过计算分析文本、语音、表情等信息判断情感状态的技术。注：情感状态如高兴、悲伤、愤怒等 |
| 3.3.9 | 问答 | question answering | 针对用户以自然语言提出的问题，自动给出答案的技术。注：如从知识库/文档中检索并生成答案 |
| 3.3.10 | 信息检索 | information retrieval | 从大规模文档/数据集合中查找满足用户需求的信息的过程 |
| 3.3.11 | 语义计算 | semantic computing | 通过对语言与内容语义的分析计算，理解并处理其含义的技术 |
| 3.3.12 | 语义理解 | semantic comprehension | 对自然语言文本的含义进行分析理解、转化为机器可处理表示的过程。［来源：GB/T 36464.3—2018］ |
| 3.3.13 | 语义网络 | semantic network | 用图结构表示概念及其之间语义关系的网络。［来源：GB/T 23703.2—2010］ |
| 3.3.14 | 自动文摘 | automatic summarization | 从较长的文本中自动提取/生成要点摘要的技术 |
| 3.3.15 | 自然语言理解；NLU | natural language understanding; NLU | 计算机理解自然语言文本的含义、并将其转换为机器可处理形式的技术 |
| 3.3.16 | 自然语言处理；NLP | natural language processing; NLP | 〈学科〉研究用计算机处理自然语言的学科领域 |
| 3.3.17 | 自然语言生成；NLG | natural language generation; NLG | 从结构化数据或内部表示自动生成自然语言文本的技术 |

### 3.4 伦理与可信术语（12 条）

| 编号 | 中文术语 | 英文 | 定义（含注要旨） |
|---|---|---|---|
| 3.4.1 | 公平性 | fairness | AI 系统无歧视、公正对待不同个体和群体的特性。注1：涉及性别、种族、地域等多种维度。注2：公平性涉及价值判断，不同场景下对"公平"的定义可能不同 |
| 3.4.2 | 可信性 | trustworthiness | 〈人工智能〉AI 系统在性能、安全、合规等方面满足利益相关方期望、可被依赖的程度。注1：是用户/社会对 AI 系统可信任程度（置信度）的综合反映。注2：可信特性包括安全性、透明性、公平性、隐私保护、问责性、可靠性、鲁棒性、韧性等。注3：可信性是贯穿系统全生命周期的综合属性，不是单一技术指标 |
| 3.4.3 | 可解释性 | explainability | 〈人工智能〉系统的行为、决策能够被人类理解的特性。注：可解释是"被理解"，不等于"正确"——一个解释得清楚的结果也可能是错的 |
| 3.4.4 | 可靠性 | reliability | 〈人工智能〉系统在规定条件下和规定时间内完成规定功能的特性 |
| 3.4.5 | 可控性 | controllability | 〈人工智能〉系统的行为能够被人类监督、干预和控制的特性 |
| 3.4.6 | 问责性 | accountability | 〈人工智能〉对系统的开发和运行结果，能够明确并追究相应责任主体。注1：责任应可追溯——由谁开发、谁部署、谁运行，出现问题时责任归属清晰。注2：涉及开发者、部署者、使用者等多方角色时，应事先明确各自责任边界 |
| 3.4.7 | 可预测性 | predictability | 〈人工智能〉系统行为可以被预期、结果具有一致性的特性 |
| 3.4.8 | 伦理 | ethics | 〈人工智能〉AI 研究开发与应用中应遵循的道德规范和价值准则 |
| 3.4.9 | 鲁棒性 | robustness | 〈人工智能〉系统在异常输入、扰动环境下仍能保持稳定正确运行的特性 |
| 3.4.10 | 偏见 | bias | 〈人工智能信任〉系统输出对特定群体或个体呈现系统性不公正倾向的误差。注：来源包括训练数据、算法设计、人类决策等 |
| 3.4.11 | 韧性 | resilience | 〈人工智能〉系统受到攻击或发生失效后恢复正常功能的能力 |
| 3.4.12 | 透明性 | transparency | 〈人工智能〉系统的相关信息能够被获得、了解和核查的特性。注1：涉及的信息包括数据来源、模型架构、训练过程、性能指标等。注2：透明性受隐私、安全等约束——并非所有信息都可无条件公开 |

## ⚠️ 时效性说明

- 该标准发布于 2022 年，未覆盖此后快速兴起的大语言模型、生成式 AI、多模态、智能体等新术语；相关概念可参考后续国家标准（如 ISO/IEC 22989、ISO/IEC 42001 的更新版）及行业标准动态。
- 本条目的中文定义由原笔记重写整理而成：原始 PDF 提取文本存在严重字体映射乱码（中文定义全部损坏），表中定义依据标准条目编号、英文原词及可辨认片段恢复表述；**引用国标原文时请以官方发布文本为准**。
- 术语编号（3.x.y）与原标准保持一致，便于对照查证。
