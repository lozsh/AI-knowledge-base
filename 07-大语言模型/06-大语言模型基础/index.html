    Transformer 大模型 提示词 深度学习

    大语言模型基础

    更新于 2026-11-03

    一句话定义：大语言模型（LLM）是基于 Transformer 架构、以"预测下一个词"为核心任务在海量文本上预训练的语言模型，是现代智能体理解指令、推理与生成的基础。

    本篇回答一个关键问题：现代智能体的大脑是如何工作的？ 从语言模型的统计时代（N-gram）走到神经网络时代（词嵌入、RNN/LSTM），再到奠定一切的 Transformer 与 Decoder-Only 架构；随后是与模型交互的两件核心技能——提示工程与分词；最后是模型生态、缩放法则与固有局限（幻觉、知识时效、偏见）。

    语言模型的演进

    统计语言模型与 N-gram

    语言模型（Language Model）的根本任务是计算一个词序列出现的概率。由链式法则：

    P(S) = P(w₁) · P(w₂|w₁) · P(w₃|w₁,w₂) ⋯ P(wₘ|w₁,…,wₘ₋₁)

    直接估计这些条件概率不可行（长词序列在语料库中几乎不出现），因此引入马尔可夫假设：一个词的出现只依赖它前面有限的 n−1 个词。由此得到 N-gram 模型：

    • Bigram（N=2）：P(wᵢ|w₁,…,wᵢ₋₁) ≈ P(wᵢ|wᵢ₋₁)；Trigram（N=3）：P(wᵢ|w₁,…,wᵢ₋₁) ≈ P(wᵢ|wᵢ₋₂,wᵢ₋₁)

    概率用最大似然估计（MLE）即计数得出：P(wᵢ|wᵢ₋₁) = Count(wᵢ₋₁,wᵢ) / Count(wᵢ₋₁)。

    手算示例：迷你语料库 "datawhale agent learns datawhale agent works"（共 6 词），用 Bigram 估算 P(datawhale agent learns) = P(datawhale)·P(agent|datawhale)·P(learns|agent) ≈ (2/6)·(2/2)·(1/2) ≈ 0.167。

    N-gram 的两个致命缺陷： 1. 数据稀疏性（Sparsity）：未见过的词序列概率为 0，平滑（Smoothing）只能缓解不能根除。 2. 泛化能力差：词是孤立离散符号，无法理解语义相似性——见过 "agent learns" 不代表能算出 "robot learns" 的概率。

    神经网络语言模型与词嵌入

    Bengio 等人（2003）提出前馈神经网络语言模型（NNLM），核心思想两步： 1. 构建语义空间：把每个词映射为高维连续向量，即词嵌入（Word Embedding），语义相近的词在空间中位置相近。 2. 学习映射：用神经网络学习"前 n−1 个词的词向量 → 下一个词的概率分布"。词嵌入在"预测下一个词"的训练中自动学到丰富语义。

    度量词向量相似性最常用余弦相似度：similarity(a,b) = cos(θ) = (a·b)/(‖a‖‖b‖)，1 表示完全相关、0 无关、−1 完全负相关。著名例子：vector('King') − vector('Man') + vector('Woman') ≈ vector('Queen')，说明词嵌入学到了"性别""皇室"这类抽象概念。

    NNLM 解决了泛化问题，但上下文窗口仍是固定的（只看前 n−1 个词）。

    RNN 与 LSTM

    循环神经网络（RNN）引入隐藏状态（hidden state）作为网络的短期记忆：每步读取当前输入并结合上一时刻的记忆，生成新记忆向后传递，从而打破固定窗口限制。

    但标准 RNN 有长期依赖问题：序列长度等于网络深度，反向传播时梯度多次连乘，导致梯度消失/爆炸，学不到长距离依赖。

    LSTM（长短期记忆网络）用细胞状态（Cell State）（一条独立于隐藏状态的信息通路）加三个门控机制解决：遗忘门（决定从上一时刻细胞状态丢弃哪些信息）、输入门（决定当前输入中哪些新信息写入细胞状态）、输出门（决定细胞状态中哪些信息输出到隐藏状态）。

    Transformer 架构

    RNN/LSTM 的循环结构带来新瓶颈：第 t 步必须等第 t−1 步完成，无法大规模并行，限制了模型规模与训练速度。Transformer（Vaswani et al., 2017，Google）完全抛弃循环结构，只靠注意力机制捕捉依赖，实现真正的并行计算。

    Encoder-Decoder 整体结构

    原始 Transformer 为机器翻译设计，宏观是编码器-解码器架构：编码器负责"理解"输入句子，为每个词元生成含全局上下文的表示；解码器负责"生成"目标句子，参考已生成前文并"咨询"编码器的理解结果。

    核心组件逐层堆叠：多头自注意力 →（解码器另有交叉注意力）→ 逐位置前馈网络，每个子模块都被 Add & Norm 包裹。

    自注意力与多头注意力

    自注意力（Self-Attention）允许每个词元兼顾句中所有其他词并分配注意力权重。为每个词元引入三个由可学习权重矩阵（\(W_Q\)、\(W_K\)、\(W_V\)，分别把词元表示变换成查询/键/值）变换出的角色：

    • 查询（Query, Q）：当前词元主动"查询"其他词元；键（Key, K）：可被查询的词元"标签/索引"；值（Value, V）：词元本身携带的内容。

    计算四步：Q 与所有 K 点积得相关性得分 → 除以缩放因子 \(\sqrt{d_k}\)（\(d_k\) 为键向量维度）防梯度过小 → Softmax 归一化为权重 → 对 V 加权求和。公式：

    \[\text{Attention}(Q, K, V) = \text{softmax}\left(QK^\top / \sqrt{d_k}\right) V\]

    单头注意力只能学一种关联；多头注意力把 Q、K、V 在维度上切分成 h 份独立计算（h 个"专家"从不同角度看句子，如指代、时态、从属关系），输出拼接后经线性变换整合。

    前馈网络（FFN）

    逐位置前馈网络独立作用于每个词元（所有位置共享同一组权重），从注意力聚合的信息中提取更高阶特征：

    \[\text{FFN}(x) = \max(0, xW_1 + b_1)W_2 + b_2\]

    通常先扩大（\(d_{ff} \approx 4 \cdot d_{model}\)，\(d_{model}\) 为模型主干隐藏维度，\(d_{ff}\) 为前馈层隐维度）再缩回 \(d_{model}\)，"先扩大再缩小"有助于学习更丰富的特征。

    残差连接与层归一化（Add & Norm）

    • 残差连接（Add）：Output = x + Sublayer(x)，让梯度可绕过子模块直接回传，解决深网络梯度消失。
    • 层归一化（Norm）：对单个样本的所有特征归一化（均值 0 方差 1），稳定每层输入分布，加速收敛。

    位置编码

    自注意力本身不含词序信息（"agent learns" 与 "learns agent" 对它等价），因此要给每个词元嵌入加上位置向量。原论文用固定的正弦/余弦公式（非学习得到）：

    \[\text{PE}(\text{pos}, 2i) = \sin(\text{pos} / 10000^{2i/d_{model}})$$ $$\text{PE}(\text{pos}, 2i+1) = \cos(\text{pos} / 10000^{2i/d_{model}})\]

    其中 \(\text{pos}\) 是词元位置，\(i\) 是维度索引，\(d_{model}\) 是嵌入维度。位置不同则最终向量不同，即使词元本身相同。

    Decoder-Only 架构

    GPT 的洞察：语言的核心任务就是预测下一个词——回答问题、写故事、写代码本质上都是"文字接龙"。于是完全抛弃编码器，只留解码器，即 Decoder-Only 架构，工作模式为自回归（Autoregressive）：输入起始文本 → 预测下一个词 → 拼回输入 → 再预测，循环至结束。

    训练时如何保证预测第 t+1 个词时不"偷看"后面的答案？答案是掩码自注意力（Masked Self-Attention）：在注意力分数矩阵经 Softmax 之前应用因果掩码，把当前位置之后的所有分数替换为极大负数，Softmax 后这些位置概率变 0。这保证了训练方式与生成时的自回归使用方式一致。

    Decoder-Only 的三大优势：训练目标统一（唯一任务"预测下一个词"，极适合海量无标注文本预训练）；结构简单、易扩展（GPT-4、Llama 等数千亿参数模型都基于此）；天然适合生成任务（自回归与对话、写作、代码生成完美契合，是通用智能体基座的核心原因）。

    与大语言模型交互

    提示工程

    提示（Prompt）是与模型"大脑"沟通的语言，提示工程研究如何设计提示引导期望输出。

    采样参数——本质是调整模型对概率分布的采样策略（Softmax：pᵢ = e^(zᵢ) / Σⱼ e^(zⱼ)）：

    参数 原理 特点与适用
    Temperature 引入温度系数 T：pᵢ = e^(zᵢ/T) / Σⱼ e^(zⱼ/T) T 小 → 分布陡峭，保守、重复率高：事实性任务（问答、代码、0~0.3）；T 中 → 平衡自然：日常对话、常规创作（0.3~0.7）；T 大 → 分布平坦，多样、可能不连贯：创意任务（0.7~2）
    Top-k 取概率前 k 个 token 组候选集再归一化 k=1 退化为贪心采样（完全确定）
    Top-p（核采样） 从最高概率起累加，取累积概率 ≥ p 的最小集合再归一化 截断大小动态适应分布长尾，比固定 k 的 Top-k 适应性更好

    协同优先级：温度调整 → Top-k → Top-p（分层过滤，后者在前者结果中再筛）；实际使用中 Top-k 与 Top-p 通常二选一。特殊值：温度=0 时 Top-k/Top-p 失效（必取最优 token）；Top-k=1 时温度和 Top-p 都失效。

    示例数量：零样本（Zero-shot，不给示例，靠预训练泛化）、单样本（One-shot，给 1 个示例示范格式）、少样本（Few-shot，给多个示例覆盖任务边界与细微差别，性能最好）。

    指令调优（Instruction Tuning）：用大量"指令-回答"数据微调，使模型能直接遵循指令。早期 GPT-3 这类"文本补全"模型需要少样本示例"教会"任务；ChatGPT、DeepSeek、Qwen 等日常使用的都是经过指令调优的模型，可直接下达自然语言指令。

    基础技巧：角色扮演（赋予角色约束风格、语气与知识范围）；上下文示例（在提示中给出输入输出样例"教会"模型，尤其适合复杂格式/特定风格）。

    思维链（Chain-of-Thought, CoT）：加入"请逐步思考 / Let's think step by step"引导，让模型显式展示推理过程，显著提升逻辑推理、计算、多步任务的正确率，且结果更可信、易检查。（例：80 场赢 60% + 15 场赢 12 场，逐步计算得两赛季总胜率 60/95 ≈ 63.16%。）

    文本分词（Tokenization）

    计算机只懂数字，分词器（Tokenizer）把原始文本切分为词元（Token）并转为数字序列。三种策略：

    策略 优点 缺点
    按词（Word-based） 直观 词表爆炸；未登录词（OOV）无法处理；词形变体（look/looks/looking）语义割裂，低频词学不好
    按字符（Character-based） 词表极小，无 OOV 单字符缺乏独立语义，学习效率低
    子词（Subword） 常见词保留整词，罕见词拆成有意义的子词片段 兼顾词表大小与语义表达，现代 LLM 主流方案

    字节对编码（BPE）——GPT 系列采用的贪心合并算法：① 词表初始化为语料库中所有基本字符；② 统计相邻词元对频率，合并频率最高的一对并加入词表；③ 重复直到词表达到预设大小。示例：语料 {"hug","pug","pun","bun"} 各 1 次，合并 4 次的顺序为 u+g → ug+ → u+n → un+；对新词 "bug" 会切成 ['b', 'ug']（先查整词、再查更长前缀、最后落到子词）。

    变体：WordPiece（Google BERT）——合并标准不是最高频率，而是"能最大化提升语料库语言模型概率"；SentencePiece（Google 开源，Llama 系列采用）——把空格当作普通字符（常表示为下划线 _），分词与解码完全可逆，语言无关。

    分词器对开发者的实际影响：① 上下文窗口按 Token 计（8K/128K 等），同一段话不同语言/分词器 Token 数差异巨大，是长上下文管理的基础；② API 按 Token 计费，预估成本需了解分词方式；③ 模型异常可能源于分词——2 + 2 没问题而 2+2（无空格）可能出错，大小写不同可能切成完全不同的 Token 序列，设计提示词与解析输出时要考虑这些陷阱。

    本地部署开源模型

    除调用 API 外，敏感数据、离线运行、成本精细控制等场景需要本地部署。Hugging Face Transformers 提供标准化接口：用 AutoTokenizer + AutoModelForCausalLM 加载模型（示例为 Qwen/Qwen1.5-0.5B-Chat，约 5 亿参数的对话模型），用 tokenizer.apply_chat_template 按模型对话模板格式化输入，model.generate(max_new_tokens=...) 生成 Token ID，再 tokenizer.batch_decode 解码回文本。关键模式：输入 → Token ID → 生成 → 截掉输入部分 → 解码。

    模型选型

    选型是性能、成本、速度、部署方式之间的权衡。考量维度：性能与能力（参考 LMSys Chatbot Arena 等排行榜）、成本（API 计费 vs 本地硬件运维）、速度/延迟（实时交互场景）、上下文窗口（长文档/长记忆需 128K 级）、部署方式（API 便捷但数据出域 vs 本地自主可控）、生态与工具链（LangChain/LlamaIndex/HF 兼容性）、可微调性（开源更灵活）、安全性与伦理（偏见、毒性、幻觉）。

    • 闭源：OpenAI GPT 系列（GPT-3 → ChatGPT 引入 RLHF → GPT-4 多模态）、Google Gemini（原生多模态、超长上下文，Ultra/Pro/Nano 分层）、Anthropic Claude（安全优先，Opus/Sonnet/Haiku 分层）、国内闭源（文心一言、混元、盘古、星火、月之暗面等，中文优势）。
    • 开源：Meta Llama（Llama 4 起采用 MoE 架构，Scout 支持 1000 万 token 上下文）、法国 Mistral AI（小尺寸高性能）、国内开源（阿里 Qwen、清华/智谱 ChatGLM）。

    缩放法则与局限性

    缩放法则（Scaling Laws）

    模型性能（损失）与参数量、数据量、计算量三要素在对数-对数坐标系下呈平滑幂律关系（Kaplan et al., 2020）：持续按比例增加三要素，性能可预测地提升，无明显瓶颈。

    Chinchilla 修正（DeepMind, 2022）：给定计算预算下，参数量与数据量存在最优配比——最优模型应比此前认知更小但用多得多的数据训练。700 亿参数的 Chinchilla 用 4 倍于 GPT-3（1750 亿参数）的数据训练，性能反超。这纠正了"越大越好"，强调数据效率，指导了 Llama 等高效模型的设计。

    能力涌现（Emergent Abilities）：模型规模超过某阈值后突然出现小模型完全不具备的能力——链式思考、指令遵循、多步推理、代码生成等都在数百亿~千亿参数级才显著出现。对智能体开发的含义：足够大的模型是复杂自主决策与规划能力的前提。

    模型幻觉（Hallucination）

    模型生成与客观事实、用户输入或上下文矛盾的内容，或编造不存在的事实/实体/事件。本质是自回归生成只是"预测最可能的下一个词"，没有内置事实核查。分类：事实性幻觉（与现实世界不符）、忠实性幻觉（摘要/翻译中未忠实反映源文本）、内在幻觉（与输入直接矛盾）。

    成因：训练数据本身有错误/矛盾；自回归机制无事实核查；复杂推理链中出错后"编造"结论。例：旅游 Agent 推荐不存在的景点或订错航班号。此外 LLM 还有知识时效性（只知训练数据截止日之前的世界）与数据偏见（吸收训练数据中的刻板印象）问题。

    缓解手段：数据层面（高质量数据清洗、引入事实性知识、RLHF）；模型层面（新架构探索、让模型表达不确定性）；推理与生成层面（检索增强生成 RAG——生成前从外部知识库检索相关信息作为上下文，目前最有效手段之一；多步推理与自我/外部验证；引入外部工具——搜索引擎、计算器、代码解释器——获取实时信息或精确计算）。幻觉短期难以根除，但上述策略可显著降低其频率与影响。

    术语表

    术语 含义
    N-gram 基于马尔可夫假设、用计数估计条件概率的统计语言模型
    词嵌入 把词映射为语义空间中的连续向量
    自注意力 Q·K 点积打分、缩放、Softmax、对 V 加权求和的机制
    掩码自注意力 因果掩码阻止模型关注当前位置之后的信息
    自回归 逐词生成并把已生成内容拼回输入的循环生成方式
    Decoder-Only 只保留 Transformer 解码器的架构，GPT/Llama 等的主流选择
    指令调优 用"指令-回答"数据微调，使模型能直接遵循指令
    BPE 迭代合并最高频相邻词元对的子词分词算法
    缩放法则 性能与参数量/数据量/计算量之间的幂律关系
    能力涌现 规模超过阈值后突然出现的新能力（如 CoT、多步推理）
    幻觉 模型生成与事实/输入/上下文矛盾或编造的内容

    ⚠️ 时效性说明

    • 模型生态部分（GPT-5、Gemini 2.5、Claude 4、Llama 4 等具体版本与性能对比）反映本文撰写时点，模型迭代极快，选型时应以最新排行榜与官方文档为准；其中的选型维度与原则是长期有效的。上下文窗口、参数规模等具体数字也会随版本快速变化。
