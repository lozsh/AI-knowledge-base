    动手搭建大模型

    更新于 2026-11-03

    一句话定义：从零实现一个 LLaMA2 结构的迷你大语言模型（Tokenizer → 预训练 → SFT → 采样生成），用可运行的代码把"大模型是怎么造出来的"完整走一遍。

    本文基于 Datawhale 系列教程（llama2.c / minimind 一脉）整理，实现一个约 215M 参数的 Decoder-only Transformer（类 LLaMA2 结构）。完整路线为：定义超参数 → 逐个实现 RMSNorm / GQA Attention / RoPE / SwiGLU MLP → 组装 DecoderLayer 与整体模型 → 训练 BPE Tokenizer → 数据准备 → 预训练 → SFT → 加载模型采样生成。走通这条线就能理解所有主流开源大模型的骨架。

    核心原理

    LLaMA2 是 Meta 于 2023 年发布的开源大模型（第一代 LLaMA 为 2023 年 2 月），其相对于原始 Transformer 的关键改造：

    • Pre-RMSNorm：用 RMSNorm 替代 LayerNorm，且放在子层之前（Pre-Norm）。
    • RoPE 旋转位置编码：在注意力中给 Q/K 乘旋转矩阵，注入相对位置信息。
    • GQA 分组查询注意力：KV 头数少于 Q 头数，KV 重复扩展后参与计算，显著省显存（LLaMA2 中仅 70B 用了 GQA，教学实现里也采用以提效率）。
    • SwiGLU 前馈网络：三分支 MLP，w2(silu(w1(x)) * w3(x))。
    • 词嵌入与输出层权重共享（weight tying）。

    实现要点

    1. 超参数配置（ModelConfig）

    继承 transformers.PretrainedConfig，方便后续导出 Hugging Face 格式。关键参数：

    参数 默认值 含义
    dim 768 模型隐藏维度
    n_layers 12 Transformer 层数
    n_heads / n_kv_heads 16 / 8 注意力头数 / KV 头数（GQA）
    vocab_size 6144 词表大小
    hidden_dim None（按公式算） MLP 隐藏层维度
    multiple_of 64 隐藏维对齐基数
    norm_eps 1e-5 归一化 epsilon
    max_seq_len 512 最大序列长度
    dropout / flash_attn 0.0 / True dropout 概率；是否用 Flash Attention

    2. RMSNorm

    公式：y = x / sqrt(mean(x²) + eps) * weight，weight 为全 1 初始化的可学习缩放参数。实现要点：先转 float32 计算归一化再转回原 dtype（数值稳定），torch.rsqrt 即平方根倒数。归一化不改变张量形状（测试输入 [1,50,288] 输出同形）。

    3. Attention（GQA + RoPE）

    三个辅助函数是理解的关键：

    • repeat_kv：把 KV 的头数从 n_kv_heads 扩到 n_heads——在头维度前插入新维、expand 复制 n_rep 倍、reshape 合并。n_rep=1 时直接返回。
    • precompute_freqs_cis(dim, end, theta=10000)：注意 dim 应传 dim // n_heads（每个头单独做旋转）。生成频率序列 1/(theta^(arange(0,dim,2)/dim))，与位置序列 t 做外积，返回 cos（实部）与 sin（虚部）两个矩阵。
    • apply_rotary_emb：把 Q/K 最后一维 reshape 成 (…, 2) 拆出实部/虚部，用 reshape_for_broadcast 把频率矩阵对齐广播形状（仅第 2 维和最后一维保留大小），做复数乘法式的旋转 r*cos - i*sin、r*sin + i*cos，最后 stack+flatten 还原形状。

    Attention 主模块流程：

    x → wq/wk/wv（均无 bias，wk/wv 输出维度按 n_kv_heads）→ reshape 成多头
  → apply_rotary_emb(Q,K) → repeat_kv 扩展 K/V → transpose 成 [bs, heads, seq, head_dim]
  → 注意力计算 → transpose 回来合并头 → wo 投影回残差流 → resid_dropout

    注意力计算二选一：PyTorch ≥ 2.0 用 F.scaled_dot_product_attention(..., is_causal=True)（Flash Attention）；否则手动 softmax(QK^T/sqrt(head_dim) + mask)，mask 为预注册的上三角 -inf 缓冲区。输出形状与输入一致（[1,50,768]）。

    4. MLP（SwiGLU）

    隐藏维默认取 multiple_of * ceil((8*dim/3) / multiple_of)（即 4*dim 的 2/3 再对齐，LLaMA 惯例）。三个无 bias 线性层，前向一行核心：

    return self.dropout(self.w2(F.silu(self.w1(x)) * self.w3(x)))

    5. DecoderLayer

    Pre-Norm 残差结构，仅两行核心：

    h = x + self.attention(self.attention_norm(x), freqs_cos, freqs_sin)
out = h + self.feed_forward(self.ffn_norm(h))

    6. 整体 Transformer

    • 词嵌入 → dropout → N 层 DecoderLayer → 最终 RMSNorm → 输出投影。
    • tok_embeddings.weight = output.weight 权重共享；freqs_cos/sin 预计算后 register_buffer(..., persistent=False)。
    • 权重初始化：Linear/Embedding 均用 normal(0, 0.02)；残差投影（wo、w3）额外按 0.02/sqrt(2*n_layers) 缩放，防深层残差累积方差。
    • forward：有 targets 时全位置算 cross_entropy（ignore_index=0）；推理时只对最后一位算输出层（h[:, [-1], :]），logits 形状 [bs, 1, vocab_size]。示例配置（dim=768, n_layers=12, vocab=6144）总参数约 82.6M。
    • generate 采样：循环 max_new_tokens 次——截断超长上下文 → 取最后一位 logits → temperature=0 走贪心 topk，否则 logits/temperature 后可选 top_k 过滤（置 -inf）再 softmax + 多项式采样 → 拼回序列，遇 stop_id 停止。此版本未用 KV cache（教学实现）。

    7. Tokenizer：三类分词与 BPE 训练

    类型 思路 优点 缺点
    Word-based 按空格/标点切词 简单直观 OOV、复合词（"New York"）、无空格语言（中文）难处理
    Character-based 每字符一个 token 无 OOV、极度灵活 序列超长、计算贵、丢失词级语义
    Subword 介于词与字符之间 兼顾词表大小与 OOV 需训练合并规则

    Subword 三大算法：BPE（自底向上贪心合并最高频字符对，如 lower→[low, er]）、WordPiece（BERT 使用，最大化子词序列似然，后缀用 ## 标记）、Unigram（概率模型，先给每个子词分配概率再求最优分割）。

    训练 BPE Tokenizer 的实操骨架（Hugging Face tokenizers 库）：

    1. 数据：datasets.load_dataset("wikitext") 或本地 txt/jsonl，用 batch_iterator 分批 yield 文本。
    2. 构建：Tokenizer(models.BPE(unk_token="<unk>")) + NFKC 规范化 + ByteLevel pre-tokenizer/decoder。
    3. BpeTrainer(vocab_size=6144, special_tokens=["<unk>","<s>","</s>","<|im_start|>","<|im_end|>"], min_frequency=2, initial_alphabet=ByteLevel.alphabet())，train_from_iterator 训练。
    4. 验证特殊 token id 映射（0~4 顺序固定）后保存 tokenizer.json。
    5. 手写 tokenizer_config.json + special_tokens_map.json：bos=<|im_start|>、eos=pad=<|im_end|>，chat_template 采用 Qwen2.5 风格（<|im_start|>role\ncontent<|im_end|>）。
    6. eval_tokenizer 检查词表、特殊 token、apply_chat_template 渲染、编码解码往返。

    数据与训练流程

    数据准备

    • 预训练：Mobvoi seq-monkey 通用文本数据集（网络/百科/新闻/代码等汇总，约 10B token），下载后按 512 字符切块写成 jsonl。
    • SFT：BelleGroup/train_3.5M_CN（350 万条中文多轮对话），convert_message 把 from: human/assistant 统一转成 role: user/assistant，并加固定 system prompt"你是一个AI助手"。

    Dataset 与 loss_mask（关键设计）

    PretrainDataset 与 SFTDataset 的 X/Y 拆分相同：X = input_id[:-1]（上下文），Y = input_id[1:]（预测目标）。区别在 loss_mask：

    • 预训练：真实 token 位置为 1，padding（id=0）位置为 0，不计算损失。
    • SFT：只在 assistant 回复上计算损失——扫描 input_ids，匹配 <|im_start|>assistant\n 的 token 子序列 [3, 1074, 537, 500, 203]，从其后一直标 1 到 <|im_end|>（id=4）为止。这样模型只学"怎么回答"，不学用户说的话。

    训练循环（预训练与 SFT 共用同一套）

    lr 调度：线性 warmup → cosine 衰减到 lr/10（get_lr 按全局 step 计算）
混合精度：autocast + GradScaler（bfloat16）
梯度累积：loss / accumulation_steps，攒够再 step（先 unscale_ 再 clip_grad_norm_(1.0) 再 step）
优化器：Adam；多卡用 torch.nn.DataParallel；SwanLab 记录 loss/lr；定期存 checkpoint

    实际配置：预训练模型 dim=1024, n_layers=18，约 215M 参数；SFT 从预训练 checkpoint 热启动，加载时需剥离 torch.compile 留下的 _orig_mod. 前缀。默认超参：batch_size=64、lr=2e-4、accumulation_steps=8（预训练）/4（SFT）。

    加载与生成

    TextGenerator 类封装推理：加载 checkpoint → 设 eval 模式 → TF32 + bfloat16 autocast → apply_chat_template 包 user prompt（add_generation_prompt=True）→ 编码 → model.generate → 解码。典型采样参数：temperature=0.7，top_k=300。

    实测效果：215M 的 SFT 模型能正确回答"中国的首都是哪里""1+1等于多少"这类简单问题；预训练模型则只会续写百科式文本（内容可能胡编），说明 SFT 才赋予对话能力。

    经验与常见坑

    • 显存换时间：batch 调小可省显存（batch=4 实测只需 7G 显存），但单卡预训练预计 533 小时；原作者 4×A100 预训练 26 小时、350 万条 SFT 约 4 小时。
    • Tokenizer 往返不一致：ByteLevel(add_prefix_space=False) 下，解码 <|im_start|>user 会变成 <|im_start|> user（多一个空格），编码解码往返测试为 False——这是 ByteLevel 空格处理的已知现象，需留意。
    • 特殊 token id 必须固定：训练前就 assert <unk>=0, <s>=1, </s>=2, <|im_start|>=3, <|im_end|>=4，否则 SFT loss_mask 的硬编码子序列会失效。
    • 多卡 checkpoint：DataParallel 下保存要用 model.module.state_dict()，加载前剥离 _orig_mod. 前缀。
    • ⚠️ 时效性：教程基于 2023-2024 年技术栈（LLaMA2 结构、DataParallel、wikitext、BelleGroup）；多卡训练如今业界更常用 DDP/FSDP 而非 DataParallel；新模型词表普遍 10 万级而非 6144。
