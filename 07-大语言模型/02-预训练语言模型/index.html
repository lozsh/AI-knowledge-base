    预训练语言模型

    来源：原资料（更新于 2026-11-03）

    一句话定义：预训练语言模型（PLM）是在海量无监督语料上先预训练、再微调到下游任务的模型，按架构分为 Encoder-Only（BERT 系）、Encoder-Decoder（T5 系）、Decoder-Only（GPT 系）三大流派——最后一支正是如今所有 LLM 的基座。

    Transformer 由 Encoder 与 Decoder 两部分组成，不同团队沿 ELMo 的预训练思路走向了不同路线：Google 只取 Encoder 堆叠、提出掩码语言模型（MLM），打造了统治自然语言理解（NLU）的 BERT；OpenAI 选择 Decoder、沿用经典语言模型（LM）任务、靠不断加大参数与语料，造就了在自然语言生成（NLG）上占优的 GPT 系列——也是当今 LLM 的基座；Google 的 T5 则同时保留 Encoder 与 Decoder。本章按此三分法梳理主流模型的结构、预训练任务与优势。

    Encoder-Only：BERT 及其变体

    BERT（Google, 2018）

    全名 Bidirectional Encoder Representations from Transformers，发布即拿下 GLUE、MultiNLI 等七项 NLP 评测 SOTA，正式确立预训练+微调范式的主导地位，衍生出 MacBERT、BART 等改进模型。直到 LLM 诞生，NLP 的主导地位才从 BERT 系迁移。

    思想沿承：

    • Transformer 架构：沿用《Attention is All You Need》的 Encoder 结构堆叠；
    • 预训练+微调范式：承自 ELMo（双向 LSTM 预训练+下游微调），但架构换成 Transformer，并引入更适合文本理解、能捕捉深层双向语义的 MLM。

    模型架构（Encoder-Only）：

    • 输入经 tokenizer 转为 input_ids → Embedding 层 → N 层 Encoder Layer → 顶层 prediction_heads（线性层+激活函数，输出维度等于任务类别数）→ Softmax 得到类别概率；
    • 两种规模：base（12 层，hidden 768，110M 参数）、large（24 层，hidden 1024，340M 参数）；
    • 每层 Encoder Layer = 自注意力 + 残差连接 + Intermediate 层（线性层+激活函数）。激活函数用 GELU（高斯误差线性单元，把随机正则思想引入激活函数，自 BERT 开始被普遍关注）；
    • 位置编码：用可训练的 Position Embedding（一层线性矩阵）拟合相对位置，比 Transformer 的 Sinusoidal 绝对位置编码能拟合更丰富的位置信息，但代价是参数增加，且完全无法处理超过训练长度的输入（BERT 最大上下文 512 token）。

    预训练任务：MLM + NSP：

    预训练数据的核心要求是极大规模（数亿 token 级），只能来自无监督语料。传统 LM（上文本预测下文）可应用于任意文本，但只拟合从左到右的单向语义（BiLSTM 往往优于 LSTM 正是因为双向拟合）。MLM 模拟"完形填空"解决这一点：

    • 随机遮蔽部分 token，用其余 token 预测被遮蔽的 token，迫使模型利用上下文双向理解语义；
    • 具体策略：随机选 15% 的 token，其中 80% 换成 <MASK>、10% 换成随机 token、10% 保持不变。10% 保持不变用于缓解预训练/微调不一致（下游没有 <MASK>）；10% 随机替换迫使模型对每个位置都保持上下文表征，防止只关注被遮蔽位置。

    NSP（Next Sentence Prediction，下一句预测）针对句级任务（问答匹配、自然语言推理）：判断句对 B 是否是 A 的连续上下文（输出 1/0）。正样本取连续句子、负样本打乱抽取，训练数据同样近乎无限。

    预训练配置：800M BooksCorpus + 2500M 英文维基，共 3.3B token（13GB）；90% 数据用 128 上下文、10% 用 512；batch size 256 训练 1M 步（40 个 Epoch）——对比之下 LLM 通常只训 1 个 Epoch 且用远大于 256 的 batch。Base/Large 分别用 16/64 块 TPU 训 4 天。

    下游微调：输入首部加入特殊 token <CLS>，其编码代表整句的句级语义表征（NSP 预训练时即用它做分类输入）。微调即用少量标注数据在特定任务上以更小的学习幅度更新参数：文本分类改 prediction_heads、序列标注集成多层隐含层向量、文本生成直接取 Encoder 输出解码。BERT 一经提出在 11 个 NLP 赛道全部 SOTA；即使在 LLM 时代，对标注数据丰富、强调高吞吐的特定任务，BERT 仍比 LLM 更具可用性。

    RoBERTa（Meta, 2019）

    架构与 BERT-large 完全一致，纯靠训练策略优化刷新 SOTA，三个优化：

    1. 去掉 NSP：四组对照实验（段落对 MLM+NSP / 文档对 MLM+NSP / 跨文档 MLM / 单文档 MLM）证明后两组显著更优，单文档 MLM 最佳。同时把 Mask 从数据处理阶段（静态，40 Epoch 里每 10 Epoch 数据相同）移到训练阶段做动态遮蔽——每个 Epoch 的 Mask 位置都不同，优势微弱但更高效，此后 MLM 基本都用动态遮蔽；
    2. 更大预训练数据与步长：在 BooksCorpus+维基之外加入 CC-NEWS、OPENWEBTEXT、STORIES，共 160GB（十倍于 BERT）；batch size 提到 8K（对比 BERT 的 256），证明等 token 量下大 batch 更优；共训 500K 步（约 66 Epoch），全程 512 长度训练。用 1024 块 V100 训练 1 天；
    3. 更大 BPE 词表：30K → 50K。BPE（字节对编码）以子词对为切分单位（英文如 "Hello World"→"Hel,lo,Wor,ld"；中文按字节编码切分，如 UTF-8 的"我"=E68891 切成 E68/891）。词表越大编码效果越好，但 Embedding 参数量为 (vocab_size, hidden_size)，也随之增大。

    RoBERTa 的成功证明了更大预训练数据、更长训练步长的意义，是 LLM 诞生的认知基础之一。

    ALBERT

    从"减小参数、保持能力"的角度优化 BERT，三个优化：

    1. Embedding 参数分解：Embedding 输出维度与隐藏层维度解绑（Embedding 输出设为 128，后面接线性矩阵升维到隐藏层）。参数从 V×H 降到 E×H + E×H 项，E 远小于 H 时优化显著（隐藏层加宽到 2048 时 Embedding 参数从 23M 膨胀到 61M 的问题得以避免）；
    2. 跨层参数共享：只初始化一个 Encoder 层，计算仍过 24 次，但参数只有一份。24 层、隐藏层 2048 的 xlarge 版仅 59M 参数（对比 BERT 的 334M），效果反超；
    3. SOP 预训练任务（Sentence Order Prediction）：NSP 太简单（负例来自任意文档，模型容易判），SOP 把负例改成同一对句子顺序对调，迫使模型学习句间顺序关系。实验结论：MLM+SOP > 仅 MLM > MLM+NSP。

    局限：参数量虽小，但推理/训练仍要过 24 层计算，速度并不比 BERT 快甚至更慢——这是 ALBERT 未能取代 BERT 的关键原因。

    其他 BERT 系变体：改进预训练任务的 ERNIE、蒸馏小模型 DistilBERT、多语言 XLM 等。

    Encoder-Decoder：T5

    T5（Google, 2019）

    Text-To-Text Transfer Transformer，把所有 NLP 任务统一为文本到文本的转换，基于完整 Transformer 的 Encoder-Decoder 结构：Encoder 处理输入文本，Decoder 生成输出，两者通过 Encoder-Decoder Attention 交互。模型由若干 Block 组成（多头注意力+前馈网络+Norm 层），可像乐高一样按任务复杂度调整层数。

    与原始 Transformer 的差异：LayerNorm 换成 RMSNorm（用均方根归一化，仅一个可调参数，比 LayerNorm 更简单、更易适应不同任务）。

    预训练任务：MLM（BERT-style 目标，随机遮蔽 15% token 供预测），数据集为自建的 C4（Colossal Clean Crawled Corpus，从 Common Crawl 清洗出 750GB，已在 TensorFlow Datasets 开源）；还尝试了多任务混合预训练以学习更通用的语言表示。

    大一统思想：每个任务加一个任务描述前缀，输入输出均为纯文本——

    • 分类：输入 classify: 这是一个很好的产品，输出 正面；
    • 翻译：输入 translate English to French: How are you?，输出 Comment ça va?。

    统一格式简化了模型设计与任务处理，实现参数共享和相同的数据/训练框架，显著提升多任务学习性能与泛化能力，对后续 NLP 技术影响深远。

    Decoder-Only：GPT、LLaMA、GLM

    Decoder-Only 是当前 LLM 的基础架构（RWKV、Mamba 等非 Transformer 架构除外）。引发热潮的 ChatGPT 是 GPT 系列的大成之作，开源基石 LLaMA 也在 GPT 架构上优化而来。

    GPT（OpenAI, 2018）

    Generative Pre-Training。虽然学界普遍以 BERT 为预训练时代的代表，但首先明确提出预训练+微调思想的其实是 GPT。发布之初性能略输 BERT、Decoder-Only 未成主流，OpenAI 坚持扩大数据与参数，最终 GPT-3 奠定 LLM 时代基础。

    模型架构（Decoder-Only）：

    • input_ids → Embedding + Positional Embedding（沿用 Transformer 经典 Sinusoidal 三角函数绝对位置编码，与 BERT 的可训练编码不同）→ N 层 Decoder；
    • Decoder 层内部更像 Encoder 层：没有 Encoder 编码输入，只保留一个带掩码的自注意力层（query/key/value 均由同一 hidden_states 经三个参数矩阵生成，掩码矩阵遮蔽未来 token，实现单向注意力）；并把 LayerNorm 从注意力层之后提到之前（Pre-Norm），缓解深层模型的梯度消失/爆炸；
    • GPT-1 用 12 层 Decoder；MLP 层用两个一维卷积核代替线性矩阵（效果等价）。

    预训练任务 CLM（Causal Language Model，因果语言模型）：可视为 N-gram 的直接扩展——基于序列前面所有 token 预测下一个 token，不断重复实现生成（经典补全形式）。CLM 天生契合人类书写习惯、与下游任务直接匹配，可无差别利用海量自然语言语料，比 MLM 更直接。

    GPT 系列演进：

    模型 Decoder 层数 Hidden size 注意力头数 注意力维度 参数量 预训练语料
    GPT-1 12 3072 12 768 0.12B 5GB
    GPT-2 48 6400 25 1600 1.5B 40GB
    GPT-3 96 49152 96 12288 175B 570GB
    • GPT-1：开山之作，体量与 BERT-base 相当但表现不如，故未成预训练时代代表；
    • GPT-2：结构大体相当，Post-Norm 改 Pre-Norm 稳定梯度；以 zero-shot（零样本，不微调、直接描述问题）为核心目标——思路先进但当时模型能力不足；
    • GPT-3：LLM 开创之作，175B 参数，因体量巨大采用稀疏注意力机制；预训练从 CC、WebText、维基等采样 45T 原始数据、清洗后 570GB；估算需 1024 张 A100（80GB）训练 1 个月。其真正的突破是 few-shot / 上下文学习（In-context Learning）：在 prompt 中给 3~5 个示例，模型表现远好于 zero-shot——若多数任务靠构造几个示例即可解决，效率远高于预训练-微调范式，这正是 LLM 的核心优势。

    在 GPT-3 基础上引入"预训练-指令微调-人类反馈强化学习"三阶段训练，即诞生 ChatGPT。

    LLaMA（Meta, 2023–2024）

    Decoder-Only，整体结构类似 GPT：tokenizer 编码 → Embedding + positional embedding → 多个 decoder block（masked self-attention → MLP 两层全连接：升维-激活-降维）→ 线性层映射到词表维度 → 采样/贪婪解码生成。

    版本 时间 参数版本 语料 关键点
    LLaMA-1 2023.02 7B/13B/30B/65B 1T+ token 65B 版在 2048 张 A100 80G 上训约 21 天；开源使其迅速成为社区最受欢迎模型
    LLaMA-2 2023.07 7B/13B/34B/70B（34B 未开源） 2T token 上下文 2048→4096；引入 GQA（分组查询注意力）
    LLaMA-3 2024.04 8B/70B（另 400B 训练中） 15T+ token（LLaMA-2 的 7 倍多） 支持 8K 长文本；tokenizer 编码效率更高、词表 128K

    GLM（智谱/清华）

    国内主流中文 LLM 之一（ChatGLM 1/2/3、GLM-4），曾在多种中文评估集达到 SOTA。其独特意义在于最早提出不同于 GPT/LLaMA 的原生架构。

    架构：整体 Decoder-Only，与 GPT 有三点差异：

    1. 用 Post Norm 而非 Pre Norm（残差之后归一化，正则化更强、鲁棒性更好；Pre Norm 则利于防梯度爆炸/消失，大体量模型一般用 Pre Norm——GLM 论文称 Post Norm 可避免 LLM 数值错误，但主流 LLM 仍用 Pre Norm）；
    2. 用单个线性层而非 MLP 做最终 token 预测，减少输出层参数、把参数量留给模型本体；
    3. 激活函数从 ReLU 换成 GeLUS（对接近 0 的正向传播做非线性映射，输出具有一定连续性）。

    GLM 预训练任务：自回归空白填充，结合自编码（MLM，随机删连续 token 段）与自回归（CLM，按顺序重建被删 tokens）两种思想——对外用上下文预测整个遮蔽段，段内部又以 CLM 方式逐 token 生成。同时适配理解与生成任务，早期模型展现超出同体量 BERT 系的性能。

    ⚠️ 但迈入 LLM 时代后，CLM 在超大规模预训练上展现远超 MLM 的优势（大模型 + 大语料的 CLM 生成模型在理解上也能超越 MLM 模型），故 ChatGLM2 起回归经典 CLM、架构也基本回归 LLaMA（引入 MQA）。GLM 任务在 LLM 路径上算是失败尝试，但其融合设计与中文开源先发的借鉴意义仍在。

    GLM 家族发展：

    • ChatGLM-6B（2023.03）：首个中文开源 LLM，1T 语料预训练，2K 上下文，众多中文 LLM 研究者的起点；
    • ChatGLM2-6B（2023.06）：上下文扩到 32K，性能大幅突破；架构回归 LLaMA 系、预训练回归 CLM；
    • ChatGLM3-6B（2023.10）：语义/数学/推理/代码/知识达当时 SOTA；架构相对二代无变化，提升来自更多样的数据、更充足步长与更优训练策略；开始支持函数调用与代码解释器，可直接做 Agent 开发；
    • GLM-4 系列（2024.01）：128K 上下文，官方评估英文基准达 GPT-4 水平；未直接开源，开源轻量版 GLM-4-9B（1T 多语言语料、8K 上下文、与 GLM-4 相同后训练管道），以更少计算量超越 Llama-3-8B。

    经验与常见坑

    • MLM 的预训练/微调不一致：下游没有 <MASK>，80/10/10 的遮蔽策略就是为了缓解这一点——理解 BERT 时不要把 MLM 想成"全遮"；
    • 参数量小 ≠ 训练快：ALBERT 跨层共享大幅省参数但计算量不减，速度反而更慢；
    • NSP 的教训：任务太简单反而拖累下游（RoBERTa 直接删、ALBERT 加难度成 SOP）；
    • CLM vs MLM 的路线裁决：LLM 时代 CLM 胜出——足够大的 CLM 生成模型连理解任务也能覆盖，ChatGLM2 起回归 CLM 即为例证；
    • 大 batch 的价值：RoBERTa 证明等 token 量下 8K batch 优于 256 batch，是训练调参的重要参考。

    ⚠️ 时效性说明

    • 本文数据截至 2024 年中（LLaMA-3、GLM-4-9B）；此后 MoE、超长上下文、多模态统一模型等方向演进迅速，最新模型对比见 大模型架构原理与演进。
    • "涌现能力决定一切"的表述在后续研究中有争议（部分现象可用平滑的度量曲线解释），但"规模扩大带来质变"的总体趋势仍成立。
