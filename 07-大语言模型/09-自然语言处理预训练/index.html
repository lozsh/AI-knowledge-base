    自然语言处理：预训练

    来源：原资料（《动手学深度学习》第 14 章"自然语言处理：预训练"，更新于 2026-11-03）

    一句话定义：NLP 预训练是利用大型语料库上的自监督学习（用文本的一部分预测另一部分，无需人工标注）为词元学习向量表示的技术谱系——从上下文无关的 word2vec/GloVe/fastText，到上下文敏感的 BERT。

    概述

    计算机要理解人类语言，第一步是学习文本的表示。自监督预训练的思路是：用周围文本预测隐藏部分（或反过来），海量文本天然成为训练数据，省去昂贵的标注。预训练好的文本表示可放入各种深度学习架构，服务于不同的下游 NLP 任务。

    预训练表示分两代：第一代（word2vec、GloVe、fastText）是上下文无关的——同一个词无论出现哪里，向量都相同，无法处理多义词（"bank"在"去银行存钱"和"去河岸坐下"中向量一样）；第二代（BERT 等）是上下文敏感的——同一词元根据上下文获得不同表示。

    词嵌入（word2vec）

    词向量是表示单词意义的实向量（也可看作词的特征向量）；将词映射到实向量的技术称为词嵌入。

    为什么独热向量不行

    词典大小为 N 时，独热向量把词 i 表示成长度 N、仅第 i 位为 1 的向量。致命缺陷：任意两个不同词的独热向量余弦相似度恒为 0（cos = xᵀy/(‖x‖‖y‖) ∈ [−1, 1]），完全无法表达词间相似度。

    两个模型：跳元与连续词袋

    word2vec（Mikolov et al., 2013）含两个自监督模型，均依赖条件概率，每词有两个 d 维向量：中心词向量 v_i 和上下文词向量 u_i。

    跳元模型（Skip-Gram）：假设中心词生成周围词。以"the man loves his son"为例，中心词"loves"、窗口 2，在条件独立假设下：

    $$P(w_o \mid w_c) = \frac{\exp(\mathbf{u}o^\top \mathbf{v}_c)}{\sum{i \in V} \exp(\mathbf{u}_i^\top \mathbf{v}_c)}$$

    对长度 T 的序列、窗口 m，最大化似然即最小化损失 −Σ_t Σ_{−m≤j≤m, j≠0} log P(w^{(t+j)} | w^{(t)})。应用中跳元模型的中心词向量用作词表示。

    连续词袋（CBOW）：方向相反，用上下文词预测中心词，多个上下文词向量先取平均再算 softmax：

    $$P(w_c \mid w_{o_1},\dots,w_{o_{2m}}) = \frac{\exp(\mathbf{u}c^\top \bar{\mathbf{v}}_o)}{\sum{i \in V} \exp(\mathbf{u}i^\top \bar{\mathbf{v}}_o)},\quad \bar{\mathbf{v}}_o = \frac{1}{2m}\sum{j=1}^{2m}\mathbf{v}_{o_j}$$

    CBOW 通常用上下文词向量作为词表示。

    近似训练

    softmax 的分母要对整个词表（几十万到数百万词）求和，梯度计算代价巨大。两种近似方法：

    负采样（Negative Sampling）：改写目标函数为二分类——真实上下文词为正例（σ(u_oᵀv_c)），再从预定义分布 P(w) 采 K 个噪声词为负例。对数损失变为：

    $$-\log \sigma(\mathbf{u}{i_t+j}^\top \mathbf{v}{i_t}) - \sum_{k=1}^{K} \log \sigma(-\mathbf{u}{h_k}^\top \mathbf{v}{i_t})$$

    每步梯度成本与词表大小无关，线性依赖 K。噪声词采样概率实践上取词频的 0.75 次幂（word2vec 论文建议）。

    层序 Softmax（Hierarchical Softmax）：把词表放进二叉树，每个叶节点一个词；条件概率分解为从根到叶路径上每步"向左/向右"的 sigmoid 判定之积。路径长度 L(w)−1 约为 O(log₂|V|)，训练成本降为词表大小的对数。

    预训练数据集与工程流程（以 PTB + 跳元 + 负采样为例）

    1. 读取与建词表：Penn Tree Bank（PTB，华尔街日报文章，42069 句），出现次数 < 10 的词替换为 <unk>，词表 6719。
    2. 下采样（Subsampling）：高频词（the/a/in）共现信息少、拖慢训练，按概率丢弃：

    $$P(w_i) = \max\left(1 - \sqrt{\frac{t}{f(w_i)}},\ 0\right)$$

    其中 f(w_i) 是词的相对频率，t ≈ 10⁻⁴。效果："the" 从 50770 次降到 2056 次（不到 1/20），低频词 "join"（45 次）完全保留。 3. 提取中心词-上下文词对：每个位置随机采样 1 到 max_window_size（PTB 上取 5）之间的窗口，收集约 150 万对。 4. 负采样：每对上下文词配 K=5 个噪声词（词频^0.75 加权采样，排除真实上下文词）。 5. 小批量组装（batchify）：因各样本上下文+噪声词数不同，需填充 0 并配两个对齐变量——mask（1=真实、0=填充）和 label（1=上下文正例、0=噪声负例）。 6. 训练：两个 nn.Embedding（中心词/上下文词各一，embed_size=100）+ 批量矩阵乘法算点积 + 带掩码的二元交叉熵损失（SigmoidBCELoss），Adam 优化。 7. 应用：用词向量余弦相似度找最近词，如 "chip" → microprocessor(0.773)、hitachi、computers。

    GloVe：全局向量的词嵌入

    GloVe（Pennington et al., 2014）用全局共现统计重新解释跳元模型：x_ij 为词 w_j 与中心词 w_i 在整个语料库的共现计数。因交叉熵损失对大语料中的罕见事件权重过高且需全词表归一化，GloVe 改用加权平方损失拟合共现计数的对数：

    $$\sum_{i \in V}\sum_{j \in V} h(x_{ij})\left(\mathbf{u}j^\top \mathbf{v}_i + b_i + c_j - \log x{ij}\right)^2$$

    权重函数 h(x)：x < c（c=100）时取 (x/c)^α（α=0.75），否则取 1；h(0)=0 使零共现项可直接省略。

    理解角度——共现概率比值：以 ice/steam 为例，P(solid|ice)/P(solid|steam)=8.9（与 ice 相关的词比值大）、gas 为 0.085（与 steam 相关）、water 为 1.36、fashion 为 0.96（无关词接近 1）。比值能直观表达词间关系，GloVe 用 exp(uⱼᵀv_i) 拟合这个比值。

    对称性：共现计数 x_ij = x_ji，GloVe 中中心词向量与上下文词向量数学上等价，实际因初始化不同而异，输出时取两者之和。

    子词嵌入

    word2vec 和 GloVe 不看词的内部结构，而 "helps/helped/helping"、"dog/dogs" 明明共享词形信息（形态学）。

    fastText（Bojanowski et al., 2017）：子词级跳元模型。子词 = 字符 n-gram（词首尾加 < > 区分前后缀，如 n=3 时 "where" → <wh whe her ere re> 及特殊子词 <where>），词向量 = 其所有子词向量之和。词表更大、计算更贵，但稀有词甚至词表外词也能得到较好表示。

    字节对编码（BPE，Sennrich et al., 2015）：从单字符符号出发，迭代合并最频繁的连续符号对（贪心，不跨词边界），得到固定词表内可变长度的子词。示例：对 fast_/faster_/tall_/taller_ 迭代 10 次合并出 ta→tal→tall、fa→fas→fast、er→er_，"faster_" 分割为 "fast er_"。BPE 及其变种用于 GPT-2、RoBERTa 等模型的输入表示；BERT 原始实现用的 WordPiece 是 BPE 的稍加修改版。

    词相似性与类比任务

    在大型语料库预训练的 GloVe（如 40 万词表的 50 维 glove.6b.50d）上：

    • 词相似度：按余弦相似度做 k 近邻。"chip" → chips(0.856)、intel(0.749)、electronics(0.749)；"beautiful" → lovely(0.921)、gorgeous、wonderful。
    • 词类比：对 a : b :: c : d，找与 vec(b) − vec(a) + vec(c) 最相似的词 d。预训练词向量能捕捉语义（man:woman::son:daughter → daughter；beijing:china::tokyo → japan）和句法（bad:worst::big → biggest；do:did::go → went）。

    从上下文无关到上下文敏感的演进（都在 2018 年）

    模型 编码方向 任务适配 局限
    ELMo 双向（拼接预训练双向 LSTM 各中间层） 每个任务需特定架构，表示作为附加特征 架构不通用
    GPT 仅从左到右（Transformer 解码器） 任务无关，微调全部参数 + 线性输出层 看不到右侧上下文
    BERT 双向（Transformer 编码器） 任务无关，微调全部参数 + 最小架构改动 —

    BERT（Devlin et al., 2018）结合两者优点：双向编码 + 架构改动最小，改进了 11 项 NLP 任务 SOTA，分四类：单一文本分类（情感分析）、文本对分类（自然语言推断）、问答、文本标记（命名实体识别）。GPT 是自回归的，对 "bank"（银行/河岸）这类多义词，左右上下文不同也无法区分；BERT 实验证实同一词元（如 crane，鹤/吊车）在两个上下文中表示向量确实不同。

    输入表示

    BERT 输入序列 = 词元嵌入 + 片段嵌入 + 位置嵌入（三者相加）。

    • 单文本：<cls> + 文本词元 + <sep>；文本对：<cls> + 句A + <sep> + 句B + <sep>。
    • 片段嵌入 e_A/e_B 区分句 A（索引 0）与句 B（索引 1）。
    • 与原始 Transformer 不同，BERT 用可学习的位置嵌入。
    • <cls> 的最终表示聚合整句（对）信息，用于分类。

    两个预训练任务（标签全部来自语料库，无需人工标注）

    掩蔽语言模型（MLM）：随机选 15% 的词元作为预测目标。为避免预训练（见 <mask>）与微调（见真实词）的不匹配，被选中的位置按 80% 替换为 <mask>、10% 替换为随机词元、10% 保持不变。随机噪声让模型不过分偏向掩蔽位置。预测头是单隐藏层 MLP，只对被掩蔽位置计算交叉熵损失。

    下一句预测（NSP）：MLM 无法显式建模文本对之间的逻辑关系。生成句子对时，一半为真实连续句（标签"真"），一半第二句从语料库随机抽（标签"假"）；用 <cls> 的编码经 MLP 做二分类。

    最终预训练损失 = MLM 损失 + NSP 损失。原始 BERT 在 Books Corpus（8 亿词）+ 英文维基百科（25 亿词）上预训练。

    模型规格与实现要点

    • BERT_BASE：12 层 Transformer 编码器块、768 隐藏单元、12 个注意力头，1.1 亿参数。
    • BERT_LARGE：24 层、1024 隐藏单元、16 头，3.4 亿参数。
    • 教学实现常用 2 层 / 128 隐藏 / 2 头的小模型，在 WikiText-2 上演示（WikiText-2 保留标点、大小写和数字，适合 NSP，比 PTB 大两倍多）。
    • 预训练数据生成：为 NSP 按 50/50 采样句子对（超长丢弃），为 MLM 抽 15% 位置做 80/10/10 替换，最后统一填充到 max_len 并用 mlm_weights 过滤填充位损失。
    • 激活函数：原始 BERT 用 GELU（高斯误差线性单元）而非 ReLU。

    术语表

    术语 含义
    词嵌入 / 词向量 将词映射为实向量，表达语义相似度与类比关系
    跳元模型（Skip-Gram） 中心词 → 预测周围上下文词
    CBOW 上下文词（取平均）→ 预测中心词
    负采样 用真实对（正例）+ 噪声词（负例）的二分类替代全词表 softmax
    层序 Softmax 用二叉树路径把 softmax 成本降为 O(log₂|V|)
    下采样 按 √(t/f(w)) 概率丢弃高频词以加速训练
    GloVe 用加权平方损失拟合全局词-词共现计数对数
    fastText 词向量 = 字符 n-gram 子词向量之和，惠及稀有词/词表外词
    BPE 迭代合并最频繁相邻符号对，得到可变长子词词表
    MLM BERT 预训练任务：双向上下文预测被掩蔽的 15% 词元
    NSP BERT 预训练任务：判断第二句是否为第一句的真实下一句
    上下文无关/敏感 同词是否因上下文而获得不同向量表示

    经验与常见坑

    • 独热向量相似度恒为 0——任何语义相似度计算都必须用稠密词向量。
    • 负采样的 K 是速度与质量的权衡旋钮；噪声词分布取词频^0.75 而非原始词频。
    • 下采样会把高频词大量丢弃（"the" 只剩 1/20），这是特性不是 bug。
    • MLM 的 80/10/10 替换比例是为了预训练-微调一致性，全部用 <mask> 反而伤下游表现。
    • 词类比公式 vec(b)−vec(a)+vec(c) 是"减去 a 加上 b 的关系再从 c 出发"，方向写反会得到错答案。
    • 训练大语料时，同一中心词在不同迭代可用不同上下文词/噪声词，等效数据增强。

    ⚠️ 时效性说明

    • 本章技术（word2vec/GloVe/fastText/BERT）属 NLP 预训练的经典地基（2013–2018）；现代 LLM（GPT 系列、Llama 等）已转向 Transformer 解码器 + 下一词元预测 + 超大规模预训练，上下文敏感表示的思想被继承但模型规模、分词（BPE 变种）和训练目标有重大演进。
    • BERT 的 NSP 任务在后续工作（RoBERTa 等）中被证明可省略；实践选型请参考更新条目。
