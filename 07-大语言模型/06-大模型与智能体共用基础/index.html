    大模型与智能体共用基础

    来源：原资料（更新于 2026-11-03）

    一句话定义：大模型是"能理解与生成"的参数化神经网络底座，智能体是"能行动"的系统层；两者共同构成了 2022 年（ChatGPT 发布）以来人机交互从"人学机器语言"转向"机器理解人类意图"的技术基础。

    大模型与智能体不是两个割裂的世界：大模型通过预训练获得广泛的语言理解与生成能力，再通过后训练变得更像助手，接着通过检索、工具调用、浏览器、终端接上外部世界，于是"会回答问题的模型"逐渐变成"能够持续完成任务的系统"。这个演化链条中，系统工程、评测、风险和治理从边缘问题变成了主问题。

    本条目覆盖三块共用基础：大模型与智能体的时代背景与基本概念（含 AI/ML/DL 术语谱系）、神经网络与训练优化的地基、Transformer 统一底座及其架构演化。

    核心原理

    从聊天机器人到通用接口

    ChatGPT 于 2022-11-30 上线，5 天注册破百万、约两个月月活过亿。它成为现象级事件的关键不是某项单点能力，而是把对话、写作、编程、翻译、推理等分散在不同软件里的能力放进同一个对话框。其本质变化是接口变化：自然语言接口让"人学习机器的语言"反转为"机器尽量理解人的意图"，大模型成为连接人类意图与数字世界能力的中间层，软件复杂度从人的一侧部分转移到系统一侧。

    大模型 vs 智能体的边界（一句话）：大模型回答问题，智能体完成任务。大模型能表达、能生成，但"未必能行动、未必能负责一个持续过程"——它能告诉你订机票要注意什么，却不会自己打开浏览器查票。智能体是系统层概念：在环境中接收任务、获取信息、决策、执行动作并根据反馈调整，除大模型"大脑"外还需工具、检索、记忆、任务状态、执行器、监控器、人类检查点与权限控制。不是所有带工具调用的应用都算智能体——固定规则包装在对话界面里只是工作流；真正的智能体需具备环境感知、任务分解和动态决策能力。现实系统多处在两者之间的连续谱上。

    术语谱系：AI ⊃ ML ⊃ DL ⊃ 大模型

    层级 含义 关键脉络
    AI（人工智能） 让机器表现智能行为的整个研究领域 1956 达特茅斯会议；早期以符号主义/专家系统为主，规则编不全、例外比规则多
    ML（机器学习） 从数据中归纳规律而非手写规则 1980 年代起取代符号主义；分监督/无监督/强化学习三类
    DL（深度学习） 用多层神经网络自动提取层次化表示 2012 AlexNet 引爆；从"手工特征+浅层模型"转向端到端表示学习
    大模型 DL 在规模、数据、工程上走到极致的产物 "少量底座 + 大量下游适配"的能力组织方式，是时代代号而非参数口径

    今天大模型把三种学习范式都用上了：预训练用自监督（无监督式），后训练用监督微调 + 基于人类反馈的强化学习。注意并非所有 AI 都是深度学习——工业界跑得最稳的推荐、风控系统仍以线性模型、决策树、梯度提升为主（便宜、可解释、好调试）。

    为什么是语言：智能在文字里的压缩

    语言不只是交流工具，更是人类智能对世界的一次次压缩：几千年写作（书、百科、手册、论文、对话）构成一台庞大的"世界压缩机"输出，通过文字间接编码了物理、社会、心理、技术的海量知识。"猜下一个词"要在这种压缩语料上做好，模型不得不反向学会常识、因果、人物动机、文体规范乃至世界结构——表面是学文字分布，深层是学"什么样的世界更可能生成这样的文字"。图像数据没经过认知过滤、机器人数据稀缺昂贵，只有文字是人类积累最丰、最致密的智能矿藏，所以通用智能率先在语言上突破。但模型学到的世界知识是间接的、纸面化的，这是幻觉、多模态与具身智能要补的另一半世界。

    大模型的朴素目标：猜下一个词

    训练目标可写为 p(w_t | w_1,…,w_{t-1})。思路源自香农 1951 年前后的"猜字母实验"。关键是自监督学习（SSL）：互联网每段文本的前 t−1 个词是输入、第 t 个词是答案，数据自己充当老师。许多下一个词并非靠语法猜出，而要知道句子背后的世界（指代消解、物理常识、算术、地理事实），于是模型被迫把大量规律压进参数。

    为什么这一轮 AI 不同

    四件事构成主线：① 统一底座——同一套 Transformer 架构 + 预训练范式覆盖语言、代码、图像、语音、多模态，能力迁移与工程复用变容易；② 预训练范式成熟——海量未标注数据先学"世界通常怎样组织"，再做行为塑形；③ 规模带来的非线性收益——参数、数据、算力、工程体系同步扩大，出现涌现能力（Emergence）；④ 接上工具与环境——模型从纯文本沙盒进入可执行、会出错、有后果的真实世界，智能体在此诞生。

    涌现的争议：同一任务上模型规模跨过某区间后表现从接近零突然跳变（类比水到 100℃沸腾，仅是直观类比而非已证实的物理相变）。有研究（Schaeffer 等《Are Emergent Abilities… a Mirage?》）指出跳变可能是离散指标（全对才算对）造成的假象，连续部分得分下提升更平滑。无论哪种解释，结论都是：需要更细致的评估而非只看榜单，且要对危险能力（欺骗/说服、网络安全、自我扩散）提前评估。

    早期信号：AlphaGo（2016，4:1 胜李世石，第 2 局第 37 手"肩冲"）与 AlphaZero（2017，不看人类棋谱纯自我对弈）不属于大语言模型的技术线（一边是规则可验证的棋局信号，一边是互联网级文本预测），但预演了共同主题：足够大的神经网络 + 足够多的反馈循环 + 足够清晰的目标，可以让机器走出训练数据之外。RLHF、推理模型、可验证奖励是这条主题在语言世界的延续。

    代表性模型家族

    • 闭源前沿模型：GPT、Claude、Gemini 系列——综合能力最强、产品成熟、对齐投入大，权重不公开。
    • 开源/开放权重模型：Llama、Mistral、Qwen、DeepSeek 等。注意"开源模型"多数更准确叫法是"开放权重模型"（训练数据与完整训练代码通常不公开）。意义在于把创新权从少数巨头分散出去。
    • 小而精模型：在手机、汽车、企业内网低成本运行；未来生态很可能是前沿大模型、开放权重、端侧小模型各司其职。

    能力、成本与产业结构

    • 训练成本：GPT-3 级约数百万美元，GPT-4/Gemini Ultra 被外界估算为数千万到上亿美元（不含人员、试验、失败重训摊销）。DeepSeek-V3 报告的约 278.8 万 H800 GPU 小时、约 557.6 万美元只是正式训练 run 的算力口径。算力门槛 + NVIDIA 的"芯片 + 互联 + 软件"（CUDA/cuDNN/NCCL/TensorRT）生态锁定，决定了能训前沿模型的公司极少。Stargate（星际之门）计划宣布四年最高 5000 亿美元投入 AI 基础设施，标志前沿竞争打包了算力、电力、土地、数据中心。
    • 推断成本：训练像造飞机、推断像每次飞行的燃油。降本手段：量化、蒸馏、缓存、投机解码、MoE 稀疏激活、专用硬件。
    • 商业模式五条路：API 订阅（按词元计费）、消费级订阅、企业定制、开源带头周边变现（模型免费、跑模型的机器不免费）、广告与免费增值（⚠️ 2025–2026 年 Google 与 OpenAI 先后在搜索新形态与 ChatGPT 免费层测试广告，如何不劫持回答是难点）。
    • 职业暴露度（Eloundou et al. 2023《GPTs are GPTs》）：约 80% 美国劳动力所在职业至少 10% 任务受 LLM 影响，约 19% 至少一半任务受影响。分界线：越是读写、转换符号的工作越先被改变（翻译、写作、报税、会计、数学家）；依赖身体、现场、即时操作的工作短期难被改变（厨师、石匠、洗碗工）。高暴露 ≠ 失业预告：职业是一捆任务，大模型首先改写工作流，人的位置转向"提出目标、拆清边界、调度工具、评审结果"。
    • 产业视角：像一次"软件接口层级上移"——在操作系统、数据库、云之上长出以模型和智能体为核心的任务解释层，可能是新一层平台。

    关键概念：神经网络与训练优化的地基

    深度学习三十年（算法/算力/数据三曲线的交汇）

    反向传播 1986 年发表，真正引爆在 2012 年，中间是漫长低谷（SVM 等统计学习主流化）。坚持者：Hinton（多伦多，CIFAR 资助）、LeCun（LeNet-5，1998，手写数字识别）、Bengio（2003 神经语言模型，Word2Vec/GPT 路线源头）。2006 年 Hinton 的 DBN 用逐层无监督预训练重启"深度学习"旗帜；2009–2011 语音识别突破 + Xavier 初始化 + ReLU 到位；2012 年 AlexNet（两块 GTX 580 训练）把 ImageNet Top-5 错误率从约 26.2% 降到 15.3%。2018 年三人同获图灵奖；2024 年 Hinton 又获诺贝尔物理学奖。每个组件单独看都已存在多年，爆发是三条曲线同时跨过门槛的结果。

    神经元、激活函数与前馈网络

    • 人工神经元：y = f(w·x + b)。单层感知器连 XOR 都解不了（线性不可分）——神经网络的力量在于许多简单单元被组织成层、用非线性连接、由数据训练。
    • 激活函数必须非线性：否则多层塌缩为单层线性变换。演化谱系：Sigmoid（梯度消失）→ ReLU max(0,x)（不饱和、稀疏，但有"死亡 ReLU"）→ GELU/SiLU（平滑）→ SwiGLU（门控，Llama/Qwen/DeepSeek 普遍使用）。经验：不知道用什么就用 ReLU，调优试 GELU/SwiGLU。
    • 前馈网络（FNN/MLP）：h = f(Wx+b) 逐层递推。Transformer 的大部分参数在 FFN 子层而非注意力——最先进的大模型是"若干注意力路由 + 大量小前馈网络"。
    • 深度的意义：层次化抽象（浅层边缘 → 中层部件 → 深层对象；语言上浅层词法 → 中层句法 → 深层语义）。浅层学边缘的现象与 Hubel & Wiesel 1959 年猫视觉皮层实验（Gabor 感受野，1981 诺奖）遥相呼应。
    • 通用近似定理：单隐藏层足够宽的前馈网络可逼近任意连续函数。但三个限制：可能需要天文数字神经元；只保证好参数存在、不保证训得出来；只覆盖连续函数。实践中深通常比宽更划算。

    CNN 与 RNN：两种归纳偏置

    • CNN（图像）：局部连接 + 参数共享（卷积核），带来平移等变性；池化引入近似平移不变性；感受野随层数扩大。谱系：AlexNet(2012, GPU+ReLU+Dropout) → VGG(2014, 全 3×3 小卷积核，加深优于加宽) → ResNet(2015, 何恺明，残差连接，训到 152 层) → EfficientNet(2019, 复合缩放) → ViT(2020, 图像切块当词元，纯卷积时代结束)。
    • RNN（序列）：隐状态 h_t = f(W_x·x_t + W_h·h_{t−1}) 提供记忆，时间上共享权重。顽疾是梯度消失/爆炸（每步乘矩阵，特征值 <1 指数衰减、>1 指数放大），LSTM（1997，细胞状态 + 遗忘门/输入门/输出门）与 GRU（两门简化版）缓解；GNMT（2016）是 LSTM 路线工业巅峰，一年后被 Transformer 打穿。Seq2Seq 的固定上下文向量瓶颈催生了 2014 年注意力机制——最初只是 RNN 的辅助。

    训练深层网络为什么难：三难与解药

    三类困难对应三套工具箱：

    困难 症状 解药
    走不动（优化难） 高维非凸、鞍点比局部最优更常见（局部最优要求所有方向向上，概率低） 优化器、动量、小批量噪声
    信号失真（传播难） 梯度消失/爆炸（每层平均乘 0.8，30 层后剩 0.001） 合理初始化、规范化、残差连接、梯度裁剪
    学得太死（泛化难） 过拟合：训练损失为零常是过拟合预兆 正则化全家桶
    • 优化器：小批量 SGD（批量 32–1024，太大泛化可能变差）→ 动量 v_t = βv_{t−1} + ∇L（β≈0.9，压震荡、累方向）→ AdaGrad（累积梯度平方缩放，会后期停滞）→ RMSProp（改指数加权平均）→ Adam（一阶矩 + 二阶矩自适应，θ ← θ − η·m/(√v+ε)）→ AdamW（权重衰减与梯度更新解耦，大模型默认）。视觉大规模训练中带动量 SGD 泛化有时更强——优化器只有与任务/架构/数据规模的匹配，没有绝对优劣。
    • 学习率：最重要的超参数。训练不动或剧烈震荡都先怀疑它。标准配方：预热（warmup，前几百到几千步从小值升到目标）+ 余弦退火（衰减到峰值约 10%）。跨数量级超参按对数尺度试（10⁻⁴, 3×10⁻⁴, 10⁻³…）。大模型时代用 µP（Maximal Update Parametrization）等超参迁移：小模型调好、大模型直接套。
    • 初始化：全零初始化让同层神经元永远一样；Xavier（2010，适配 Sigmoid）与 He（2015，适配 ReLU）都追求每层输出方差稳定。
    • 规范化：BN（2015，沿批量方向统计，CNN 主流，附带正则效果）；LN（单样本内沿隐藏维度统计，不依赖批量，序列模型自然选择）；RMSNorm（LN 的轻量变体，只按整体尺度缩放，大模型主流）。本质同一：防止中间表示数值尺度失控。
    • 残差连接：h^{(l+1)} = h^{(l)} + f(h^{(l)})，每层学"修正"而非"输出"。梯度沿残差流（Residual Stream）直通回传——训练百层网络的关键；可解释性研究把残差流视为模型的"共享内存"，各层读写增量。与初始化、规范化并称"训得起来"的三大支柱。
    • 正则化：统一视角是把尖锐最优打磨成平坦最优（平坦极小值泛化更好）。手段：权重衰减（ℓ2）、暂退法 Dropout（Hinton 从银行柜员轮岗得到灵感，隐式集成子网络，Transformer 中常见 0.1）、数据增强（注入"哪些变化不该改变标签"的先验）、提前停止（验证误差回升即停）、标签平滑（1 → 0.9）。隐式正则化：梯度下降天然偏好平坦解，这解释了过参数化模型为何没有崩盘——优化与正则紧密缠绕。
    • 损失函数：回归用 MSE/MAE/Huber；分类用交叉熵（= 最大似然，严厉惩罚"自信且错"）；类别极不平衡用 Focal Loss（2017 RetinaNet，"换损失就换结果"的干净案例）；度量学习用对比损失/三元组损失/InfoNCE（CLIP、SimCLR 的基础）。实战铁律：先跑通简单基线、一次只改一件事、会读训练/验证曲线（都不降=模型弱或实现错；训练降验证不降=过拟合；NaN=梯度爆炸或数据异常）、排错顺序永远是数据 → 损失实现 → 学习率 → 初始化/规范化 → 最后才怀疑架构。

    Transformer：统一底座与架构演化

    注意力机制

    解决 RNN 两大痛点：长距离依赖弱（信息逐步传递衰减）与无法并行（必须算完第 t 步才能算第 t+1 步）。直觉是"柔性字典查询"：query 与每个 key 算相似度，按权重聚合 value。核心公式（缩放点积注意力）：

    Attention(Q, K, V) = softmax(QK^T / √d)·V

    QK^T 生成一张 N×N 的"谁该看谁"关系表——力量与麻烦都来自这张表（上下文越长膨胀越快）。√d 缩放防止大维度下点积过大导致 Softmax 梯度消失。自注意力（Q、K、V 来自同一序列）让任意两位置一步直连、且序列维度可完全并行——没有它就没有今天的大语言模型。多头注意力（MHSA）让多个头从语法/语义/指代等不同视角看序列（原始论文 8 头，当代模型 12–32+ 头）。注意：注意力是信息路由机制，注意力权重高 ≠ 因果重要、≠ "理解"。

    位置编码

    自注意力对词序不敏感（打乱输出不变），必须显式注入位置。演化：正弦/余弦编码（原始 Transformer，值有界可外推）→ 可学习位置向量（BERT，不能外推）→ 相对位置编码（T5、Transformer-XL）→ RoPE 旋转位置编码（把位置编码为 q/k 的旋转，点积自然带相对位置；Llama/Qwen/DeepSeek 采用）。长上下文外拍方案：ALiBi（线性距离惩罚，天然外推但表达粗糙）、Position Interpolation、NTK-aware scaling、YaRN（NTK + 斜率退火 + 注意力温度调节，当前最常用）。残余问题：中间丢失（Lost in the Middle）、位置偏差——"窗口数字变大"远不等于"读得懂长文"，需大海捞针（Needle in a Haystack）类评测。

    Transformer block 与三种范式

    四个部件：多头自注意力、FFN（宽约 4 倍，大部分参数所在，也是 MoE 动刀的地方）、残差连接、LayerNorm。LayerNorm 位置从后规范化（Post-LN，深层不稳）演进为前规范化（Pre-LN，现代主流）。三种组合范式：

    范式 代表 训练目标 擅长
    仅编码器 BERT (2018) 掩码填空（15% 词元） 理解类：分类、问答、NER；今仍是搜索召回/嵌入的骨干
    仅解码器 GPT 系列 因果下一词预测（因果掩码） 生成类；因任务最通用而成为当代大模型主流
    编码器-解码器 T5、BART 输入转输出（交叉注意力） 翻译、摘要；今用于蛋白质设计等特定领域

    Transformer 成为底座的五个原因：并行训练效率（契合 GPU 大矩阵乘法与 Tensor Core）、长距离依赖一步到位、规模化友好（Scaling Law 可预测增益）、跨模态通用性（凡能表示成向量序列的数据皆可处理）、与 CUDA 生态正反馈。Bitter Lesson 的体现：它放弃了 CNN 的空间先验和 RNN 的时序先验，"一无所长"反而让它在数据算力足够时最容易跨任务迁移。

    可解释性：Transformer 是怎么"理解"的

    三条路线：注意力可视化（直观但高权重 ≠ 因果）、探针实验（验证了浅层表层特征/中层句法/深层语义的层次化学习）、回路分析（机理可解释性，Anthropic/OpenAI/DeepMind 均有专门团队）。OpenMOSS 团队的实践：稀疏自编码器（SAE）把稠密表示分解成少数活跃单义特征（解决神经元"多义"与特征叠加问题），Llama Scope 是开放的百万级特征字典，Lorsa 用低秩稀疏分解把注意力头再拆成可解释子单元，更进一步做完整替换模型与训练动态观察。知识存储：FFN 层像"键-值记忆体"承载事实知识，但知识整体是分布式关系网——知识编辑能局部成功却难"改一处不影响其他"。上下文学习（ICL）的流行假设：预训练让模型隐式学会"遇到少量例子如何推广"的元能力（有实验显示其计算模式与隐式梯度下降相似，尚非定论）。

    架构演化：当规模成为瓶颈

    架构创新越来越像系统创新——每一项都要同时过"能力有没有上升、训练/推断成本是否可控、工程复杂度是否值得"这道账。

    • 稀疏激活与 MoE：把 FFN 拆成多个专家，路由器按 token 分派（Gate(x) = TopK(softmax(W_g·x), k)），总参数大而每 token 激活稀疏。难点在路由与负载均衡：辅助损失（Switch Transformer 式 L_aux = α·N·Σf_i·p_i，α≈0.01）、Expert Capacity 限制、无辅助损失的动态加分（DeepSeek-V3）。演化方向：细粒度专家（拆小、增多，如 256 选 8）+ 共享专家（公共路径承载通用能力，DeepSeek-V2/V3）。工程现实：专家并行需 all-to-all 通信（一去一回两次），通信常占大头；推断时所有专家参数都要常驻显存（如"37B 激活/671B 总参数"仍吃 700GB 量级）。
    • 高效注意力（KV 缓存侧）：MQA（所有头共享一套 KV，省到极致略伤表达）→ GQA（分组共享，Llama 2/3、Mistral、Qwen 主流）→ MLA（DeepSeek，KV 低秩压缩后恢复，显存接近 MQA 且不输完整多头）。
    • 稀疏/线性注意力：局部窗口 + 全局词元 + 随机注意力（Longformer、BigBird、Mistral 滑窗）把 O(N²) 降到 O(N log N)~O(N)；线性注意力用核函数 φ(Q)φ(K)^T 重排绕开 N×N 中间矩阵，具有并行-串行对偶（训练并行、推断像 RNN 只维护 d×d 状态）——RetNet、RWKV、Mamba 沿此开辟分支，但线性核难以逼近 softmax 的尖锐稀疏关注，尚未在通用任务上替代标准注意力。
    • FlashAttention：不改数学、只重排计算让中间结果留在 SRAM，把注意力显存从 O(N²) 降到 O(N)——理论复杂度更漂亮的方案至今没把它挤出默认配置，是"架构创新=系统创新"的最好例证。
    • 训练友好 vs 推断友好：MoE 训练诱人、推断复杂；GQA 没把缓存压到极致却质量几乎不掉而被主流收编。评价架构看四件事：能力提升、训练成本、推断成本、稳定性与可工程化。
    • 其他路线：检索增强把"记住一切"改为"知道去哪找"；状态空间模型用递推压缩状态适合超长序列。新架构多以"兼容 Transformer 主干的改进件"身份进入产业——落地时少有团队愿为局部优势放弃成熟工具链。

    经验与常见坑

    • 别把所有带工具的系统吹成智能体，也别把系统工程问题当成"模型再大点自然解决"。
    • 会做卷子 ≠ 能当律师：考试成绩不等于可靠的专业判断（GPT-4 律考接近前 10% 的说法，后续研究指出对比基线偏严）。
    • 训练成本数字要看口径：单次 run 的 GPU 租用估算 ≠ 公司完整研发投入。
    • Inference 译"推断"（模型运行生成输出），Reasoning 译"推理"（多步思考、逻辑推导）——两者含义不同，勿混用。
    • "开源模型"多为"开放权重模型"；开放权重模型 ≠ 数据与训练代码公开。
    • 排错顺序：数据 → 损失实现 → 学习率 → 初始化/规范化 → 最后才怀疑架构。真实工程里最常见的问题几乎从来不是"理论不够先进"。
