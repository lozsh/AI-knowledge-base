    模型后训练

    来源：原资料（更新于 2026-11-03）

    一句话定义：后训练（Post-training）是在预训练完成后，通过 SFT（监督微调）和强化学习（RL）等技术改动模型权重，把"博学但不好用"的基座模型变成听得懂指令、能泛化、可部署的实用模型（Agent 大脑）的过程。

    现代大模型的能力分三个阶段炼成，环环相扣：预训练（Pre-training）在海量互联网文本上做"预测下一个词"，让模型学会语言规律、世界知识和基本推理——像读完了图书馆里所有的书，博学但还不会好好回答问题，这是最贵的一步（动辄数千万美元）；监督微调（SFT）用几千到几万条"问题—标准回答"示范数据，教会模型用什么格式、风格、流程回答，便宜、快、稳；强化学习（RL）不再给标准答案，让模型自己试、按结果好坏调高调低行为概率，学会在没见过的情况下做合理决策——也是后训练中篇幅最大、最需要工程功力的一步。类比：预训练是"读万卷书"，SFT 是"看老师示范标准解法"，RL 是"自己下场做题、按对错打磨"。三者是流水线，不是三选一。

    本章（原教材第 7 章）有两条贯穿始终的主线：主线一：SFT 记忆，RL 泛化——相同任务相同预算下，SFT 倾向于记住训练数据里的答案、部署环境一变就失效；RL 学到可迁移的策略、面对没见过的情形更稳。这是可测量的现象，有多组对照实验反复验证。主线二：数据和环境比算法更重要——现成的 RL 算法（PPO、GRPO 等）会用、能选对就够了，真正决定成败的是仿真环境的保真度和训练数据的质量；很多场景下只要 SFT 数据质量到位，根本不需要做 RL。

    核心原理

    三阶段总览

    阶段 数据 优化目标 学到什么 典型代价
    预训练 海量原始互联网文本 预测下一个词 语言规律、世界知识、基本推理 极高（数百万～数千万美元）
    SFT 几千～几万条"输入—输出"示范对 预测下一个词（只在回答上算损失） 指令遵循、输出格式、风格、流程协议 低（几小时～几天）
    RL 任务 + 奖励函数（无标准答案） 最大化期望奖励 可迁移的决策策略、探索出的新解法 高（常是 SFT 的几十～上百倍）

    预训练与 SFT 的本质

    预训练的全部"智能"建立在下一个词预测（Next Token Prediction, NTP）上：给定前文，模型对词表里每个 token 输出一个概率分布；预测与真实 token 的差距叫损失（Loss），训练就是调整参数让想要的 token 概率更高。这个"输出是概率分布"的关键点一路贯穿到 SFT 和 RL——三阶段的区别只在"想要什么"以及"用什么信号定义想要"。

    SFT 在数学上就是换了数据的预训练——同一个任务、同一个损失函数，差别只有两点：

    1. 数据不同：从无结构的互联网文本换成人工准备的"用户提问 → 理想回答"示范对，模型由此学会"被提问时该回答"这个协议。
    2. 损失只算在回答上（loss masking，损失屏蔽）：把问题部分的 token 屏蔽掉，只对回答部分回传梯度。这是 SFT 在工程上与预训练唯一实质性的区别。

    由此"SFT 记忆"顺理成章：它的目标是把标注回答里每个 token 的概率提到最高，即"把标准答案背下来"。一句话概括 SFT：用极高的样本效率，把一套稳定的"输入→输出"映射与协议固化进参数。它固化的是协议性知识（格式、风格、流程——该怎么说、怎么做），而非大量事实性知识（知道什么）——后者要靠预训练或 RAG。

    LoRA：后训练的工程默认项

    全参微调要为数十亿参数存梯度和优化器状态，显存开销大。LoRA（Low-Rank Adaptation）不动原始大权重矩阵，只在旁边挂一个低秩"补丁"学习任务，参数量仅占原模型的 1%–5%，效果可接近全参微调；且原权重冻结，灾难性遗忘风险更低。经验法则（Schulman & Thinking Machines Lab, "LoRA Without Regret", 2025）：

    • LoRA 必须应用到所有主要权重矩阵（尤其参数占比最大的 MLP 层），只加注意力层会掉点；
    • 最优学习率约为全参微调的 10 倍（SFT、RL 都成立）；
    • SFT 用中高 rank（64–256）；RL 因每轮信息量小，用小 rank（8–32）甚至 rank=1；
    • 部署时一台推理服务器可同时挂多个 LoRA adapter 做多租户服务。

    为什么必须先 SFT 后 RL

    RL 不看标准答案，让模型自己生成回答再按好坏打分——前提是输出能被可靠解析。若任务要求 JSON 或工具调用而模型输出格式混乱，奖励函数无从计算，RL 无从学起。所以 SFT 先"把话说利索"（稳定输出格式），RL 才有能打分的起点。借用中国画的说法：SFT 先立"形"（格式、结构），RL 再求"神"（策略、泛化）——先形后神。

    ⚠️ 边界条件："必须先 SFT"在"较小基础模型 + 严格结构化输出"的设定下成立（Llama-3.2-Vision-11B 量级不经 SFT 直接 RL 会完全失败）。足够强的基础模型可以跳过 SFT——DeepSeek-R1-Zero 直接 RL 成功并涌现反思与长链思考，但输出可读性差、中英文混杂，所以 R1 最终仍加回"冷启动 SFT"把"形"立稳。这段往返正是"先形后神"的最好注脚。

    SFT 与 RL 的本质区别（最核心的一张表）

    两者的一切差异源于优化目标不同：SFT 优化"像不像标准答案"（极大似然，唯一示范答案，学到固定映射）；RL 优化"结果好不好"（期望奖励，任何高奖励输出都算好，学到通用策略）。经典例子：21 点中 J/Q/K 计为 10，SFT 记死"见 J/Q/K 用 10"，测试时 J 变 11 就照旧用 10 出错；RL 模型用同一策略重算一遍，不受影响。

    维度 SFT RL
    优化目标 最大化标注答案概率（极大似然） 最大化期望奖励
    训练信号 唯一标准答案（每个 token 都有监督） 自己生成的多条回答 + 奖励（每条一个成败信号）
    学到的东西 固定"输入→输出"映射（记忆） 可迁移的决策策略（泛化）
    分布漂移下 套用旧答案、性能下降 用同一策略重新求解、更稳
    样本效率 高（几千条见效） 低（几十～上百倍）
    稳定性 高、收敛快 低、易震荡
    最适合 固化格式/风格/流程、有高质量示范、环境稳定 需泛化到新场景、探索最优策略、标注成本过高

    两个更深的机制：

    • mass-covering vs mode-seeking（寻峰）：SFT 的极大似然是覆盖式的（"雨露均沾"，连一般质量的模式也分概率）；RL（带 KL 约束的策略优化，数学上对应反向 KL）是寻峰式的（"赢者通吃"，概率集中到少数高奖励模式）——这解释了 RL 后的模型回答更"笃定"、多样性更低。
    • RL 的上限为什么更高——因为它是"在线"的：SFT 是离线方法，天花板就是示范者水平（60 分老师标不出 90 分学生）；RL 只看结果奖励，能自己发现示范里不存在的更优策略（SimpleVLA-RL 中模型自创的"推切"动作从未出现在人类演示里）。根本原因是"验证"比"生成"容易（验证—生成不对称）：数学答案能对照、代码能跑测试，只要"认出好"比"做出好"容易，RL 就能训出比任何示范者都强的模型——这是 RLVR 威力的来源。另外离线模仿有协变量漂移（covariate shift）问题：学生走进示范数据里没有的状态后不会回正轨，误差随轨迹长度 T 大致按 T² 增长；在线训练把它压到约 T。

    关键概念

    经典 RL 背景（可选基础）

    • MDP（马尔可夫决策过程）：RL 的数学框架，五元组 (S, A, P, R, γ)，核心假设是马尔可夫性——未来只取决于当前状态。传统 RL Agent 的动作空间封闭有限（棋类可枚举、机器人连续但有界），便于动态规划和搜索，但样本效率低、泛化差、无法利用先验。
    • 贝尔曼方程 / Q-learning：一个动作的真实价值 = 即时奖励 + 到达下一状态后的最大未来价值 Q(s,a) = r + γ·max_{a'} Q(s',a')；γ 是折扣因子（越接近 1 越重视长期回报）。Q-learning 用"一步实际结果修正旧估计"（时序差分学习 TD），且是离轨（off-policy）方法——可用任意策略产生的数据学最优策略。
    • RL 独有特征：试错搜索（没有老师直接告诉正确答案）、延迟奖励（好棋的价值终局才显现）、探索—利用权衡。五个核心要素：动作空间、策略、奖励信号、价值函数、环境模型（可选）。
    • 实验对照（寻宝游戏）：Q-learning 需约 10000 次尝试、跑 10 秒才学会 11 步最优解；LLM Agent（携带预训练先验）第一局即 18 步通关。计算成本上 Q-learning 占优，但现实交互成本高、需快速适应时，LLM Agent 的样本效率才实际。

    LLM Agent 范式 vs 经典 RL

    最根本差异在动作空间：MDP 封闭有限，LLM 开放无限（自然语言 + 工具调用，一个代码解释器理论上可执行任何可计算任务）。最重要创新是把"思考"作为特殊动作纳入动作空间——不改变外部世界、无即时奖励、成本较低，但显著改善行动质量。预训练语料中的人类思考过程让 LLM 的思维链（CoT）沿有结构路径前进，极大压缩搜索空间。OpenAI 的探索史（姚顺雨《The Second Half》）点破认知反转：2015-16"算法中心主义"→ 2016-18"环境的重要性"（Gym、Universe、Dota 2）→ 2018 至今"先验的觉醒"（GPT-2/3、WebGPT、ChatGPT）。真实排序是先验 > 环境 > 算法，而非几十年 RL 界默认的算法 > 环境 > 先验。

    预训练相关实验（理解天花板从哪来）

    • 从头训练小模型（MiniMind 2，1 亿参数）：消费级 GPU 约 14 小时 / 34 美元；引入 QK Norm 和 Muon 优化器两项算法改进后收敛速度提升 3 倍。启示：预算受限时，算法/架构改进比堆规模更具性价比。
    • 训练 VLM："视觉编码器（CLIP，冻结）+ 轻量投影层（唯一从头训练）+ LLM"骨架实现跨模态对齐；先冻结 LLM 只训投影层避免灾难性遗忘，对齐后再解冻 LLM 做 SFT。
    • 继续预训练注入新语言（Mistral 7B 学韩语）：用约 80% 韩语 + 20% 英语混合数据继续无监督预训练缓解灾难性遗忘，再用韩语指令数据 SFT。结论：让模型记住大量新领域知识靠继续预训练，而非 SFT。

    分类/类型

    RLHF：从人类偏好到奖励模型

    InstructGPT（OpenAI, 2022）确立了沿用至今的三段式管线：

    1. SFT：人工示范的"指令—回答"对微调，建立基本指令遵循。
    2. 训练奖励模型（RM）：对同一提示生成多个回答，人类两两比较标注偏好（因为绝对分数标不一致，相对判断可靠得多），用 Bradley-Terry 模型训练：L_RM = −log σ(r(x, y_w) − r(x, y_l))，即让 RM 给被偏好回答 y_w 打更高分。
    3. 用 RM 打分做 PPO：以 RM 分数为奖励，对 SFT 模型做 PPO。

    KL 惩罚：实际优化的是 r = r_RM − β·KL(π_θ‖π_ref)，四个关键点：

    • KL 散度衡量两个概率分布差异（相同为 0），这里比的是当前策略与参考策略（SFT 模型）在同一段前文上的下一 token 分布；工程上按 token 逐位算并掺进奖励（per-token KL），不是单独一项 loss。
    • 方向是反向 KL KL(π_θ‖π_ref)：惩罚"当前策略去了参考模型认为概率几乎为零的地方"，把模型摁在"说人话、格式正常"的安全区。若用正向 KL 会逼模型覆盖参考模型的一切表达方式，不是目的。
    • 反向 KL 是 mode-seeking 的：允许保留少数高分模式、丢掉其余——正合 RLHF 需要（见前文 mass-covering/mode-seeking）。
    • 不加会怎样：RM 只在参考策略附近的分布上训练过，模型飘走后 RM 打分成为无依据外推。KL 惩罚同时防 reward hacking 和分布崩塌。⚠️ DAPO、Open-Reasoner-Zero 等少数工作有意去掉 KL（DeepSeek-R1-Zero 的 GRPO 本身仍显式含 KL 项）。

    奖励模型过度优化：RM 只是偏好的代理指标（proxy），Goodhart 定律——指标一旦成为优化目标就不再是好指标。OpenAI 实测（Gao et al., 2023）：RL 推进中代理奖励单调上升，人类评估的真实质量先升后降；模型学会的是"让 RM 打高分"（冗长、讨好、貌似严谨的空话）。缓解：KL 惩罚 + 早停。

    DPO（Direct Preference Optimization）：跳过显式 RM，把偏好对直接变成带隐式奖励的分类损失——数学上等价于带 KL 约束的离线偏好优化，RM 被隐式藏进策略本身。像 SFT 一样简单（无在线采样、无价值网络、无独立 RM）；代价是完全离线，天花板由偏好数据的质量与覆盖面决定。

    RLHF 与 RLVR 的关系：RLHF 的奖励来自学出来的 RM（背后是人类偏好数据）；RLVR（可验证奖励 RL）的奖励来自规则验证器（测试通过、答案正确）。Agent 任务大多可验证，故本章以 RLVR 为主线；但两者是叠加而非取舍——实际模型 RLHF 管对话质量与安全对齐，RLVR 管推理与 Agent 能力。

    RL 算法比较

    先记住：这些算法早已封装进 veRL、TRL 等框架，选对即可，决定成败的是数据和环境。算法大多建立在策略梯度（REINFORCE：∇J = E[∇log π(a|s)·G]，回报越高越强化该动作；引入基线 b 得优势 A = G − b 降方差）之上。

    方法 类型 核心思路 优势 劣势 适用
    REINFORCE 在线 RL 整条轨迹奖励更新策略 实现简单 方差大；带基线变体（RLOO、REINFORCE++）是主流之一 理论基准
    PPO 在线 RL 裁剪概率比限制单步更新幅度 稳定；价值网络提供细粒度信用分配 需训练/存价值网络，超参敏感 多轮 Agent、长轨迹
    GRPO 在线 RL 同一问题采 N 条轨迹，优势 = (r_i − mean)/std，组内相对比较 无需价值网络，成本低 优势按整条回复均摊，信用分配粗；依赖组内奖励有区分度 单轮/短轨迹、奖励区分度好
    DPO 离线 偏好对 → 隐式奖励分类损失 极简高效 无法探索新策略，受离线数据限制 已有高质量偏好数据
    KTO 离线 单样本"好/坏"标签即可 标注成本极低 信号粗糙 标注资源极有限
    Best-of-N 推理时 生成 N 个选最优 不改模型 推理成本翻倍，能力不沉淀 早期快速提升；RL 收益上界估计

    术语澄清：在轨（on-policy） 只用当前策略自己新采样的数据更新（PPO/GRPO 的标准形式，每轮用当前模型 rollout 更新）；离轨（off-policy） 可用其他/旧策略的数据（Q-learning；SFT 本质是离轨的模仿学习）；DPO 是离线偏好优化。PPO 与 GRPO 对奖励来源不挑剔（皆可接 RLVR 或 RLHF），真正差异在优势估计方式。实测参考：GeneralPoints/V-IRL 用带价值网络的 PPO，ReTool 用 veRL 改造的 PPO，SimpleVLA/RLVP 用 GRPO，AdaptThink 用自定义约束优化 + 重要性采样。

    On-Policy Distillation：兼得 SFT 与 RL 之长

    Thinking Machines Lab（2025）提出，已成主流方法。它针对两个互补短板：

    • SFT 短板——Learner-Sampler Mismatch：数据由教师/专家采样，学生被动模仿；部署时学生自己走进训练数据没有的偏差状态就不会回正轨（协变量漂移）。
    • RL 短板——信号稀疏：在轨解决了分布不匹配，但每条轨迹只有一个成败标量。

    On-Policy Distillation = 在轨 + 稠密信号：学生自己生成轨迹，教师对每一步给出完整的目标 token 分布，学生最小化与教师分布的 KL 散度——逐 token 的分布对齐比终点二元信号密集一个数量级。效果：同等性能训练步数约为纯 RL 的 1/10；长链思考任务优势尤其明显；每次轨迹不同故还缓解过拟合。一个干净验证（Agent 时间感实验）：DPO 与四种 RL 配方各踩中一个失败模式（稀疏、目标错位、rollout 形状不匹配、训练崩溃）全部未能越过 SFT 天花板，换成 On-Policy Distillation 后四种条件下通过率比 SFT 基线高 23–47 个百分点——卡住后训练的往往不是奖励函数不够巧，而是信号不够密。前提：必须有足够真实的仿真环境让学生在部署分布上探索。

    提升样本效率的另一路：RLVP（奖励结果、惩罚路径）

    现实 Agent 还须遵守与结果无关的约束（outcome-neutral constraints）：不要反复拨打明确拒接的用户、不要跳过身份验证、不要执行 rm -rf、不要为让测试通过改测试文件……麻烦在于违反约束常让"表面成功率"更高，纯结果奖励反而激励违规。RLVP（Li & Shi, 2026）配方一句话：奖励结果，惩罚路径。

    • 核心洞察：真实可判定环境是不对称的验证器——"检测坏动作"便宜可靠，"判定有意义的进展"昂贵易错。所以环境能可靠提供的密集信号是"路径上的惩罚"而非"进展上的奖励"。
    • 总奖励 R = O + β·Φ：O 是稀疏的结果奖励（真正的目标）；Φ 是确定性规则引擎逐动作给出的路径信号，两种用法——惩罚（−λ）：每次可验证违规动作扣分；守规/进展奖励（+μ，Partial Credit）：每次可验证的好动作/子目标/通过的测试数增加就加分。两路各自归一化再合并，不改优化算法、直接接 PPO/GRPO。
    • 为什么有效——组内方差：GRPO 的优势本质是组内方差，一组 rollout 奖励全相同时方差为零、无梯度。纯结果奖励在两个极端必然"瞎"：全败组（训练早期）和全胜组（训练后期）。惩罚永远能补回方差（坏动作总可查，全败组"失败得规不规矩"各不相同）；进展奖励只在可达时补回方差（定理证明里"待证目标数下降"可达就有用；软件修复里整批 rollout 连一个测试都过不了就没用）——"可达性门控"。可达性可在训练前用少量 base 模型 rollout 测组内方差诊断。
    • 惩罚用法的四条设计原则（消融验证）：① 只惩罚可验证的"动作"，绝不惩罚"没进展"（否则教成什么都不做）；② 结果奖励始终是主驱动力，纯惩罚会掉进不作为陷阱（每种子成功率塌到零）；③ 每个 −λ 配一个对应 +μ，给出路而不是只堵；④ 合规路径必须可达（少量脚本示范），惩罚靶子必须是确定性检查而非学出来的"合规度评委"（否则钻空子转移到评委身上）。实测：TerminalBench 违规次数 3.71 → 0.66（约 6 倍）而成功率持平；miniF2F 达 0.9 成功率所需迭代 7.0 → 4.4（4B）/ 8.5 → 5.4（30B）；全败组占比 65% → 8%。
    • 与 RLVR 只差一个字母，恰好点出互补：RLVR 验证结果，RLVP 额外验证过程。

    多轮任务：信用分配与奖励设计

    从单轮（一次交互出结果，即时奖励）到多轮（ReAct 循环，延迟奖励），出现两大难题：信用分配（Credit Assignment，10 轮解决的好评归功于第 2 轮的精准提问还是第 7 轮的耐心解释？）和部分可观测性（须从历史观测构建隐含状态表征），还有长距离依赖（早期子目标设定的影响数十步后才显现）。

    奖励密度谱：二元奖励（成功 1/失败 0，适合有明确对错的任务，如数学题、SQL 结果比对、SWE-bench 测试通过）→ 里程碑/过程奖励（每步即时反馈，降低信用分配难度）。稀疏奖励的困境（Pine AI 打电话案例）：二元奖励训练打电话办事 Agent，100 次尝试才偶然成功——客服明说"需要信用卡后四位"，model-free RL 只看最终 reward=0，无法从环境的丰富反馈中学习（Silver & Sutton《Era of Experience》指出的核心局限）。

    奖励表示范式（以同一案例打分为例）：标量（7.2 分，零诊断能力）→ 半标量（先分析优缺点再给分）→ 向量（多维度分别打分，像体检报告精确定位短板）→ 生成式奖励（自然语言给出带推理的评判，支持多次采样从不同角度分析）。DeepSeek 研究（Liu et al., 2025）：生成式 RM 可通过推理时扩展（多次采样评价再汇总）持续提升评判质量，超越仅靠扩大规模的标量方案；它是 Bradley-Terry 判别式 RM 的演进，更透明、更易扩展到开放任务。训练三步：模型自动生成评价原则 → 按原则逐条评价执行过程 → 系统自动检查评价准确性给反馈；优势是学到"定标准、做评价"的元能力、评价透明可审、RM 与策略可协同进化。

    过程奖励 vs 结果奖励：过程奖励（PRM，对每个中间步骤打分，代表工作 OpenAI《Let's Verify Step by Step》）像逐题批改作业、反馈快，但标注成本高且可能限制探索；结果奖励（ORM，只看终点）像只看期末考试、探索自由度最大但训练难。RLVR 的规则验证器可看作 ORM 的特例。信用分配的工程实现：折扣因子 γ 在多轮 LLM RL 中通常直接设 1；PPO 用 GAE（价值网络逐步估优势，偏差方差折中）；GRPO 把整条 response 视为单一动作、轨迹级优势均摊到所有 token（第 2 轮的精准提问和第 7 轮的寒暄拿到相同信用），长程多轮任务会稀释信号——turn-level 分摊（以轮为单位算优势）是常见折中。

    对照实验印证取舍：V-IRL-VL 空间思考（过程奖励）——RL 在规则 OOD 上 +11.0% 而 SFT 降 79.5%；视觉 OOD 上 RL 从 16.7% → 77.8%，开源模型端到端 RL 超越闭源强基线。密集反馈 + 验证重试（verify_iter=2）降低长时序信用分配难度；还发现 RL 的结果导向优化信号反向传播改善视觉识别本身，SFT 则在思考层过拟合、忽视感知层。SimpleVLA-RL（结果奖励）——仅二元成败信号 + 三项探索增强（动态采样过滤全成功/全失败组、裁剪界放宽到 [0.8, 1.28]、温度 1.6），LIBERO 上达 97.6%；每任务仅 1 条轨迹 SFT（17.3%）加 RL 后 91.7%（相对提升约 430%），证明 RL 在数据稀缺下的威力。涌现出"推切"（pushcut）新动作——省去抬起步骤直接水平推动，RL 能超越模仿学习、发现人类未想到的更优策略。两者对照：中间步骤对错易定义时过程奖励更高效，最优路径未知时结果奖励更有潜力。

    RL 学习工具调用

    工具使用面临三层难度：单工具掌握（何时/如何调用 + 错误处理）→ 多工具选择 → 工具链编排（依赖、互斥、成本优化）。两条活跃路线：检索增强（Search-R1：RL 训练模型在思考中自主决定何时搜索）与软件工程（SWE-Gym：真实代码库上多轮 RL）。共同挑战是长时序信用分配与环境工程。

    关键工程细节：对环境反馈 token 做损失屏蔽——工具轨迹里模型生成的 token（思考、调用参数）与环境返回的 token（沙盒输出、搜索结果）混在一起，后者不是策略生成的，计入策略梯度会让模型学"预测沙盒输出什么"，既偏离目标又不稳定。标准做法是屏蔽环境 token、只对模型自己生成的 token 回传梯度（ReTool、Search-R1 的核心技术点，veRL/AWorld 内置）。

    • ReTool（代码解释器增强数学解题）：SFT 预热约 1 小时建立工具调用模式，再基于 veRL 改造的 PPO 训练约 9 天/400 步；模型生成 代码、沙盒执行结果包在 中反馈，形成"文本 + 代码 + 反馈"混合推理序列（每步 512 个响应，平均 7-9 轮交互）。AIME 2024：25% → 110 步 52% → 400 步 67%（纯文本 RL 1080 步仅 40%）。涌现能力：代码自我修正、工具调用从后期验证转为早期探索、思考长度减 40% 准确率反升。
    • DAPO（Yu et al., 2025，ReTool 训练数据来源团队的四项 PPO 改进，核心是防过早收敛）：① Clip-Higher 放宽探索上限（发现更好路径时允许更大胆调整）；② Token-Level Policy Gradient Loss 去掉按样本平均，让每个 token 权重相等（否则长回答被 1/|o_i| 稀释，长链思考得不到相称奖励）；③ Dynamic Sampling 把算力集中到成功率 20%-80% 的"可学习区间"；④ Overlong Reward Shaping 软惩罚超长响应。
    • AWorld-train（MCP 沙盒多工具训练）：26 个 MCP 服务器、126 个工具（搜索/浏览器/文档/多媒体/代码沙盒/Excel/知识检索），分布式 rollout 7 天→12 小时；真实 API 有速率限制、封号、副作用，稳定可控可重放的仿真环境是多工具 RL 的工程前提。单工具到多工具的质变：从"何时/如何调用"到"调用哪个/如何组合"（前置依赖、互斥约束、成本差异）。

    经验与常见坑

    SFT vs RL 决策框架（按序自问）：

    1. 需要后训练吗？若 Harness 工程（prompt、工具设计、上下文管理）能解决，不训练——大多数 Agent 应用落在这里。
    2. 需要训练则先试 SFT：固化输出格式、协议性知识（术语用法、流程习惯）、统一风格。注意 SFT 不适合注入大量事实性知识——那要继续预训练或 RAG。
    3. SFT 不够时加 RL：部署分布系统性漂移、专家示范非最优、标注成本过高时。务必先 SFT 稳定格式再 RL。实用判据：当"无论怎么增加示范数据，新场景表现仍上不去"时，就是转向 RL 的临界点。

    数据从哪来（SFT 三条路）：人工专家示范（贵且慢，用来定义格式的"种子数据"）、教师模型生成（合成数据，过滤后蒸馏）、模型自举（拒绝采样微调 RFT：同一问题采多条候选、验证器筛出正确样本反训自己）。常组合：人工种子立格式 → 教师模型放大规模 → 拒绝采样拉齐质量。构造流程：定义任务分布与 schema → 批量生成 → 规则校验 + 格式检查 + 人工抽检 → 去重、平衡配比。量级上与其堆十万条脏数据，不如精修一万条干净数据——数据里每处噪声 SFT 都会忠实写进参数。

    蒸馏的两个方向：Prompt 蒸馏把"长提示 + 思考型教师"压成"短/无提示 + 非思考学生"，降低延迟费用；可"大到小"和"思考到非思考"（20-30 倍响应提速）两个维度同时做。CoT 蒸馏则相反，转移完整思考轨迹（强教师可恢复 70%-80% 能力，DeepSeek-R1 蒸馏 Qwen/Llama 系列是代表；学生同样要经拒绝采样过滤错误轨迹，否则连错误思考一起模仿）。注意：蒸馏继承教师的系统性错误与冗长习惯；教师不须"全球第一"，只需"明显高于学生"（200B 以下用开源 SOTA 当教师完全够用）；闭源模型多隐藏原始 CoT（防蒸馏），选开源教师。

    数据质量胜过算法（三维度）：覆盖面（含长尾与边界情况）、多样性（否则塌缩到单一模式）、标注准确性（错误示范/思考会被一并固化）。行业例证：Anthropic 2025 年前的配方只是海量高质量数据 SFT + RLAIF（Constitutional AI，用"宪法"引导模型自评做对齐），不怎么依赖 RLVR，Coding 模型已顶尖——数据决定你能到哪，RL 决定你还能再高多少。拒绝采样是把"标注准确性"拉满的标准动作：每条提示采 k 条（4-16）→ 验证器/单测/参考答案判对错 → 只留通过者并去重限流 → SFT，模型变强后重新采样迭代（STaR/RFT 自举循环）。

    环境（仿真保真度）：环境失真，策略必废——模型学到只在仿真里管用的"应试策略"，一上线露馅（RL 项目最常见翻车方式，不是算法不行，是练习场和考场不是一回事）；高保真环境的构建成本常高于训练本身。

    用力顺序：先选强基础模型 → 打磨环境和数据 → 最后才在算法与超参上做边际优化。环境和数据没做好就去卷算法是南辕北辙。

    常见陷阱清单：

    1. 过度依赖后训练记忆事实——应交给 RAG（可动态更新、可追溯、不因训练遗忘），后训练聚焦"如何使用知识"。
    2. 格式未稳定就引入 RL——JSON 解析失败率超 20% 时 RL 完全失败，必须先 SFT。
    3. 奖励函数设计不当导致 reward hacking——应评估最终目标而非中间指标（如回复长度）。
    4. 忽视仿真保真度——高保真环境构建成本可能高于训练。
    5. 过度训练导致泛化下降——SFT 训到"格式稳定、能力初具"即止，不宜恋战（过度训练使模型塌缩到训练分布，RL 也救不回 OOD）；早停至关重要。
    6. 价值函数崩溃与探索不足——PPO 价值估计不准致训练震荡；温度过低陷入局部最优。
    7. 低估 RL 计算成本——可能需 SFT 的 10-100 倍训练时间；测试分布与训练高度一致时 SFT 可能已够。
    8. 训练数据质量低下——SFT 固化噪声，RL 沿有偏差的奖励越走越远。

    与 RAG/ICL 的协同（完整图景）：后训练、外部化学习、上下文学习是 Agent 能力的三个可调"旋钮"。ICL 零参数改动、即时操控，是探索期首选但示例多了延迟费用暴涨；RAG 外接事实与证据、可更新可溯源、天然抑制幻觉；后训练把行为与风格写进参数、一致性最高。最稳健做法：RAG 管事实性知识，后训练固化行为与结构，用 ICL + 强模型快速迭代、把稳定的行为内化进参数；后训练还可实现蒸馏（大模型能力 → 低成本小模型）。核心原则：大规模投入前先用小实验验证关键假设（少量数据测 SFT 能否稳格式、简化环境测 RL 能否收敛、小样本查奖励是否反映真实目标）——快速失败好过大规模失败。

    术语表

    术语 含义
    SFT 监督微调；换了数据、只在回答上算损失的"预测下一个词"，固化协议与映射
    RLHF 基于人类反馈的强化学习；SFT → 训练奖励模型 → PPO 三段管线
    RLVR 可验证奖励强化学习；奖励来自规则验证器（测试通过、答案正确）
    RLVP 验证路径惩罚；奖励结果 + 惩罚/奖励路径，补回组内方差
    DPO 直接偏好优化；跳过显式 RM，把偏好对变成带隐式奖励的分类损失
    Reward Model 奖励模型；从人类偏好学出的打分器（判别式 ORM/PRM、生成式 RM 皆其变体）
    ORM / PRM 结果奖励模型（只评最终结果）/ 过程奖励模型（逐步骤打分）
    loss masking 损失屏蔽；不对某些 token（SFT 的问题部分、工具轨迹的环境反馈）回传梯度
    KL 惩罚 r = r_RM − β·KL(π_θ‖π_ref)，把策略约束在参考模型附近，防 RM 外推失真
    mode-seeking / mass-covering 反向 KL 集中于少数高峰（赢者通吃）/ 极大似然覆盖所有模式（雨露均沾）
    信用分配 判断多步序列中哪一步对最终结果贡献最大
    协变量漂移 离线模仿中学生走进数据外状态、不会回正轨，误差随轨迹长度按 T² 增长
    拒绝采样（RFT） 采 k 条候选、验证器筛对的做 SFT；介于纯 SFT 与 RL 之间的数据构造法
    On-Policy Distillation 在轨蒸馏；学生自己走轨迹 + 教师逐 token 给目标分布（在轨 + 稠密信号）
    reward hacking 模型钻奖励漏洞刷高分而非真完成任务
    灾难性遗忘 学新技能后忘掉旧能力；LoRA/混合数据可缓解
    动作分块 模型一次推理生成未来多步动作，控制线程异步执行，保证机器人连续运动
