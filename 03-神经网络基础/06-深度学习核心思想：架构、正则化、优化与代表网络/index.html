    深度学习核心思想：架构、正则化、优化与代表网络

    更新于 2026-11-03

    一句话概括：深度学习 = 深度前馈架构 + 反向传播优化 + 正则化控制泛化；其上的代表网络各占一类归纳偏置——CNN 管空间网格、RNN/LSTM 管时间序列、自编码器/DBN 管表示学习、GAN 管生成对抗、DQN 类管决策。

    核心概念

    深度学习为什么赢：AlphaGo vs 深蓝的心智模型

    • 深蓝的核心是"算"：暴力穷举 + 专用硬件 + 人工写定的规则评估，是领域的专用智能。
    • AlphaGo 的核心是"想"：通用硬件上的纯软件，从海量棋谱中用神经网络学出走子概率——除"获胜"外对围棋规则一无所知，是基于学习的更通用智能。
    • AlphaGo Zero 更进一步：完全抛弃人类棋谱，自我对弈从零超越人类——数据来源本身可以被学习过程替代。
    • 深度学习由数据驱动：大量有标记样本是复杂模型的前提——这解释了它为何直到大数据时代才爆发。

    深度前馈网络与通用逼近

    • 深度前馈网络 = 多隐藏层的进化版 MLP；不考虑数据的特定结构（无先验），特征提取能力以计算复杂度为代价。
    • 通用逼近定理：单隐藏层 + 足够但有限的神经元即可任意精度逼近任意连续函数——但是存在性定理：不告诉你需要多少神经元（可能是天文数字），也不给构造方法。
    • 深度的真正意义：深度架构能用更少的单元表示同样的复杂函数，且泛化误差更低。背后假设：复杂函数是若干简单函数的层次化组合（与神经科学的层次加工呼应）。
    • 设计核心问题：网络架构、损失函数、输出/隐藏单元设计、训练误差处理；学习仍靠"BP 求梯度 + SGD 找最小值"。

    核心原理

    正则化：与过拟合的战争

    • 定义：对学习算法的修改，目的在于减少泛化误差（常以训练误差上升为代价）。哲学根据：奥卡姆剃刀。
    • 概率视角：正则化 ≈ 给参数施加先验分布；效果 = 在不过度增加偏差的前提下显著减少方差。
    • 五类正则化策略（按作用对象）：训练数据（预处理、数据增强）、网络架构（ dropout、权重共享、参数绑定）、误差函数、正则化项（L1/L2）、优化过程（早停）。
    • 深度学习参数众多，正则化从"可选项"变成"必选项"。

    优化的三大挑战

    • 深度网络的损失是非凸的（传统 ML 小心设计成凸优化以保可解性，深度网络放弃了这一点）。
    • 病态 Hessian：微小扰动引起目标剧烈波动——SGD 中很小步长也会增加代价，学习异常缓慢。
    • 局部极小值泛滥：隐藏神经元互换后模型等价（不可辨认性），m 层每层 n 神经元的网络有 (n!)^m 种等价排列 → 大量等价局部极小。
    • 鞍点：梯度为零但既非极大也非极小的点；高维空间中鞍点数目激增，以找临界点为目标的牛顿法受害严重。
    • 实践结论：深度学习仍用传统优化方法的改进版（动量、自适应学习率等），靠工程技巧绕过理论困难。

    自编码器：学习数据的重新表达

    • 结构：深度前馈网络，输入输出单元数相等；目的不是预测输出，而是重建输入——学习编码映射 φ 与解码映射 ψ 的组合，使重建误差（均方误差）最小。
    • 欠完备（隐藏层维度 < 输入维度）：线性 + 均方误差时等价于 PCA——隐藏层保留的就是前 k 个主成分；非线性时能捕捉更复杂的结构。
    • 信息论视角：编码 = 对输入信源的有损压缩；学习的目标是让压缩在训练分布上精确、并泛化到测试数据。
    • 过度完备（隐藏层维度 > 输入）+ 无约束：可能只学到恒等映射（白费功夫）；但配合稀疏约束/去噪/早停时，过度完备的非线性自编码器反而能学到有用表示。
    • 变体思想：稀疏自编码器（加稀疏惩罚）、去噪自编码器（从损坏输入恢复原输入，强迫学到稳健特征）。

    深度信念网络 DBN：深度学习的复活起点

    • 2006 年 Hinton 提出，吹响连接主义复兴号角。概率生成模型：建立输入与类别的联合分布。
    • 结构：多个隐藏层自下而上提取逐层抽象的特征（每个隐藏层 = 输入的一种中间表示）；最顶两层无向对称连接，构成联想记忆。
    • 基本积木：受限玻尔兹曼机 RBM——两层（可见层+隐藏层）全连接、层内无连接（"受限"的来源）；训练 = 前向编码 + 反向重构，循环压低重构误差；多个 RBM 逐层堆叠 + 逐层预训练，解决了深层网络训练不动的老大难（⚠️ 如今预训练-微调范式已由监督预训练与自监督大模型继承，RBM 本身已边缘化）。

    卷积神经网络 CNN：空间网格的归纳偏置

    • 定义：至少有一层用卷积运算代替矩阵乘法的神经网络；卷积 = 以核函数为权重对输入局部加权求和。类比做菜：输入是原料，核是菜谱——同一食材，不同配比（核）出不同菜。
    • 适用数据：网格结构（图像=二维像素网格，文本=一维词序列）。
    • 三大性质（取代手工特征的根基）：
    • 稀疏交互：核远小于图像，每个输出只看局部；
    • 参数共享：同一核扫全图，参数量骤减；
    • 平移不变性：目标平移后仍被识别。
    • 历史定位：LeNet-5（1998，手写数字）→ 2006 逐层初始化 → 2012 后成为视觉中坚。⚠️ 2018 年内容以 CNN 为视觉核心；如今 ViT 等注意力架构在视觉中已与 CNN 分庭抗礼。
    • 对照传统视觉流水线：预处理 → 人工设计特征（线条/边角/纹理）→ 通用分类器（SVM）——特征靠人工、识别本质由人完成；CNN 把特征设计变成了可学习的问题。

    循环神经网络 RNN 与 LSTM：时间的归纳偏置

    • RNN 引入时间维度：同一组权重沿时间步共享，处理变长序列（把不定长输入切成等长小块用同一权重处理）。
    • 对偶视角：CNN 是空间参数共享，RNN 是时间参数共享；价值在利用时域关联（"完形填空靠上下文"）。
    • RNN 的记忆是短期的：插播一段广告就"断片"——长期依赖难以学习（梯度随时间步消失/爆炸）。
    • LSTM（"长-短期记忆网络"）：让"记住长期信息"成为默认行为。核心洞见：既要学会记忆，也要学会遗忘——宝贵的存储不能什么都装，要判断信息的价值做取舍；还要能把长期记忆聚焦成当前要用的工作记忆（类似注意力）。
    • 结构：记忆单元 cell + 三门——输入门（新信息是否写入）、遗忘门（旧信息是否清除）、输出门（记忆多少暴露给当前输出），四个功能层协同实现细粒度的信息跟踪。
    • 术语提醒：RNN 缩写两义——循环神经网络（Recurrent，链状时间结构）与递归神经网络（Recursive，树状结构）；循环是递归的特例。

    生成式对抗网络 GAN：左右互搏

    • 古德菲洛提出：两个神经网络在零和博弈框架下竞争——生成器从随机噪声模拟真实数据分布、造以假乱真的样本；判别器练火眼金睛分辨真假。
    • 训练 = 极大极小博弈：判别器最大化分辨准确率，生成器最小化它——对抗推动双方共同进化，理想终点是"假作真时真亦假"，生成分布 = 真实分布。
    • 学习性质上是无监督（不需标注），但判别器的反馈又像监督信号——"带有监督影子的无监督学习"。
    • 意义（谷歌三网络保密通信实验）：神经网络能在没有先验规则的条件下，通过无监督学习达成目标，并根据条件变化动态调整学习方式。⚠️ 2018 年 GAN 是生成模型主角；2020 年代扩散模型已成图像生成主流，GAN 退居特定场景。

    深度强化学习：感知 + 决策

    • 强化学习：智能体与环境的交互中试错学习，最大化累积奖励；反馈只是"动作好坏"的评价，信息量远少于监督标签——必须在探索新行为与利用已有经验之间平衡（exploration vs exploitation）。
    • 数学框架：马尔可夫决策过程 MDP = (状态集 S, 动作集 A, 状态转移概率 P, 奖励函数 R)。
    • 深度强化学习 = 深度学习的感知能力 + 强化学习的决策能力：AlphaGo、AlphaGo Zero（纯自我对弈、端到端）是标志性战果。

    经验与常见坑

    • 通用逼近 ≠ 实用：宽而浅的网络理论可行、实践难训；深度换宽度的本质是表示效率与泛化。
    • 训练不收敛时按序排查：数据与预处理 → 学习率（过大震荡/过小停滞）→ 梯度消失 → 架构不合理。
    • 自编码器过度完备且无约束 = 恒等映射陷阱；必须加稀疏/去噪/早停等约束才有意义。
    • RNN 长序列训练注意梯度爆炸（截断）与消失（LSTM/GRU 门控缓解）；⚠️ 长序列任务如今多为注意力/Transformer 方案。
    • GAN 训练不稳定是常态（模式崩塌、博弈失衡），判别器太强或太弱都会让生成器学不到东西。
    • 深度学习黑箱：能识别猫却说不出为什么——可解释性要靠知识图谱、概念级模型等外部手段补足。
