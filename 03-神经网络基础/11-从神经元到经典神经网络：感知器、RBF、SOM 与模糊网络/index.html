    从神经元到经典神经网络：感知器、RBF、SOM 与模糊网络

    更新于 2026-11-03

    一句话概括：从 MP 神经元到感知器、多层感知器（BP）、径向基网络（局部作用）、自组织特征映射（竞争学习）、模糊神经网络（模糊逻辑融合）——经典神经网络的两条主线是"监督纠错"与"无监督竞争"。

    核心概念

    连接主义的世界观

    • AI 三大主义中的连接主义：智能不源于数理逻辑，而是大量简单单元通过复杂连接并行运行的结果——用非线性并行处理器模拟神经元，用连接关系模拟突触。
    • 与符号主义的分野：连接主义看重智能赖以实现的"硬件"（结构），符号主义看重"思维方式"（规则）。
    • 生理学依据：人脑约千亿神经元、亿亿突触；信号超过阈值神经元即激活并向上层传递。思维不能用还原论解决——每级整合都有"1+1>2"的突生功能，实质在于"把大量神经元组装成功能系统的设计原理"。

    MP 神经元（1943，McCulloch & Pitts）

    • 模型：y = φ(Σwᵢxᵢ)，输入线性加权后经传递函数输出。
    • 特点：输入输出限定二值，传递函数为不连续的符号函数 → 类似数字电路逻辑门，故称阈值逻辑单元。
    • 致命缺陷：权重固定，没有学习机制。

    赫布理论与感知器（1949 / 1957）

    • 赫布理论："一起激活的神经元连接增强"——给出了改变神经元间权重的准则，是神经网络学习机制的思想源头。
    • 感知器（Rosenblatt）：第一个用算法定义的神经网络，二分类监督学习算法；输入层 + 输出层（一个 MP 神经元），权重可通过误差驱动更新。
    • 历史转折：Minsky《感知器》指出单层感知器连异或（XOR）都解决不了——线性不可分问题判了单层死刑，神经网络进入第一次寒冬（"一个青年才俊的意外死亡"）。

    多层感知器 MLP 与反向传播

    • 解法朴素：单层不行就加隐藏层。单隐藏层即可完美解决异或（隐藏神经元各自负责一条分界线，输出层组合）。
    • 结构要点：含一个或多个隐藏层；除输入节点外每个节点都是非线性激活函数的神经元；层间全连接；信号单向前进 → 属于前馈神经网络。
    • 反向传播 BP：信号前向传播、误差反向传播；通过求误差函数对每个权重的偏导数来更新权重使误差最小化。
    • 误差函数设计细节：多输出时若直接把误差相加，正负误差会抵消造成假象 → 每个输出的误差写成平方项再求和（二次型），消除符号影响。
    • 可更新的只有权重：输入是外部信号、传递函数在设计时已定——所以训练 = 调权重。
    • 传递函数从符号函数（不连续、不可导）换成 Sigmoid——可微是 BP 的前提。
    • 局限：隐藏层多时梯度逐层衰减（梯度消失的雏形），浅层网络训练困难——深度网络要等到 2006 年才复活。

    径向基函数网络 RBFN：局部作用

    • 动机：MLP 是全局逼近——每个权重影响所有输出，牵一发动全身，收敛慢。
    • 生理依据：感受野——只有落在特定区域内的刺激才能激活该感觉神经元（仰望星空，不同位置的星光激活视觉神经的不同部分）。
    • 结构：三层。输入层-隐藏层直接相连（权重为 1）；隐藏层是核心，每个神经元用径向基函数（通常是高斯函数，只取决于与中心向量的距离，圆周对称）；输出层做线性组合。
    • 隐藏层完成从低维输入空间到高维特征空间的非线性映射，把非线性可分数据变成（大概率）线性可分——与 SVM 的核技巧思路完全一致，只是核方法把映射隐含在核函数里，RBF 显式构造。
    • 特点：局部作用——空间相近的输入激活同一批神经元，训练只局部调权、收敛快。

    自组织特征映射 SOM：竞争学习

    • 定位：把无监督学习引入神经网络（柯霍宁，1981）。
    • 两大特性：
    • 降维 + 保拓扑：把高维输入映射到低维（通常二维）网格，相似的输入映射到相邻神经元——保留输入数据的结构化特征；
    • 竞争性学习（而非纠错学习）：神经元竞争响应权，胜者"通吃"。
    • 生理依据：侧向抑制——兴奋的神经元会抑制相邻神经元的活性，竞争中胜出的神经元抑制所有失败者。
    • 训练三过程：竞争（每个神经元算判别函数，最大者为赢家）→ 合作（赢家确定兴奋拓扑邻域）→ 自适应（邻域内神经元调整权重，强化对同类输入的响应）。
    • 心智模型：网格上神经元的位置本身就是知识的表示——相近神经元处理相似模式，输入空间的统计结构被压印到二维坐标上。

    模糊神经网络：模糊逻辑 + 神经网络

    • 背景：扎戴 1965 年模糊集合论。"当系统复杂性增加时，精确化能力下降，复杂性和精确性相互排斥。"
    • 模糊集合：元素与集合的隶属关系用隶属度定量表示（"七分功三分过"），非黑即白被打破；模糊数：只有取值范围而无精确数值的数（"中年"）。
    • 概念辨析：
    • 神经模糊系统（neuro-fuzzy）：输入输出是确定对象，必须有模糊化层和去模糊化层，用网络实现模糊推理；
    • 模糊神经网络：输入输出都是模糊对象，做的是模糊推理的模糊化。
    • 直觉：给常规神经网络赋予模糊输入信号和模糊权值，用神经网络的结构和学习机制实现"类人"的含糊推理。

    术语表

    术语 英文 一句话解释
    MP 神经元 MP neuron 加权求和 + 阈值函数的最简神经元，权重固定
    阈值逻辑单元 threshold logic unit 二值化的类逻辑门神经元
    赫布理论 Hebbian theory 共同激活的神经元连接增强
    感知器 perceptron 第一个可学习的单层二分类神经网络
    隐藏层 hidden layer 输入输出之间的中间层，负责特征变换
    反向传播 backpropagation 误差反向传播 + 梯度下降更新权重的算法
    全连接 fully connected 相邻层神经元两两相连
    全局/局部逼近 global/local approximation 每个权重影响全部输出 / 只影响局部区域
    感受野 receptive field 能引起神经元响应的刺激区域
    径向基函数 radial basis function 只依赖与中心距离的对称函数（通常高斯）
    侧向抑制 lateral inhibition 兴奋神经元抑制邻近神经元的生理效应
    竞争学习 competitive learning 神经元竞争响应权、胜者通吃的无监督学习
    隶属度 membership degree 元素属于模糊集合的程度（0-1）
    拓扑保持 topology preservation 降维后高维近邻仍为低维近邻

    经验与常见坑

    • 线性不可分是单层网络的天花板：遇到模型怎么调都不行时，先怀疑表达能力不够（层数/特征变换），而不是怀疑优化。
    • BP 的误差函数不能直接求和（正负抵消），要用平方项——看似细节，实为算法能否收敛的关键设计。
    • 符号函数不可导 → 必须换可微激活函数（Sigmoid），可微性是梯度法的硬要求。
    • RBF 与 SVM 核技巧的等价视角：同一个"升维使线性可分"思想，一个显式（RBF 网络隐藏层）、一个隐式（核函数）。
    • SOM 的结果依赖网格大小与邻域函数的衰减 schedule，缺乏像监督学习那样明确的"正确率"评估——评估常靠可视化与领域知识。
    • 模糊系统与概率是两套语言：隶属度不是概率（不满足归一化的频率解释），混用会出概念错误。

    ⚠️ 时效性说明

    • 2017-2018 年内容。RBF 网络、SOM、模糊神经网络在今天的前沿研究与工业应用中已边缘化，但在教学上分别保留了"局部逼近""拓扑保持/竞争学习""软边界推理"三个重要心智模型。
    • 现代深度网络的标准激活函数已从 Sigmoid 演进为 ReLU 家族（缓解梯度消失），BP 框架本身未变。
