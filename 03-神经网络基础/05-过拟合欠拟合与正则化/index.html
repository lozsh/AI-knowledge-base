    过拟合、欠拟合与正则化

    更新于 2026-11-06

    一句话定义：过拟合 = 模型把训练数据里的噪声当模式记住（训练误差远低于泛化误差），欠拟合 = 模型容量不足连训练数据都拟合不好；应对手段包括模型选择与交叉验证、权重衰减（L2 正则）、暂退法（Dropout），以及识别部署阶段的分布偏移。

    训练误差 vs 泛化误差

    泛化误差是模型在"同分布无限多新样本"上的期望误差——永远无法精确计算，只能用独立测试集估计。三个思维实验说明差距：① 学生背往年考题 vs 理解原理；② 查表法可完美记住训练集，但 \(28 \times 28\) 灰度图（每像素 256 种取值）有 \(256^{784}\) 种可能——比宇宙原子还多，不可能存全表；③ 公平硬币分类器泛化误差恒为 \(1/2\)，但在小样本上"总猜多数类"的训练误差可以更低（数据增加后两者才趋同）。理论基础：格里文科-坎特利定理（训练误差收敛到泛化误差的速率）与 VC 维理论。

    独立同分布（i.i.d.）假设：训练/测试数据从同一分布独立抽取。现实中几乎所有应用都存在轻度违背（跨医院、时间相关性），通常仍能工作；但严重违背（用大学生人脸数据训练、用于疗养院）注定失效。深度网络为何能泛化仍是未解的理论难题。

    模型复杂度、模型选择与交叉验证

    模型复杂度的经验因素：可调整参数数量（自由度）、参数取值范围、训练样本数量。经验法则：能轻松解释任意事实的模型是复杂的，表达能力有限但解释良好的模型更可能有用（与波普尔可证伪性标准相关）。

    模型选择与交叉验证：验证集用于模型选择/调参，测试集只许用一次。数据稀缺时用 \(K\) 折交叉验证（把数据分成 \(K\) 份轮流做验证）：取 \(K\) 次验证误差的平均（需训练 \(K\) 个模型，误差估计对数据划分的依赖更小）。

    欠拟合与过拟合的诊断

    训练/验证误差都高 → 欠拟合（加数据也难救，需更大模型）；训练误差远低于验证误差 → 过拟合（更多数据是首选解）。多项式拟合的直观例子：一阶多项式欠拟合、高阶多项式过拟合、恰当阶数刚好。

    正则化之一：权重衰减（L2）

    在损失上加 \(\frac{\lambda}{2}\lVert w \rVert^2\)（\(\lambda\) 为正则强度、\(w\) 为权重向量；通常不罚偏置 \(b\)——\(b\) 只控制偏移不带来方差性）。直觉：权重小 → 函数更平滑，输入变化不会引起输出剧烈波动，不易把噪声当模式。

    • 贝叶斯解释：L2 正则等价于对权重施加高斯先验的最大后验估计（L1 则对应拉普拉斯先验）；
    • \(\lambda=0\) 退化为原损失；\(\lambda\) 过大会把权重压得过小导致欠拟合；用验证集选；
    • 简洁实现：trainer = torch.optim.SGD(net.parameters(), lr=lr, weight_decay=wd)，同一训练器可对不同参数组设不同 weight_decay（权重衰减系数，代码里的参数名，例如只罚权重不罚偏置）。

    正则化之二：暂退法（Dropout）

    动机：好的预测模型应对输入的微小扰动不敏感（平滑性）。毕晓普 1995 年证明：对输入加噪声的训练等价于 Tikhonov 正则化。斯里瓦斯塔瓦等人 2014 年把这一思想推广到网络内部层——训练时在计算后续层之前向每层注入噪声。原始论文的类比：dropout 破坏层间的"共适应性"，如同有性生殖破坏共适应的基因。

    标准做法（无偏注入）：每个中间活性值 \(h\) 以暂退概率 \(p\) 被置零，其余除以 \((1-p)\)：

    \[h' = \begin{cases} 0, & \text{概率 } p \\ \frac{h}{1-p}, & \text{其他}\end{cases} \qquad E[h'] = h\]

    效果：每次迭代相当于训练一个原始网络的随机子网，输出层无法过度依赖任何单个神经元。

    def dropout_layer(X, dropout):
    mask = (torch.rand(X.shape) > dropout).float()
    return mask * X / (1.0 - dropout)

# 简洁实现：每个 nn.Dropout 层可指定不同概率
net = nn.Sequential(nn.Flatten(), nn.Linear(784, 256), nn.ReLU(),
                    nn.Dropout(dropout1), nn.Linear(256, 10))

    要点：测试时不用 dropout（不丢弃也不缩放）；例外是有研究者测试时启用 dropout 来估计预测不确定性——多次遮罩预测一致则说明网络稳定。dropout 通常只用在隐藏层之间。经验：全连接网络中 dropout 是防止过拟合的常用手段，与权重衰减、控制模型容量配合使用。

    环境与分布偏移

    许多部署失败源于没想清楚"数据从哪来、输出到哪去"。最危险的场景：模型部署本身扰乱数据分布——贷款模型发现"穿牛津鞋与低违约相关"后开始按鞋放贷，顾客学会穿牛津鞋，模型被自己破坏。更尖锐的例子：预测犯罪的模型把更多警力派往某地区→更多犯罪被发现→模型更确信该地区危险（反馈循环）。

    三种分布偏移（若无 \(p_S\)（源域/训练数据分布）与 \(p_T\)（目标域/测试数据分布）关系的假设，恢复性能在理论上不可能）：

    类型 假设 适用场景
    协变量偏移（covariate shift） \(P(y \mid x)\) 不变，\(P(x)\) 变 \(x\) 导致 \(y\) 时自然成立（真实照片训练、卡通图片测试）
    标签偏移（label shift） \(P(x \mid y)\) 不变，\(P(y)\) 变 \(y\) 导致 \(x\) 时成立（疾病流行率变化，症状由疾病引起）；基于标签的方法倾向处理低维对象，常更有利
    概念偏移（concept shift） 标签定义本身变了 时髦语、诊断标准、职位名称的地域/时代变化（美国"软饮"称呼的地域分布）

    经验风险最小化的暗坑：训练目标（经验风险）与真实风险之间隔着分布偏移。应对手段从简单的（要求"正确"的数据）到困难的（强化学习、因果建模、算法公平性）不等。批归一化等技术与修正测试期统计量（correcting test-time statistics）相关；检测协变量偏移可用判别器区分训练/测试样本。

    经验与常见坑（Kaggle 房价实战）

    真实数据比合成数据脏得多，完整流程值得记录：

    1. 下载与缓存：数据集下载逻辑做成带缓存目录的函数，避免重复下载；
    2. 预处理：数值特征用均值填补缺失（有时按 neighborhood 分组填中位数更准）、标准化（\(\mu = 0\)，\(\sigma = 1\)，即均值 0、标准差 1——否则优化会因不同特征尺度差异而低效）；离散特征 pd.get_dummies 独热化（对训练集+测试集联合处理保证类别对齐）；训练集/测试集特征按列对齐（features = pd.concat((train.iloc[:, 1:-1], test.iloc[:, 1:]))）；
    3. 损失用 log MSE：预测房价的对数与真实价格的对数之差——因为我们更关心相对误差（30 万估成 40 万 与 300 万估成 400 万 应同等惩罚，而平方误差会偏爱高价位房子）；
    4. \(K\) 折交叉验证选超参：数据只有千余条样本，\(K\) 折平均比分一次更稳；
    5. 流程：先建基线（线性/MLP），在验证曲线上看是否过拟合，再迭代调超参（学习率、epoch、隐藏层宽度、正则强度）。

    ⚠️ 时效性说明

    • 代码基于 PyTorch（torch.nn / torch.optim），API 长期稳定；主流框架的 dropout 默认行为已是"测试时不丢弃也不缩放"，早期框架的"训练时缩放"实现语义等价；
    • Kaggle 房价（House Prices）竞赛页面与数据集下载地址可能随时间变动，本地复现时以 Kaggle 官方页面为准。
